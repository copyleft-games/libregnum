* Input Map
:PROPERTIES:
:CUSTOM_ID: input-map
:END:
An =LrgInputMap= is a container for input actions with YAML serialization support. It manages all actions for your game and allows players to save and load their custom control schemes.

** Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:
An input map:

- Contains multiple named actions
- Can be saved to and loaded from YAML files
- Provides convenience methods to query actions by name
- Supports persistence for user control remapping

** Creating an Input Map
:PROPERTIES:
:CUSTOM_ID: creating-an-input-map
:END:
#+begin_src C
g_autoptr(LrgInputMap) input_map = lrg_input_map_new();
#+end_src

** Adding Actions
:PROPERTIES:
:CUSTOM_ID: adding-actions
:END:
#+begin_src C
g_autoptr(LrgInputMap) input_map = lrg_input_map_new();

/* Create an action */
g_autoptr(LrgInputAction) jump = lrg_input_action_new("jump");

/* Add bindings to it */
LrgInputBinding *space = lrg_input_binding_new_keyboard(GRL_KEY_SPACE,
                                                        LRG_INPUT_MODIFIER_NONE);
lrg_input_action_add_binding(jump, space);
lrg_input_binding_free(space);

/* Add action to map (map takes ownership) */
lrg_input_map_add_action(input_map, jump);

/* g_autoptr will clean up jump when it goes out of scope */
#+end_src

*** Clear on Load
:PROPERTIES:
:CUSTOM_ID: clear-on-load
:END:
Loading a file *clears* any existing actions in the map:

#+begin_src C
g_autoptr(LrgInputMap) map = lrg_input_map_new();

/* Add default actions */
g_autoptr(LrgInputAction) jump = lrg_input_action_new("jump");
/* ... add bindings ... */
lrg_input_map_add_action(map, jump);

g_message("Before: %u actions", lrg_input_map_get_action_count(map));

/* Load user's config - this clears the map first */
g_autoptr(GError) error = NULL;
lrg_input_map_load_from_file(map, "config/user_controls.yaml", &error);

g_message("After: %u actions", lrg_input_map_get_action_count(map));
/* The default actions are gone, replaced by loaded ones */
#+end_src

** YAML Format
:PROPERTIES:
:CUSTOM_ID: yaml-format
:END:
Input maps serialize to human-readable YAML: an =actions= mapping of action name to a mapping with a =bindings= list. This is the format =lrg_input_map_load_from_file()= / =lrg_input_map_load_from_data()= read and =lrg_input_map_save_to_file()= / =lrg_input_map_save_to_data()= write:

#+begin_src yaml
version: 2                  # unknown to the engine: kept, written back in place
actions:                    # required: action name -> action, in order
  jump:
    label: Jump             # unknown action key: kept in place
    bindings:               # the action's inputs, in order
    - type: keyboard        # keyboard | mouse_button | gamepad_button | gamepad_axis
      key: SPACE            # a key name (SPACE, A..Z, 0..9, F1..F12, LEFT_SHIFT, ...)
      hint: primary         # unknown binding key: kept after the known ones
    - type: gamepad_button
      gamepad: 0            # gamepad index
      button: RIGHT_FACE_DOWN
  fire:
    bindings:
    - type: mouse_button
      button: LEFT          # LEFT | RIGHT | MIDDLE | SIDE | EXTRA | FORWARD | BACK
      modifiers:            # optional on keyboard and mouse bindings
      - SHIFT               # SHIFT | CTRL (or CONTROL) | ALT
  move_right:
    bindings:
    - type: gamepad_axis
      gamepad: 0
      axis: LEFT_X          # LEFT_X | LEFT_Y | RIGHT_X | RIGHT_Y | LEFT_TRIGGER | RIGHT_TRIGGER
      threshold: 0.2        # > 0; 0.5 when absent or not positive
      positive: true        # which direction of the axis
editor-note: keep me        # unknown root key: kept in place
#+end_src

An action that is not a mapping, a binding that is not a mapping or has an unknown =type= are skipped with a warning; an action without =bindings= is kept empty (with a warning). A document whose root is not a mapping or has no =actions= mapping fails.

*** Order and unknown keys (0.9.0)
:PROPERTIES:
:CUSTOM_ID: order-and-unknown-keys
:END:
- *Declaration order*: actions are kept in the order they were added (file order for a loaded map): =lrg_input_map_get_actions()= returns them in that order, and the writer writes them so. A replaced action (=lrg_input_map_add_action()= with a name already present) keeps its place; a new one goes last.
- *Unknown keys*: the map keeps the parsed document of its last load. The writer regenerates =actions= (and each action's =bindings=) from the map, but writes every other root key and action key back where it was, and a binding's extra keys after its known keys when the binding at the same index still has the same =type=. Keys of a removed action go with it. Comments are not kept (the editor's document model keeps them).
- *Numbers*: =threshold= is written in its shortest exact form.

Saving a map loaded from saved text gives the same bytes (=tests/test-format-writers.c= checks the fixture above byte for byte).

*** From memory
:PROPERTIES:
:CUSTOM_ID: from-memory
:END:
#+begin_src C
g_autoptr(LrgInputMap) map = lrg_input_map_new ();
g_autofree gchar *text = NULL;

if (!lrg_input_map_load_from_data (map, yaml_text, -1, &error))
    return FALSE;
/* ... rebind ... */
text = lrg_input_map_save_to_data (map, NULL, &error);
#+end_src

=lrg_input_map_load_from_data()= behaves exactly like the file loader (it clears the map first); =lrg_input_map_save_to_data()= returns what =lrg_input_map_save_to_file()= writes.

** Complete Example
:PROPERTIES:
:CUSTOM_ID: complete-example
:END:
#+begin_src C
void setup_input_map(LrgInputMap *map)
{
    /* Create and bind jump action */
    g_autoptr(LrgInputAction) jump = lrg_input_action_new("jump");

    LrgInputBinding *jump_space = lrg_input_binding_new_keyboard(
        GRL_KEY_SPACE,
        LRG_INPUT_MODIFIER_NONE
    );
    lrg_input_action_add_binding(jump, jump_space);

    LrgInputBinding *jump_gamepad = lrg_input_binding_new_gamepad_button(
        0,
        GRL_GAMEPAD_BUTTON_RIGHT_FACE_DOWN
    );
    lrg_input_action_add_binding(jump, jump_gamepad);

    lrg_input_binding_free(jump_space);
    lrg_input_binding_free(jump_gamepad);

    lrg_input_map_add_action(map, jump);

    /* Create movement actions */
    const gchar *movement_keys[] = {
        "move_left",  "move_right",  "move_up",  "move_down"
    };
    GrlKey keys[] = {
        GRL_KEY_A,     GRL_KEY_D,      GRL_KEY_W,  GRL_KEY_S
    };
    GrlGamepadAxis axes[] = {
        GRL_GAMEPAD_AXIS_LEFT_X,   /* left negative */
        GRL_GAMEPAD_AXIS_LEFT_X,   /* right positive */
        GRL_GAMEPAD_AXIS_LEFT_Y,   /* up negative */
        GRL_GAMEPAD_AXIS_LEFT_Y,   /* down positive */
    };
    gboolean positives[] = {
        FALSE,  TRUE,  FALSE,  TRUE
    };

    for (guint i = 0; i < G_N_ELEMENTS(movement_keys); i++)
    {
        g_autoptr(LrgInputAction) action = lrg_input_action_new(movement_keys[i]);

        LrgInputBinding *key_binding = lrg_input_binding_new_keyboard(
            keys[i],
            LRG_INPUT_MODIFIER_NONE
        );
        lrg_input_action_add_binding(action, key_binding);

        LrgInputBinding *axis_binding = lrg_input_binding_new_gamepad_axis(
            0,
            axes[i],
            0.2f,
            positives[i]
        );
        lrg_input_action_add_binding(action, axis_binding);

        lrg_input_binding_free(key_binding);
        lrg_input_binding_free(axis_binding);

        lrg_input_map_add_action(map, action);
    }
}

void game_init(void)
{
    g_autoptr(LrgInputMap) input_map = lrg_input_map_new();
    g_autoptr(GError) error = NULL;

    /* Try to load user's config */
    if (!lrg_input_map_load_from_file(input_map,
                                      "config/controls.yaml", &error))
    {
        g_message("No saved controls, using defaults");
        setup_input_map(input_map);

        /* Save defaults for next time */
        lrg_input_map_save_to_file(input_map, "config/controls.yaml", &error);
    }

    /* Use the map in game */
    game->input_map = g_steal_pointer(&input_map);
}

void game_update(void)
{
    /* Query input using the map */
    if (lrg_input_map_is_pressed(game->input_map, "jump"))
    {
        player_jump();
    }

    gfloat move_x = lrg_input_map_get_value(game->input_map, "move_right") -
                    lrg_input_map_get_value(game->input_map, "move_left");

    player_move(move_x * player_speed);
}
#+end_src

** Notes
:PROPERTIES:
:CUSTOM_ID: notes
:END:
- Input maps are reference-counted GObjects
- Loading clears existing actions
- Actions keep their declaration order; unknown keys of the last loaded document are written back
- The editor's input-map data editor validates documents with =lrg_input_map_load_from_data()= on the document text (see [[file:../../editor/data-editors.org][Data editors]])
- File paths are relative to the current working directory (usually the game directory)
- YAML files are human-editable for manual control customization
- Convenience queries return safe defaults if action doesn't exist
