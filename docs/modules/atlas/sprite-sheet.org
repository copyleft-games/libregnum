** Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:
An =LrgSpriteSheet= describes the frames of one image: rectangles (=LrgAtlasRegion=) with names and pivots, in order. It does not own a texture; it records the image path and size so it works without a GL context (tools, servers, tests), and the code drawing it holds the texture.

Frames come from:

- *a grid* (=lrg_sprite_sheet_slice_grid()=, 0.9.0: margins, spacing, a pivot, remembered for saving; or the older =lrg_sprite_sheet_generate_grid()= / =lrg_sprite_sheet_new_from_grid()=);
- *alpha islands* (=lrg_sprite_sheet_slice_alpha()=, 0.9.0: one frame per opaque blob, the sprite slicer's "auto" mode);
- *explicit rectangles* (=lrg_sprite_sheet_add_frame_rect()=, =lrg_sprite_sheet_add_frame()=).

Animations come in two forms: the 0.9.0 *clips* (=LrgSpriteAnimation=: per-frame durations, loop modes, events, played by =LrgSpriteAnimationPlayer=; see [[file:sprite-animation.org][Sprite animations]]) and the older *sequences* (=lrg_sprite_sheet_define_animation()=: a frame list at one duration). New code should use clips and the =.rsprite= format.

** Concepts
:PROPERTIES:
:CUSTOM_ID: concepts
:END:
- *Frame index*: frames are numbered in insertion order from 0; clips and sequences refer to frames by index.
- *Frame name*: optional and unique; grid and alpha slicing name frames =frame_<index>=. =lrg_sprite_sheet_get_frame_by_name()= looks names up.
- *Pivot*: per frame, in pixels from the frame's top-left corner (=lrg_atlas_region_set_pivot()=): where the sprite's position is; feet for characters.
- *UVs*: when the image size is known (=lrg_sprite_sheet_set_texture_size()=) frames get normalised UVs; =lrg_sprite_sheet_recalculate_uvs()= refreshes them after a size change.
- *Format* (=LrgSpriteSheetFormat=): which tool layout the sheet came from (=GRID=, =ASEPRITE=, =TEXTUREPACKER=, =LIBREGNUM=); informational.

** Legacy YAML format
:PROPERTIES:
:CUSTOM_ID: legacy-format
:END:
=lrg_sprite_sheet_new_from_file()= / =lrg_sprite_sheet_save_to_file()= read and write the pre-0.9.0 description: =name= (required), =texture_path=, =texture_width=, =texture_height=, =format= (=grid=, =aseprite=, =texturepacker=, =libregnum=), =frames= (list of ={name, x, y, width, height}=) and =animations= (list of ={name, frame_duration, loop, frame_indices}= or ={..., start_frame, end_frame}=). It is lenient (unknown keys and bad entries are skipped) and its animation order is not stable across saves; use =.rsprite= for assets you edit.

** Examples
:PROPERTIES:
:CUSTOM_ID: examples
:END:
#+begin_src C
/* an 8-column character sheet with feet pivots */
g_autoptr(LrgSpriteSheet) sheet = lrg_sprite_sheet_new ("knight");
LrgAtlasRegion *frame;

lrg_sprite_sheet_set_texture_path (sheet, "knight.png");
lrg_sprite_sheet_set_texture_size (sheet, 512, 256);
lrg_sprite_sheet_slice_grid (sheet, 64, 64, 8, 4, 30, 0, 0, 0, 0, 32.0f, 60.0f);

/* draw frame 9 at the knight's feet */
frame = lrg_sprite_sheet_get_frame (sheet, 9);
DrawTexturePro (knight_tex,
                (Rectangle) { lrg_atlas_region_get_x (frame), lrg_atlas_region_get_y (frame),
                              lrg_atlas_region_get_width (frame), lrg_atlas_region_get_height (frame) },
                (Rectangle) { feet_x, feet_y, 64, 64 },
                (Vector2) { lrg_atlas_region_get_pivot_x (frame), lrg_atlas_region_get_pivot_y (frame) },
                0.0f, WHITE);
#+end_src

#+begin_src C
/* auto-slice a packed props image on the CPU */
g_autoptr(GrlImage) image = grl_image_new_from_file ("props.png");
gsize size = 0;
guint8 *rgba = grl_image_get_pixels (image, &size);

lrg_sprite_sheet_slice_alpha (sheet, rgba, size, grl_image_get_width (image),
                              grl_image_get_height (image), 8, 4, 0.5f, 1.0f);
#+end_src

** Performance
:PROPERTIES:
:CUSTOM_ID: performance
:END:
Frames are an array and a name hash table: index and name lookups are O(1). Alpha slicing is one flood fill over the image (linear in pixels; a 1024x1024 sheet takes a few milliseconds) and is meant for authoring time.

** Pitfalls
:PROPERTIES:
:CUSTOM_ID: pitfalls
:END:
- *Slicing replaces all frames*; clips keep their frame indices, which may now point elsewhere.
- *Duplicate names*: =frames_by_name= keeps the last; the =.rsprite= reader rejects duplicates.
- *Pivots are pixels* on regions but fractions in =lrg_sprite_sheet_slice_alpha()= (convenient for mixed sizes).
- *No texture inside*: load it yourself (=grl_texture_new_from_file()=) or hand it to the player.

** Using it from the editor
:PROPERTIES:
:CUSTOM_ID: editor
:END:
Hooks for the sprite slicer of the next editor wave: grid mode calls =lrg_sprite_sheet_slice_grid()= live as the fields change; auto mode calls =lrg_sprite_sheet_slice_alpha()= on the image's pixels; manual mode adds and edits rectangles with =lrg_sprite_sheet_add_frame_rect()= / =lrg_sprite_sheet_replace_frame()= / =lrg_sprite_sheet_remove_frame()=; pivots are dragged with =lrg_atlas_region_set_pivot()=; the document saves with =lrg_sprite_sheet_save_rsprite_to_data()= and validates with =lrg_sprite_sheet_new_from_rsprite_data()=.
