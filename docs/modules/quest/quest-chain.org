* LrgQuestChain - Quest Storyline
:PROPERTIES:
:CUSTOM_ID: lrgquestchain---quest-storyline
:END:
An ordered list of quest IDs that a character completes one after another, such as a zone storyline or a class quest line. The chain stores IDs only and derives all progress from a caller-supplied =LrgQuestLog=, so it can never disagree with the authoritative log.

** Type
:PROPERTIES:
:CUSTOM_ID: type
:END:
- *Final GObject Class* - Cannot be subclassed
- *Type ID* - =LRG_TYPE_QUEST_CHAIN=
- *GIR Name* - =Libregnum.QuestChain=

** Properties
:PROPERTIES:
:CUSTOM_ID: properties
:END:
| Property | Type | Flags | Meaning |
|----------+------+-------+---------|
| =id= | string | construct-only | Unique chain identifier |
| =name= | string, nullable | read-write | Display name |
| =storyline= | string, nullable | read-write | Storyline for grouping chains in a UI |
| =description= | string, nullable | read-write | Description |

Setters notify only when the value changes.

** Authoring
:PROPERTIES:
:CUSTOM_ID: authoring
:END:
*** lrg_quest_chain_link_prerequisites()
:PROPERTIES:
:CUSTOM_ID: lrg_quest_chain_link_prerequisites
:END:
#+begin_src C
gboolean lrg_quest_chain_link_prerequisites (LrgQuestChain *self,
                                             GHashTable    *defs,
                                             GError       **error);
#+end_src

For every quest after the first, adds its predecessor as a prerequisite of its definition, skipping prerequisites that are already present (so it is idempotent). Every ID is resolved first; the operation is atomic.

*Parameters:*

- =self= - An =LrgQuestChain=
- =defs= - (element-type utf8 LrgQuestDef) Definitions by ID
- =error= - (nullable) Error return

*Returns:* =TRUE= on success

*Errors:* =LRG_PROGRESSION_ERROR_NOT_FOUND= if any chain quest is missing from =defs=; no definition is modified

** Example
:PROPERTIES:
:CUSTOM_ID: example
:END:
#+begin_src C
g_autoptr(LrgQuestChain) chain = lrg_quest_chain_new ("westfall", "The Defias Brotherhood");
g_autoptr(GError) error = NULL;

lrg_quest_chain_set_storyline (chain, "Westfall");
lrg_quest_chain_add_quest (chain, "defias_1");
lrg_quest_chain_add_quest (chain, "defias_2");
lrg_quest_chain_add_quest (chain, "defias_3");

/* Data authoring: defias_2 requires defias_1, defias_3 requires defias_2. */
if (!lrg_quest_chain_link_prerequisites (chain, defs, &error))
    g_error ("Broken chain data: %s", error->message);

/* UI projection for a character. */
g_print ("%s: %u/%u\n", lrg_quest_chain_get_name (chain),
         lrg_quest_chain_get_progress (chain, log), lrg_quest_chain_get_length (chain));
if (!lrg_quest_chain_is_complete (chain, log))
    g_print ("Next: %s\n", lrg_quest_chain_get_next (chain, log));
#+end_src
