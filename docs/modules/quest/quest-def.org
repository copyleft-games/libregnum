* LrgQuestDef - Quest Definition
:PROPERTIES:
:CUSTOM_ID: lrgquestdef---quest-definition
:END:
A blueprint for a quest containing stages (objectives), rewards, and prerequisites. Quest definitions are templates that can be instantiated multiple times to track individual player progress.

** Type
:PROPERTIES:
:CUSTOM_ID: type
:END:
- *Derivable GObject Class* - Can be subclassed for custom quest behavior
- *Type ID* - =LRG_TYPE_QUEST_DEF=
- *GIR Name* - =Libregnum.QuestDef=

:CUSTOM_ID: virtual-methods
:END:
*** check_prerequisites()
:PROPERTIES:
:CUSTOM_ID: check_prerequisites
:END:
#+begin_src C
gboolean (*check_prerequisites) (LrgQuestDef *self,
                                 gpointer     player);
#+end_src

Checks if quest prerequisites are met. Can be overridden for custom logic.

The default implementation inspects =player=: when it is an =LrgQuestLog= the check passes iff every prerequisite quest has a completion record in that log and no exclusive quest (see =lrg_quest_def_add_exclusive()=) is active or completed there. For any other =player= (including =NULL=) it keeps the historical rule and passes only when the quest has no prerequisites. A non-=NULL= =player= must be a =GTypeInstance= (normally a =GObject=) because the default implementation type-checks it.

** Parallel Stage Objectives
:PROPERTIES:
:CUSTOM_ID: parallel-stage-objectives
:END:
A stage may hold up to =LRG_QUEST_MAX_STAGE_OBJECTIVES= (16) objectives that progress in parallel, for example "kill 8 wolves AND collect 5 pelts". The objective passed to =lrg_quest_def_add_stage()= is objective 0 of the stage; =lrg_quest_def_get_stage()= and =lrg_quest_def_get_stages()= keep returning objective 0 only, so single-objective code is unaffected. A stage completes only once every one of its objectives is complete.

** Prerequisite Checking and Reward Granting

*** lrg_quest_def_check_prerequisites()
:PROPERTIES:
:CUSTOM_ID: lrg_quest_def_check_prerequisites
:END:
#+begin_src C
gboolean lrg_quest_def_check_prerequisites (LrgQuestDef *self,
                                            gpointer     player);
#+end_src

Checks if all prerequisites are met by calling the =check_prerequisites= virtual method (see above for the default rules).

*Parameters:*

- =self= - An =LrgQuestDef=
- =player= - (nullable) Player context; pass the character's =LrgQuestLog= to get real prerequisite checks

**** Migration note: default check_prerequisites changed
:PROPERTIES:
:CUSTOM_ID: migration-check-prerequisites
:END:
Before the MMO progression work the default implementation ignored =player= and returned =TRUE= only for quests without prerequisites, so any quest with a prerequisite was permanently locked unless a subclass overrode the method. The default now recognises an =LrgQuestLog= passed as =player= and answers from its completion records and exclusivity rules. Callers passing =NULL= or another object see the old result unchanged. Subclasses that override the method are unaffected; subclasses that chain up with a =LrgQuestLog= now receive real answers. Code that passed a non-GObject pointer (for example a plain C struct) as =player= must switch to passing =NULL=, a GObject, or the quest log, because the default implementation now type-checks the pointer. Server code should prefer =lrg_quest_log_can_start()=, which reports why a quest is unavailable and also checks level and repeat periods.

*Returns:* =TRUE= if prerequisites are satisfied

** Example
:PROPERTIES:
:CUSTOM_ID: example
:END:
#+begin_src C
/* Create a quest */
g_autoptr(LrgQuestDef) quest = lrg_quest_def_new("collect_herbs");
lrg_quest_def_set_name(quest, "Gather Medicinal Herbs");
lrg_quest_def_set_description(quest, "The herbalist needs rare plants");
lrg_quest_def_set_giver_npc(quest, "herbalist");

/* Add prerequisites */
lrg_quest_def_add_prerequisite(quest, "learn_herbalism");

/* Add objective: collect 5 moonflowers */
g_autoptr(LrgQuestObjective) collect = lrg_quest_objective_new(
    "collect_moonflowers",
    "Collect moonflowers",
    LRG_QUEST_OBJECTIVE_TYPE_COLLECT
);
lrg_quest_objective_set_target_id(collect, "moonflower");
lrg_quest_objective_set_target_count(collect, 5);
lrg_quest_def_add_stage(quest, collect);

/* Add rewards */
lrg_quest_def_set_reward_gold(quest, 500);
lrg_quest_def_set_reward_xp(quest, 1000);
lrg_quest_def_add_reward_item(quest, "herb_bag", 1);

/* MMO metadata */
lrg_quest_def_set_min_level(quest, 10);
lrg_quest_def_set_category(quest, "profession");
lrg_quest_def_set_zone(quest, "moonglade");

/* A parallel objective in stage 0: also collect 2 dew drops */
LrgQuestObjective *dew = lrg_quest_objective_new("collect_dew", "Collect dew drops",
                                                 LRG_QUEST_OBJECTIVE_COLLECT);
lrg_quest_objective_set_target_id(dew, "dew_drop");
lrg_quest_objective_set_target_count(dew, 2);
lrg_quest_def_add_stage_objective(quest, 0, dew);

/* Check prerequisites against the character's quest log */
if (lrg_quest_def_check_prerequisites(quest, quest_log)) {
    g_print("Can start this quest\n");
}

/* Grant rewards */
lrg_quest_def_grant_rewards(quest, player);
#+end_src
