* Tab View Widget
:PROPERTIES:
:CUSTOM_ID: tab-view-widget
:END:
=LrgTabView= is a container widget that displays content in switchable tabs. Users can click on tab headers to switch between different content panels.

** Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:
The tab view provides:

- *Tab Bar* - Horizontal row of clickable tab headers
- *Content Area* - Displays the active tab's content widget
- *Tab Position* - Headers can be at top or bottom
- *Hover/Active States* - Headers glide between looks; an accent indicator slides and resizes to the active tab on springs
- *Keyboard* - Left / Right switch tabs while the view is focused

** Input Handling
:PROPERTIES:
:CUSTOM_ID: input-handling
:END:
On a canvas the tab view behaves like any focusable widget:

1. *Hover* - the header under the pointer cross-fades to its hovered look on its own spring.
2. *Click* - a left press on a header activates that tab (and focuses the view).
3. *Content* - the content widgets are real children, so the canvas hit-tests and routes events to them directly; anything they do not consume bubbles up to the view.

When events are delivered straight to the view with =lrg_widget_handle_event()= (no canvas), they are first offered to the active content, as before.

** Keyboard and Gamepad
:PROPERTIES:
:CUSTOM_ID: keyboard-and-gamepad
:END:
- With focus on the view itself, Left and Right switch to the previous / next tab (clamped at the ends) and are consumed, so focus stays on the view. The indicator slides to the new tab.
- When a widget inside a tab has focus, arrows belong to that content: unconsumed arrows move focus between widgets and never switch tabs.
- Gamepad D-pad navigation reaches the view like any other focusable widget; Tab / Shift+Tab move into and out of its content.

** Parts and States
:PROPERTIES:
:CUSTOM_ID: parts-and-states
:END:
The view records itself with =paint()=; each part's built-in look comes from the theme.

| Part        | Resting                                     | Hovered (per header)        | Selected (active tab)            | Disabled     |
|-------------+---------------------------------------------+-----------------------------+----------------------------------+--------------|
| =box=       | =PANEL= surface behind the content, =BORDER= hairline, =CORNER_RADIUS= |              |                                  | opacity 0.45 |
| =tab=       | transparent, =TEXT_MUTED= label, rounded    | =CONTROL_HOVER=, =TEXT=     | faint =ACCENT= wash, =TEXT=      | opacity 0.45 |
| =indicator= | =ACCENT= pill, =size= 3 (thickness), accent glow |                        |                                  | opacity 0.45 |
| =focus=     | ring around the whole view                  |                             |                                  |              |

Headers share the view's width equally. Each header's look is resolved with the view's state minus its own hover/press, plus =SELECTED= for the active tab, and blended to the =HOVERED= variant by that header's hover spring. The indicator sits on the content side of the header strip, inset 12% from the header's sides, and its position and width follow springs (the widget's motion preset) whenever the active tab changes; =lrg_tab_view_get_indicator_rect()= returns where it is heading. The active content is painted last, clipped to the content area.

** Complete Example
:PROPERTIES:
:CUSTOM_ID: complete-example
:END:
#+begin_src C
#include <libregnum.h>

static void
on_tab_changed (LrgTabView *tabs,
                guint       index,
                gpointer    user_data)
{
    const gchar *label = lrg_tab_view_get_tab_label (tabs, index);
    g_print ("Tab changed to: %s (index %u)\n", label, index);
}

int
main (void)
{
    /* Initialize engine and window... */

    /* Create tab view */
    LrgTabView *tabs = lrg_tab_view_new ();
    lrg_widget_set_position (LRG_WIDGET (tabs), 50, 50);
    lrg_widget_set_size (LRG_WIDGET (tabs), 500, 400);

    /* Create tab content */
    LrgVBox *general = lrg_vbox_new ();
    lrg_container_add_child (LRG_CONTAINER (general),
                             LRG_WIDGET (lrg_label_new ("General Settings")));

    LrgVBox *graphics = lrg_vbox_new ();
    lrg_container_add_child (LRG_CONTAINER (graphics),
                             LRG_WIDGET (lrg_label_new ("Resolution: 1920x1080")));
    lrg_container_add_child (LRG_CONTAINER (graphics),
                             LRG_WIDGET (lrg_button_new_with_label ("Apply")));

    LrgVBox *audio = lrg_vbox_new ();
    lrg_container_add_child (LRG_CONTAINER (audio),
                             LRG_WIDGET (lrg_label_new ("Master Volume: 80%")));

    /* Add tabs */
    lrg_tab_view_add_tab (tabs, "General", LRG_WIDGET (general));
    lrg_tab_view_add_tab (tabs, "Graphics", LRG_WIDGET (graphics));
    lrg_tab_view_add_tab (tabs, "Audio", LRG_WIDGET (audio));

    /* Connect signal */
    g_signal_connect (tabs, "tab-changed",
                      G_CALLBACK (on_tab_changed), NULL);

    /* Set initial tab */
    lrg_tab_view_set_active_tab (tabs, 1);  /* Start on Graphics */

    /* In game loop */
    while (running)
    {
        /* Handle input */
        lrg_widget_handle_event (LRG_WIDGET (tabs), event);

        /* Draw */
        lrg_widget_draw (LRG_WIDGET (tabs));
    }

    g_object_unref (tabs);
    return 0;
}
#+end_src
