This page lists *every* public function of each widget class in =src/ui/=, one section per widget, with the prototype copied from the header, ownership and nullability annotations and what the call actually does (including the checks it makes and what it queues or emits). The per-widget pages linked from each section explain looks, parts, input handling and theming; this page is the place to look up a single call.

Conventions that hold for every table below:

- Every function takes a non-=NULL= instance of its class as =self= and checks it with =g_return_if_fail= / =g_return_val_if_fail=.
- Constructors return a (transfer full) reference. =LrgWidget= derives from plain =GObject= (no floating references): a container takes its own reference in =lrg_container_add_child()=, so drop yours after adding, or hold it in a =g_autoptr=.
- Colour getters return (transfer none) pointers into the widget, valid until the matching setter runs; colour setters copy the colour and require it to be non-=NULL= unless noted.
- "Reported" defaults: the legacy appearance properties (=*-color=, =corner-radius=, =font-size=, ...) keep their pre-paint default values in their getters, but the widget draws with the theme until a value is set explicitly. Setting one makes it win over the theme for that widget; theme style rules still apply on top.
- Setters notify their property only when the value changes, and queue a layout when the change can affect the preferred size.

The base class (=LrgWidget=: geometry, layout hints, state, looks) is in [[file:widget.org][LrgWidget]], containers (=lrg_container_add_child()= ...) in [[file:container.org][LrgContainer]], and the root =LrgCanvas= in [[file:canvas-api.org][LrgCanvas API]].
