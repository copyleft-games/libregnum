=LrgUIEvent= (=src/ui/lrg-ui-event.h=) is a small boxed value describing one input event delivered to a widget's =handle_event()= virtual method. =LrgCanvas= creates and dispatches them from each input frame; widgets read them. How events are routed (bubbling, pointer capture, focus, hover, popups) is described in [[file:input-and-focus.org][input, focus and popups]].

** Event types
:PROPERTIES:
:CUSTOM_ID: ui-event-types
:END:
| =LrgUIEventType= | Generated when | Delivered to | Bubbles | Data |
|------------------+----------------+--------------+---------+------|
| =LRG_UI_EVENT_MOUSE_MOVE= | the pointer moved | pointer capture, else the widget under the pointer | yes | x, y, modifiers |
| =LRG_UI_EVENT_MOUSE_BUTTON_DOWN= | a button went down | capture (after a left press starts one), else the hit widget | yes | button, x, y, modifiers |
| =LRG_UI_EVENT_MOUSE_BUTTON_UP= | a button went up | capture, else the hit widget | yes | button, x, y, modifiers |
| =LRG_UI_EVENT_KEY_DOWN= | a key was pressed (Tab excluded: it navigates) | focused widget, else the top popup | yes | key, modifiers |
| =LRG_UI_EVENT_KEY_UP= | not generated by the canvas | - | - | key |
| =LRG_UI_EVENT_SCROLL= | the wheel moved | the widget under the pointer | yes | x, y, scroll x, scroll y, modifiers |
| =LRG_UI_EVENT_FOCUS_IN= | the widget gained *keyboard* focus | that widget | no | - |
| =LRG_UI_EVENT_FOCUS_OUT= | the widget lost keyboard focus | that widget | no | - |
| =LRG_UI_EVENT_TEXT_INPUT= | a composed character was typed | focused widget | yes | codepoint, modifiers |
| =LRG_UI_EVENT_POINTER_ENTER= | the pointer entered the widget or a descendant | each widget joining the hover path | no | - |
| =LRG_UI_EVENT_POINTER_LEAVE= | the pointer left the widget and its descendants | each widget leaving the hover path | no | - |
| =LRG_UI_EVENT_ACTIVATE= | Enter / Space (unhandled) or gamepad A on the focused widget | focused widget | yes | - |
| =LRG_UI_EVENT_CANCEL= | Escape (unhandled) or gamepad B | focused widget, else the top popup | yes | - |

*Hover does not send focus events.* =FOCUS_IN= / =FOCUS_OUT= are keyboard focus only; use =POINTER_ENTER= / =POINTER_LEAVE= (or the =HOVERED= state flag) for hover. Text should be taken from =TEXT_INPUT= (layout, Shift and dead keys applied), not from =KEY_DOWN= codes.

** Handling events in a widget
:PROPERTIES:
:CUSTOM_ID: ui-event-handling
:END:
=handle_event= returns =TRUE= to consume the event (bubbling stops) or =FALSE= to let the parent see it. Chain up for anything you do not handle so base-class behaviour (and the container's bubbling guard) still applies.

#+begin_src c
static gboolean
game_toggle_handle_event (LrgWidget        *widget,
                          const LrgUIEvent *event)
{
	GameToggle *self = GAME_TOGGLE (widget);

	switch (lrg_ui_event_get_event_type (event))
	{
	case LRG_UI_EVENT_MOUSE_BUTTON_DOWN:
		/* consume the press so ancestors don't react; the canvas has
		 * already focused us and captured the pointer */
		return lrg_ui_event_get_button (event) == GRL_MOUSE_BUTTON_LEFT;

	case LRG_UI_EVENT_MOUSE_BUTTON_UP:
		/* a click is a left release inside the widget; releasing
		 * outside after dragging off cancels */
		if (lrg_ui_event_get_button (event) == GRL_MOUSE_BUTTON_LEFT &&
		    lrg_widget_contains_point (widget, lrg_ui_event_get_x (event),
		                               lrg_ui_event_get_y (event)))
			game_toggle_set_active (self, !self->active);
		return TRUE;

	case LRG_UI_EVENT_ACTIVATE:
		/* Enter, Space, gamepad A */
		game_toggle_set_active (self, !self->active);
		return TRUE;

	default:
		break;
	}

	return LRG_WIDGET_CLASS (game_toggle_parent_class)->handle_event (widget, event);
}
#+end_src

While an event bubbles, =lrg_ui_event_get_target()= is the widget it was first delivered to and =lrg_ui_event_get_bubbling()= is =TRUE=. A parent can use that to react to clicks anywhere in its subtree (e.g. a list row selecting itself when any child is clicked) without each child knowing about it.

** Construction
:PROPERTIES:
:CUSTOM_ID: ui-event-construction
:END:
Mostly used by the canvas and by tests that call =lrg_widget_handle_event()= directly. All return (transfer full); free with =lrg_ui_event_free()= or =g_autoptr (LrgUIEvent)=.

| Function | Creates |
|----------+---------|
| =lrg_ui_event_new (type)= | An event of any type with no data (=ACTIVATE=, =CANCEL=, =POINTER_ENTER=, =POINTER_LEAVE= ...) |
| =lrg_ui_event_new_mouse_move (x, y)= | =MOUSE_MOVE= |
| =lrg_ui_event_new_mouse_button (type, button, x, y)= | =MOUSE_BUTTON_DOWN= / =UP=; =button= is a =GrlMouseButton= (0 left, 1 right, 2 middle) |
| =lrg_ui_event_new_key (type, key)= | =KEY_DOWN= / =KEY_UP= |
| =lrg_ui_event_new_scroll (x, y, scroll_x, scroll_y)= | =SCROLL= |
| =lrg_ui_event_new_focus_in ()= / =new_focus_out ()= | =FOCUS_IN= / =FOCUS_OUT= |
| =lrg_ui_event_new_text_input (codepoint)= | =TEXT_INPUT= |
| =lrg_ui_event_copy (self)= / =lrg_ui_event_free (self)= | Boxed copy / free |

Note the argument order of =lrg_ui_event_new_mouse_button()=: the button comes *before* the coordinates.

** Accessors
:PROPERTIES:
:CUSTOM_ID: ui-event-accessors
:END:
| Function | Returns |
|----------+---------|
| =lrg_ui_event_get_event_type (self)= | The =LrgUIEventType= |
| =lrg_ui_event_get_x= / =get_y= | Pointer position in canvas (world) coordinates, for pointer events |
| =lrg_ui_event_get_button (self)= | Mouse button (=GrlMouseButton=) for button events |
| =lrg_ui_event_get_key (self)= | =GrlKey= for key events |
| =lrg_ui_event_get_scroll_x= / =get_scroll_y= | Wheel movement for =SCROLL= |
| =lrg_ui_event_get_codepoint (self)= | Unicode character for =TEXT_INPUT=, 0 otherwise |
| =lrg_ui_event_get_modifiers (self)= | =LrgInputModifiers= (=SHIFT=, =CTRL=, =ALT=) held when the event happened |
| =lrg_ui_event_get_target (self)= | (transfer none) (nullable) widget the event was first delivered to |
| =lrg_ui_event_get_bubbling (self)= | =TRUE= while the event travels up from the target |

Setters used by the canvas (and tests): =lrg_ui_event_set_target()=, =lrg_ui_event_set_bubbling()=, =lrg_ui_event_set_modifiers()=.

** Consumption flag (legacy)
:PROPERTIES:
:CUSTOM_ID: ui-event-consumed
:END:
=lrg_ui_event_get_consumed()=, =set_consumed()= and =consume()= remain for compatibility, but the canvas decides propagation *only from =handle_event='s return value*; the flag is not consulted. Return =TRUE= to stop an event. (=handle_event= receives a =const= event, so the old pattern of calling =lrg_ui_event_consume()= inside it is no longer meaningful.)

** Testing with events
:PROPERTIES:
:CUSTOM_ID: ui-event-testing
:END:
Unit-test a widget's handler directly:

#+begin_src c
static void
test_toggle_activates (void)
{
	g_autoptr(GameToggle) toggle = game_toggle_new ();
	g_autoptr(LrgUIEvent) ev = lrg_ui_event_new (LRG_UI_EVENT_ACTIVATE);

	g_assert_true (lrg_widget_handle_event (LRG_WIDGET (toggle), ev));
	g_assert_true (game_toggle_get_active (toggle));
}
#+end_src

For whole-tree behaviour (bubbling, capture, focus) drive the canvas with input frames instead: see [[file:input-and-focus.org::#input-testing][replays and tests]].
