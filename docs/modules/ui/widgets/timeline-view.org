* Timeline View Widget
:PROPERTIES:
:CUSTOM_ID: timeline-view-widget
:END:

** Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:
=LrgTimelineView= is a multi-track sequencer for cutscenes, animation and audio. It shows a column of track headers, a time ruler and the track area, and lets the user scrub, zoom, scroll and edit clips and keyframes. It is a paint-pipeline widget (=paint()= + =style_defaults()=): everything is recorded as SDF shapes, follows the theme, and moves on springs.

(Not to be confused with the editor's =LrgTimeline= in =src/editor/=, which is the cutscene data model. =LrgTimelineView= is a pure UI widget; the application maps its model onto it.)

What it shows:

- *Tracks* (=LrgTimelineViewTrack= objects): a name, a colour, a height, collapsed / muted / locked flags, optional nesting (a track added with a parent is drawn indented under its group; collapsing the group hides its tracks), and an optional *curve lane* under the clip lane that plots the keyframe values.
- *Clips* on tracks: start, duration, label, optional colour. Clips on one track cannot overlap unless the track allows it.
- *Keyframes* on tracks: time, value and the interpolation of the segment that starts at them (=step=, =linear=, =ease=, =bezier= with tangents). Drawn as diamonds across the clip lane and as points on the value curve (drawn with =lrg_paint_list_curve()=, glowing in the track colour). =lrg_timeline_view_evaluate()= samples the same curve that is drawn.
- *Markers*: a flag on the ruler and a line across the tracks.
- *Playhead*: an accent line with a glowing handle on the ruler; the glow grows while the handle is hovered or scrubbed.
- *Loop range*: tinted on the ruler and over the tracks while =loop= is on.
- *Ruler*: adaptive ticks. The major step is the smallest "nice" step (1 / 2 / 5 / 10 frames with an fps, then 1-2-5 seconds, then minute multiples) that keeps labels about 80 units apart; minor ticks subdivide it and are halved while closer than 5 units. Labels use the =time-format= (seconds, timecode, frames).
- *Corner*: a play / pause button (built-in playback) and the current time.
- *Scrollbars*: the shared overlay scrollbars (=lrg-scrollbar-private.h=) on the right and bottom of the track area, fading in on activity.

Ids: every clip, keyframe and marker has a unique =guint= id (never 0, =LRG_TIMELINE_VIEW_INVALID_ID=); all per-item API takes ids, all signals pass ids.

Scale: clips and keyframes are kept per track in arrays sorted by time, so painting and hit testing find what is on screen with binary searches. Only visible rows are painted; clips narrower than 4 units (far zoomed out) are merged into one bar per run. 100 tracks x 1000 clips record in a few thousand instances at any zoom (tested).

** Creation
:PROPERTIES:
:CUSTOM_ID: creation
:END:
#+begin_src C
LrgTimelineView      *tl = lrg_timeline_view_new ();
LrgTimelineViewTrack *cam;
LrgTimelineViewTrack *fade;
guint                 shot;

lrg_timeline_view_set_duration (tl, 30.0);
lrg_timeline_view_set_fps (tl, 30.0);

cam = lrg_timeline_view_add_track (tl, "Camera", NULL);
shot = lrg_timeline_view_add_clip (tl, cam, 0.0, 2.5, "Wide shot");

fade = lrg_timeline_view_add_track (tl, "Fade", NULL);
lrg_timeline_view_track_set_curve_lane (fade, TRUE);
lrg_timeline_view_add_keyframe (tl, fade, 0.0, 0.0, LRG_TIMELINE_VIEW_INTERPOLATION_EASE);
lrg_timeline_view_add_keyframe (tl, fade, 1.0, 1.0, LRG_TIMELINE_VIEW_INTERPOLATION_LINEAR);

lrg_timeline_view_add_marker (tl, 2.5, "Cut");
g_signal_connect (tl, "playhead-moved", G_CALLBACK (on_seek), game);
lrg_container_add_child (LRG_CONTAINER (editor), LRG_WIDGET (tl));

/* every frame, if the game drives time itself: */
lrg_timeline_view_set_time (tl, cutscene_time);
/* ... and sample a curve: */
alpha = lrg_timeline_view_evaluate (tl, fade, cutscene_time);
#+end_src

Or let the widget play: =lrg_timeline_view_set_playing (tl, TRUE)= advances the playhead every canvas frame by the frame time times =rate=, wrapping around the loop range when =loop= is set.

** Behaviour
:PROPERTIES:
:CUSTOM_ID: behaviour
:END:
| Input                                         | Where                     | Effect                                                                                           |
|-----------------------------------------------+---------------------------+--------------------------------------------------------------------------------------------------|
| Press / drag                                  | ruler                     | Scrub: the playhead follows the pointer (snapped to markers, clip edges, grid)                   |
| Click                                         | marker flag               | Playhead jumps to the marker, =marker-activated=                                                 |
| Click                                         | play button (corner)      | Toggle =playing=                                                                                 |
| Click                                         | chevron / speaker / lock  | Toggle the track's =collapsed= / =muted= / =locked=                                              |
| Double click                                  | track name                | Toggle =collapsed=                                                                               |
| Click                                         | clip / keyframe           | Select only it (Ctrl / Shift toggles it); =clip-selected= for clips                              |
| Drag                                          | clip body                 | Move the selected clips (one clip may change track); they lift with a deeper shadow              |
| Drag                                          | clip edge (6 units)       | Resize that end; a grip shows on the hovered edge                                                |
| Drag                                          | keyframe diamond          | Move the selected keyframes in time                                                              |
| Drag                                          | curve point               | Move that keyframe in time and value                                                             |
| Double click                                  | curve lane                | Add a linear keyframe there (=keyframe-added=)                                                   |
| Drag                                          | empty lane                | Rubber band selection (Ctrl / Shift adds to the selection)                                       |
| Alt held during a drag                        | any drag                  | No snapping                                                                                      |
| Esc during a drag                             |                           | Put everything back                                                                              |
| Wheel / Shift + wheel / horizontal wheel      | anywhere                  | Scroll tracks vertically / horizontally (plain wheel scrolls time when the tracks fit)           |
| Ctrl + wheel, pinch                           | anywhere                  | Zoom about the pointer (the time under it stays put while the zoom spring glides)                |
| Touch pan                                     | anywhere                  | Scroll both axes, flick on release                                                               |
| Delete / Backspace                            | focused                   | Remove the selected clips and keyframes (not on locked tracks)                                   |
| Ctrl+C / Ctrl+V / Ctrl+A                      | focused                   | Copy selected clips / paste them at the playhead / select everything                             |
| Left / Right (Shift: x10)                     | focused                   | Step the playhead a frame (0.1 s without an fps)                                                 |
| Home / End                                    | focused                   | Playhead to the start / end                                                                      |
| Enter / Space / gamepad A (ACTIVATE)          | focused                   | Toggle =playing=                                                                                 |

Snapping (=snap= flags): a dragged clip snaps either edge (whichever is closer) onto the playhead, markers, the sequence ends and the edges of other clips and keyframes within =snap-distance= units, showing a glowing guide line; otherwise the start is quantized to the grid (frames with an fps, else the ruler's minor ticks). Overlaps: a move that would overlap a resting clip (on a track that forbids it) is refused for that frame, so the clip stops at its last valid place; resizing clamps at the neighbours and keeps at least one frame (10 ms without an fps).

Follow playhead: with =follow-playhead= (default on) the view pages so a playhead that leaves the view (playback, =set_time=, keys) sits 10 % in from the left edge. Scrubbing never scrolls.

Interpolation of the segment from key a to key b, with u = (t - a.time) / (b.time - a.time) and d = b.time - a.time: step = a; linear = a + (b - a) u; ease = a + (b - a) (3u^2 - 2u^3); bezier = Hermite h00 a + h10 d a.out + h01 b + h11 d b.in.

** Pitfalls
:PROPERTIES:
:CUSTOM_ID: pitfalls
:END:
- Ids are only valid while the item exists; a removed id is never reused.
- =add_clip()= silently returns =LRG_TIMELINE_VIEW_INVALID_ID= on an overlap; check it, or set =allow-overlap= on the track.
- =playhead-moved= fires for =set_time()= too. If the app drives the playhead every frame and also seeks on =playhead-moved=, ignore the signal while the app itself is setting the time.
- Locked tracks only refuse pointer edits; the API still edits them.
- The muted flag is only visual; the application decides what muting does.
- With =follow-playhead= on, every =set_time()= outside the view scrolls it; turn it off while the user browses during playback if that is not wanted.
- Keyframe interpolation belongs to the segment that *starts* at the keyframe; the last keyframe's interpolation is unused.
