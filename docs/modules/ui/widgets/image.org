* Image Widget
:PROPERTIES:
:CUSTOM_ID: image-widget
:END:

** Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:
=LrgImage= displays a texture (or a region of a sprite sheet) scaled into its rectangle. It records image instances into the paint list, so images batch with the rest of the UI and get anti-aliased rounded corners from =corner-radius=: set it to half the shorter side for a circular avatar.

Scale modes:

- =LRG_IMAGE_SCALE_MODE_FIT= (default): keep the aspect ratio, fit inside, centre (may letterbox).
- =LRG_IMAGE_SCALE_MODE_FILL=: keep the aspect ratio, cover the whole rectangle, crop the centre.
- =LRG_IMAGE_SCALE_MODE_STRETCH=: fill the rectangle exactly.
- =LRG_IMAGE_SCALE_MODE_TILE=: repeat at native size, clipped to the rectangle (tiles are not rounded).

The preferred size is the texture's (or source rectangle's) size, 100 × 100 without a texture. Changing the texture or source rectangle queues a layout. Disabled images fade to 45 %.

** Creation
:PROPERTIES:
:CUSTOM_ID: creation
:END:
#+begin_src C
g_autoptr(GrlTexture) tex = grl_texture_new_from_file ("portrait.png");
LrgImage *avatar = lrg_image_new_with_texture (tex);

lrg_widget_set_size (LRG_WIDGET (avatar), 64, 64);
lrg_image_set_scale_mode (avatar, LRG_IMAGE_SCALE_MODE_FILL);
lrg_image_set_corner_radius (avatar, 32);   /* circle */
#+end_src

** Properties
:PROPERTIES:
:CUSTOM_ID: properties
:END:
| Property        | Type                | Default  | Notes                                                    |
|-----------------+---------------------+----------+----------------------------------------------------------|
| =texture=       | =GrlTexture=        | =NULL=   | The texture to draw                                      |
| =scale-mode=    | =LrgImageScaleMode= | =FIT=    | See above                                                |
| =tint=          | =GrlColor=          | white    | Multiplied with the texture                              |
| =source-rect=   | =GrlRectangle=      | =NULL=   | Sprite-sheet region; =NULL= for the whole texture        |
| =corner-radius= | float               | 0        | Rounded corners (not applied to =TILE=)                  |

** Signals
:PROPERTIES:
:CUSTOM_ID: signals
:END:
No image-specific signals.

** Parts and states
:PROPERTIES:
:CUSTOM_ID: parts-and-states
:END:
The image has no themed parts: its colours are the texture's, multiplied by =tint=. While =LRG_WIDGET_STATE_DISABLED= is set the tint's alpha is scaled to 45 %. Put it inside an =LrgPanel= for a frame.

** Style classes
:PROPERTIES:
:CUSTOM_ID: style-classes
:END:
None.

** Theming
:PROPERTIES:
:CUSTOM_ID: theming
:END:
Images are not styled by theme rules. For a themed frame, wrap the image in a panel and style that:

#+begin_src yaml
styles:
  - widget: LrgPanel
    class: avatar-frame
    part: box
    radius: 999
    border: "#cba6f7"
    border-width: 2
#+end_src

** Keyboard, mouse and gamepad
:PROPERTIES:
:CUSTOM_ID: keyboard-mouse-gamepad
:END:
Display-only: the image never takes focus and does not consume events.

** Example
:PROPERTIES:
:CUSTOM_ID: example
:END:
#+begin_src C
/* Frame 3 of a 32x32 sprite sheet, scaled up crisply */
GrlRectangle frame = { 96, 0, 32, 32 };
LrgImage    *icon = lrg_image_new_with_texture (sheet);

lrg_image_set_source_rect (icon, &frame);
lrg_image_set_scale_mode (icon, LRG_IMAGE_SCALE_MODE_STRETCH);
lrg_widget_set_size (LRG_WIDGET (icon), 64, 64);
lrg_image_set_corner_radius (icon, 8);
#+end_src
