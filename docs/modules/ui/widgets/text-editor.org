* Text editor
:PROPERTIES:
:CUSTOM_ID: text-editor
:END:
=LrgTextEditor= is a multi-line editor for scripts, consoles and chat boxes: syntax highlighting (=LrgSyntax=), a line-number gutter, word wrap or horizontal scrolling, undo / redo with typing runs coalesced, find, bracket matching, a caret that glides to its new cell on springs and blinks with an eased fade, and spring-smoothed scrolling with the shared overlay scrollbars. It is an =LrgContainer= only to host its two scrollbar hit zones; do not add children.

Text is stored as an array of lines with UTF-8 positions; the public API speaks in /character/ columns. Painting is virtualised: only visible rows are laid out, tokenized and recorded, and lines above the view are lexed once for their state only, so a 10 000-line file paints in constant time (the tests check both the tokenize count and the paint list size).

** Creation
:PROPERTIES:
:CUSTOM_ID: text-editor-creation
:END:
#+begin_src C
LrgTextEditor *script = lrg_text_editor_new ();

lrg_text_editor_set_language (script, "lua");
lrg_text_editor_set_show_line_numbers (script, TRUE);
lrg_text_editor_set_insert_spaces (script, TRUE);
lrg_text_editor_set_tab_width (script, 2);
lrg_text_editor_set_text (script, contents);
g_signal_connect (script, "changed", G_CALLBACK (on_script_changed), NULL);
#+end_src

A chat box: Enter sends, Shift+Enter breaks the line, wrap on.
#+begin_src C
static void
on_send (LrgTextEditor *box,
         gpointer       user_data)
{
	g_autofree gchar *msg = lrg_text_editor_get_text (box);

	chat_send (msg);
	lrg_text_editor_set_text (box, "");
}

LrgTextEditor *box = lrg_text_editor_new ();

g_object_set (box, "submit-on-enter", TRUE, "wrap", TRUE,
              "placeholder", "Message #general", "font", "ui", NULL);
g_signal_connect (box, "submit", G_CALLBACK (on_send), NULL);
#+end_src

A console log: read-only, keeps the last 2000 lines and follows new output while the caret sits at the end.
#+begin_src C
LrgTextEditor *log = lrg_text_editor_new ();

lrg_text_editor_set_read_only (log, TRUE);
lrg_text_editor_set_max_lines (log, 2000);
lrg_text_editor_append (log, "\n[info] level loaded");
#+end_src

** Behaviour
:PROPERTIES:
:CUSTOM_ID: text-editor-behaviour
:END:
| Input                              | Action                                                                 |
|------------------------------------+------------------------------------------------------------------------|
| Typing (=TEXT_INPUT=)              | Inserts at the caret, replacing the selection                          |
| Left / Right                       | Character (a selection collapses to its edge); Ctrl: by word           |
| Up / Down                          | Visual row, keeping the column; Ctrl: scroll one row without moving    |
| Home / End                         | Row start (first press: indentation) / row end; Ctrl: document start / end |
| Page Up / Page Down                | A page of rows; the view moves with the caret                          |
| Shift + any of the above           | Extends the selection                                                  |
| Backspace / Delete                 | Character, selection, or word with Ctrl; in space indentation back to the previous tab stop |
| Enter                              | Newline with auto-indent (one level more after =(= =[= ={= or =:=; ={\vert{}}= splits onto three lines) |
| Enter with =submit-on-enter=       | Emits =submit=; Shift+Enter inserts a newline                          |
| Ctrl+Enter without it              | Emits =submit=                                                         |
| Tab / Shift+Tab                    | Tab or spaces to the next stop; with a multi-line selection indent / outdent every line (the class accepts Tab, see =lrg_widget_set_accepts_tab()=) |
| Ctrl+Tab / Ctrl+Shift+Tab          | Moves focus out of the editor (the canvas never offers Ctrl+Tab to it) |
| Ctrl+A / C / X / V                 | Select all, copy, cut, paste (Ctrl+Insert / Shift+Insert too)          |
| Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y     | Undo / redo                                                            |
| Escape                             | Clears the selection (otherwise left to the canvas)                    |
| Click / double / triple click      | Caret / word / line; dragging extends in the same unit; Shift+click extends |
| Wheel, Shift+wheel, touch pan      | Vertical / horizontal scrolling with rubber band; flicks coast         |

Key consumption follows the shared shortcut rule: printable keys are consumed only without Ctrl, Alt or Super (AltGr, Ctrl+Alt together, still types), so application shortcuts such as Ctrl+S fire while the editor has focus; the Ctrl chords listed above are consumed. Arrows and editing keys are always consumed so focus does not move. In read-only mode typing, paste, cut and undo do nothing, selection and copy work, and Tab is not consumed.

Typing coalesces into one undo step until the caret moves, 1.5 s of canvas time pass, or a word ends (a space after a non-space). Backspace and Delete runs coalesce the same way. =lrg_text_editor_set_text()= and dropping lines through =max-lines= clear the history.

*** Bracket matching
:PROPERTIES:
:CUSTOM_ID: text-editor-brackets
:END:
While focused, the bracket just before the caret (or, if it has no partner, the one just after it) and its partner are outlined with the =indicator= look. The partner is found by counting nesting of the same pair (=()=, =[]=, ={}=) forwards or backwards, across lines, for at most 200 000 bytes. With a language set, brackets inside =STRING=, =ESCAPE= and =COMMENT= tokens are plain text: they neither count towards nesting nor match, and a caret next to one shows no pair (it does not pair with another bracket in the same string either). So in =f ("(", x)= the outer parentheses match. The token test uses the same per-line spans and carried state as painting (block comments and multi-line strings work); lines without painted spans are tokenized into a scratch array that is not cached. With no language, every bracket counts, as before. =lrg_text_editor_get_bracket_match()= returns the outlined pair.

*** Find
:PROPERTIES:
:CUSTOM_ID: text-editor-find
:END:
=lrg_text_editor_find()= highlights every match (=indicator= / =checked=) and selects the first at or after the caret, wrapping. Case-sensitive find compares bytes. Case-insensitive find compares Unicode case folds: each character of the line and of the needle is folded with =g_utf8_casefold()= and decomposed with =g_utf8_normalize (G_NORMALIZE_DEFAULT)= (ASCII takes a direct lowercase fast path), and a per-byte map leads every folded byte back to the character it came from, so the selection and highlights cover the real source bytes even when folding changes the length. Examples: =äbc= finds =ÄBC=, =straße= finds =STRASSE= (and vice versa; =ss= matches a whole =ß=), =σίσυφος= finds =ΣΊΣΥΦΟΣ= (final and medial sigma fold alike), a precomposed =Ä= finds a decomposed =A= + U+0308. A match must begin and end on character boundaries of the source: =s= never matches half of a =ß=. The fold of the line being searched is cached until the next edit, so painting the rows of a wrapped line or counting matches folds it once.

** Motion
:PROPERTIES:
:CUSTOM_ID: text-editor-motion
:END:
- The caret glides to its new cell on two springs (snappy; instant with =LRG_MOTION_NONE=). The blink is solid for 0.6 s after any activity, then a 1.1 s cosine fade. It is a pure function of the canvas clock and does not keep =lrg_canvas_update()= busy.
- Scrolling uses the shared spring axes with rubber band ends; caret moves scroll the least amount that keeps the caret (plus two columns sideways) in view.
- The first =step()= snaps everything so a new editor does not animate in.

** YAML
:PROPERTIES:
:CUSTOM_ID: text-editor-yaml
:END:
Supported by =LrgUILoader= as =LrgTextEditor= (=type: text-editor=); every setting is a GObject property (=text=, =language=, =show-line-numbers=, =wrap=, =read-only=, =tab-width=, =insert-spaces=, =placeholder=, =submit-on-enter=, =max-lines=, =font=, =font-size=, =highlight-current-line=, =auto-indent=). Two loader keys bring languages (see [[file:../declarative-ui.org::#text-editor-keys][Declarative UI]]):

- the document's top-level =languages:= registers =LrgSyntax= definitions (inline mappings in the [[file:syntax.org::#syntax-yaml][syntax schema]], file names, or ={file: name}=) before any widget is built, so =language: name= finds them;
- =language-file: file.yaml= on the editor loads a definition, registers it and sets the editor's =syntax=.

#+begin_src yaml
languages:
  - name: studio-script
    keywords: [on, do, end, let]
    builtins: [spawn, play]
    line-comment: "#"
root:
  type: vbox
  children:
    - type: text-editor
      id: script
      language: studio-script
      show-line-numbers: true
      text: |
        on start do
          play("intro")
        end
    - {type: text-editor, id: config, language-file: langs/toml-lite.yaml, read-only: true}
#+end_src

Language files are watched with the document. A hot reload keeps the text the user typed unless =text:= changes in the file.

** Pitfalls
:PROPERTIES:
:CUSTOM_ID: text-editor-pitfalls
:END:
- The editor class sets =accepts-tab= (=lrg_widget_class_set_accepts_tab()=), so the canvas offers Tab / Shift+Tab to it as =KEY_DOWN= before moving focus. A read-only editor returns =FALSE= for Tab, so focus moves on; an editable one keeps it, and Ctrl+Tab is the way out. Turn it off per instance with =lrg_widget_set_accepts_tab (editor, FALSE)= for single-purpose forms where Tab should always move focus.
- Held keys auto-repeat (the canvas forwards the operating system's repeat as =KEY_DOWN= with =lrg_ui_event_get_repeat()= set), so arrows, Backspace, Delete and Enter repeat; typed characters repeat through the character queue.
- Layout is a monospace grid: proportional fonts work but drift within a run of text. Wide (CJK) characters take two cells, tabs reach the next tab stop.
- Find is single-line. Case folding is per character and has no locale: Turkish dotless / dotted i are not special-cased, so =İ= folds to =i= + U+0307 and is found by =İ= or =i̇= but not by a plain =i=. A bare base letter does match the base of a decomposed character (=a= finds the =a= of =a= + U+0308) but not a precomposed one (=a= does not find =ä=). Combining marks are not reordered, so two decomposed spellings with marks in different orders do not match.
- Case-insensitive matches can be longer or shorter than the needle in bytes (=ß= vs =ss=); use the selection bounds, never =strlen (needle)=, to find where a match ends.
- Bracket matching scans at most 200 000 bytes. Strings and comments are skipped only with a language set, and only as well as the language's tokenizer knows them (a bracket in a Markdown code span is still a bracket).
- =lrg_text_editor_get_line()= returns internal storage valid until the next edit.
- Do not add children with =lrg_container_add_child()=; the only children are the scrollbar zones.
