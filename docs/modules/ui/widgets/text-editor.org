* Text editor
:PROPERTIES:
:CUSTOM_ID: text-editor
:END:
=LrgTextEditor= is a multi-line editor for scripts, consoles and chat boxes: syntax highlighting (=LrgSyntax=), a line-number gutter, word wrap or horizontal scrolling, undo / redo with typing runs coalesced, find, bracket matching, a caret that glides to its new cell on springs and blinks with an eased fade, and spring-smoothed scrolling with the shared overlay scrollbars. It is an =LrgContainer= only to host its two scrollbar hit zones; do not add children.

Text is stored as an array of lines with UTF-8 positions; the public API speaks in /character/ columns. Painting is virtualised: only visible rows are laid out, tokenized and recorded, and lines above the view are lexed once for their state only, so a 10 000-line file paints in constant time (the tests check both the tokenize count and the paint list size).

** Creation
:PROPERTIES:
:CUSTOM_ID: text-editor-creation
:END:
#+begin_src C
LrgTextEditor *script = lrg_text_editor_new ();

lrg_text_editor_set_language (script, "lua");
lrg_text_editor_set_show_line_numbers (script, TRUE);
lrg_text_editor_set_insert_spaces (script, TRUE);
lrg_text_editor_set_tab_width (script, 2);
lrg_text_editor_set_text (script, contents);
g_signal_connect (script, "changed", G_CALLBACK (on_script_changed), NULL);
#+end_src

A chat box: Enter sends, Shift+Enter breaks the line, wrap on.
#+begin_src C
static void
on_send (LrgTextEditor *box,
         gpointer       user_data)
{
	g_autofree gchar *msg = lrg_text_editor_get_text (box);

	chat_send (msg);
	lrg_text_editor_set_text (box, "");
}

LrgTextEditor *box = lrg_text_editor_new ();

g_object_set (box, "submit-on-enter", TRUE, "wrap", TRUE,
              "placeholder", "Message #general", "font", "ui", NULL);
g_signal_connect (box, "submit", G_CALLBACK (on_send), NULL);
#+end_src

A console log: read-only, keeps the last 2000 lines and follows new output while the caret sits at the end.
#+begin_src C
LrgTextEditor *log = lrg_text_editor_new ();

lrg_text_editor_set_read_only (log, TRUE);
lrg_text_editor_set_max_lines (log, 2000);
lrg_text_editor_append (log, "\n[info] level loaded");
#+end_src

** Behaviour
:PROPERTIES:
:CUSTOM_ID: text-editor-behaviour
:END:
| Input                              | Action                                                                 |
|------------------------------------+------------------------------------------------------------------------|
| Typing (=TEXT_INPUT=)              | Inserts at the caret, replacing the selection                          |
| Left / Right                       | Character (a selection collapses to its edge); Ctrl: by word           |
| Up / Down                          | Visual row, keeping the column; Ctrl: scroll one row without moving    |
| Home / End                         | Row start (first press: indentation) / row end; Ctrl: document start / end |
| Page Up / Page Down                | A page of rows; the view moves with the caret                          |
| Shift + any of the above           | Extends the selection                                                  |
| Backspace / Delete                 | Character, selection, or word with Ctrl; in space indentation back to the previous tab stop |
| Enter                              | Newline with auto-indent (one level more after =(= =[= ={= or =:=; ={\vert{}}= splits onto three lines) |
| Enter with =submit-on-enter=       | Emits =submit=; Shift+Enter inserts a newline                          |
| Ctrl+Enter without it              | Emits =submit=                                                         |
| Tab / Shift+Tab                    | Tab or spaces to the next stop; with a multi-line selection indent / outdent every line |
| Ctrl+A / C / X / V                 | Select all, copy, cut, paste (Ctrl+Insert / Shift+Insert too)          |
| Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y     | Undo / redo                                                            |
| Escape                             | Clears the selection (otherwise left to the canvas)                    |
| Click / double / triple click      | Caret / word / line; dragging extends in the same unit; Shift+click extends |
| Wheel, Shift+wheel, touch pan      | Vertical / horizontal scrolling with rubber band; flicks coast         |

Key consumption follows the shared shortcut rule: printable keys are consumed only without Ctrl, Alt or Super (AltGr, Ctrl+Alt together, still types), so application shortcuts such as Ctrl+S fire while the editor has focus; the Ctrl chords listed above are consumed. Arrows and editing keys are always consumed so focus does not move. In read-only mode typing, paste, cut and undo do nothing, selection and copy work, and Tab is not consumed.

Typing coalesces into one undo step until the caret moves, 1.5 s of canvas time pass, or a word ends (a space after a non-space). Backspace and Delete runs coalesce the same way. =lrg_text_editor_set_text()= and dropping lines through =max-lines= clear the history.

** Motion
:PROPERTIES:
:CUSTOM_ID: text-editor-motion
:END:
- The caret glides to its new cell on two springs (snappy; instant with =LRG_MOTION_NONE=). The blink is solid for 0.6 s after any activity, then a 1.1 s cosine fade. It is a pure function of the canvas clock and does not keep =lrg_canvas_update()= busy.
- Scrolling uses the shared spring axes with rubber band ends; caret moves scroll the least amount that keeps the caret (plus two columns sideways) in view.
- The first =step()= snaps everything so a new editor does not animate in.

** Pitfalls
:PROPERTIES:
:CUSTOM_ID: text-editor-pitfalls
:END:
- The canvas turns Tab into focus navigation before widgets see it, so Tab / Shift+Tab inside the editor only work when the host delivers =GRL_KEY_TAB= as a key (see the note in the agent report); =lrg_text_editor_indent()= / =lrg_text_editor_outdent()= are always available.
- Layout is a monospace grid: proportional fonts work but drift within a run of text. Wide (CJK) characters take two cells, tabs reach the next tab stop.
- Find is single-line and folds ASCII case only.
- Bracket matching ignores strings and comments and scans at most 200 000 bytes.
- =lrg_text_editor_get_line()= returns internal storage valid until the next edit.
- Do not add children with =lrg_container_add_child()=; the only children are the scrollbar zones.
