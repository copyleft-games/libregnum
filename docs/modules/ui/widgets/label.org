* Label Widget
:PROPERTIES:
:CUSTOM_ID: label-widget
:END:

** Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:
=LrgLabel= displays text. It records the text through the paint pipeline with the theme's UI font, so it batches with shapes and picks its colour and size from the theme.

- Colour: the theme's =TEXT= (=TEXT_MUTED= with the =muted= class, =DISABLED= while insensitive). An explicitly set colour wins over the theme default and over theme style rules, in every state but the disabled one.
- Size: the theme's =FONT_SIZE=, or =FONT_SIZE_TITLE= / =FONT_SIZE_LARGE= / =FONT_SIZE_SMALL= with the =title= / =heading= / =caption= classes. An explicitly set size wins.
- Multi-line text (=\n=): each line is aligned on its own (left, centre or right within the label's width); lines are 1.2 font sizes apart.
- When the label is allocated taller than its text (for example stretched in a row next to a button) the text block is centred vertically; otherwise it starts at the top edge.
- Labels are not focusable and do not consume input.
- The legacy immediate path (=lrg_widget_draw()=) skips labels that lie wholly outside the render target, so long lists stay cheap.

** Creation
:PROPERTIES:
:CUSTOM_ID: creation
:END:
#+begin_src C
LrgLabel *title = lrg_label_new ("Settings");
LrgLabel *hint = lrg_label_new ("Changes apply immediately.");

lrg_widget_add_class (LRG_WIDGET (title), "title");
lrg_widget_add_class (LRG_WIDGET (hint), "muted");
#+end_src

** Properties
:PROPERTIES:
:CUSTOM_ID: properties
:END:
| Property    | Type               | Default         | Notes                                                    |
|-------------+--------------------+-----------------+----------------------------------------------------------|
| =text=      | string             | =NULL=          | May contain newlines; changing it queues a layout        |
| =font=      | =GrlFont=          | =NULL=          | =NULL= uses the theme's UI font                          |
| =font-size= | float              | 20 (reported)   | Theme size (by class) until set                          |
| =color=     | =GrlColor=         | legacy white    | Theme =TEXT= / =TEXT_MUTED= until set                    |
| =alignment= | =LrgTextAlignment= | =LEFT=          | Horizontal alignment of each line                        |
| =ellipsize= | boolean            | =FALSE=         | Given less width than its text, draw the first line cut with "…" instead of past its edge (since 0.8.6) |

=font-size= and =color= keep their old default values in their getters, but the label draws with the theme until a value is set explicitly. Precedence, lowest to highest: widget defaults < theme style rules < explicit setters < =lrg_widget_set_part_look()= overrides (see [[file:../styling.org::#styling-precedence][UI styling: precedence]]).

** Signals
:PROPERTIES:
:CUSTOM_ID: signals
:END:
The label has no signals of its own (see =LrgWidget= for =state-changed=).

** Parts and states
:PROPERTIES:
:CUSTOM_ID: parts-and-states
:END:
| Part    | What it is | Resting                          | Disabled   |
|---------+------------+----------------------------------+------------|
| =LABEL= | The text   | =TEXT= (or explicit =color=)     | =DISABLED= |

The label has no surface; put it in an =LrgPanel= for a background.

** Style classes
:PROPERTIES:
:CUSTOM_ID: style-classes
:END:
| Class     | Effect                          |
|-----------+---------------------------------|
| =muted=   | =TEXT_MUTED= colour             |
| =title=   | =FONT_SIZE_TITLE= (32 by default) |
| =heading= | =FONT_SIZE_LARGE= (24)          |
| =caption= | =FONT_SIZE_SMALL= (12)          |

:PROPERTIES:
:CUSTOM_ID: theming
:END:

metrics:
  font-size-title: 40

  # Accent-coloured headings
  - widget: LrgLabel
    class: heading
    part: label
    foreground: "#cba6f7"

  # A "warning" class of your own
  - widget: LrgLabel
    class: warning
    part: label
    foreground: "#fbbf24"
#+end_src

** Keyboard, mouse and gamepad
:PROPERTIES:
:CUSTOM_ID: keyboard-mouse-gamepad
:END:
None: labels are display-only and never take focus. Clicks pass to the parent.

** Example
:PROPERTIES:
:CUSTOM_ID: example
:END:
#+begin_src C
LrgVBox  *card = lrg_vbox_new ();
LrgLabel *name = lrg_label_new ("Captain Mira");
LrgLabel *bio = lrg_label_new ("Level 12 navigator\nLast seen: Kepler Station");

lrg_widget_add_class (LRG_WIDGET (name), "heading");
lrg_widget_add_class (LRG_WIDGET (bio), "muted");
lrg_label_set_alignment (bio, LRG_TEXT_ALIGN_CENTER);

lrg_container_add_child (LRG_CONTAINER (card), LRG_WIDGET (name));
lrg_container_add_child (LRG_CONTAINER (card), LRG_WIDGET (bio));
#+end_src
