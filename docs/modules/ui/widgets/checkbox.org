* Checkbox Widget
:PROPERTIES:
:CUSTOM_ID: checkbox-widget
:END:

** Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:
=LrgCheckbox= is a two-state toggle with an optional label to the right of its indicator. The =style= property picks the indicator:

- =LRG_CHECKBOX_STYLE_CHECK= (default): a rounded box. When checked it fills with =ACCENT= and a tick of two thick strokes draws itself in.
- =LRG_CHECKBOX_STYLE_RADIO=: a circle; a dot grows from the centre when checked. (Grouping radios into exclusive sets is up to the caller: uncheck the others in =toggled=.)
- =LRG_CHECKBOX_STYLE_SWITCH=: a pill-shaped track (=TRACK= off, =ACCENT= on) with a round =HANDLE= knob that slides across on a spring.

A "check" spring follows the checked state and drives every transition: the tick length, the dot radius, the knob position (with the theme's overshoot for bouncy motion) and the cross-fade between the unchecked and checked colours. Hover and press blend on the widget's own springs. The spring is stepped by the widget's =step()= with the canvas frame time (=lrg_canvas_update()=), never while painting, and =lrg_canvas_update()= returns =TRUE= until it settles. Before its first frame a checkbox shows its state directly, and that first step snaps the spring, so freshly built screens do not animate in; changes after that animate. =LRG_WIDGET_STATE_CHECKED= mirrors =checked=, so theme rules can target it.

** Creation
:PROPERTIES:
:CUSTOM_ID: creation
:END:
#+begin_src C
LrgCheckbox *subtitles = lrg_checkbox_new ("Subtitles");
LrgCheckbox *vsync = lrg_checkbox_new_with_style ("V-Sync", LRG_CHECKBOX_STYLE_SWITCH);

lrg_checkbox_set_checked (vsync, TRUE);
g_signal_connect (vsync, "toggled", G_CALLBACK (on_vsync_toggled), NULL);
#+end_src

** Properties
:PROPERTIES:
:CUSTOM_ID: properties
:END:
| Property      | Type               | Default        | Notes                                                       |
|---------------+--------------------+----------------+-------------------------------------------------------------|
| =checked=     | boolean            | =FALSE=        | Mirrored by =LRG_WIDGET_STATE_CHECKED=                      |
| =label=       | string             | =NULL=         | Text to the right; changing it queues a layout              |
| =style=       | =LrgCheckboxStyle= | =CHECK=        | =CHECK=, =RADIO= or =SWITCH=                                |
| =box-size=    | float              | 20 (reported)  | Indicator height; theme =CHECK_SIZE= until set (switch is 1.75× wide) |
| =spacing=     | float              | 8 (reported)   | Gap to the label; theme =SPACING= until set                 |
| =font-size=   | float              | 20 (reported)  | Theme =FONT_SIZE= until set                                 |
| =box-color=   | =GrlColor=         | legacy grey    | Unchecked fill; theme =CONTROL= (=TRACK= for switches) until set |
| =check-color= | =GrlColor=         | legacy green   | Checked fill; theme =ACCENT= until set                      |
| =text-color=  | =GrlColor=         | legacy white   | Label colour; theme =TEXT= until set                        |

The legacy properties keep their old default values in their getters, but the checkbox draws with the theme until a value is set explicitly. An explicitly set value then wins over the theme default and over theme style rules (hover and pressed shades are derived from it; an explicit check colour also outlines and tints the glow of the checked indicator, and an explicit text colour applies in every state but the disabled one). Precedence, lowest to highest: widget defaults < theme style rules < explicit setters < =lrg_widget_set_part_look()= overrides (see [[file:../styling.org::#styling-precedence][UI styling: precedence]]).

=lrg_checkbox_get_check_progress()= reports the check spring (0 unchecked, 1 checked) for custom drawing or tests.

** Style classes
:PROPERTIES:
:CUSTOM_ID: style-classes
:END:
No built-in classes: the indicator kind is the =style= property. Add your own classes and target them with rules.

** Keyboard, mouse and gamepad
:PROPERTIES:
:CUSTOM_ID: keyboard-mouse-gamepad
:END:
- Focusable: Tab, arrows and the D-pad reach it; a click focuses it.
- A left click anywhere on the widget (indicator or label) toggles it on release.
- Enter, Space and gamepad A toggle the focused checkbox.

** Example
:PROPERTIES:
:CUSTOM_ID: example
:END:
#+begin_src C
static void
on_mode_toggled (LrgCheckbox *radio,
                 gboolean     checked,
                 gpointer     user_data)
{
    GPtrArray *group = user_data;
    guint      i;

    /* Exclusive radio group: turning one on turns the others off */
    if (!checked)
        return;
    for (i = 0; i < group->len; i++)
        if (g_ptr_array_index (group, i) != radio)
            lrg_checkbox_set_checked (g_ptr_array_index (group, i), FALSE);
}

static void
build_modes (LrgContainer *box,
             GPtrArray    *group)
{
    const gchar *names[] = { "Windowed", "Borderless", "Fullscreen" };
    guint        i;

    for (i = 0; i < G_N_ELEMENTS (names); i++)
    {
        LrgCheckbox *radio = lrg_checkbox_new_with_style (names[i], LRG_CHECKBOX_STYLE_RADIO);

        g_ptr_array_add (group, radio);
        g_signal_connect (radio, "toggled", G_CALLBACK (on_mode_toggled), group);
        lrg_container_add_child (box, LRG_WIDGET (radio));
    }
    lrg_checkbox_set_checked (g_ptr_array_index (group, 0), TRUE);
}
#+end_src
