* Toast and Toast Queue
:PROPERTIES:
:CUSTOM_ID: toast-widget
:END:
=LrgToast= is a short notification card. It has a title, a muted message, a coloured stripe for its kind, and a thin hairline along the bottom that shrinks as its time runs out. =LrgToastQueue= is a see-through layer that covers the canvas and shows toasts in a corner. Cards rise about 14 units into place while they fade in. They fade out where they are when they expire or are clicked, and the rest of the stack glides into the freed space.

** Creation
:PROPERTIES:
:CUSTOM_ID: toast-creation
:END:
#+begin_src c
/* once, after the rest of the UI so it is on top */
LrgToastQueue *toasts = lrg_toast_queue_new ();

/* The overlay layer keeps toasts above dialogs and their veil; adding
 * the queue as an ordinary child also works, but a modal dialog then
 * dims it */
lrg_canvas_add_overlay (canvas, LRG_WIDGET (toasts));

/* whenever something happens */
g_autoptr(LrgToast) toast = lrg_toast_new ("Saved", "Your level was written to disk.");
lrg_toast_set_kind (toast, LRG_TOAST_KIND_SUCCESS);
lrg_toast_queue_show (toasts, toast);   /* the queue takes its own reference */
#+end_src

A queue with no size of its own sizes itself to its parent and follows the parent's size. Because it is pointer-transparent (=lrg_widget_set_pointer_transparent()=), clicks on its empty areas reach the widgets underneath; only the cards catch the pointer.

*** Buttons
:PROPERTIES:
:CUSTOM_ID: toast-buttons
:END:
=lrg_toast_add_button (toast, "Undo", "app.undo")= adds a small pill to a row along the bottom of the card ("Undo", "View", "Retry"). Buttons are laid out from the trailing corner (right, or left in right-to-left layouts), in the order they were added. The action is a GIO detailed action name ("app.undo", "app.open::recent", "app.zoom(2)"); it is activated with =lrg_widget_activate_action()= on the toast, so it is found on the queue, its ancestors or the canvas, like menu and shortcut actions. A button click only counts when the press and the release land on the same button. Pass =NULL= as the action to handle the click yourself in =::button-clicked=.

#+begin_src C
LrgToast *toast = lrg_toast_new ("3 nodes deleted", NULL);

lrg_toast_add_button (toast, "Undo", "app.undo");
lrg_toast_set_default_action (toast, "app.show-history");
lrg_toast_queue_show (queue, toast);
#+end_src

*** Dismiss reasons
:PROPERTIES:
:CUSTOM_ID: toast-dismiss-reasons
:END:
| =LrgToastDismissReason= | Cause |
|-------------------------+-------|
| =LRG_TOAST_DISMISS_REASON_NONE= | Still up |
| =LRG_TOAST_DISMISS_REASON_EXPIRED= | Its duration ran out |
| =LRG_TOAST_DISMISS_REASON_CLICKED= | The card was clicked (after =default-action= ran) |
| =LRG_TOAST_DISMISS_REASON_BUTTON= | A button was clicked |
| =LRG_TOAST_DISMISS_REASON_PROGRAMMATIC= | =lrg_toast_dismiss()= (also what =lrg_toast_queue_clear()= and replace mode use) |

The toast keeps its own clock. =lrg_toast_advance (toast, seconds)= runs it; the queue calls it every frame. The clock pauses while the pointer is over the card, so the player can finish reading. =lrg_toast_get_elapsed()= and =lrg_toast_get_remaining_fraction()= expose it. Every card is 340 units wide, so stacks line up.

*** Modes
:PROPERTIES:
:CUSTOM_ID: toast-modes
:END:
| Mode | Behaviour |
|------+-----------|
| =LRG_TOAST_MODE_REPLACE= | A new toast dismisses the one showing; the old card fades out in place while the new one rises over it |
| =LRG_TOAST_MODE_SEQUENCE= | One at a time, in order: the next one appears once the current card has fully faded out |
| =LRG_TOAST_MODE_STACK= | Up to =max-visible= cards; the newest is nearest the corner, and the rest wait and come in as places free up |

*** Time
:PROPERTIES:
:CUSTOM_ID: toast-time
:END:
=lrg_toast_queue_advance (queue, seconds)= runs the visible toasts' clocks and the enter, leave and re-flow springs. It removes cards that have faded out and brings in waiting toasts. With =auto-advance= on (the default), the queue's =step()= calls it every frame with the canvas delta time (=lrg_canvas_update (canvas, delta_time)=, called by =lrg_canvas_process_input()=); painting never advances time, so drawing twice cannot double the clock. =lrg_canvas_update()= returns =TRUE= while a card enters, leaves or re-flows, while a visible toast with a duration counts down, and while toasts wait; a toast without a duration that has finished entering does not keep the canvas busy. An explicit =lrg_toast_queue_advance()= call made while =auto-advance= is on adds to the frame clock (it skips ahead), it does not replace it. Turn =auto-advance= off to drive time only yourself: toasts that should freeze while the game is paused, or manual control; then frames do not move the toasts and the queue never reports itself busy. =lrg_toast_queue_clear()= dismisses everything, showing or waiting. =lrg_toast_queue_get_visible_toast (queue, i)= returns the i-th live card, oldest first.

** Input
:PROPERTIES:
:CUSTOM_ID: toast-input
:END:
Toasts never take keyboard focus, so they never interrupt the player's navigation. Clicking a card dismisses it early, and hovering pauses its timer. Clicks on the rest of the queue pass through to the UI below.

** Example
:PROPERTIES:
:CUSTOM_ID: toast-example
:END:
#+begin_src c
typedef struct
{
	LrgCanvas     *canvas;
	LrgToastQueue *toasts;
} Hud;

static void
hud_init (Hud *hud)
{
	hud->canvas = lrg_canvas_new ();
	lrg_widget_set_size (LRG_WIDGET (hud->canvas), 1280.0f, 720.0f);

	/* ... the rest of the HUD ... */

	hud->toasts = lrg_toast_queue_new ();
	lrg_toast_queue_set_mode (hud->toasts, LRG_TOAST_MODE_STACK);
	lrg_toast_queue_set_max_visible (hud->toasts, 4);
	lrg_toast_queue_set_toast_valign (hud->toasts, LRG_ALIGN_START);   /* top-right */
	lrg_canvas_add_overlay (hud->canvas, LRG_WIDGET (hud->toasts));
	g_object_unref (hud->toasts);   /* the canvas owns it */
}

static void
hud_notify (Hud          *hud,
            LrgToastKind  kind,
            const gchar  *title,
            const gchar  *message,
            gdouble       seconds)
{
	g_autoptr(LrgToast) toast = lrg_toast_new (title, message);

	lrg_toast_set_kind (toast, kind);
	lrg_toast_set_duration (toast, seconds);
	lrg_toast_queue_show (hud->toasts, toast);
}

/* usage */
hud_notify (&hud, LRG_TOAST_KIND_SUCCESS, "Achievement", "First blood", 3.5);
hud_notify (&hud, LRG_TOAST_KIND_DANGER, "Disconnected", "Trying to reconnect...", 0.0);

/* every frame */
lrg_canvas_handle_input (hud.canvas);
lrg_canvas_render (hud.canvas);
#+end_src
