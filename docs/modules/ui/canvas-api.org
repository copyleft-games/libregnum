* LrgCanvas API
:PROPERTIES:
:CUSTOM_ID: canvas-api
:END:
#+begin_quote
*[[file:../../index.org][Home]]* > *[[file:../index.org][Modules]]* > *[[file:index.org][UI]]* > LrgCanvas API
#+end_quote

=LrgCanvas= (=src/ui/lrg-canvas.h=, final type deriving from =LrgContainer=) is the root of a widget tree. Once per frame it turns an input frame into UI events, advances every widget's springs, lays out what changed, records the tree (plus the popup layer) into its own =LrgPaintList= and renders it with the shared paint renderer. =LrgCanvasInput= (=src/ui/lrg-canvas-input.h=) is the plain value struct that describes one frame of input.

This page lists every public function with its exact signature, ownership and behaviour. For the concepts behind them see:

- [[file:widgets/canvas.org][Canvas widget page]]: creating a canvas, adding widgets, the frame loop.
- [[file:input-and-focus.org][Input, focus and popups]]: dispatch order, bubbling, capture, spatial navigation, modality, testing with hand-built frames.
- [[file:../paint/paint-list.org][LrgPaintList]]: what =lrg_canvas_record()= produces.

** Rendering and recording
:PROPERTIES:
:CUSTOM_ID: canvas-api-rendering
:END:
| Function | Signature | Notes |
|----------+-----------+-------|
| =lrg_canvas_render= | =void lrg_canvas_render (LrgCanvas *self);= | Record + draw. Call once per frame in the draw phase, inside =BeginDrawing()= (and inside =BeginMode2D()= / a render texture if the UI should follow it) |
| =lrg_canvas_record= | =LrgPaintList * lrg_canvas_record (LrgCanvas *self);= | Lays out the tree and records it without drawing. (transfer none): the canvas's own list, valid until the next record. Works headless, which is what tests use |
| =lrg_canvas_get_paint_list= | =LrgPaintList * lrg_canvas_get_paint_list (LrgCanvas *self);= | (transfer none): the list recorded by the last render or record, for inspection and profiling |
| =lrg_canvas_update= | =gboolean lrg_canvas_update (LrgCanvas *self, gfloat delta_time);= | Advances every widget's springs and appear animations by =delta_time= seconds. =lrg_canvas_process_input()= already calls it with the frame's =delta_time=; call it yourself only when you skip input processing. Returns =TRUE= while something is still animating (useful to stop redrawing an idle tool UI) |
| =lrg_canvas_get_paint_background= | =gboolean lrg_canvas_get_paint_background (LrgCanvas *self);= | =TRUE= when the canvas fills its own rectangle with the theme's =LRG_THEME_COLOR_WINDOW= before painting the tree |
| =lrg_canvas_set_paint_background= | =void lrg_canvas_set_paint_background (LrgCanvas *self, gboolean paint_background);= | Off by default so a game scene drawn first shows through the UI. Turn it on for full-screen menus and tool windows so the theme's window colour is the backdrop (it is the first instance of the list, so it costs no extra draw call) |

** Input
:PROPERTIES:
:CUSTOM_ID: canvas-api-input
:END:
| Function | Signature | Notes |
|----------+-----------+-------|
| =lrg_canvas_handle_input= | =void lrg_canvas_handle_input (LrgCanvas *self);= | Polls graylib (=lrg_canvas_input_poll()= with =GetFrameTime()=) and calls =lrg_canvas_process_input()=. Needs an open window. Call once per frame before rendering |
| =lrg_canvas_process_input= | =void lrg_canvas_process_input (LrgCanvas *self, const LrgCanvasInput *input);= | Turns one frame into UI events and dispatches them, then updates springs. =input->pointer_x= / =pointer_y= must already be in canvas coordinates: no pointer transform is applied here. Drive it from your own input layer, a replay or a test |
| =lrg_canvas_set_default_pointer_transform= | =void lrg_canvas_set_default_pointer_transform (LrgCanvasPointerTransform transform, gpointer user_data);= | Process-wide: =transform= (nullable, scope notified) maps window pointer coordinates into canvas coordinates for every canvas in =lrg_canvas_handle_input()= / =lrg_canvas_input_poll()=. =NULL= restores raw coordinates. Installed by whatever presents a scaled render target, e.g. the 2D game template's virtual resolution |
| =lrg_canvas_widget_at_point= | =LrgWidget * lrg_canvas_widget_at_point (LrgCanvas *self, gfloat x, gfloat y);= | (transfer none) (nullable): the deepest visible, enabled widget containing the point (depth-first, last child on top). Open popups are searched first, newest first; below a modal popup the result is =NULL= (its veil swallows the point). Pointer-transparent widgets with no hit child are skipped, and the canvas itself is never returned |
| =lrg_canvas_get_hovered_widget= | =LrgWidget * lrg_canvas_get_hovered_widget (LrgCanvas *self);= | (transfer none) (nullable): the widget under the pointer after the last processed frame |

=LrgCanvasPointerTransform= is =void (*) (gfloat *x, gfloat *y, gpointer user_data)=: both coordinates are (inout).

/* Arrows steer the ship while the HUD is up; restore menu navigation on pause */

on_pause_changed (Game *game, gboolean paused)
{
	if (lrg_canvas_get_navigation_enabled (game->hud) != paused)
		lrg_canvas_set_navigation_enabled (game->hud, paused);
}

* LrgCanvasInput
:PROPERTIES:
:CUSTOM_ID: canvas-input-api
:END:
=LrgCanvasInput= is a value struct; its fields (pointer, button masks, wheel, up to =LRG_CANVAS_INPUT_MAX_KEYS= (16) keys and characters, modifiers, =nav=, =activate=, =cancel=, =delta_time=) are described in [[file:input-and-focus.org::#input-frames][input frames]]. C code keeps it on the stack and resets it with =lrg_canvas_input_init()= every frame.

** Overlay layer
:PROPERTIES:
:CUSTOM_ID: canvas-api-overlay
:END:
The overlay layer sits above the widget tree, every popup and the veil of a modal popup: it is painted last and hit-tested first. Put notifications (an =LrgToastQueue=), HUD layers or custom cursors there so they stay visible and bright while a dialog is open. Overlay widgets are parented to the canvas (coordinates, theme) but are not children: focus navigation never visits them, so keep them non-interactive or pointer-transparent layers with clickable pieces (like toast cards).

| Function | Signature | Notes |
|----------+-----------+-------|
| =lrg_canvas_add_overlay= | =void lrg_canvas_add_overlay (LrgCanvas *self, LrgWidget *widget);= | =widget= must have no parent; the canvas takes a reference. Laid out, stepped, painted (above popups) and hit-tested (before popups) every frame. |
| =lrg_canvas_remove_overlay= | =void lrg_canvas_remove_overlay (LrgCanvas *self, LrgWidget *widget);= | Releases the widget and unparents it; drops any pointer capture inside it. No-op for widgets not in the layer. |
| =lrg_canvas_get_n_overlays= | =guint lrg_canvas_get_n_overlays (LrgCanvas *self);= | Number of overlay widgets. |

#+begin_src c
LrgToastQueue *toasts = lrg_toast_queue_new ();

/* Toasts stay above dialogs and their veil */
lrg_canvas_add_overlay (canvas, LRG_WIDGET (toasts));
g_object_unref (toasts);
#+end_src

** Boxed type
:PROPERTIES:
:CUSTOM_ID: canvas-input-api-boxed
:END:
=LrgCanvasInput= is registered as a =GBoxed= type so bindings and =GValue= can carry a frame (for example a replay recorder that stores frames in a =GPtrArray=). The struct holds no pointers, so copies are flat and independent.

| Function | Signature | Notes |
|----------+-----------+-------|
| =lrg_canvas_input_get_type= | =GType lrg_canvas_input_get_type (void) G_GNUC_CONST;= | The boxed =GType=, also =LRG_TYPE_CANVAS_INPUT= |
| =lrg_canvas_input_new= | =LrgCanvasInput * lrg_canvas_input_new (void);= | (transfer full): a heap frame already reset with =lrg_canvas_input_init()= |
| =lrg_canvas_input_copy= | =LrgCanvasInput * lrg_canvas_input_copy (const LrgCanvasInput *self);= | (transfer full): =g_memdup2()= of the whole struct, key and character arrays included. =self= must not be =NULL= |
| =lrg_canvas_input_free= | =void lrg_canvas_input_free (LrgCanvasInput *self);= | Frees a heap frame; =self= is (nullable). =g_autoptr (LrgCanvasInput)= is supported |

#+begin_src c
/* Record frames while playing, replay them later in a test */
static void
recorder_capture (GPtrArray *frames, const LrgCanvasInput *frame)
{
	g_ptr_array_add (frames, lrg_canvas_input_copy (frame));
}

static void
recorder_replay (GPtrArray *frames, LrgCanvas *canvas)
{
	guint i;

	for (i = 0; i < frames->len; i++)
		lrg_canvas_process_input (canvas, (const LrgCanvasInput *) g_ptr_array_index (frames, i));
}
