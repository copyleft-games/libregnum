* Post-Processing Module
:PROPERTIES:
:CUSTOM_ID: post-processing-module
:END:
The post-processing module runs screen-space effects over a finished frame: the scene is captured into an offscreen (HDR when available) target, a chain of shader passes runs over it, and the result is composited into the window or a render texture. Looks can be authored as data (=.rpost= post stacks) and blended for post volumes.

** Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:
- *LrgPostProcessor* runs the chain: capture targets (RGBA16F, RGBA8 fallback), ping-pong passes, composite, resize, quality tier ([[file:post-processor.org][post-processor.org]]).
- *LrgPostEffect* is the base class of every effect, with the apply contract and helpers to write your own ([[file:post-effect.org][post-effect.org]]).
- *LrgPostStack* is a look as data: the =.rpost= format, building into a processor, blending two looks by weight ([[file:post-stack.org][post-stack.org]]).
- *Built-in effects*: bloom, tonemap, vignette, colour grade, FXAA, film grain, screen shake, heat haze ([[file:effects.org][effects.org]]), the colour-blindness filter ([[file:accessibility.org][accessibility.org]]), sharpen ([[file:sharpen.org][sharpen.org]]) and palettize ([[file:palettize.org][palettize.org]]).
- *LrgColorLut* is a 3D colour lookup table (=.cube=) that [[file:effects.org::#lrgcolorgrade][LrgColorGrade]] applies after its grade ([[file:color-lut.org][color-lut.org]]).

** Quick start
:PROPERTIES:
:CUSTOM_ID: quick-start
:END:
#+begin_src C
g_autoptr(GError)           error = NULL;
g_autoptr(LrgPostProcessor) post = lrg_post_processor_new (GetRenderWidth (), GetRenderHeight ());
g_autoptr(LrgPostStack)     look = lrg_post_stack_new_from_file ("looks/default.rpost", &error);

if (look == NULL || !lrg_post_stack_build (look, post, &error))
	g_warning ("%s", error->message);
lrg_post_processor_set_auto_resize (post, TRUE);

/* each frame */
BeginDrawing ();
lrg_post_processor_begin_capture (post);
ClearBackground (BLACK);
draw_scene ();
lrg_post_processor_end_capture (post);
lrg_post_processor_render (post, GetFrameTime ());
draw_hud ();
EndDrawing ();

/* at exit, before CloseWindow () */
lrg_post_processor_release (post);
#+end_src
with =looks/default.rpost=:
#+begin_src yaml
version: 1
effects:
  - type: bloom
    params: { threshold: 1.0, intensity: 0.8 }
  - type: tonemap
    params: { operator: aces }
  - type: vignette
    params: { intensity: 0.3 }
  - type: fxaa
#+end_src

** Pipeline
:PROPERTIES:
:CUSTOM_ID: effect-pipeline
:END:
1. *Capture*: =begin_capture()= binds the processor's target 0; the scene draws into it; =end_capture()= rebinds the previous target.
2. *Chain*: every enabled effect, lowest priority first, reads the previous image and writes the other ping-pong target, blending off (HDR values and alpha pass through).
3. *Composite*: =render()= draws the result over the bound target, alpha blended and scaled to it.

Renderers that own their scene target call =lrg_post_processor_process()= instead and draw the returned texture themselves.

** Built-in effects
:PROPERTIES:
:CUSTOM_ID: built-in-effects
:END:
| Effect | Type name | Look | Use |
|--------+-----------+------+-----|
| =LrgBloom= | =bloom= | Glow around bright areas | Fire, magic, emissives, sun glints |
| =LrgTonemap= | =tonemap= | HDR to display (ACES, filmic, Reinhard) + exposure | Any HDR scene |
| =LrgVignette= | =vignette= | Darker/tinted edges | Focus, cinematic, low health |
| =LrgColorGrade= | =color-grade= | Exposure, white balance, lift/gamma/gain, LUT | Mood, style |
| =LrgFxaa= | =fxaa= | Smoothed edges | Anti-aliasing |
| =LrgFilmGrain= | =film-grain= | Animated grain | Film, horror, retro |
| =LrgScreenShake= | =screen-shake= | Trauma-driven shake | Impacts, explosions |
| =LrgHeatHaze= | =heat-haze= | Horizon shimmer | Deserts, hot days |
| =LrgColorblindFilter= | =colorblind-filter= | Daltonize/simulate | Accessibility |
| =LrgSharpen= | =sharpen= | Contrast-adaptive sharpening | After upscaling or TAA |
| =LrgPalettize= | =palettize= | Palette, ordered dither | Retro 8-bit look |
