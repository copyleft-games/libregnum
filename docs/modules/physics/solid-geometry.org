* LrgSolidGeometry - Closed Solid Collision
:PROPERTIES:
:CUSTOM_ID: lrgsolidgeometry---closed-solid-collision
:END:
Retained closed solids. A point is outside, touching or inside the volume. =LrgCollisionMesh= answers triangle-surface distance and does not provide this result. =LrgRigidBody= remains a 2D simulation. This module is collision only: no mass, inertia, joints, sleep or timestep.

Y is up. A sphyl is a capsule whose cylinder axis is local +Y. A flat cylinder is a separate shape whose axis is local +Z and whose ends are disks; it is not a sphyl and it is not rotated onto +Y. Transforms are column-major, translation in elements 12..14, and must be a rotation plus a positive uniform scale. Nonuniform scale, reflection, shear and non-finite values are rejected and no object is published.

** Types
:PROPERTIES:
:CUSTOM_ID: types
:END:
- =LrgSolidGeometry= - *Final GObject Class*, =LRG_TYPE_SOLID_GEOMETRY=, GIR =Libregnum.SolidGeometry=. Immutable after construction.
- =LrgCollisionModel= - *Final GObject Class*, =LRG_TYPE_COLLISION_MODEL=, GIR =Libregnum.CollisionModel=. One geometry, one world transform, one filter.
- =LrgSolidWorld= - *Final GObject Class*, =LRG_TYPE_SOLID_WORLD=, GIR =Libregnum.SolidWorld=. Generation-tagged slots.
- =LrgSolidHandle= - plain struct (=index=, =generation=). A zeroed handle is never issued.
- =LrgSolidContact= - overlap depth, unit normal and a point on the first solid. The normal translates the second solid out of the first.
- =LrgSolidHit= - sweep time in 0..1, unit normal and contact point. The normal pushes the moving sphere out of the static solid.
- *Headers* - =physics/lrg-solid-geometry.h=, =physics/lrg-collision-model.h=

An aggregate of one sphere stays an aggregate. Child geometry is referenced. The aggregate copies already-baked primitives, so a later change of a child is impossible: children are immutable.

** Queries
:PROPERTIES:
:CUSTOM_ID: queries
:END:
| Function | Result |
|----------+--------|
| =lrg_solid_geometry_classify_point()= | =OUTSIDE=, =TOUCHING= (within 1e-5) or =INSIDE= |
| =lrg_solid_geometry_overlap()= | contact or separation |
| =lrg_solid_geometry_contains()= | every inner primitive is inside one outer primitive |
| =lrg_solid_geometry_sweep_sphere()= | first contact of a moving sphere, or a miss |
| =lrg_solid_world_add()= / =remove()= / =get_model()= | generation-tagged slots |
| =lrg_solid_world_classify_point()= / =overlap()= / =contains()= / =sweep_sphere()= | the same queries after the model transform |

Supported overlap pairs are sphere-sphere, sphere-box, sphere-sphyl, sphere-convex, sphere-cylinder, box-box, box-convex, sphyl-sphyl and convex-convex. Sphyl-sphyl uses the exact closest points of the two capsule segments. Sphere-cylinder uses the signed distance to the flat cylinder. Box and convex pairs test every face normal and every unique edge-direction cross product. A hull that would need more than 128 unique edges fails the query instead of guessing an overlap. A box against a sphyl, a sphyl against a convex hull, and any cylinder pair other than sphere-cylinder return =G_IO_ERROR_NOT_SUPPORTED=. An aggregate that hides one of those pairs fails the whole query and does not write the outputs.

Containment of a single outer primitive is exact for the implemented pairs. A sphere, box, convex hull or sphyl inside a cylinder uses the cylinder as a convex volume. A cylinder inside a sphere, box or convex hull uses the cylinder support function. A cylinder inside a sphyl or another cylinder returns =G_IO_ERROR_NOT_SUPPORTED=. An aggregate used as the outer solid (a union) returns =G_IO_ERROR_NOT_SUPPORTED=. An aggregate inner is contained only when every primitive is contained. A sphere sweep against a cylinder returns =G_IO_ERROR_NOT_SUPPORTED=.

A world sphere sweep requires the moving model to bake to exactly one sphere. The caller supplies the motion vector. It is not scaled again by the model transform. A filter miss is a successful separation, not an error. Hull sweeps advance at most 64 steps. If those steps stay inside the segment without reaching the surface, the sweep reports a hit at the current time so the sphere does not tunnel.

** Handles
:PROPERTIES:
:CUSTOM_ID: handles
:END:
=add= reuses the lowest empty slot and then bumps its generation. Generation 0 is never issued. =remove= drops the world's reference and keeps the generation, so the same handle removes twice. The next occupant bumps the generation. A stale handle returns =G_IO_ERROR_NOT_FOUND=. =set_transform= copies the previous decomposed transform back when the new matrix is rejected.

The world holds a reference to each live model. The model holds a reference to its geometry. Destroying the world does not destroy a geometry the caller still holds.

** What this is not
:PROPERTIES:
:CUSTOM_ID: what-this-is-not
:END:
This is not articulated Karma, not =PHYS_KarmaRagDoll=, and not a decoded =.ka= asset. Triangle meshes, character capsules and asset identifiers are different types and must not be passed off as these solids. A flat cylinder is not a stand-in for a capsule, and a capsule is not a stand-in for a flat cylinder. A game that needs a Karma block transition still has to stage a real descriptor before it may report success.
