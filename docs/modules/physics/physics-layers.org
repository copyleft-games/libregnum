#+title: Physics Layers - Collision Layers and the Collide Matrix
#+description: LrgPhysicsLayers and LrgPhysicsSettings in libregnum 0.9.0: 32 named collision layers, a symmetric collide matrix, per-body layer and mask, the world settings, and the physics: block of project.ryaml that games and play-in-editor apply.

* Physics Layers
:PROPERTIES:
:CUSTOM_ID: physics-layers
:END:
=LrgPhysicsLayers= (=src/physics/lrg-physics-layers.h=, 0.9.0) is the project-wide table that decides which bodies may collide. It holds up to 32 *named layers* (slots 0 to 31) and a *symmetric collide matrix* (does layer A collide with layer B?). Every body has one *object layer* and a *mask* of the layers it accepts. The table is project data: it is stored in the =physics:= block of =project.ryaml=, not in a separate file, and the world applies it to every pair its broadphase finds ([[file:broadphase.org][LrgBroadphase]]).

Next to the table the same block holds the project's *world settings* (=LrgPhysicsSettings=, same header): gravity, the fixed substep and its cap, solver iterations and the sleep threshold. Since 0.9.0 the runtime honours the whole block: =lrg_level_load_world3d()= / =lrg_level_instantiate_3d()= find the level's =project.ryaml= and configure the world's physics from it, and play-in-editor uses the open project's settings ([[#runtime][The block at runtime]]).

** Concepts
:PROPERTIES:
:CUSTOM_ID: concepts
:END:
*** The pair rule
:PROPERTIES:
:CUSTOM_ID: pair-rule
:END:
Two bodies A (layer =la=, mask =ma=) and B (layer =lb=, mask =mb=) may collide when all three hold:

1. the matrix lets =la= and =lb= collide,
2. =ma= has the bit of =lb= (=LRG_PHYSICS_LAYER_BIT (lb)=),
3. =mb= has the bit of =la=.

=lrg_physics_layers_should_collide (layers, la, ma, lb, mb)= is exactly this rule (and with a =NULL= table only the two mask tests apply). The matrix is the project's policy ("debris never hits characters"); the masks are per body exceptions ("this one trigger only sees the player"). A body that should follow the matrix alone uses the mask =LRG_PHYSICS_LAYERS_ALL=.

The matrix is always symmetric: setting a cell also sets its mirror, so "A collides with B" and "B collides with A" cannot disagree. Rows are stored as 32-bit masks, so the test is one AND (=lrg_physics_layers_get_collide_mask()= returns a row).

*** Names and indices
:PROPERTIES:
:CUSTOM_ID: names
:END:
A slot can be named or unnamed. Unnamed slots still work (by index) and collide with everything until you edit their row. Names are unique, non-empty, not ="all"= and not a number, so a reference in a file or a level (=lrg_physics_layers_resolve()=) is unambiguous: a decimal string is an index, anything else is a name. =lrg_physics_layers_get_count()= is one past the highest named slot, the number of rows an editor shows.

*** The default layers
:PROPERTIES:
:CUSTOM_ID: defaults
:END:
=lrg_physics_layers_new_default()= / =lrg_physics_layers_reset_default()= name slots 0 to 8 after the =LrgPhysicsLayer= enum and clear nine cells of the matrix:

| Index | Name (enum) | Meant for |
|-------+-------------+-----------|
| 0 | =default= (=LRG_PHYSICS_LAYER_DEFAULT=) | Anything not classified |
| 1 | =static= (=LRG_PHYSICS_LAYER_STATIC=) | Level geometry |
| 2 | =dynamic= (=LRG_PHYSICS_LAYER_DYNAMIC=) | Props and rigid bodies |
| 3 | =kinematic= (=LRG_PHYSICS_LAYER_KINEMATIC=) | Moving platforms, doors |
| 4 | =character= (=LRG_PHYSICS_LAYER_CHARACTER=) | Character controllers |
| 5 | =trigger= (=LRG_PHYSICS_LAYER_TRIGGER=) | Sensors |
| 6 | =debris= (=LRG_PHYSICS_LAYER_DEBRIS=) | Fracture chunks, gibs |
| 7 | =ragdoll= (=LRG_PHYSICS_LAYER_RAGDOLL=) | Ragdoll bones |
| 8 | =projectile= (=LRG_PHYSICS_LAYER_PROJECTILE=) | Bullets, thrown objects |

Pairs that do *not* collide by default: static-static, static-kinematic, kinematic-kinematic (none of them can move the other), static-trigger, trigger-trigger, character-debris, trigger-debris, debris-debris (cheap rubble) and debris-projectile. Everything else, including the unnamed slots 9 to 31, collides. A plain =lrg_physics_layers_new()= has no names and a full matrix.

** The physics: block of project.ryaml
:PROPERTIES:
:CUSTOM_ID: format
:END:
The table lives in a root-level =physics:= mapping next to =project:=. The loader also accepts a =physics:= nested inside =project:=; =lrg_project_save()= always writes it at the root.

#+begin_src yaml
project:
  name: Skyfall
  default_level: levels/hub.rlevel
  asset_dirs: [assets/]

physics:
  # Slot names. The position in the list is the layer index (0, 1, 2, ...).
  # An empty string keeps a slot unnamed (here slot 9 is unnamed, 10 is "water").
  layers: [default, static, dynamic, kinematic, character, trigger, debris, ragdoll, projectile, '', water]

  # Pairs that do NOT collide. Every other pair collides (the matrix starts full).
  # Each entry is [layer, layer]: names, or indices for unnamed slots.
  # [a, a] turns off collisions inside one layer. Order inside a pair does not matter.
  no_collide:
    - [static, static]
    - [static, kinematic]
    - [static, trigger]
    - [kinematic, kinematic]
    - [character, debris]
    - [trigger, trigger]
    - [trigger, debris]
    - [debris, debris]
    - [debris, projectile]
    - [debris, water]
    - [20, 31]

  # World settings (LrgPhysicsSettings, see "World settings" below).
  # LrgPhysicsLayers ignores them; LrgPhysicsSettings ignores layers/no_collide.
  gravity: [0, -9.81, 0]
  fixed_dt: 0.0166667
  max_substeps: 4
  iterations: 10
  sleep_threshold: 0.0009
  sleep_substeps: 30

  # Keys neither type knows are kept by every writer (lrg_project_save(),
  # lrg_physics_settings_write_data()).
  cloth_quality: high
#+end_src

| Key | Type | Default | Meaning |
|-----+------+---------+---------|
| =layers= | sequence of strings, at most 32 | none named | Slot names by position; =''= or =~= keeps a slot unnamed |
| =no_collide= | sequence of two-element sequences | empty (all collide) | Matrix cells to clear; each side is a name or a decimal index 0 to 31 |
| =gravity= | sequence of three numbers | =[0, -9.81, 0]= | World acceleration in m/s², Y up |
| =fixed_dt= | number, (0, 0.1] | =1/60= | The fixed substep in seconds |
| =max_substeps= | whole number, 1 to 8 | =4= | Substeps one step (or one frame of an =LrgWorld3D=) may run |
| =iterations= | whole number, 1 to 32 | =10= | Solver velocity passes per substep |
| =sleep_threshold= | number >= 0 | =9e-4= | A body whose \vert{}v\vert{}²+\vert{}ω\vert{}² stays below this is quiet |
| =sleep_substeps= | whole number >= 1 | =30= | Quiet substeps before an island sleeps |

Rules:

- No =physics:= block (or an empty one) means no named layers and a full matrix (=lrg_physics_layers_new()= state). Projects the editor creates get the default layer set written out.
- =no_collide= is resolved after =layers=, so it may use names declared in the same block.
- The writer emits one =layers= entry per slot up to the highest named one and lists the cleared cells of the upper triangle in row-major order (names, or integers for unnamed slots). Writing a loaded table gives the same text.
- Errors (=LRG_PHYSICS_LAYERS_ERROR=): =PARSE= (not YAML), =FORMAT= (wrong shape: =layers= not a sequence, a pair without two entries, a name that is a number or ="all"=, more than 32 layers), =UNKNOWN_LAYER= (a name not in =layers=, an index >= 32), =DUPLICATE= (a name used twice). A failed load leaves the table unchanged.
- World settings: a missing key takes its default (a missing block gives all defaults); a present key must have the right shape and range, or =lrg_physics_settings_load_from_data()= fails with =FORMAT= naming the key (=gravity= needs exactly three numbers; the counts must be whole numbers). The writer emits floats with the fewest digits that read back exactly (=-3.7=, not =-3.70000005=) and integers as integers, so a load / write round trip is stable.

*** Signal
:PROPERTIES:
:CUSTOM_ID: api-signal
:END:
=LrgPhysicsLayers::changed= is emitted once per call that actually changed a name or a cell (a no-op edit does not emit). Worlds that cache rows and the editor's matrix view listen to it. =LrgBroadphase= reads the table live and needs no notification.

*** A game: the level's project configures its world
:PROPERTIES:
:CUSTOM_ID: example-game
:END:
#+begin_src c
/* game/
 *   project.ryaml        physics: { layers: [...], gravity: [0, -3.7, 0], ... }
 *   levels/mars.rlevel   nodes with physics: blocks, layer: ghost, ...
 */
g_autoptr(LrgWorld3D) world = lrg_world3d_new ();
g_autoptr(LrgLevel)   level = lrg_level_load_world3d ("game/levels/mars.rlevel", world, &error);

#+end_src

To override the project (a low-gravity cheat, a test), give the world its settings first; instantiation then leaves them alone:

#+begin_src c
LrgPhysicsSettings moon;

lrg_physics_settings_init_default (&moon);
moon.gravity[1] = -1.62f;
lrg_world3d_set_physics_settings (world, &moon, NULL, &error);   /* default layer table */
level = lrg_level_load_world3d (path, world, &error);
#+end_src

** Performance
:PROPERTIES:
:CUSTOM_ID: performance
:END:
The matrix is 32 x 32 bits (128 bytes). =lrg_physics_layers_should_collide()= is three ANDs plus the type check; the broadphase copies the 32 rows once per =lrg_broadphase_find_pairs()= and tests every pair with plain bit operations, so filtering costs nothing measurable next to the box tests.

** Pitfalls
:PROPERTIES:
:CUSTOM_ID: pitfalls
:END:
- *Both masks must accept the other layer.* A body whose mask leaves out =static= falls through the floor even though the matrix says dynamic-static collides.
- *Queries ignore the matrix.* =lrg_broadphase_query_*()= and the casts filter with the =layer_mask= you pass; use =lrg_physics_layers_get_collide_mask()= when a query should behave like a body of some layer.
- *Unnamed slots collide with everything.* Using an index that has no name is legal, but it is not covered by any =no_collide= entry you wrote by name.
- *Renaming does not move a row.* The matrix is by index; renaming slot 6 from =debris= to =rubble= keeps its row. References in levels by the old name stop resolving.
- *A name cannot be a number or ="all"=* (those spell indices and the full mask in files).
- *The world's fixed step follows the project.* A world given project settings takes =fixed_dt= and =max_substeps= as its =LrgWorld3D:fixed-step= / =LrgWorld3D:max-substeps= (the project default cap is 4, a bare =LrgWorld3D='s is 8). Without project settings the world keeps the step the game chose. Set the world's step after loading the level if the game wants its own.
- *First come, first served.* Instantiation only reads the project when the world has neither settings nor a physics world; loading a second level into a world keeps the first project's settings. Call =lrg_world3d_set_physics_settings (world, NULL, NULL, NULL)= and detach the physics world to start over.
- *The layer table is shared, not copied.* =lrg_world3d_set_physics_settings()= and play-in-editor keep a reference to the table, so later edits of it apply on the next step; copy it (=lrg_physics_layers_copy()=) for a snapshot.
- *A broken settings value is an error, not a default.* =lrg_physics_settings_load_from_data()= fails on =iterations: 0= or =gravity: [0, -9.81]=; =lrg_project_open()= and instantiation warn and fall back to the defaults.
- *A broken physics: block does not stop a project from opening.* =lrg_project_open()= warns, uses an empty table and keeps the block text; fix the block before saving, or the save writes the empty table.

** Tests
:PROPERTIES:
:CUSTOM_ID: tests
:END:
In =tests/test-broadphase.c=:

- =/physics-layers/basic=: names, duplicates, reserved names, out-of-range indices, resolve, symmetry of single cells and whole rows, the pair rule with and without a table, one =changed= per effective edit, masks from and to names,
- =/physics-layers/default=: the default names match the =LrgPhysicsLayer= nicks and the default matrix,
- =/physics-layers/round-trip=: a customised table (with an unnamed gap and an unnamed cell) survives =to_data= then =load_from_data=, and writing the loaded table gives the same text; =copy= and =assign=,
- =/physics-layers/project-file=: root-level and nested blocks, the block alone, a file without a block, unknown keys ignored, a missing file,
- =/physics-layers/load-errors=: every error code, and a failed load leaves the table untouched,

** Using it from the editor
:PROPERTIES:
:CUSTOM_ID: editor
:END:
The editor keeps the table and the world settings on its =LrgProject= (=lrg_project_get_physics_layers()=, =lrg_project_get_physics_settings()=). Both are loaded with the project and written back by Project Settings saves (File > Project Settings > Physics, see [[file:../../editor/physics-asset-editor.org::#project-physics][Project Settings > Physics]]): the collide matrix is a triangle of check boxes, the world settings a form. Bodies and colliders pick their layer by name in the Physics panel, and the =.rlevel= physics block stores the name (or the index for an unnamed slot). Play-in-editor runs with the project's current settings and table (unsaved edits included), and the game, loading its levels with =lrg_level_load_world3d()=, reads the saved block, so what you set is what both simulate.
