* LrgTalentNode / LrgTalentTree - Tiered Talent Trees
:PROPERTIES:
:CUSTOM_ID: lrgtalenttree
:END:
Classic tiered talent trees. A tree is a grid of ranked talents: rows are tiers, and spending a point in tier /t/ requires /t × tier-gate/ points already spent in the same tree. A talent may require another talent of a lower tier at its maximum rank, may grant an ability once it has at least one rank (a "capstone"), and may carry a value per rank for a game-interpreted effect key that loadouts sum up.

Trees are static content: build them once (from code or data), validate them with =lrg_talent_tree_validate()= at load time, and share them read-only between every player. Per-player state lives in [[file:talent-loadout.org][LrgTalentLoadout]] and [[file:talent-book.org][LrgTalentBook]].

** Types
:PROPERTIES:
:CUSTOM_ID: types
:END:
- =LrgTalentNode= - *Boxed type* (=LRG_TYPE_TALENT_NODE=, GIR =Libregnum.TalentNode=) with public fields, copied with =lrg_talent_node_copy()= and freed with =lrg_talent_node_free()= (=g_autoptr= supported).
- =LrgTalentTree= - *Final GObject class* (=LRG_TYPE_TALENT_TREE=, GIR =Libregnum.TalentTree=) owning its nodes.

*** lrg_talent_tree_add_node()
#+begin_src C
gboolean lrg_talent_tree_add_node (LrgTalentTree *self, LrgTalentNode *node, GError **error);
#+end_src
Adds =node= (transfer full: ownership is taken *even on failure*, so never free it yourself).

*Errors:*
- =LRG_PROGRESSION_ERROR_DUPLICATE= - a node with the same id exists
- =LRG_PROGRESSION_ERROR_INVALID= - id empty, longer than 128 bytes or not UTF-8; =max_rank= outside 1..100

Checks that involve several nodes are deferred to =lrg_talent_tree_validate()= so nodes can be added in any order.

*** lrg_talent_tree_validate()
#+begin_src C
gboolean lrg_talent_tree_validate (LrgTalentTree *self, GError **error);
#+end_src
Validates the whole structure. Run it once at content load and refuse to start the server on failure. Checks in node order (tier, column, id):

| Check                                                                   | Error         |
|-------------------------------------------------------------------------+---------------|
| =max_rank= in 1..100 (public field may have been edited)                | =INVALID=     |
| =rank_values= length is 0 or =max_rank=                                 | =INVALID=     |
| prerequisite names a node of this tree                                  | =NOT_FOUND=   |
| prerequisite is in a strictly lower tier (also rejects self-reference)  | =INVALID=     |
| (tier, column) unique                                                   | =DUPLICATE=   |
| every populated tier /t/ reachable: max points of tiers < /t/ >= /t/ × tier-gate | =REQUIREMENT= |

An empty tree is valid. With a tier gate of 5, a tier-0 row whose ranks sum to exactly 5 makes tier 1 reachable; 4 does not. Skipped tiers are allowed as long as the points below suffice.

** Example
:PROPERTIES:
:CUSTOM_ID: example
:END:
#+begin_src C
g_autoptr(GError) error = NULL;
LrgTalentTree *arms;
LrgTalentNode *node;
guint i;

arms = lrg_talent_tree_new ("arms", "warrior");
lrg_talent_tree_set_name (arms, "Arms");
lrg_talent_tree_set_role (arms, "damage");

/* Tier 0: +1..+5 strength */
node = lrg_talent_node_new ("improved_strength", 0, 0, 5);
lrg_talent_node_set_effect (node, "strength");
for (i = 1; i <= 5; i++)
    lrg_talent_node_add_rank_value (node, (gdouble)i);
lrg_talent_tree_add_node (arms, node, &error);

/* Tier 1 capstone: requires improved_strength at rank 5, grants an ability */
node = lrg_talent_node_new ("mortal_strike", 1, 0, 1);
lrg_talent_node_set_prerequisite (node, "improved_strength");
lrg_talent_node_set_grants_ability (node, "mortal_strike");
lrg_talent_tree_add_node (arms, node, &error);

if (!lrg_talent_tree_validate (arms, &error))
    g_error ("bad talent content: %s", error->message);
#+end_src
