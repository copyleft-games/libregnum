* LrgVital - Resource Pool
:PROPERTIES:
:CUSTOM_ID: lrgvital
:END:
A regenerating or decaying resource such as mana, rage or energy. The pool has a separate in-combat and out-of-combat rate; a negative rate decays the pool (rage). All changes clamp to 0..maximum and spending is atomic.

** Type
:PROPERTIES:
:CUSTOM_ID: type
:END:
- *Boxed type* - =LRG_TYPE_VITAL=, GIR =Libregnum.Vital=; =g_autoptr= supported
- Header: =progression/lrg-vital.h=

** Constants
:PROPERTIES:
:CUSTOM_ID: constants
:END:
| Constant                 | Value     | Meaning                                         |
|--------------------------+-----------+-------------------------------------------------|
| =LRG_VITAL_MAX_VALUE=    | 1e9       | Largest maximum and largest absolute rate       |
| =LRG_VITAL_VARIANT_TYPE= | "(sdddd)" | Persistence type string                         |

** Fields
:PROPERTIES:
:CUSTOM_ID: fields
:END:
| Field        | Type    | Meaning                                                       |
|--------------+---------+---------------------------------------------------------------|
| =kind=       | gchar*  | "mana", "rage", "energy", ... (1-128 bytes of UTF-8)          |
| =current=    | gdouble | Current amount, 0..=maximum=                                  |
| =maximum=    | gdouble | Capacity, greater than 0                                      |
| =regen=      | gdouble | Change per second in combat                                   |
| =idle_regen= | gdouble | Change per second out of combat; negative decays              |

Read the fields directly; change them through the functions so the clamping rules hold.

** Functions
:PROPERTIES:
:CUSTOM_ID: functions
:END:
*** lrg_vital_new()
#+begin_src C
LrgVital *lrg_vital_new (const gchar *kind, gdouble maximum, gdouble regen, gdouble idle_regen);
#+end_src
*Returns:* (transfer full) a pool that starts full when =idle_regen >= 0= and empty otherwise. =kind= must be valid, =maximum= finite in (0, 1e9] and the rates finite within ±1e9 (criticals otherwise, returning =NULL=).

*** lrg_vital_copy() / lrg_vital_free()
#+begin_src C
LrgVital *lrg_vital_copy (const LrgVital *self);   /* deep copy */
void      lrg_vital_free (LrgVital *self);         /* NULL-safe */
#+end_src

*** lrg_vital_tick()
#+begin_src C
void lrg_vital_tick (LrgVital *self, gdouble delta, gboolean in_combat);
#+end_src
Adds =rate × delta= using =regen= in combat and =idle_regen= otherwise, clamped to 0..=maximum=. NaN, infinite and negative deltas are ignored.

*** lrg_vital_spend()
#+begin_src C
gboolean lrg_vital_spend (LrgVital *self, gdouble amount);
#+end_src
Spends the whole =amount= or nothing. *Returns:* =FALSE= (pool unchanged) when =amount= exceeds =current= or is negative, NaN or infinite; spending 0 succeeds.

*** lrg_vital_gain()
#+begin_src C
void lrg_vital_gain (LrgVital *self, gdouble amount);
#+end_src
Adds =amount= (negative drains), clamped to 0..=maximum=. Non-finite amounts are ignored. Use it for rage generated by damage, mana returns, or drains.

*** lrg_vital_set_maximum()
#+begin_src C
void lrg_vital_set_maximum (LrgVital *self, gdouble maximum, gboolean keep_ratio);
#+end_src
Changes the capacity (finite, in (0, 1e9]; criticals otherwise). With =keep_ratio= the current fraction is preserved (50/100 becomes 100/200); without it the current amount is kept and clamped to the new maximum. Use =keep_ratio= for gear/level changes and =FALSE= for temporary buffs if your design prefers.

*** lrg_vital_get_fraction()
#+begin_src C
gdouble lrg_vital_get_fraction (const LrgVital *self);
#+end_src
*Returns:* =current / maximum= in 0..1, the value to send clients for resource bars.

** Persistence
:PROPERTIES:
:CUSTOM_ID: persistence
:END:
#+begin_src C
GVariant *lrg_vital_to_variant       (const LrgVital *self);                 /* (transfer full), non-floating */
LrgVital *lrg_vital_new_from_variant (GVariant *variant, GError **error);    /* (transfer full) (nullable) */
#+end_src
Type =(sdddd)= = (=kind=, =current=, =maximum=, =regen=, =idle_regen=). =new_from_variant= fails with =INVALID= for another type string, a non-normal variant, an empty/overlong/non-UTF-8 kind, a maximum that is not finite in (0, 1e9], a current value outside 0..maximum or not finite, or a rate that is not finite within ±1e9. A round trip reproduces the identical variant.

** Example
:PROPERTIES:
:CUSTOM_ID: example
:END:
#+begin_src C
g_autoptr(LrgVital) mana = lrg_vital_new ("mana", 1200.0, 4.0, 24.0);
g_autoptr(LrgVital) rage = lrg_vital_new ("rage", 100.0, 0.0, -1.0);

if (lrg_vital_spend (mana, 180.0))
    cast_frostbolt ();

lrg_vital_gain (rage, damage_taken * 0.1);
lrg_vital_tick (mana, 0.05, in_combat);
lrg_vital_tick (rage, 0.05, in_combat);
lrg_vital_set_maximum (mana, 1350.0, TRUE);   /* level-up */
#+end_src
