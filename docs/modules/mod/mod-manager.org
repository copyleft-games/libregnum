* LrgModManager
:PROPERTIES:
:CUSTOM_ID: lrgmodmanager
:END:
** Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:
=LrgModManager= is the central orchestrator for mod lifecycle management. It handles discovery, dependency resolution, load ordering, and provides access to mod content through provider queries.

** Type Information
:PROPERTIES:
:CUSTOM_ID: type-information
:END:
- *Type Name*: =LrgModManager=
- *Type ID*: =LRG_TYPE_MOD_MANAGER=
- *Base Class*: =GObject=
- *Final Type*: Yes
- *Singleton*: Yes (default instance)

*** lrg_mod_manager_load_all
:PROPERTIES:
:CUSTOM_ID: lrg_mod_manager_load_all
:END:
#+begin_src C
gboolean lrg_mod_manager_load_all(LrgModManager *self, GError **error);
#+end_src

Loads every enabled mod in the computed load order (see [[#load-order][Load Order]]).  One failure never stops the others:

- A mod whose required dependency is missing, disabled or failed is marked failed with that reason, for example =Required dependency failed to load: base=.  Optional dependencies only order the load.
- Members of a dependency cycle fail with =Circular dependency between mods=.
- Mods that are already loaded stay loaded.  Failed mods (including invalid manifests found at discovery) stay failed until they are rediscovered or reloaded with =lrg_mod_manager_reload_mod()=.

Each outcome emits =mod-loaded= or =mod-failed=.

*Returns:* =TRUE= if nothing failed; otherwise =FALSE= with =LRG_MOD_ERROR_LOAD_FAILED= giving the failure count

*Example:*

#+begin_src C
g_autoptr(GError) error = NULL;
if (!lrg_mod_manager_load_all(mgr, &error)) {
    g_warning("Mod loading failed: %s", error->message);
    return FALSE;
}
#+end_src

*** lrg_mod_manager_reload_mod / lrg_mod_manager_unload_mod
:PROPERTIES:
:CUSTOM_ID: lrg_mod_manager_reload_mod
:END:
#+begin_src C
gboolean lrg_mod_manager_reload_mod (LrgModManager *self, const gchar *mod_id, GError **error);
void     lrg_mod_manager_unload_mod (LrgModManager *self, const gchar *mod_id);
#+end_src

Unloads a single mod, or reloads it, for example after its files changed.  A
script mod's =lrg_mod_shutdown()= runs, its context is dropped, and a reload
runs the entry file and =lrg_mod_init()= again.  Mods that depend on it keep
running.  =mod-unloaded=, then =mod-loaded= or =mod-failed=, are emitted.

** Load Order
:PROPERTIES:
:CUSTOM_ID: load-order
:END:
*** lrg_mod_manager_get_load_order
:PROPERTIES:
:CUSTOM_ID: lrg_mod_manager_get_load_order
:END:
#+begin_src C
GPtrArray *lrg_mod_manager_get_load_order(LrgModManager *self);
#+end_src

Gets the computed load order.  It covers every discovered mod, enabled or
not, so toggling a mod needs no recomputation:

- Dependencies (required and optional, when present), =load_after= and =load_before= are hard constraints.
- Among mods that are free to load, a lower priority value loads first (=lowest= … =highest=), then discovery order.  Discovery sorts folder names, so the order is deterministic.
- Members of a dependency cycle are placed last and fail in =lrg_mod_manager_load_all()=.

A dependency therefore always loads before its dependents, whatever their
priorities.

*Returns:* (transfer full) (element-type utf8) Mod IDs in order

** Signals
:PROPERTIES:
:CUSTOM_ID: signals
:END:
| Signal | Arguments | When |
|--------+-----------+------|
| =mod-loaded= | =LrgMod= | after a mod loads |
| =mod-failed= | =LrgMod= | a load failed (see =lrg_mod_get_error()=) |
| =mod-unloaded= | =LrgMod= | after a loaded mod unloads |
| =mod-prepare-scripting= | =LrgMod=, =LrgScripting= | a script mod's context exists and its entry file has not run yet |

=mod-prepare-scripting= is where a host publishes its API to every script mod:

#+begin_src C
static void
on_prepare (LrgModManager *mgr, LrgMod *mod, LrgScripting *ctx, gpointer data)
{
    lrg_scripting_register_function (ctx, "log", host_log, mod, NULL);
}

g_signal_connect (mgr, "mod-prepare-scripting", G_CALLBACK (on_prepare), NULL);
#+end_src

    g_free(resolved);

** Example
:PROPERTIES:
:CUSTOM_ID: example
:END:
#+begin_src C
/* Initialize mod system */
g_autoptr(LrgModManager) mgr = lrg_mod_manager_get_default();
lrg_mod_manager_add_search_path(mgr, "mods/");

/* Discover */
guint count = lrg_mod_manager_discover(mgr, NULL);
g_print("Found %u mods\n", count);

/* Show discovered mods */
g_autoptr(GPtrArray) mods = lrg_mod_manager_get_mods(mgr);
for (guint i = 0; i < mods->len; i++) {
    LrgMod *mod = g_ptr_array_index(mods, i);
    g_print("  - %s (%s)\n", lrg_mod_get_id(mod), lrg_mod_get_state(mod) ? "loaded" : "not loaded");
}

/* Load */
g_autoptr(GError) error = NULL;
if (lrg_mod_manager_load_all(mgr, &error)) {
    g_print("All mods loaded\n");
} else {
    g_print("Load error: %s\n", error->message);
}

/* Register content from providers */
g_autoptr(GList) entities = lrg_mod_manager_collect_entity_types(mgr);
for (GList *l = entities; l; l = l->next) {
    GType entity_type = GPOINTER_TO_INT(l->data);
    register_entity_type(entity_type);
}
#+end_src
