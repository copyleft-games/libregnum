** Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:
=LrgColorGradient= (=core/lrg-color-gradient.h=, 0.9.0) maps a position =t= in 0 .. 1 to an RGBA colour (floats 0 .. 1) through sorted stops. It is what runtime code samples per particle or per vertex: colour over life, colour along a ribbon. It has three interpolation modes, an exact evaluator and a table-driven fast one, a one-line text form shared with the formats, and lossless conversion to and from =LrgGradientStops=, the boxed value type the editor's property grid edits with its gradient widget (=LrgGradientEdit=). Formats store gradients as =LrgGradientStops= properties (so the property grid works) and keep an =LrgColorGradient= internally for sampling.

** Concepts
:PROPERTIES:
:CUSTOM_ID: concepts
:END:
- *Stops* are kept sorted by offset. A stop added at an existing offset goes after it, making a hard edge.
- *Evaluation*: before the first stop its colour, after the last its colour, in between the two neighbouring stops blended by the mode: =LINEAR= (straight blend of all four channels), =STEP= (the left stop's colour until the next stop), =SMOOTH= (smoothstep =3f^2 - 2f^3= of the segment fraction). One stop gives its colour everywhere; *no stop gives opaque white*, the neutral value of a colour multiplier.
- *The table*: =lrg_color_gradient_evaluate_fast()= samples a 256-entry table (=LRG_COLOR_GRADIENT_LUT_SIZE=) rebuilt on first use after a change and blends the two nearest entries: exact for linear gradients at entries, within 1/255 elsewhere.
- *Text form*: ="offset #rrggbbaa; offset #rrggbbaa; ..."= (the format of =lrg_gradient_stops_to_string()=; =#rgb= and =#rrggbb= read as opaque), optionally prefixed with =linear:=, =step:= or =smooth:=. The writer uses =%.9g= offsets and 8-bit channels, so text round-trips exactly.

** Performance
:PROPERTIES:
:CUSTOM_ID: performance
:END:
=evaluate()= is a binary search plus a blend; =evaluate_fast()= is two table reads and a blend (the particle modules use it). Rebuilding the table costs 256 exact evaluations, once per change.

** Pitfalls
:PROPERTIES:
:CUSTOM_ID: pitfalls
:END:
- In YAML, quote the text form: =#= after a space starts a comment.
- Colours are clamped to 0 .. 1 (no HDR intensities).
- =to_stops()= drops the mode; formats that need it store it beside the stops.
