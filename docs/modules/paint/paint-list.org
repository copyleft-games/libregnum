=LrgPaintList= (=src/paint/lrg-paint-list.h=, final =GObject=) is a recorded frame of 2D drawing: a flat array of =LrgPaintInstance= structs plus a short command stream of instance batches and callbacks. Widgets record into it from their =paint()= virtual method; =LrgPaintRenderer= draws it. Recording needs no window. See the [[file:index.org][module overview]] for how instances become pixels.

** Lifecycle
:PROPERTIES:
:CUSTOM_ID: paint-list-lifecycle
:END:
#+begin_src c
g_autoptr(LrgPaintList) list = lrg_paint_list_new ();

/* every frame */
lrg_paint_list_clear (list);          /* keeps the allocation */
/* ... record ... */
lrg_paint_renderer_render (lrg_paint_renderer_get_default (), list);
#+end_src

| Function | Purpose | Notes |
|----------+---------+-------|
| =lrg_paint_list_new (void)= | Creates an empty list | (transfer full) |
| =lrg_paint_list_clear (self)= | Drops all instances and commands, resets the clip and opacity stacks, releases texture/font references and runs callback destroy notifies | Memory is kept for the next frame |

You rarely create lists yourself in widget code: =LrgCanvas= owns one per canvas and passes it to =paint()=. Create your own to draw UI-style shapes outside the widget tree (a HUD overlay, a debug view) or in tests.

** Coordinates and colours
:PROPERTIES:
:CUSTOM_ID: paint-list-coordinates
:END:
- All coordinates are in canvas units with y pointing down. Widgets draw at their *world* position (=lrg_widget_get_world_x/y()=), not relative to their parent.
- Colours are =GrlColor= (straight RGBA8). The current opacity (see [[#paint-list-opacity][opacity stack]]) is multiplied into the alpha at record time.
- Shapes with nothing visible (zero size, fully transparent fill and border, or entirely outside the current clip) are not recorded.

*** Example: a card with a shadow, gradient header and border
:PROPERTIES:
:CUSTOM_ID: paint-list-example-card
:END:
#+begin_src c
static void
paint_card (LrgPaintList *list,
            gfloat        x,
            gfloat        y)
{
	static const GrlColor shadow = { 0, 0, 0, 110 };
	static const GrlColor panel = { 31, 31, 36, 255 };
	static const GrlColor edge = { 52, 52, 60, 255 };
	static const GrlColor top = { 124, 108, 255, 255 };
	static const GrlColor bottom = { 70, 56, 200, 255 };
	LrgCornerRadii        all;
	LrgCornerRadii        header;
	LrgPaintGradient      grad;

	/* soft elevation: blur 18, pushed 6 units down */
	lrg_paint_list_shadow (list, x, y, 320.0f, 200.0f, 12.0f,
	                       18.0f, 0.0f, 0.0f, 6.0f, &shadow);

	/* body with a 1-unit inner border */
	lrg_corner_radii_init_uniform (&all, 12.0f);
	lrg_paint_list_rect_ex (list, x, y, 320.0f, 200.0f, &all,
	                        &panel, NULL, 1.0f, &edge);

	/* header: only the top corners rounded, vertical gradient */
	header.top_left = 12.0f;
	header.top_right = 12.0f;
	header.bottom_right = 0.0f;
	header.bottom_left = 0.0f;
	lrg_paint_gradient_init_linear (&grad, &top, &bottom, 90.0f);
	lrg_paint_list_rect_ex (list, x, y, 320.0f, 44.0f, &header,
	                        NULL, &grad, 0.0f, NULL);
}
#+end_src

** Text
:PROPERTIES:
:CUSTOM_ID: paint-list-text
:END:
| Function | Purpose | Nullable / notes |
|----------+---------+------------------|
| =lrg_paint_list_text (self, font, text, x, y, size, spacing, color)= | Records UTF-8 text, one image instance per glyph, sampling the font atlas | =font= =NULL= = raylib's built-in font (needs a window); ='\n'= starts a new line at =1.2 * size=; origin snapped to whole units; the list refs =font= until cleared |
| =lrg_paint_measure_text (font, text, size, spacing, width, height)= | Measures exactly as =lrg_paint_list_text()= lays out | =width= / =height= (out, optional); width = widest line without the trailing spacing; height = =size + (lines - 1) * 1.2 * size=; without glyph data returns an estimate (=0.55 * size= per character) |

Text and shapes share batches as long as one font atlas is in use. Pass the theme's UI font straight through:

#+begin_src c
LrgTheme *theme = lrg_widget_get_theme (widget);
GrlFont  *font = lrg_theme_get_ui_font (theme);     /* may be NULL headless */
gfloat    size = lrg_theme_get_metric (theme, LRG_THEME_METRIC_FONT_SIZE);
gfloat    w;
gfloat    h;

/* centre a label in a box */
lrg_paint_measure_text (font, "Continue", size, 0.0f, &w, &h);
lrg_paint_list_text (list, font, "Continue",
                     bx + (bw - w) * 0.5f, by + (bh - h) * 0.5f,
                     size, 0.0f, lrg_theme_get_color (theme, LRG_THEME_COLOR_TEXT));
#+end_src

Glyphs are placed exactly where raylib's =DrawTextCodepoint()= would put them (glyph offsets and atlas padding included), so measurement agrees with legacy =MeasureTextEx()= for the same font. Spaces and tabs advance the pen but emit no instance.

 * visible ones are cut per pixel */
lrg_paint_list_push_clip (list, vx, vy, vw, vh);
for (i = 0; i < n_rows; i++)
	paint_row (list, vx, vy + i * row_h - scroll_y, vw, row_h);

** Groups
:PROPERTIES:
:CUSTOM_ID: paint-list-groups
:END:
| Function | Purpose | Notes |
|----------+---------+-------|
| =lrg_paint_list_begin_group (self)= | Returns a mark (the current instance count) | |

Example, a "squash" on press independent of the widget machinery:

#+begin_src c
guint  mark = lrg_paint_list_begin_group (list);
gfloat p = lrg_widget_get_press_progress (widget);   /* 0..1 spring */
gfloat cx = x + w * 0.5f;
gfloat cy = y + h * 0.5f;

paint_my_button (list, x, y, w, h);
lrg_paint_list_transform_group (list, mark, 1.0f - 0.04f * p, cx, cy,
                                0.0f, 0.0f, 1.0f);
#+end_src

Opacity: blur, glass and effect instances carry the current opacity separately (=data[2]=) and keep their colours as given; group fades multiply that value. Curves fade their colours like other shapes.

*** Example: a frosted sidebar over a game scene
:PROPERTIES:
:CUSTOM_ID: paint-list-example-glass

lrg_paint_list_shadow (list, 16.0f, 16.0f, 260.0f, 560.0f, 16.0f, 24.0f, 0.0f, 0.0f, 8.0f,
                       &(GrlColor){ 0, 0, 0, 90 });
lrg_paint_list_glass (list, 16.0f, 16.0f, 260.0f, 560.0f, &radii, &glass);
lrg_paint_list_text (list, font, "Inventory", 36.0f, 36.0f, 22.0f, 0.0f, &white);

** Escape hatch: callbacks
:PROPERTIES:
:CUSTOM_ID: paint-list-callbacks
:END:
| Function | Purpose | Notes |
|----------+---------+-------|
| =lrg_paint_list_callback (self, func, user_data, destroy)= | Records a call into raw graylib/raylib drawing at this point of the paint order | Ends the current batch; =destroy= (nullable) runs when the list is cleared or finalized; the active clip becomes a scissor rectangle |

=LrgPaintCallback= is =void (*) (gpointer user_data)=. Use it for anything the instance pipeline cannot express: a 3D viewport, a custom shader, a particle system. Legacy widgets that only override =draw()= are recorded through one automatically.

#+begin_src c
static void
draw_minimap (gpointer user_data)
{
	GameMinimap *map = user_data;

	/* plain raylib: runs between paint batches, scissored to the clip */
	game_minimap_draw (map);
}

lrg_paint_list_callback (list, draw_minimap, g_object_ref (map), g_object_unref);
#+end_src

A headless test asserting what a widget painted:

#+begin_src c
static void
test_card_paints_shadow_first (void)
{
	g_autoptr(LrgPaintList) list = lrg_paint_list_new ();
	const LrgPaintInstance *inst;

	paint_card (list, 10.0f, 10.0f);

	g_assert_cmpuint (lrg_paint_list_get_n_instances (list), ==, 3);
	inst = lrg_paint_list_get_instance (list, 0);
	g_assert_cmpint (lrg_paint_instance_get_prim (inst), ==, LRG_PAINT_PRIM_SHADOW);
	/* the shadow rect is the caster moved 6 units down */
	g_assert_cmpfloat_with_epsilon (inst->rect[1], 16.0f, 0.001f);

	/* everything is untextured: one batch */
	g_assert_cmpuint (lrg_paint_list_get_n_commands (list), ==, 1);
}

*** Boxed types and GTypes
:PROPERTIES:
:CUSTOM_ID: paint-list-boxed-types
:END:
The three value types are registered as =GBoxed= types so they can travel through =GValue=, properties, signals and GObject Introspection. Copies are flat (=g_memdup2()= of the struct: none of them own pointers), so a copy never shares state with the original. Every =_free= accepts =NULL=, and =G_DEFINE_AUTOPTR_CLEANUP_FUNC= is declared for each type, so =g_autoptr (LrgCornerRadii)= and friends work. C code normally keeps these structs on the stack and uses the =_init_*= helpers; the heap functions exist mainly for bindings and for storing a value in a =GValue=.

| =lrg_corner_radii_init_uniform= | =void lrg_corner_radii_init_uniform (LrgCornerRadii *self, gfloat radius);= | (out caller-allocates): all four corners set to =radius= |
| =lrg_corner_radii_scale= | =void lrg_corner_radii_scale (LrgCornerRadii *self, gfloat factor);= | Multiplies every corner by =factor= in place |

Radii are in canvas units and are clamped to half the shorter side when drawn, so =G_MAXFLOAT= always gives a pill or a circle. =lrg_corner_radii_scale()= is what a squash or zoom animation uses to keep corners proportional to a scaled box:

#+begin_src c
LrgCornerRadii radii;

/* the theme radius, shrunk with the box while a button is pressed */
lrg_corner_radii_init_uniform (&radii, lrg_theme_get_metric (theme, LRG_THEME_METRIC_CORNER_RADIUS));
lrg_corner_radii_scale (&radii, 0.96f);
#+end_src

Both =_init_*= functions zero the whole struct first, so stale fields of a reused gradient never leak into the new one. There is no =_new=: declare the struct and initialise it, then pass it to =lrg_paint_list_rect_ex()= (or put it in an =LrgPartLook=). #+begin_src c
LrgPaintGradient glow;
GrlColor centre = { 255, 255, 255, 40 };
GrlColor edge = { 255, 255, 255, 0 };

lrg_paint_gradient_init_radial (&glow, &centre, &edge, 0.5f, 0.35f, 0.0f);
lrg_paint_list_rect_ex (list, x, y, w, h, &radii, NULL, &glow, 0.0f, NULL);
#+end_src

** Pitfalls
:PROPERTIES:
:CUSTOM_ID: paint-list-pitfalls
:END:
- Pass world coordinates; relative coordinates draw at the canvas origin.
- Measure and draw with the same font, size and spacing, or alignment drifts.
- =lrg_paint_list_text()= with a =NULL= font records nothing headless; tests that count glyph instances need a real font.
- Do not keep instance pointers across further recording.
- Effects and curve pulses only move when someone calls =lrg_paint_list_set_time()= before rendering and keeps redrawing; a list recorded once stays still.
- Glass sees only what was drawn *into the same target before it*; a UI rendered into its own transparent render texture shows nothing behind its glass. Draw the UI over the scene, or the scene into the UI's target first.
- A callback's =user_data= must outlive the list or be ref-counted with a =destroy= notify; it runs at render time, possibly after the recording widget changed.
- See also the [[file:index.org::#paint-pitfalls][module-level pitfalls]].
