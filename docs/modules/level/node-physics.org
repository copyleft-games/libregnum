** Overview
:PROPERTIES:
:CUSTOM_ID: node-physics-overview
:END:
=src/level/lrg-node-physics.h= (0.9.0 M5) holds the authored description of a node's physics body: the =physics:= block of a node in a =.rlevel= or =.rprefab= file. Three final GObjects, plain property bags with =G_PARAM_EXPLICIT_NOTIFY= properties so inspectors can edit them:

| Type                   | What                                                                               |
|------------------------+------------------------------------------------------------------------------------|
| =LrgNodePhysics=       | the body: =body-kind=, =mass=, =layer=, =friction=, =restitution=, =linear-damping=, =angular-damping=, =gravity-factor=, =ccd=, plus ordered lists of shapes and joints |
| =LrgNodePhysicsShape=  | one collision shape: =kind= (#LrgCollider3DKind), =half-extent-x/y/z=, =radius=, =half-height=, =offset-x/y/z=, =rotation-x/y/z= (degrees), =trigger=, =friction= / =restitution= overrides (-1: the body's), =layer=, =mesh= |
| =LrgNodePhysicsJoint=  | one joint: =kind= (#LrgJointKind), =target= (node GUID), =anchor-x/y/z=, =axis-x/y/z=, =limits-enabled=, =limit-min=, =limit-max=, =spring-frequency=, =spring-damping=, =motor-velocity=, =motor-max-force=, =break-force= |

A node holds one (=lrg_node_get_physics()= / =lrg_node_set_physics()=, property =LrgNode:physics=, a reference held, =NULL= for no body). =lrg_node_copy_state()= deep-copies it (undo snapshots, play-in-editor restore, prefab clones) and =lrg_node_state_equal()= compares it with =lrg_node_physics_equal()=.

** Prefabs
:PROPERTIES:
:CUSTOM_ID: node-physics-prefabs
:END:
- *Joint targets follow new GUIDs.* Every prefab path that gives nodes new GUIDs rewrites the joint targets it knows a new GUID for: =lrg_prefab_clone()= / =lrg_prefab_instantiate()= and =lrg_prefab_regenerate_guids()= through their old-to-new table, =lrg_prefab_instantiate_linked()=, =lrg_prefab_sync_instance()= and =lrg_prefab_instantiate_reference()= through the link (source GUID to instance GUID). A joint inside a prefab to another node of the same prefab therefore points at the instance's node; targets outside the prefab are kept.
- *The block is one override.* =lrg_prefab_compute_overrides()= records an instance's edited block as the path =physics= (=GUID:physics= below the root); joint targets are compared through the link, so the remapped targets of an unedited instance are not an override. A sync keeps an overridden block; without the override it copies the source block (targets localized). =lrg_prefab_apply_overrides_to_source()= writes the block back with the targets translated to source GUIDs. =lrg_prefab_diff_node_state()= (no link) compares the blocks as they are.

** Format
:PROPERTIES:
:CUSTOM_ID: node-physics-format
:END:
The YAML schema with every key and default is in [[file:../../editor/yaml-format.org::#physics][.rlevel Format > Physics Block]]. Writing is deterministic (fixed key order, defaults left out where noted), so a load / save round trip is byte stable (=tests/test-physics-bodies.c=, =/physics-bodies/level-round-trip=).

** Instantiation
:PROPERTIES:
:CUSTOM_ID: node-physics-instantiate
:END:
=lrg_level_instantiate_3d()= (and =lrg_level_instantiate_node_3d()=, =lrg_level_load_world3d()=) turn the block into components on the node's entity, after the visual component and before the registry and script components:

1. =lrg_world3d_ensure_physics()= on the target world;
2. an =LrgRigidBodyComponent= of =body-kind=, configured with =lrg_node_physics_apply()=;
3. one =LrgColliderComponent3D= per shape, in order (=lrg_node_physics_shape_apply()=);
4. one =LrgJointComponent= per joint, in order (=lrg_node_physics_joint_apply()=); targets resolve by GUID once the target entity exists.

The 2D path (=lrg_level_instantiate()=) ignores the block.

** Example
:PROPERTIES:
:CUSTOM_ID: node-physics-example
:END:
#+begin_src C
/* a crate with a box body and a trigger sphere around it */
g_autoptr(LrgNode)             crate = lrg_node_new ("crate");
g_autoptr(LrgNodePhysics)      phys = lrg_node_physics_new (LRG_DYNAMICS_BODY_DYNAMIC);
g_autoptr(LrgNodePhysicsShape) box = lrg_node_physics_shape_new (LRG_COLLIDER3D_BOX);
g_autoptr(LrgNodePhysicsShape) zone = lrg_node_physics_shape_new (LRG_COLLIDER3D_SPHERE);

lrg_node_physics_set_mass (phys, 20.0f);
lrg_node_physics_set_layer (phys, "debris");
lrg_node_physics_shape_set_half_extents (box, 0.5f, 0.5f, 0.5f);
lrg_node_physics_add_shape (phys, box);
lrg_node_physics_shape_set_radius (zone, 2.0f);
lrg_node_physics_shape_set_trigger (zone, TRUE);
lrg_node_physics_add_shape (phys, zone);
lrg_node_set_physics (crate, phys);
lrg_level_add_node (level, crate, NULL);   /* saved under the node as physics: */
#+end_src

** Performance
:PROPERTIES:
:CUSTOM_ID: node-physics-performance
:END:
The descriptions are small objects; copies are deep (one object per shape and joint). Nothing is simulated until instantiation.

** Pitfalls
:PROPERTIES:
:CUSTOM_ID: node-physics-pitfalls
:END:
- =layer= is a name resolved at runtime against the project's layer table; a typo is a warning and layer 0, not a load error.
- Edit a copy (=lrg_node_physics_copy()=) when the same object may be shared by an undo snapshot.

** Using it from the editor
:PROPERTIES:
:CUSTOM_ID: node-physics-editor
:END:
The Physics panel edits the block of the selected node (body, shapes, joints, fit to mesh; every change one undo step), the viewport draws collider and joint gizmos with drag handles and a Physics overlay (authored shapes while authoring, the play world's debug draw while playing), the inspector shows a summary and the hierarchy a badge; scripts and agents use the =physics.*= IPC methods. See [[file:../../editor/physics.org][Physics in Levels]]. Layers and the collide matrix are edited in Project Settings > Physics.
