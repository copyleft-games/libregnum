#+title: Auxiliary UV integration and verification contract

* Boundary and acceptance
LrgStaticBatch owns copied auxiliary UV streams, per-chunk lifetime, GPU buffers and the shader attribute contract. Game-specific lightmaps/material semantics remain consumer policy. Channels 1..7 contain two finite scalar float components per merged vertex and use attributes 5,8..13; channel zero is the existing primary UV stream. Replacing a valid stream invalidates its GPU upload; invalid replacements preserve CPU views and GPU state. Growing geometry leaves an explicitly stale stream until replaced. Repeated GPU unload preserves CPU streams; clear/finalization release them. GPU resources must be released before their context closes.

Public headers describe array ownership, nullability, output lengths and GError. The low-level =add_mesh()= remains visible to introspection: its four component arrays are nonterminated, optional where documented, and sized by 3/3/2/4 times the scalar vertex count. GIR cannot encode these multipliers; callers/bindings must validate them. The index array has its exact index-count length. Auxiliary setters/getters have exact float-component length parameters, a copied input and a borrowed nullable output; no vertex/scalar length is conflated.
