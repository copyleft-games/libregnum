* LrgModelAnimator - Shared Skinned Model Animation
:PROPERTIES:
:CUSTOM_ID: lrgmodelanimator---shared-skinned-model-animation
:END:
Drives one shared skinned =GrlModel= for many actors. The animator owns the clip table (lookup, aliases, full names) and the model's current pose; every actor keeps its own small =LrgModelAnimState= (clip, time, rate, loop, crossfade). Right before an actor is drawn, =lrg_model_animator_apply()= poses the shared model for that actor's state — and skips the expensive re-skinning when the pose would not change — then =lrg_model_animator_draw_masked()= draws the meshes the actor should show.

:PROPERTIES:
:CUSTOM_ID: types

struct _LrgModelAnimState {
    gint     clip;           /* current clip, -1 = none */
    gdouble  time;           /* seconds into clip */
    gdouble  rate;           /* speed multiplier, negative plays backwards */
    gboolean loop;           /* wrap, or hold the last frame */
    gint     previous_clip;  /* clip fading out, -1 = none */
    gdouble  previous_time;
    gboolean previous_loop;
    gdouble  fade;           /* seconds into the crossfade */
    gdouble  fade_duration;  /* 0 = not fading */
};

** Clip Lookup
:PROPERTIES:
:CUSTOM_ID: clip-lookup
:END:
=lrg_model_animator_find_clip()= resolves a name in three steps and returns the clip index or -1:

1. *Exact*, case-sensitive match (lowest index wins).
2. *Alias* table: =set_alias ("walk", "Walking_A")=. The target is resolved by exact then suffix matching; aliases do not chain. Passing a =NULL= target removes an alias.
3. *Suffix* match, case-insensitive, at a word boundary: the clip name must end with the name and the preceding character must not be a letter or digit. "walk" finds "Armature|Walk" and "Rat_Walk" but never "Sidewalk". Candidates rank by what precedes the suffix — nothing (whole name ignoring case), then =|= (exporter prefixes like =Armature|=), then any other separator — so "idle" prefers "CharacterArmature|Idle" over "CharacterArmature|Jump_Idle" and "Armature|Idle" over "Jump_Idle". Within a rank the shortest name wins, then the lowest index.

*Truncated names.* raylib keeps only the first 31 bytes of an animation name. Files such as the Quaternius cat ("AnimalArmature|AnimalArmature|AnimalArmature|Walk") end up with eight identical names. =lrg_model_animator_set_clip_names_from_info()= replaces them with the full names from the file's =LrgGltfInfo=, after checking the clip count and that every current name is a prefix of the corresponding full name. Suffix lookup then works normally.

** Playback Semantics
:PROPERTIES:
:CUSTOM_ID: playback-semantics
:END:
- *Sampling*: clips are sampled at 60 fps (=LRG_MODEL_ANIMATOR_FPS=, matching raylib's glTF import). A clip of N frames lasts N / 60 s. =frame_of()= is =floor (time * 60)= with a 1e-6 frame tolerance for rounding.
- *Looping* clips wrap =time= into =[0, duration)=, forwards or backwards (negative =rate=), so time never grows without bound.
- *One-shot* clips clamp =time= to =[0, (N - 1) / 60]= and hold the last frame; =is_finished()= reports reaching it (or time 0 when playing backwards).
- =play()= with the clip that is already current only updates =loop=; call it every tick without restarting. =restart()= rewinds explicitly. Out-of-range clips are refused (=FALSE=, state untouched); clip -1 stops.
- *Crossfade*: a positive =fade_seconds= from a valid current clip moves the current clip into the =previous_*= fields and starts the new clip at time 0. Both clips keep advancing at the state's rate; =fade= advances by real time. =lrg_model_anim_state_get_blend()= = =fade / fade_duration=. When the fade completes the previous clip is dropped. Zero, negative or non-finite fades — or a fade from no/invalid clip — cut immediately.
- =advance()= ignores negative or non-finite =dt=.

** Posing: apply() and the Pose Key
:PROPERTIES:
:CUSTOM_ID: posing
:END:
=apply()= computes a key of *(clip, frame, previous clip, previous frame, quantized blend)*. The blend weight is quantized to 64 levels (=LRG_MODEL_ANIMATOR_BLEND_LEVELS=); a weight that rounds to full degrades to the plain current pose (same key as a finished fade). If the key equals the last key the animator applied, nothing happens and =apply()= returns =FALSE=. Otherwise it poses the model — a single clip or a blend (previous → current at the quantized weight) while fading — and returns =TRUE=. On the GPU path (below) that means posing the bones only (=grl_model_animation_update_bones()= / =grl_model_animation_blend_bones()=); on the CPU path =grl_model_animation_update()= / =grl_model_animation_blend()= also skin every vertex and re-upload the buffers.

Because the key is stored in the animator, actors that share a clip and frame share one posing pass. Use *one animator per model*, shared by all actors of that model. Call =invalidate()= if anything else changed the model's pose.

A clip whose skeleton does not match the model (=clip_is_valid()= false) is never applied. Headless animators track keys without posing, which is how the key logic is unit tested.

** GPU and CPU Skinning
:PROPERTIES:
:CUSTOM_ID: skinning
:END:
raylib skins animated models on the CPU: every pose transforms each vertex and normal of each skinned mesh and re-uploads the position and normal buffers. With many actors on different frames that runs once per actor per frame and dominates the frame. The animator skins in the vertex shader instead whenever it can, and keeps the CPU path as the fallback.

*When the GPU path is used.* On every =apply()= that poses, all of these must hold, else the whole model is skinned on the CPU (=apply()= poses all meshes at once, so a model goes one way):
- GPU skinning is allowed (=set_gpu_skinning()=, default =TRUE=);
- the model has a skeleton and at least one mesh with bone data;
- =grl_model_prepare_gpu_skinning()= succeeds: OpenGL 3.3 or 4.3 with vertex arrays (it uploads the bone indices and weights into the meshes' vertex arrays at raylib's bone attribute locations, since the embedded raylib has =SUPPORT_GPU_SKINNING 0=);
- every material used by a skinned mesh either uses raylib's default shader — drawn with the animator's skinning variant of it, which holds =LRG_MODEL_ANIMATOR_MAX_GPU_BONES= (128) bone matrices, so the model may have at most that many bones, and the variant must compile — or a custom shader that reads raylib's skinning inputs: the =boneMatrices= uniform array with room for every bone (probed by looking up =boneMatrices[bone_count - 1]=) and the =vertexBoneIndices= / =vertexBoneWeights= attributes at raylib's default locations 7 and 8. Verdicts on custom shaders are cached per program until =invalidate()=.

Custom shaders without those inputs, too many bones, or no vertex arrays fall back to the CPU. =uses_gpu_skinning()= tells which way the last pose went.

*Same picture.* The skinning variant is raylib's default vertex stage with the skinning in front of the MVP transform, and raylib's fragment stage unchanged. It mirrors raylib's CPU loop: zero weights are skipped, the weighted positions =w_i * (boneMatrices[i] * p)= are summed, and the result gets =w = 1=, so even weights that do not add up to one move a vertex identically. The test =/model-animator/gl/gpu-matches-cpu= renders a 300-vertex, 8-bone tube in three poses (a clip frame, another clip, a half-way crossfade) on both paths, then on the GPU again after the CPU wrote a pose, and compares the images: 0 differing pixels on llvmpipe (the test allows 1 % of the covered pixels for edge rounding). =/model-animator/gl/shader-selection= checks the shader rules: a plain custom shader goes CPU, a skinning shader with a 4-matrix array on the 8-bone model goes CPU, one with 16 matrices goes GPU and matches the CPU picture.

*CPU-side data.* =Mesh.vertices= and =Mesh.normals= always hold the bind pose on both paths (raylib's ray/mesh collision and bounding boxes read those, so nothing changes for picking). With GPU skinning the posed positions exist only on the GPU and =animVertices= holds the bind pose; nothing in libregnum or graylib reads =animVertices=. Switching paths on a shared model is safe: graylib restores the bind pose in the buffers the first time the GPU path follows a CPU pose.

*Drawing the model elsewhere.* After a GPU pose the model's buffers hold the bind pose, so drawing it with =grl_model_draw()= and the default shader shows the rest pose; draw animated models through =draw_masked()= / =draw_masked_ex()=, or turn GPU skinning off for that animator.

=set_gpu_skinning (animator, FALSE)= forces the CPU path (for debugging, or for code that wants posed vertices in =animVertices=); it drops the pose key so the next =apply()= re-poses.

** Drawing Subsets of a Model
:PROPERTIES:
:CUSTOM_ID: drawing
:END:
=draw_masked()= replicates raylib's =DrawModelEx()= for the meshes whose mask byte is non-zero: material diffuse tint, bone matrix upload (=SHADER_LOC_MATRIX_BONETRANSFORMS=, once per program per call), =DrawMesh()= with =model.transform × transform=. After a GPU pose, skinned meshes on raylib's default shader are drawn with its skinning variant. A =NULL= mask, or bytes missing past its end, draw everything. =draw_masked_ex()= builds the transform from position, yaw (radians about +Y, raylib's rotation convention) and uniform scale in DrawModelEx order. Both do nothing headless and must run inside a 3D mode.

Masks usually come from node names — accessory nodes in character packs:

#+begin_src C
static const gchar *const unarmed[] = {
    "1H_Sword", "1H_Sword_Offhand", "2H_Sword",
    "Badge_Shield", "Rectangle_Shield", "Round_Shield", "Spike_Shield", NULL
};
g_autoptr(GBytes) mask = lrg_model_animator_build_node_mask (animator, knight_info, unarmed);
#+end_src

=build_node_mask()= returns =NULL= when the info describes a different mesh count than the model (wrong file).

** Example
:PROPERTIES:
:CUSTOM_ID: example
:END:
#+begin_src C
/* Once per model. */
GrlModel  *model = lrg_asset_manager_load_model (assets, "models/Knight.glb", &error);
GPtrArray *clips = lrg_asset_manager_load_model_animations (assets, "models/Knight.glb", &error);
g_autoptr(LrgGltfInfo) info = lrg_gltf_info_new_from_file (resolved_path, &error);
g_autoptr(LrgModelAnimator) knight = lrg_model_animator_new (model, clips);

lrg_model_animator_set_clip_names_from_info (knight, info);
lrg_model_animator_set_alias (knight, "walk", "Walking_A");
walk = lrg_model_animator_find_clip (knight, "walk");
idle = lrg_model_animator_find_clip (knight, "idle");

/* Per actor, per tick. */
lrg_model_animator_play (knight, &actor->anim, actor->moving ? walk : idle, TRUE, 0.15);
lrg_model_animator_advance (knight, &actor->anim, dt);

/* Per actor, when drawing. */
lrg_model_animator_apply (knight, &actor->anim);
lrg_model_animator_draw_masked_ex (knight, actor->mask, actor->x, 0.0f, actor->z,
                                   actor->yaw, 1.0f, NULL);
#+end_src

** Lifetime
:PROPERTIES:
:CUSTOM_ID: lifetime
:END:
The animator references the model and every clip. Models from the asset manager are only freed after both the manager's cache entry and every animator are released; release animators before closing the window.
