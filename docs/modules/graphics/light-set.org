* LrgLightSet - Forward Lighting for Static Geometry
:PROPERTIES:
:CUSTOM_ID: lrglightset---forward-lighting-for-static-geometry
:END:
Lights static 3D geometry drawn with =DrawMesh()= - [[file:static-batch.org][LrgStaticBatch]] chunks and [[file:terrain.org][LrgTerrain]] meshes - with an ambient colour, one directional light (the sun or moon) and any number of point lights (torches, lamp posts, windows). Each frame the point lights nearest the camera, up to =LRG_LIGHT_SET_MAX_ACTIVE= (16), are selected and uploaded to a GLSL 330 shader that the light set owns and hands out with =get_shader()=. The same shader applies optional distance fog (linear, exponential, uniform or height), which the weather module's [[file:../weather/index.org][LrgFog]] and =LrgWeatherManager= drive.

Light bookkeeping, the nearest-N selection and the fog model are headless; only the shader needs GL. Without GLSL 330 (or without a window) =get_shader()= returns =NULL= and callers keep raylib's default shader, so a game degrades to unlit rather than failing.

** Semantics
:PROPERTIES:
:CUSTOM_ID: semantics
:END:
*** Lighting model
:PROPERTIES:
:CUSTOM_ID: lighting-model
:END:
Per fragment, with unit normal =n=:

#+begin_example
light = ambient
      + directional_color * max(dot(n, -direction), 0)
      + sum over active point lights of
          color * intensity * k² * max(dot(n, L), 0),   k = clamp(1 - dist / radius, 0, 1)
lit   = texel * colDiffuse * vertexColor * light
final = mix(lit, fog_color, fog_amount(fragment))   (alpha unchanged)
#+end_example

=L= is the unit vector from the fragment to the light. Colours are the 0..255 channels divided by 255; the sum is not clamped before multiplying, so overlapping lights can over-brighten (clamped by the framebuffer). The directional =direction= is where the light travels (for an [[file:sky-dome.org][LrgSkyDome]], the negated sun direction).

*** Shader contract
:PROPERTIES:
:CUSTOM_ID: shader-contract
:END:
- GLSL 330 using raylib's default names: attributes =vertexPosition=, =vertexTexCoord=, =vertexNormal=, =vertexColor=; uniforms =mvp=, =matModel=, =matNormal=, =colDiffuse=, =texture0=. =DrawMesh()= fills all of them, so the shader drops into =lrg_static_batch_set_shader()= and =lrg_terrain_set_shader()= unchanged. Meshes need normals (both of those have them); missing vertex colours default to white.
- Lighting happens in the space the model matrix maps to. LrgTerrain draws origin-relative, so give the light set the same origin (=set_origin()=): light positions are uploaded as =(world - origin)=. Selection always uses world coordinates.
- Uniforms persist in the program: =apply()= once per frame (and after changing lights) is enough for every batch using the shader.
- =set_alpha_cutoff (c)= with =c > 0= discards fragments whose final alpha is below =c= (foliage, fences) so they never write depth; 0 (default) keeps all.
- =get_shader()= builds the shader on the first call with a window; if raylib falls back to its default program (compile failure, e.g. GLES2), it returns =NULL= for good. The shader belongs to the light set; release the light set and any batch holding the shader before closing the window.

*** Distance fog
:PROPERTIES:
:CUSTOM_ID: distance-fog
:END:
Off by default. =set_fog()= turns it on; the fragment blends toward the fog colour by

#+begin_example
d = distance(fragment, camera)          (both in draw space: world minus the origin)
LINEAR       f = clamp((d - start) / (end - start), 0, 1)     end <= start: 0 before end, 1 from end
EXPONENTIAL  f = 1 - exp(-density * d)
UNIFORM      f = clamp(density, 0, 1)                         every distance
HEIGHT       f = (1 - exp(-density * d)) * exp(-falloff * max(height - base, 0))
fog_amount = f * fog_color.alpha / 255
#+end_example

- The camera is the one of the last =select()= / =apply()=; =apply()= uploads it with the fog uniforms (=fogType= -1 when off, =fogColor=, =fogParams= = (density, start, end, falloff), =fogBase=, =fogCamera=).
- The colour's alpha caps the fog: 255 lets distant surfaces vanish into the colour, 128 never fogs more than half. Weather fades fog in and out through this alpha.
- =set_fog_height (base, falloff)= shapes HEIGHT fog (defaults 0 and 1); =base= is a world height, moved by the origin like everything else.
- Non-finite numbers are stored as 0; negative densities as 0. =clear_fog()= turns it off.
- =sample_fog (position)= is the same model on the CPU, for a draw-space position; it equals what the shader computes there (tests, picking, CPU-lit geometry).
- Lit [[file:billboard-batch.org][billboard batches]] fog their quads per fragment with the same model and uniforms.
- The sky is not fogged (it does not use this shader); match its horizon to the fog colour for a seamless far plane.

*** Light grid
:PROPERTIES:
:CUSTOM_ID: light-grid
:END:
With only the 16 nearest lights a large scene (a dungeon with 90 torches, a city with 155 lamps) lights just the area around the camera: distant rooms go dark and lights pop in and out as the 16th-nearest changes. =set_grid (cell_size, cells)= replaces that with a world-space light grid:

- =select()= lays a square of =cells x cells= cells (XZ plane, =cell_size= each) around the camera's cell, snapped to multiples of the cell size so the grid never swims, and sorts every enabled light (intensity > 0, within =max_distance= when set) into the cells its radius reaches. A cell keeps at most =LRG_LIGHT_SET_GRID_SLOTS= (16) lights, ranked by =distance(light, cell rectangle) / radius= (0 inside, 1 at the edge of its reach), so strong lights beat weak ones at the same distance.
- =apply()= uploads the lights referenced by any cell as a =RGBA32F= texture (two texels per light: draw-space position and radius, colour times intensity; at most =LRG_LIGHT_SET_GRID_MAX_LIGHTS=) and the cell lists as a second one (four light indices per texel, -1 ends a list), binds them to texture units 14 and 15 (above raylib's 12 material maps, which =DrawMesh()= binds and unbinds per draw) and sets =useGrid=, =gridParams= = (grid corner X, Z in draw space, cell size, cells).
- The fragment shader finds its cell from =fragPosition.xz= and adds the lights of that list; fragments outside the square get no point light. The per-fragment cost stays bounded by 16 lights however many the scene has.
- =get_grid_light_count (x, z)= / =get_grid_light (x, z, i)= expose a cell's list (headless); =sample()= uses the same lists, so CPU-lit billboards match the geometry.
- =set_grid (0, 0)= returns to the nearest-16 uniform arrays. =max_active= and the nearest-N selection keep working either way (=get_active_light()=).

*** Light limit
:PROPERTIES:
:CUSTOM_ID: light-limit
:END:
The model sums ambient, sun and point lights without tonemapping, so a bright light next to a wall can push the texel to white, brighter than daylight. =set_light_limit (m)= (0 = off, the default) rolls the summed light off per channel: values up to =0.75 m= pass unchanged, above that =knee + (m - knee) (1 - exp(-(l - knee) / (m - knee)))= approaches =m= with slope 1 at the knee, so ordinary levels are untouched. =limit_light (m, value)= is the same curve on the CPU; =sample()= applies it.

*** Emission
:PROPERTIES:
:CUSTOM_ID: emission
:END:
=set_emission (color, intensity)= sets =emissionColor=; the shader adds =texture(emissionMap, uv).rgb * emissionColor= to the lit colour before the fog, independent of the lights (lit windows at night). =emissionMap= is raylib's =MATERIAL_MAP_EMISSION= (texture unit =LRG_LIGHT_SET_EMISSION_UNIT= = 5): [[file:static-batch.org][LrgStaticBatch]] binds a material's map from =lrg_static_batch_set_material_emission()= and a black 1x1 map for materials without one, so nothing left in that unit can glow. The default is no emission (black).

*** Selection
:PROPERTIES:
:CUSTOM_ID: selection
:END:
- Candidates are enabled lights with intensity > 0.
- Each is ranked by its distance from the camera to its sphere, =|light - camera| - radius= (negative when the camera is inside), so a large light slightly further away beats a small one at the same centre distance. Ties go to the lower id.
- =set_max_distance (d)= (0 = unlimited) drops candidates whose rank exceeds =d=; =set_max_active (n)= caps the selection (0 .. 16).
- The best =n= are kept by insertion into a fixed array: O(lights × n), no allocation. =get_active_light (i)= gives them nearest first.
- Removing or clearing lights empties the selection until the next =select()= / =apply()=.

*** CPU evaluation
:PROPERTIES:
:CUSTOM_ID: cpu-evaluation
:END:
=sample()= evaluates exactly the lighting model above for one point, with the point lights of the last selection (=select()= / =apply()=; none before the first; with a light grid, the lights of the point's cell) and positions in draw space (world minus the origin, the space of =fragPosition=). A =NULL= or zero normal drops every Lambert term, the convention for camera-facing quads. The result is the =light= term after the light limit (unclamped without one). It lights geometry the shader cannot reach, such as [[file:billboard-batch.org][LrgBillboardBatch]] quads drawn through rlgl's immediate batch.

The same evaluation exists on the GPU for libregnum's own shaders (=graphics/lrg-light-set-private.h=, not installed): =LRG_LIGHT_SAMPLE_GLSL= declares the light uniforms and =vec3 lrg_light_sample (vec3 p)= (ambient, the directional colour without a Lambert term, the point lights of =p='s grid cell or the active list, the light limit); =lrg_light_set_sample_locations()= finds its uniforms in a shader and =lrg_light_set_upload_sample()= uploads the set's last selection and grid (and binds the grid textures to units 14 and 15). The billboard batch's GPU path lights its static quads with it in the vertex shader, so CPU and GPU lighting agree.

*** Binding
:PROPERTIES:
:CUSTOM_ID: binding
:END:
=bind()= makes a light set the process-wide bound set (a reference is held until =unbind()= or the next =bind()=), like raylib's current shader. Billboard batches without a light set of their own are lit by it, so a game can light every billboard drawn between =bind()= and =unbind()= (scenery, monsters, loot) without handing the set to each batch. Drawing is single threaded; so is the binding.

** Example
:PROPERTIES:
:CUSTOM_ID: example
:END:
#+begin_src C
g_autoptr(LrgLightSet) lights = lrg_light_set_new ();
GrlShader *shader;
GrlColor torch = { 255, 170, 90, 255 };
GrlColor night = { 30, 30, 50, 255 };
GrlVector3 sun, sun_light;

lrg_light_set_set_ambient (lights, &night);
lrg_light_set_add_point_light (lights, 1204.5, 2.0, -88.0, &torch, 6.0f);

shader = lrg_light_set_get_shader (lights);       /* NULL: stay unlit */
lrg_static_batch_set_shader (town, shader);
lrg_terrain_set_shader (ground, shader);

/* each frame */
lrg_sky_dome_get_sun_direction (sky, &sun);
sun_light.x = -sun.x; sun_light.y = -sun.y; sun_light.z = -sun.z;
lrg_light_set_set_directional (lights, &sun_light, &sun_color);
lrg_light_set_set_origin (lights, origin_x, 0.0, origin_z);
lrg_weather_manager_apply_fog (weather, lights);   /* or lrg_light_set_set_fog () */
lrg_light_set_apply (lights, player_x, player_y, player_z);

grl_camera3d_begin (camera);
lrg_terrain_draw (ground);
lrg_static_batch_draw (town, LRG_STATIC_BATCH_ALL_LAYERS);
lrg_light_set_bind (lights);          /* billboards lit on the CPU */
lrg_billboard_batch_draw (trees, &eye);
lrg_light_set_unbind ();
grl_camera3d_end (camera);
#+end_src
