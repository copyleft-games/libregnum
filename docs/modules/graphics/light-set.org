* LrgLightSet - Forward PBR Lighting
:PROPERTIES:
:CUSTOM_ID: lrglightset---forward-lighting-for-static-geometry
:END:
Lights 3D geometry drawn with =DrawMesh()= - [[file:static-batch.org][LrgStaticBatch]] chunks, [[file:terrain.org][LrgTerrain]] meshes, [[file:skinned-mesh.org][LrgSkinnedMesh]], mesh-renderer components and the editor viewport - with GGX/Smith/Schlick metallic-roughness shading (since 0.9.0), an ambient colour or an image-based environment, one directional light (the sun or moon) and any number of point and spot lights (torches, lamp posts, flashlights, street lamps).  It is the one lit shader of the engine: materials ([[file:material.org][LrgMaterial]]), user shaders ([[file:shader-asset.org][LrgShaderAsset]]), the environment ([[file:../lighting/environment.org][LrgEnvironment]]), SSAO ([[file:ssao.org][LrgSsao]]) and decals ([[file:decal.org][LrgDecalSet]]) plug into it through the [[#shader-contract-090][shader contract]] below.  The guide [[file:../../guides/materials-and-pbr.org][Materials and PBR]] walks through the whole flow. Each frame the point lights nearest the camera, up to =LRG_LIGHT_SET_MAX_ACTIVE= (16), are selected and uploaded to a GLSL 330 shader that the light set owns and hands out with =get_shader()=. The same shader applies optional distance fog (linear, exponential, uniform or height), which the weather module's [[file:../weather/index.org][LrgFog]] and =LrgWeatherManager= drive.

Light bookkeeping, the nearest-N selection and the fog model are headless; only the shader needs GL. Without GLSL 330 (or without a window) =get_shader()= returns =NULL= and callers keep raylib's default shader, so a game degrades to unlit rather than failing.

** Semantics
:PROPERTIES:
:CUSTOM_ID: semantics
:END:
*** Lighting model (0.9.0)
:PROPERTIES:
:CUSTOM_ID: lighting-model
:END:
Per fragment, with the shading normal =n= (the normal map's when the material has one), the geometric normal =ng=, the unit view vector =v= toward the eye (=mapCamera=) and the material's linear albedo, metallic, roughness and occlusion:

#+begin_example
lin(c)  = pow(c, 2.2)                     display (sRGB) -> linear
brdf(l) = ((1 - F)(1 - metallic) * albedo + pi * D G F / (4 N.V N.L)) * N.L
          D = GGX(alpha = roughness^2), G = Smith-Schlick (k = (roughness + 1)^2 / 8),
          F = Schlick, F0 = mix(0.04, albedo, metallic), roughness clamped to >= 0.045
sun     = brdf(-sunDirection) * lin(sunColor) * sun_shadow
light_i = brdf(L_i) * lin(color_i * intensity_i * k_i^2 * cone_i) * shadow_i,
          k = clamp(1 - dist / radius, 0, 1), cone = smoothstep(cos outer, cos inner, cos angle)
indirect = environment active ? kd * albedo * env_diffuse(n) + env_specular(n, v, roughness) * (F0 * brdf_lut.x + brdf_lut.y)
                              : lin(ambient) * albedo
radiance = sun + sum light_i + indirect * occlusion * ssao        (light limit applied here)
colour   = display(radiance + emission)  -> ground overlay -> volumetric air -> fog -> output encoding
#+end_example

- The pi is folded into the BRDF: a white rough dielectric facing a white light reflects about 1, so scenes authored for the pre-0.9 Lambert model keep their brightness.  =lrg_light_set_brdf()= is the direct term on the CPU (the reference =tests/test-pbr.c= checks the shader against).
- Colours stay authored in display space (0..255 channels, colour x intensity): =ambientColor=, =sunColor=, the point and spot colours, =colDiffuse=, the albedo texture and the emission colour are linearized in the shader.  The falloff =k^2= and the cone are display-space factors linearized together with the colour, so one light alone gives the same on-screen =(1 - d / r)^2= curve as before and as =sample()= and the billboards; several lights add in linear space.
- A light's intensity therefore scales the display-space colour: 2 is about 4.6 times the linear radiance.  It is not a photometric unit (no lux or lumen); a directional light's colour x intensity saturates at white when it comes from =add_light_desc()=.
- The directional =direction= is where the light travels (for an [[file:sky-dome.org][LrgSkyDome]], the negated sun direction).
- Without an environment the indirect term is the flat ambient colour times the albedo for metals and dielectrics alike (the two diverge only with real image-based light).
- =set_output_linear (TRUE)= writes the linear colour (after fog and air, re-linearized) for an HDR target that a post stack tonemaps; the default writes display colour straight to the screen.

*** Shader contract
:PROPERTIES:
:CUSTOM_ID: shader-contract
:END:
- GLSL 330 using raylib's default names: attributes =vertexPosition=, =vertexTexCoord=, =vertexNormal=, =vertexColor=; uniforms =mvp=, =matModel=, =matNormal=, =colDiffuse=, =texture0=. =DrawMesh()= fills all of them, so the shader drops into =lrg_static_batch_set_shader()= and =lrg_terrain_set_shader()= unchanged (on OpenGL 3.3 the terrain issues its own base-vertex draws but sends exactly the uniforms =DrawMesh()= would, see [[file:terrain.org::#gpu-layout][its GPU layout]]). Meshes need normals (both of those have them); missing vertex colours default to white.
- Lighting happens in the space the model matrix maps to. LrgTerrain draws origin-relative, so give the light set the same origin (=set_origin()=): light positions are uploaded as =(world - origin)=. Selection always uses world coordinates.
- Uniforms persist in the program: =apply()= once per frame (and after changing lights) is enough for every batch using the shader.
- =set_alpha_cutoff (c)= with =c > 0= discards fragments whose final alpha is below =c= (foliage, fences) so they never write depth; 0 (default) keeps all.
- =get_shader()= builds the shader on the first call with a window; if raylib falls back to its default program (compile failure, e.g. GLES2), it returns =NULL= for good. The shader belongs to the light set; release the light set and any batch holding the shader before closing the window.

*** Distance fog
:PROPERTIES:
:CUSTOM_ID: distance-fog
:END:
Off by default. =set_fog()= turns it on; the fragment blends toward the fog colour by

#+begin_example
d = distance(fragment, camera)          (both in draw space: world minus the origin)
LINEAR       f = clamp((d - start) / (end - start), 0, 1)     end <= start: 0 before end, 1 from end
EXPONENTIAL  f = 1 - exp(-density * d)
UNIFORM      f = clamp(density, 0, 1)                         every distance
HEIGHT       f = (1 - exp(-density * d)) * exp(-falloff * max(height - base, 0))
fog_amount = f * fog_color.alpha / 255
#+end_example

- The camera is the one of the last =select()= / =apply()=; =apply()= uploads it with the fog uniforms (=fogType= -1 when off, =fogColor=, =fogParams= = (density, start, end, falloff), =fogBase=, =fogCamera=).
- The colour's alpha caps the fog: 255 lets distant surfaces vanish into the colour, 128 never fogs more than half. Weather fades fog in and out through this alpha.
- =set_fog_height (base, falloff)= shapes HEIGHT fog (defaults 0 and 1); =base= is a world height, moved by the origin like everything else.
- Non-finite numbers are stored as 0; negative densities as 0. =clear_fog()= turns it off.
- =sample_fog (position)= is the same model on the CPU, for a draw-space position; it equals what the shader computes there (tests, picking, CPU-lit geometry).
- Lit [[file:billboard-batch.org][billboard batches]] fog their quads per fragment with the same model and uniforms.
- The sky is not fogged (it does not use this shader); match its horizon to the fog colour for a seamless far plane.

*** Light grid
:PROPERTIES:
:CUSTOM_ID: light-grid
:END:
With only the 16 nearest lights a large scene (a dungeon with 90 torches, a city with 155 lamps) lights just the area around the camera: distant rooms go dark and lights pop in and out as the 16th-nearest changes. =set_grid (cell_size, cells)= replaces that with a world-space light grid:

- =select()= lays a square of =cells x cells= cells (XZ plane, =cell_size= each) around the camera's cell, snapped to multiples of the cell size so the grid never swims, and sorts every enabled light (intensity > 0, within =max_distance= when set) into the cells its radius reaches. A cell keeps at most =LRG_LIGHT_SET_GRID_SLOTS= (16) lights, ranked by =distance(light, cell rectangle) / radius= (0 inside, 1 at the edge of its reach), so strong lights beat weak ones at the same distance.
- =apply()= uploads the lights referenced by any cell as a =RGBA32F= texture (two texels per light: draw-space position and radius, colour times intensity; at most =LRG_LIGHT_SET_GRID_MAX_LIGHTS=) and the cell lists as a second one (four light indices per texel, -1 ends a list), binds them to texture units 14 and 15 (above raylib's 12 material maps, which =DrawMesh()= binds and unbinds per draw) and sets =useGrid=, =gridParams= = (grid corner X, Z in draw space, cell size, cells).
- The fragment shader finds its cell from =fragPosition.xz= and adds the lights of that list; fragments outside the square get no point light. The per-fragment cost stays bounded by 16 lights however many the scene has.
- =get_grid_light_count (x, z)= / =get_grid_light (x, z, i)= expose a cell's list (headless); =sample()= uses the same lists, so CPU-lit billboards match the geometry.
- Nothing is redone that did not change: =select()= rebuilds the lists only when a point light changed (any setter, add, remove, clear), the grid's shape changed, the camera crossed into another cell or layer, or =max_distance= changed (with a distance limit set, also when the camera moved, since the limit measures from it). =apply()= re-sends the cell texture only after a rebuild and the light texture only when its texels (draw-space position, colour, shadow slot, which also follow =set_origin()= and the shadow renderer) differ from what the GPU holds; the buffers persist between frames.
- =set_grid (0, 0)= returns to the nearest-16 uniform arrays. =max_active= and the nearest-N selection keep working either way (=get_active_light()=).

*** Light limit
:PROPERTIES:
:CUSTOM_ID: light-limit
:END:
The model sums ambient, sun and point lights without tonemapping, so a bright light next to a wall can push the texel to white, brighter than daylight. =set_light_limit (m)= (0 = off, the default) rolls the summed light off per channel: values up to =0.75 m= pass unchanged, above that =knee + (m - knee) (1 - exp(-(l - knee) / (m - knee)))= approaches =m= with slope 1 at the knee, so ordinary levels are untouched. =limit_light (m, value)= is the same curve on the CPU; =sample()= applies it.

*** Material slots
:PROPERTIES:
:CUSTOM_ID: material-slots
:END:
The lit shader reads raylib material maps on fixed texture units: =texture0= (unit 0, albedo), =metallicMap= (unit 1, legacy metallic-gloss: metallic in red, smoothness in alpha), =normalMap= (unit 2, tangent space, green up), =ormMap= (unit 4, glTF occlusion-roughness-metallic), =emissionMap= (unit 5) and =heightMap= (unit 6, red, 0.5 is the surface).  The tangent frame comes from screen-space derivatives of position and texture coordinate, so meshes need no tangents.  The normal map perturbs the shading normal, scaled by =pbrParams.w= (the shadow lookups keep the geometric one); the height map shifts the texture coordinates by a parallax offset of the view ray (=LRG_LIGHT_SET_HEIGHT_SCALE=).  Which maps are bound is told by =mapFlags= (see the contract).  =lrg_static_batch_set_material_normal/metallic/height()= still bind the legacy maps per batch material; [[file:material.org][LrgMaterial]] binds the full set with =lrg_material_apply()=.

*** Emission
:PROPERTIES:
:CUSTOM_ID: emission
:END:
=set_emission (color, intensity)= sets the light set's global =emissionColor= (lit windows at night).  The shader always adds =lin(texture(emissionMap, uv).rgb * tint)= after the lights, where =tint= is a material's own =emissionOwn.rgb= when =emissionOwn.w= is 1, else the global colour.  =emissionMap= is raylib's =MATERIAL_MAP_EMISSION= (unit 5): [[file:static-batch.org][LrgStaticBatch]] binds a material's map from =lrg_static_batch_set_material_emission()=, white for an own colour without a map and a black 1x1 map otherwise, so nothing left in that unit can glow.  The default is no emission (black).

*** Spot lights (0.9.0)
:PROPERTIES:
:CUSTOM_ID: spot-lights
:END:
A spot light is a point light (same id space, same position / colour / radius / intensity / enable / shadow-priority calls, same selection, grid and clusters) limited to a cone: =add_spot_light (x, y, z, direction, color, radius, inner, outer)= or =set_spot_light (id, direction, inner, outer)= on an existing light (a =NULL= direction makes it a point light again).  The half-angles are degrees; the inner is clamped to 0 .. 89 and the outer to inner .. 89.  The cone factor is =smoothstep (cos outer, cos inner, cos angle)= (=lrg_light_set_spot_factor()=), applied in the lit shader, in =sample()= and in the billboard / grass / water sampler.  The grid and clusters keep treating a spot as its sphere (conservative).  A spot with a shadow priority competes for the shadow renderer's spot maps, not its cubes (=lrg_shadow_renderer_set_spots()=).

*** Render layers and per-light bias (0.9.0)
:PROPERTIES:
:CUSTOM_ID: render-layers
:END:
=set_light_layers (id, mask)= limits a point or spot light to the [[file:render-layers.org][render layers]] in =mask= (every layer by default); =set_draw_layers (mask)= tells the shader the layers of what draws next (uploaded at once and by every =apply()=).  A light whose mask shares no bit with the draw's is skipped for that draw; the sun and the ambient reach everything.  The 32-bit masks travel as two 16-bit halves (=drawLayers= ivec2, the light texel's =zw=).  =set_light_shadow_bias (id, bias)= gives one light its own shadow depth bias in world units (0 = the shadow renderer's).

*** Lights from components (0.9.0)
:PROPERTIES:
:CUSTOM_ID: light-desc
:END:
=add_light_desc (desc)= adds the light an =LrgLight3DDesc= describes (what [[file:../world3d/components.org][LrgLightComponent]] registers with its world): directional sets the directional light (colour x intensity), point and spot add a light with range as radius, the cone, the layer mask, shadow priority 1 when =cast_shadows= is set and the =shadow-bias= property of =desc->source= when it has one.  =lrg_light_component_add_to_light_set()= is the component-side shortcut.

*** Selection
:PROPERTIES:
:CUSTOM_ID: selection
:END:
- Candidates are enabled lights with intensity > 0.
- Each is ranked by its distance from the camera to its sphere, =|light - camera| - radius= (negative when the camera is inside), so a large light slightly further away beats a small one at the same centre distance. Ties go to the lower id.
- =set_max_distance (d)= (0 = unlimited) drops candidates whose rank exceeds =d=; =set_max_active (n)= caps the selection (0 .. 16).
- The best =n= are kept by insertion into a fixed array: O(lights × n), no allocation. =get_active_light (i)= gives them nearest first.
- Removing or clearing lights empties the selection until the next =select()= / =apply()=.

*** CPU evaluation
:PROPERTIES:
:CUSTOM_ID: cpu-evaluation
:END:
=sample()= evaluates exactly the lighting model above for one point, with the point lights of the last selection (=select()= / =apply()=; none before the first; with a light grid, the lights of the point's cell) and positions in draw space (world minus the origin, the space of =fragPosition=). A =NULL= or zero normal drops every Lambert term, the convention for camera-facing quads. The result is the =light= term after the light limit (unclamped without one). It lights geometry the shader cannot reach, such as [[file:billboard-batch.org][LrgBillboardBatch]] quads drawn through rlgl's immediate batch.

The same evaluation exists on the GPU for libregnum's own shaders (=graphics/lrg-light-set-private.h=, not installed): =LRG_LIGHT_SAMPLE_GLSL= declares the light uniforms and =vec3 lrg_light_sample (vec3 p)= (ambient, the directional colour without a Lambert term, the point lights of =p='s grid cell or the active list, the light limit); =lrg_light_set_sample_locations()= finds its uniforms in a shader and =lrg_light_set_upload_sample()= uploads the set's last selection and grid (and binds the grid textures to units 14 and 15). The billboard batch's GPU path lights its static quads with it in the vertex shader, so CPU and GPU lighting agree.

*** Binding
:PROPERTIES:
:CUSTOM_ID: binding
:END:
=bind()= makes a light set the process-wide bound set (a reference is held until =unbind()= or the next =bind()=), like raylib's current shader. Billboard batches without a light set of their own are lit by it, so a game can light every billboard drawn between =bind()= and =unbind()= (scenery, monsters, loot) without handing the set to each batch. Drawing is single threaded; so is the binding.

*** Clusters (M14)
:PROPERTIES:
:CUSTOM_ID: clusters
:END:
=lrg_light_set_set_grid_layers (layer_height, layers)= stacks the grid into =layers= layers of cells centred on the camera's height, so storeys above one another (a dungeon's levels) keep their own lists instead of sharing one column; the lowest and highest layers reach down and up without end, and one layer (the default) is the flat grid. =lrg_light_set_set_grid_slots (slots)= sets how many lights a cell lists (4 .. =LRG_LIGHT_SET_GRID_MAX_SLOTS= (32), default 16). A light joins a cluster when its sphere reaches the cluster's box; the list keeps the closest relative to their radius. =lrg_light_set_get_cluster_light_count (x, y, z)= and =get_cluster_light()= read a cluster; the older XZ queries read the camera's layer. The cell texture is (cells x slots / 4) x (cells x layers); both the mesh shader and the billboard sampler (=LRG_LIGHT_CLUSTER_GLSL=) find a fragment's cluster the same way, and =lrg_light_set_sample()= reads the cluster of its point's own height.

*** Shadows (M14)
:PROPERTIES:
:CUSTOM_ID: shadows
:END:
=lrg_light_set_set_shadow_renderer()= gives the set an [[file:../lighting/shadow-renderer.org][LrgShadowRenderer]]; =lrg_light_set_set_point_light_shadow (id, priority)= lets a point light compete for one of its cubes. Once the renderer's passes are rendered, =apply()= binds its atlases (units 12 and 13) and the shader darkens the directional light's Lambert term and every shadowed point light where casters hide them (the light's shadow slot travels in the light texel's fourth channel with a grid, in =lightShadow[]= without). =lrg_light_set_get_origin()= and =lrg_light_set_get_directional()= read back what the renderer plans with. =sample()= does not look at shadows.  Since 0.9.0 shadowed spot lights get a perspective map in the spot atlas (unit 11, slot in the light texel's =3.y=, =lightSpotExtra[].y= without a grid), filtered with the renderer's PCF radius; each point or spot light may carry its own depth bias.  =lrg_light_set_get_shadow_renderer()= returns the renderer, =lrg_light_set_get_point_light_shadow()= a light's priority.

*** Volumetric air (M14)
:PROPERTIES:
:CUSTOM_ID: volumetric-air
:END:
=lrg_light_set_set_air (density, anisotropy, intensity, steps, max_distance, tint)= marches each fragment's view ray from the camera (up to =max_distance=) in =steps= jittered steps. Each step adds the light scattered toward the eye: the directional light through the Henyey-Greenstein phase function (=lrg_light_set_air_phase()=, g = =anisotropy=) and its cascade lookup, so shafts form behind casters at dawn and dusk; the renderer's shadowed point lights by their falloff, phase and cube lookup; and the ambient colour over 4 pi. Each step is weighted by =density= and the transmittance up to it; the fragment is then dimmed by the transmittance =exp (-density x distance)=, and the air's colour is =tint=. =lrg_light_set_sample_air()= is the same sum on the CPU (steps at their middles, no shadows). =lrg_light_set_clear_air()= turns it off (the default) and =lrg_light_set_get_air()= reads it back.  The air is evaluated in display space after the PBR lighting; spot lights do not scatter in it (only the sun, the shadowed point lights and the ambient do).

*** Light grid queries, limit and emission calls
:PROPERTIES:
:CUSTOM_ID: grid-queries
:END:
=lrg_light_set_get_grid_light_count (x, z)= and =lrg_light_set_get_grid_light (x, z, i)= read the flat grid's cell lists (the camera's layer with clusters); =lrg_light_set_get_grid_slots()= returns the lights per cell.  =lrg_light_set_set_light_limit()= / =lrg_light_set_get_light_limit()= set and read the soft limit and =lrg_light_set_limit_light()= is its curve; since 0.9.0 the limit is applied to the summed irradiance in display space and the reflected radiance is scaled by the same factor, so a limited light keeps its colour and the specular highlight scales with it.  =lrg_light_set_set_emission()= is described under [[#emission][Emission]].

** Shader contract (0.9.0)
:PROPERTIES:
:CUSTOM_ID: shader-contract-090
:END:
Everything a material, a user shader, or another pass needs to know to work with the lit shader.  The fragment shader is =#version 330=, the varyings of the vertex source, =finalColor=, the library (=lrg_light_set_get_glsl_library()=) and a one-line =main()= calling =lrg_light_shade()=.

*** Material uniforms
:PROPERTIES:
:CUSTOM_ID: material-uniforms
:END:
| Uniform | Type | Unit | Meaning |
|-+-+-+-|
| =texture0= | sampler2D | 0 | albedo, sRGB; white when unset |

| =mapFlags= | int | | bits below |
| =emissionOwn= | vec4 | | material emission colour x strength (sRGB) in rgb, w = 1 to use it instead of =emissionColor= |

| =alphaCutoff= | float | | discard below this alpha (texel x =colDiffuse= x vertex alpha) |

| =mapFlags= bit | Macro | Effect |
|-+-+-|
| 1 | =LRG_LIGHT_SET_MAP_NORMAL= | normal map perturbs the shading normal, xy scaled by =pbrParams.w= |

| 4 | =LRG_LIGHT_SET_MAP_HEIGHT= | parallax offset of the texture coordinates |

*** Texture units
:PROPERTIES:
:CUSTOM_ID: texture-units
:END:
| Unit | Use |
|-+-|
| 0, 1, 2, 4, 5, 6 | material maps (above) |
| 7 .. 10 | free (raylib's cubemap / irradiance / prefilter / BRDF slots, unused); the hooks' fallback window on a 16-unit driver |
| 11 | spot shadow atlas |
| 12, 13 | sun and point shadow atlases |
| 14, 15 | light grid textures |
| 16 .. min (GL_MAX_TEXTURE_IMAGE_UNITS, 32) - 1 | hook binders (=LRG_LIGHT_SET_HOOK_UNIT=) |

OpenGL 3.3 guarantees only 16 fragment texture units.  The light set queries =GL_MAX_TEXTURE_IMAGE_UNITS= once (through =rlGetProcAddress ("glGetIntegerv")=): with more than 16 the hooks start at 16, with exactly 16 they get units 7 .. 10 and a hook that finds no unit left binds its inactive state.  Every desktop driver of the last decade (and llvmpipe, 32) has more than 16.

*** Hooks of other passes
:PROPERTIES:
:CUSTOM_ID: hooks
:END:
Three GLSL snippets, each owned by its feature's private header, are pasted into the library after the cluster, spot, fog, shadow, air and overlay snippets and after =LRG_PI=, =lrg_to_linear()=, =lrg_to_display()= and =struct LrgSurface= (so hooks may use them):

| Macro (header) | Functions | How the shader uses them |
|-+-+-|
| =LRG_ENV_GLSL= (=lighting/lrg-environment-glsl-private.h=) | =bool lrg_env_active()=, =vec3 lrg_env_diffuse(vec3 n)=, =vec3 lrg_env_specular(vec3 n, vec3 v, float rough)=, =vec2 lrg_env_brdf(float nv, float rough)= | indirect light when active (linear radiance), else the flat ambient |
| =LRG_SSAO_GLSL= (=graphics/lrg-ssao-glsl-private.h=) | =float lrg_ssao()= | multiplies the indirect light (with the material occlusion) |
| =LRG_DECAL_GLSL= (=graphics/lrg-decal-glsl-private.h=) | =void lrg_decals_apply(vec3 p, vec3 ng, inout vec4 albedo, inout vec3 n, inout float rough, inout float metal)= | after material sampling, before lighting; =albedo= is linear |

Each header also declares a binder, called by every =lrg_light_set_apply()= in this order with the lit program enabled:

#+begin_src C
void lrg_environment_bind_private (LrgEnvironment *env, guint shader_id, gint *texture_unit);
void lrg_ssao_bind_private (LrgSsao *ssao, guint shader_id, gint *texture_unit);
void lrg_decal_set_bind_private (LrgDecalSet *decals, guint shader_id, gint *texture_unit);
#+end_src

A =NULL= object binds the inactive state (uniform switches off).  Binders look their uniforms up per program id, take texture units from =*texture_unit= upward (checking each with =lrg_light_set_hook_unit_usable()= from =graphics/lrg-light-set-private.h=) and advance it.  A =samplerCube= must always point at a unit of its own, even when inactive: left on unit 0 beside the =sampler2D= =texture0= it makes every draw fail with =GL_INVALID_OPERATION=.  =set_environment()=, =set_ssao()= and =set_decals()= hold references.

*** GLSL library for user shaders
:PROPERTIES:
:CUSTOM_ID: glsl-library
:END:
=lrg_light_set_get_glsl_library()= returns every uniform, hook and function above without =#version=, varyings or =main()=; =lrg_light_set_get_vertex_source()= the complete vertex shader (raylib's attribute and matrix names in; =fragPosition=, =fragTexCoord=, =fragColor=, =fragNormal= out, in draw space).  A user fragment shader is:

#+begin_src C
g_autofree gchar *fs = g_strconcat ("#version 330\n"
                                    "in vec3 fragPosition;\n"
                                    "in vec2 fragTexCoord;\n"
                                    "in vec4 fragColor;\n"
                                    "in vec3 fragNormal;\n"
                                    "out vec4 finalColor;\n",
                                    lrg_light_set_get_glsl_library (),
                                    "void main() {\n"
                                    "    LrgSurface s = lrg_surface(fragPosition, normalize(fragNormal), fragTexCoord, fragColor);\n"
                                    "    s.albedo.rgb *= vec3(1.0, 0.6, 0.6);   /* tint in linear space */\n"
                                    "    vec3 v = normalize(mapCamera - fragPosition);\n"
                                    "    vec3 c = lrg_light_pbr(fragPosition, s.normal, v, s.albedo, s.metallic, s.roughness, s.occlusion);\n"
                                    "    finalColor = vec4(lrg_to_display(c + s.emission), s.albedo.a);\n"
                                    "}\n", NULL);
g_autoptr(GrlShader) shader = grl_shader_new_from_memory (lrg_light_set_get_vertex_source (), fs, &error);
#+end_src

| Function | Returns |
|-+-|
| =vec3 lrg_light_pbr (vec3 p, vec3 n, vec3 v, vec4 albedo, float metal, float rough, float ao)= | linear radiance: sun, point and spot lights with shadows, indirect (environment or ambient) x ao x SSAO, light limit; albedo linear |
| =vec3 lrg_light_pbr_ex (p, ng, n, v, albedo, metal, rough, ao)= | the same with a separate geometric normal for the shadow offsets |
| =LrgSurface lrg_surface (vec3 p, vec3 ng, vec2 uv, vec4 vertex_colour)= | the material maps: linear albedo + alpha, shading normal, metallic, roughness, occlusion, linear emission |
| =vec4 lrg_light_shade (vec3 p, vec3 normal, vec2 uv, vec4 vertex_colour)= | the built-in main(): surface, cutout, decals, lighting, emission, overlay, air, fog, output encoding |
| =vec3 lrg_brdf_direct (vec3 n, vec3 v, vec3 l, vec3 albedo, float metal, float rough)= | one light's BRDF x N.L |
| =vec3 lrg_to_linear (vec3)=, =vec3 lrg_to_display (vec3)= | gamma 2.2 conversions |

The library declares =texture0=, =colDiffuse= and the rest: a user shader must not declare them again.  =lrg_light_set_apply()= uploads the uniforms to the light set's own program; =lrg_light_set_bind_shader (lights, user_shader)= uploads the same state (lights of the last selection, grid, shadow atlases, fog, air, overlay, layers, output encoding and the hooks) to a user program, after =apply()= each frame.  The first call for a program looks up its uniforms, points its samplers at the light set's units (the material maps, the grid, the shadow atlases) and sets the material defaults; the locations are cached by program id, so call =lrg_light_set_forget_shader()= before unloading a program whose id could be reused.  =lrg_light_set_set_draw_layers()= updates only the light set's own program at once; a user program gets the layers at its next =bind_shader()=.  [[file:shader-asset.org][LrgShaderAsset]] does this for lit assets; =tests/test-pbr.c= =/pbr/gpu/library= checks a user shader lights pixel-identically to the built-in one.

** Performance
:PROPERTIES:
:CUSTOM_ID: performance
:END:
- Per light the GGX path adds one =normalize=, two =pow= and about a dozen multiply-adds to the old Lambert term; the 16-light / grid-slot cap keeps the worst case bounded.  The 0.9.0 change has not been benchmarked separately; measure with =lrg-bench= before raising the slot count.
- Spot cones cost one dot product and a smoothstep; a spot shadow is one perspective lookup with the PCF taps of the renderer's filter.
- The grid's light texture grew from two to four texels a light (16 KB per 1024 lights); it is still re-sent only when its texels change.
- The hooks cost one uniform test each when inactive.

** Pitfalls
:PROPERTIES:
:CUSTOM_ID: pitfalls
:END:
- Uniforms persist: a material sets =pbrParams= / =mapFlags= / =emissionOwn= and the next draw without a material inherits them unless restored.
- Do not write =emissionColor= from a material; that clobbers the light set's global emission for the rest of the frame.
- Colours are display space everywhere in the C API; do not pre-linearize them.  The light component's =color-r/g/b= are 0..1 display values despite their old "linear" wording.
- Bind something (white or black) to unit 5 for every draw: the shader samples it unconditionally.
- A samplerCube left on unit 0 breaks every draw (=GL_INVALID_OPERATION=, nothing drawn): hook binders must claim a unit for it even when inactive.
- Intensity is a display-space multiplier: doubling it is far more than double the energy.
- =sample()= stays the diffuse, display-space model (no specular, no shadows); billboards lit with it match a rough dielectric surface, not a metal.

** Using it from the editor
:PROPERTIES:
:CUSTOM_ID: editor
:END:
The editor viewport and play-in-editor draw with the light set of [[file:../world3d/renderer.org][LrgWorld3DRenderer]]: light nodes (=light_type= directional / point / spot, =intensity=, =range=, =spot_angle=, =cast_shadows=, =shadow_bias=) become [[file:../world3d/components.org][LrgLightComponent]]s, which the renderer feeds through =lrg_light_set_add_light_desc()=; material inspection and the environment page edit what the contract above reads.


** Example
:PROPERTIES:
:CUSTOM_ID: example
:END:
#+begin_src C
g_autoptr(LrgLightSet) lights = lrg_light_set_new ();
GrlShader *shader;
GrlColor torch = { 255, 170, 90, 255 };
GrlColor night = { 30, 30, 50, 255 };
GrlVector3 sun, sun_light;

lrg_light_set_set_ambient (lights, &night);
lrg_light_set_add_point_light (lights, 1204.5, 2.0, -88.0, &torch, 6.0f);

shader = lrg_light_set_get_shader (lights);       /* NULL: stay unlit */
lrg_static_batch_set_shader (town, shader);
lrg_terrain_set_shader (ground, shader);

/* each frame */
lrg_sky_dome_get_sun_direction (sky, &sun);
sun_light.x = -sun.x; sun_light.y = -sun.y; sun_light.z = -sun.z;
lrg_light_set_set_directional (lights, &sun_light, &sun_color);
lrg_light_set_set_origin (lights, origin_x, 0.0, origin_z);
lrg_weather_manager_apply_fog (weather, lights);   /* or lrg_light_set_set_fog () */
lrg_light_set_apply (lights, player_x, player_y, player_z);

grl_camera3d_begin (camera);
lrg_terrain_draw (ground);
lrg_static_batch_draw (town, LRG_STATIC_BATCH_ALL_LAYERS);
lrg_light_set_bind (lights);          /* billboards lit on the CPU */
lrg_billboard_batch_draw (trees, &eye);
lrg_light_set_unbind ();
grl_camera3d_end (camera);
#+end_src
