* LrgSkinnedMesh - Skinned Meshes with a Bone Palette
:PROPERTIES:
:CUSTOM_ID: lrgskinnedmesh---skinned-meshes-with-a-bone-palette
:END:
A triangle mesh whose vertices follow bones: each vertex carries up to four bone indices and weights, and a pose is a *palette* of one matrix per bone, =world(bone) * inverse_bind(bone)=. A posed vertex is the weighted sum of =palette(bone) * position=. Characters, creatures and first-person arms built from any skeletal format (glTF skins, NetImmerse =NiSkinData=, IQM) reduce to this: bind-space geometry, an inverse bind per bone and the bone world matrices of the current frame.

The palette math, the weight validation and a CPU reference skinning run headlessly; =upload()= and =draw()= need a GL context. Drawing skins on the GPU with a GLSL 3.30 vertex shader (=uniform mat4 boneMatrices[64]=); a mesh with more bones than the palette holds, or a context without vertex arrays, is skinned on the CPU into a dynamic position and normal buffer instead, so every mesh draws.

** Geometry
:PROPERTIES:
:CUSTOM_ID: geometry
:END:
=set_geometry()= copies the arrays and validates everything first: 1 .. 65535 vertices, a whole triangle list whose indices name existing vertices, finite non-negative weights, and every weighted bone index below the bone count. A failure is =G_IO_ERROR_INVALID_DATA= and leaves the mesh as it was. Weights are renormalised to sum to one; a vertex whose weights are all zero follows bone 0. Unweighted slots get index 0 so the shader never reads past the palette.

** Palette
:PROPERTIES:
:CUSTOM_ID: palette
:END:
Every bone starts with an identity inverse bind and the palette starts as identities, the bind pose. =compute_palette()= multiplies the caller's bone world matrices by the inverse binds without posing the mesh; =set_palette()= poses it. =compute_palette_from_skeleton()= takes an =LrgSkeleton= whose world poses are current (=lrg_skeleton_calculate_world_poses()=) and maps mesh bone /i/ to skeleton bone /i/; it fails when the skeleton has fewer bones.

=lrg_skinned_mesh_skin()= is the reference: positions are the weighted sum of =palette * p=; normals are the weighted sum of each palette entry's inverse-transpose linear transform applied to =n=, then renormalised. This preserves nonuniform import scale instead of bending normals toward a stretched axis. CPU normal matrices are cached per bone when the palette changes. The GPU uses the same guarded cofactor calculation and also inverse-transposes the model transform. A collapsed transform has no defined normal and contributes zero rather than NaNs. The affine-normal synthetic check covers nonuniform scale, reflection and collapse; existing rigid/two-bone and GPU readback checks remain applicable.

** Drawing
:PROPERTIES:
:CUSTOM_ID: drawing
:END:
=upload()= hands raylib the usual attributes and adds two buffers to the mesh's vertex array at raylib's bone attribute locations (=RL_DEFAULT_SHADER_ATTRIB_LOCATION_BONEINDICES= / =BONEWEIGHTS=, bound to the names =vertexBoneIndices= and =vertexBoneWeights= by every raylib shader program). raylib's own GPU skinning path is compiled out of graylib's raylib (=SUPPORT_GPU_SKINNING 0=), so the mesh does this itself rather than changing the third-party build. =draw()= sets =boneMatrices=, =useSkinning= and =alphaCutoff= on the shader and calls =DrawMesh()= with the albedo texture (or white) and the tint.

The built-in fragment shader multiplies the texture, tint and vertex colour, discards fragments below the alpha cutoff (hair, fur) and shades with a fixed key light. A custom shader (=set_shader()=) starts from =get_vertex_shader_source()= and keeps those attribute and uniform names. The built-in program is shared by every mesh and released with the last upload.

** Materials
:PROPERTIES:
:CUSTOM_ID: materials
:END:

** Morph targets
:PROPERTIES:
:CUSTOM_ID: morph-targets
:END:
Morph targets (blend shapes) deform the bind geometry before skinning: a morphed vertex is =base + sum(weight[i] * delta[i])= for positions and normals (normals renormalised). They live in an =LrgMorphTargets= (*Final GObject Class*, =LRG_TYPE_MORPH_TARGETS=, declared in the same header) set on the mesh.

- *Groups* - every target belongs to a group (the glTF importer uses the node name, the target name of that node's clip weight channels) and targets of a group are stored next to each other; =find_group()= returns the first index and the count, =set_morph_group_weights()= sets them from a sampled weight channel (=lrg_animation_clip_sample_weights()=).
- *Setting targets* - =set_morph_targets()= needs the mesh's vertex count (set the geometry first), references the targets, starts the weights at the defaults and makes an uploaded mesh re-upload with dynamic vertex buffers. =NULL= removes them. New geometry with another vertex count drops them.
- *Where blending runs* - on the CPU, lazily: a weight change marks the blend stale; =lrg_skinned_mesh_skin()=, =get_morphed_positions()= and the next =draw()= recompute it once (O(vertices x targets with a non-zero weight)). The GPU path then re-uploads the blended positions and normals (=UpdateMeshBuffer()=) and skins them in the shader; the CPU fallback skins the blended geometry. Unchanged weights cost nothing (the setters compare first).
- *Bounds and skinning* - =get_skinned_bounds()= and =skin()= include the morph.

/* drive a face from a clip's weight channel */

** Example
:PROPERTIES:
:CUSTOM_ID: example
:END:
#+begin_src C
g_autoptr(LrgSkinnedMesh) arm = lrg_skinned_mesh_new (2);
gfloat world[32];
gfloat palette[32];

lrg_skinned_mesh_set_geometry (arm, n, positions, normals, uvs, NULL, bones, weights,
                               n_indices, indices, &error);
lrg_skinned_mesh_set_inverse_bind (arm, 1, forearm_inverse_bind);

/* every frame: pose the skeleton, then */
lrg_skinned_mesh_compute_palette (arm, world, palette);
lrg_skinned_mesh_set_palette (arm, palette);
lrg_skinned_mesh_draw (arm, &model);
#+end_src
