* LrgImageCanvas
:PROPERTIES:
:CUSTOM_ID: lrg-image-canvas
:END:

CPU-side dynamic-texture canvas: wraps a =GrlImage= and exposes a clean,
engine-level drawing / compositing / transform / blur API, then hands back a
=GrlTexture= via =lrg_image_canvas_to_texture()=.

** Start here: the quality preset and supersampled export
:PROPERTIES:
:CUSTOM_ID: image-canvas-quality
:END:
For a finished picture (an illustration, an icon, a generated scene) create the canvas with the quality preset, or supersampled, instead of =lrg_image_canvas_new()=. The plain constructor keeps graylib's pixel-exact defaults - =GRL_IMAGE_BLEND_REPLACE= (a translucent shape overwrites the pixels under it, alpha included, leaving see-through holes), blending in gamma space and aliased edges - which suit texture work but not pictures.

| Constructor | What you get |
|-------------+--------------|
| =lrg_image_canvas_new_quality (w, h, bg)= | =lrg_image_canvas_new()= + =lrg_image_canvas_set_quality()=: =GRL_IMAGE_BLEND_OVER=, =GRL_IMAGE_COLOR_SPACE_LINEAR=, anti-aliasing on |
| =lrg_image_canvas_new_supersampled (w, h, factor, bg)= | a quality canvas of =w x factor= by =h x factor= pixels that remembers =factor=; =lrg_image_canvas_resolve()= returns the =w x h= image |

=lrg_image_canvas_set_quality()= applies the same three settings to any existing canvas; each can still be changed afterwards with =set_blend_mode=, =set_blend_color_space= and =set_antialias=. Linear blending means 50% white over black is the grey the eye expects (sRGB 188), not the dark 128 of gamma-space blending.

Supersampling renders at 2x, 3x or 4x and downsamples once at the end: thin lines, small text, polygon slivers and overlapping translucent shapes all come out smooth, far beyond what per-primitive anti-aliasing manages. =lrg_image_canvas_resolve()= uses =lrg_image_downsample()= ([[file:image-resample.org][image resampling]]): gamma-correct, on premultiplied alpha, with the filter you choose (=LRG_RESAMPLE_FILTER_LANCZOS3= for line art and text, =LRG_RESAMPLE_FILTER_MITCHELL= for soft content, =LRG_RESAMPLE_FILTER_BOX= for a plain average). Do not use =grl_image_resize()= for this: it filters the 8-bit sRGB bytes directly and darkens fine detail.

Coordinates on a supersampled canvas are in the large image's pixels: multiply by =lrg_image_canvas_get_supersample()= (or call =lrg_image_canvas_scale (canvas, f, f)= once, which covers the transform-aware primitives listed under [[#transform-stack][Transform stack]] but not gradients and text). Multiply line thickness and radii as well.

#+begin_src C
#include <libregnum.h>

int
main (void)
{
	g_autoptr(GrlColor)       bg = grl_color_new (25, 35, 70, 255);
	g_autoptr(GrlColor)       line = grl_color_new (240, 240, 230, 255);
	g_autoptr(GrlColor)       glass = grl_color_new (230, 40, 60, 140);
	g_autoptr(LrgImageCanvas) canvas = NULL;
	g_autoptr(GrlImage)       final = NULL;
	gint                      f;

	/* draw at 3x, resolve to 512 x 256 */
	canvas = lrg_image_canvas_new_supersampled (512, 256, 3, bg);
	f = (gint) lrg_image_canvas_get_supersample (canvas);

	lrg_image_canvas_draw_line (canvas, 20 * f, 236 * f, 220 * f, 40 * f, 1 * f, line);
	lrg_image_canvas_fill_circle (canvas, 380 * f, 150 * f, 45 * f, glass);
	lrg_image_canvas_fill_circle (canvas, 420 * f, 150 * f, 45 * f, glass);

	final = lrg_image_canvas_resolve (canvas, LRG_RESAMPLE_FILTER_LANCZOS3);
	return grl_image_export (final, "scene.png") ? 0 : 1;
}
#+end_src

For light that exceeds white (glows, suns, HDR shading) draw into an [[file:hdr-canvas.org][LrgHdrCanvas]] instead and tone-map it to a =GrlImage=.

** Overview

=LrgImageCanvas= is a thin, ergonomic facade over graylib's software rasterizer
for building textures procedurally without a GL context. It is useful for:

- *Dye / tint systems* — recolour a silhouette procedurally
- *Decals* — stamp blurred, alpha-composited art onto surfaces
- *Drop shadows* — one call: =lrg_image_canvas_drop_shadow()=
- *Procedural icons* — draw paths, gradients and text headlessly

All drawing is on the CPU; only =to_texture()= needs a GL context.

** Quick start

#+begin_src C
g_autoptr(LrgImageCanvas) canvas = lrg_image_canvas_new (64, 64, NULL); /* transparent */
g_autoptr(GrlColor)       white  = grl_color_new (255, 255, 255, 255);

lrg_image_canvas_set_antialias (canvas, TRUE);
lrg_image_canvas_fill_circle (canvas, 32, 32, 20, white);

/* Soft drop shadow behind the current content */
g_autoptr(GrlColor) grey = grl_color_new (0, 0, 0, 180);
lrg_image_canvas_drop_shadow (canvas,
                              lrg_image_canvas_get_image (canvas),
                              4, 4, 3, grey);

g_autoptr(GrlTexture) tex = lrg_image_canvas_to_texture (canvas); /* needs GL */
#+end_src

** Transform stack
:PROPERTIES:
:CUSTOM_ID: transform-stack
:END:

=save= / =restore= push and pop the transform; =translate=, =scale=, =rotate=
(radians) and =reset_transform= modify the current matrix. Geometry primitives
(=fill_rect=, =fill_circle=, =fill_polygon=, =fill_path=, =stroke_path=,
=stroke_circle=, =draw_line=) are transformed by the current matrix.

#+begin_src C
lrg_image_canvas_save (canvas);
lrg_image_canvas_translate (canvas, 32.0f, 32.0f);
lrg_image_canvas_rotate (canvas, 0.785f);          /* 45 deg */
lrg_image_canvas_fill_rect (canvas, 0, 0, 8, 8, white);
lrg_image_canvas_restore (canvas);
#+end_src

*Not transformed:* =draw_gradient_rect=, =draw_gradient_radial= and =draw_text=
ignore the transform stack (the underlying graylib gradient/text primitives are
not matrix-aware). =clear=, =composite=, =apply_mask= and =blur= are whole-image
pixel operations and are transform-independent by design.

** API summary

| Group | Functions |
|-------+-----------|
| Construction | =new=, =new_for_image=, =get_image=, =to_texture= |
| Quality (0.14) | =new_quality=, =set_quality=, =new_supersampled=, =get_supersample=, =resolve= |
| State | =set_blend_mode=, =set_blend_color_space=, =set_antialias=, =set_clip_rect= |
| Transform | =save=, =restore=, =translate=, =scale=, =rotate=, =reset_transform= |
| Draw | =clear=, =fill_circle=, =stroke_circle=, =fill_rect=, =draw_line=, =fill_polygon=, =fill_path=, =stroke_path=, =draw_text=, =draw_gradient_rect=, =draw_gradient_radial= |
| Composite | =composite=, =apply_mask=, =blur=, =drop_shadow= |

For anything not wrapped here, =lrg_image_canvas_get_image()= returns the
underlying =GrlImage= (transfer none) for direct graylib calls.
