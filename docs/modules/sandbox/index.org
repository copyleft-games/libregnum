#+title: Sandbox (LrgSandbox)
#+description: Confine the running process with no_new_privs, Landlock (filesystem, TCP/UDP ports, IPC scopes) and a seccomp filter; an optional bubblewrap outer layer

* Sandbox
:PROPERTIES:
:CUSTOM_ID: sandbox
:END:
=LrgSandbox= (=src/sandbox/lrg-sandbox.h=) confines the calling process so that code running inside it (a script, a mod, a bug exploited over the network) cannot start programs, escalate privileges or write outside the places the game chose.  It uses only unprivileged Linux mechanisms, no daemon and no library beyond GLib:

| Layer | Mechanism | Kernel |
|-------+-----------+--------|
| privileges | =prctl(PR_SET_NO_NEW_PRIVS)=: setuid binaries and file capabilities stop granting anything | 3.5 |
| filesystem | Landlock ruleset: every access right the kernel's ABI knows is denied except beneath the paths with a rule | 5.13 (ABI 1) .. ABI 10 |
| network | seccomp refuses IP sockets (=NONE=); Landlock restricts TCP binds/connects to ports | seccomp any; TCP ports ABI 4 (6.7); UDP ports ABI 10 |
| IPC | Landlock scopes: no abstract UNIX sockets or signals to processes outside the sandbox | ABI 6 (6.12) |
| system calls | seccomp-BPF filter, applied to every thread (=SECCOMP_FILTER_FLAG_TSYNC=) | 3.17 |

The Landlock UAPI constants and structures are copied into the source, so a binary built on an old distribution (an AppImage built on an old base) still uses every right of the newer kernel it runs on: the handled rights are masked by the ABI the kernel reports at run time.

** Policy
:PROPERTIES:
:CUSTOM_ID: policy
:END:
#+begin_src c
g_autoptr(LrgSandbox) sandbox = lrg_sandbox_new ();
g_autoptr(GError) error = NULL;

lrg_sandbox_allow_path (sandbox, "/usr", LRG_SANDBOX_ACCESS_READ);
lrg_sandbox_allow_path (sandbox, "/etc", LRG_SANDBOX_ACCESS_READ);
lrg_sandbox_allow_path (sandbox, "/dev", LRG_SANDBOX_ACCESS_DEVICE);
lrg_sandbox_allow_path (sandbox, runtime_dir, LRG_SANDBOX_ACCESS_READ | LRG_SANDBOX_ACCESS_CONNECT);
lrg_sandbox_allow_path (sandbox, saves_dir, LRG_SANDBOX_ACCESS_READ | LRG_SANDBOX_ACCESS_WRITE);
lrg_sandbox_set_network (sandbox, LRG_SANDBOX_NETWORK_CLIENT);
lrg_sandbox_allow_port (sandbox, 7710);
if (!lrg_sandbox_apply (sandbox, &error))
    g_printerr ("sandbox: %s\n", error->message);
#+end_src

| =LrgSandboxAccess= | Landlock rights granted beneath the path |
|--------------------+------------------------------------------|
| =READ= | read files, list directories |
| =WRITE= | write and truncate files; create, remove and rename regular files and directories; refer (rename across directories).  No symlinks, sockets, FIFOs or device nodes: a link planted in a writable directory could redirect a later, unsandboxed run's writes |
| =DEVICE= | read, write and ioctl on device nodes (GPU, sound, input); read the directory |
| =CONNECT= | connect to pathname UNIX sockets (Wayland, X11, PipeWire/Pulse, the session bus); ABI 9 |
| =EXECUTE= | execute files (only when =lrg_sandbox_set_allow_exec (TRUE)=) |

- A rule covers the path and everything beneath it; rules for the same path add up.  A rule on a file only keeps the file rights.
- A path that does not exist when the sandbox is applied is skipped; nothing can be created beneath it later, so a caller creates its writable directories before applying.
- Relative paths are refused (=LRG_SANDBOX_ERROR_INVALID_PATH=) before anything irreversible happens.
- =require-landlock= (default =TRUE=): without Landlock (the kernel is too old or =landlock= is missing from the =lsm== boot list) =lrg_sandbox_apply()= fails with =LRG_SANDBOX_ERROR_UNSUPPORTED=.  With =FALSE= it applies only no_new_privs and seccomp and warns.

| =LrgSandboxNetwork= | seccomp | Landlock (ABI 4+, UDP ABI 10+) |
|---------------------+---------+--------------------------------|
| =NONE= | =socket()= only for =AF_UNIX= and =AF_NETLINK=; others fail with =EACCES= | no TCP/UDP bind or connect |
| =CLIENT= | also =AF_INET= / =AF_INET6= | no TCP bind; connects (and UDP sends) only to the allowed ports, all ports when none was allowed; UDP may bind an ephemeral port |
| =SERVER= | also =AF_INET= / =AF_INET6= | binds only the allowed ports; no outgoing TCP connects; accepted connections and UDP replies work |
| =FULL= | not restricted | not restricted |

A client that resolves host names needs DNS: allow port 53 too.

** What the seccomp filter denies
:PROPERTIES:
:CUSTOM_ID: seccomp
:END:
Denied calls fail with =EPERM= (sockets with =EACCES=), so code that tries them gets a normal error instead of being killed; a system call of another architecture (=int 0x80= on x86_64, x32) kills the process.

- =execve=, =execveat= (unless allowed): no program can be started, so =g_spawn_*=, =system()=, =popen()= fail;
- =ptrace=, =process_vm_readv=, =process_vm_writev=, =pidfd_getfd=;
- =mount=, =umount2=, =pivot_root=, =chroot=, =unshare=, =setns=, the new mount API (=open_tree=, =move_mount=, =fsopen=, =fsconfig=, =fsmount=, =fspick=, =mount_setattr=), =clone= with any =CLONE_NEW*= flag;
- =clone3= returns =ENOSYS= (its flags live in memory a filter cannot read), so the C library falls back to =clone()=, which is checked; threads keep working;
- kernel modules and kexec, =bpf=, =perf_event_open=, =userfaultfd=, the key rings, =reboot=, swap, =acct=, clock setting, =syslog=, =quotactl=, file handles, =iopl= / =ioperm=, =uselib=, =vhangup=;
- =ioctl= =TIOCSTI= and =TIOCLINUX= (typing into the controlling terminal).

Architectures: x86_64, aarch64 and riscv64.  Elsewhere (and on non-Linux platforms) =lrg_sandbox_apply()= fails with =LRG_SANDBOX_ERROR_UNSUPPORTED=.

** Threads
:PROPERTIES:
:CUSTOM_ID: threads
:END:
The seccomp filter always covers every thread.  Landlock covers every thread when the kernel supports =LANDLOCK_RESTRICT_SELF_TSYNC=; on older kernels only the calling thread and the threads it starts later are restricted.  =lrg_sandbox_get_threads_synced()= reports which happened (=TRUE= also when the caller was the only thread) and a warning names the threads left out.  Apply the sandbox before starting worker threads when the kernel may be older.

** Bubblewrap as an outer layer
:PROPERTIES:
:CUSTOM_ID: bubblewrap
:END:
=lrg_sandbox_build_bwrap_argv()= turns the same policy into a [[https://github.com/containers/bubblewrap][bubblewrap]] command line: =--die-with-parent --new-session --unshare-all= (=--share-net= unless the network is =NONE=), =--cap-drop ALL=, the root read-only, a fresh =/proc= and =/tmp=, =/dev= bound when a rule grants device access to it, every writable path bound read-write and readable paths under =/tmp= bound back.  A program re-executes itself under that command when the user asks for it, and still applies the in-process sandbox inside: bubblewrap adds namespaces (a private PID and IPC namespace, no network namespace when offline), it does not replace Landlock or seccomp.

** Introspection
:PROPERTIES:
:CUSTOM_ID: introspection
:END:
- =lrg_sandbox_get_landlock_abi()= (static): the kernel's ABI, 0 without Landlock.
- =lrg_sandbox_is_applied()=, =lrg_sandbox_get_applied_abi()=, =lrg_sandbox_get_threads_synced()=.
- =lrg_sandbox_describe()=: a text summary (network, exec, one =path: rwdcx PATH= line per rule, what was applied).

** Tests
:PROPERTIES:
:CUSTOM_ID: tests
:END:
=tests/test-sandbox.c=: the policy, enums and the bubblewrap command line in the test process; then, each in a forked child process (the test process itself is never sandboxed and removes the temporary files afterwards), the sandbox applied for real: =execve= fails with =EPERM= (in a forked grandchild) and =g_spawn_sync= fails, writes outside the allowed directories and to read-only data fail with =EACCES=, writes and atomic replaces in the saves and saved-variables directories work, reads of read-only data work, IP sockets, =ptrace= and =unshare(CLONE_NEWUSER)= fail, threads still start, a thread that ran before the sandbox is restricted with TSYNC, applying twice fails; seccomp alone without Landlock; =allow-exec=; the =SERVER= (only the listen port binds, no connects) and =CLIENT= (only the allowed port connects, no binds) port rules.  The Landlock cases skip only when the kernel lacks Landlock (ABI 4 for the port cases).
