* LrgDialogTree - Dialog Tree Container
:PROPERTIES:
:CUSTOM_ID: lrgdialogtree---dialog-tree-container
:END:
A complete dialogue tree containing interconnected dialog nodes. Manages the structure of a conversation and provides node lookup and validation.

** Type
:PROPERTIES:
:CUSTOM_ID: type
:END:

- *Type ID* - =LRG_TYPE_DIALOG_TREE=

** Example
:PROPERTIES:
:CUSTOM_ID: example
:END:
#+begin_src C
/* Create a dialogue tree */
g_autoptr(LrgDialogTree) tree = lrg_dialog_tree_new("merchant_greeting");
lrg_dialog_tree_set_title(tree, "Merchant Greeting");
lrg_dialog_tree_set_description(tree, "Initial conversation with the town merchant");
lrg_dialog_tree_set_start_node_id(tree, "greeting");

/* Create and add nodes */
g_autoptr(LrgDialogNode) greeting = lrg_dialog_node_new("greeting");
lrg_dialog_node_set_speaker(greeting, "Merchant");
lrg_dialog_node_set_text(greeting, "Welcome to my shop!");
lrg_dialog_node_set_next_node_id(greeting, "browse");
lrg_dialog_tree_add_node(tree, greeting);

g_autoptr(LrgDialogNode) browse = lrg_dialog_node_new("browse");
lrg_dialog_node_set_speaker(browse, "Merchant");
lrg_dialog_node_set_text(browse, "Feel free to look around.");
g_autoptr(LrgDialogResponse) shop = lrg_dialog_response_new(
    "shop", "Show me your wares", "shopping"
);
lrg_dialog_node_add_response(browse, shop);
lrg_dialog_tree_add_node(tree, browse);

g_autoptr(LrgDialogNode) shopping = lrg_dialog_node_new("shopping");
lrg_dialog_node_set_speaker(shopping, "Merchant");
lrg_dialog_node_set_text(shopping, "Here's what I have...");
lrg_dialog_tree_add_node(tree, shopping);

/* Validate tree */
g_autoptr(GError) error = NULL;
if (!lrg_dialog_tree_validate(tree, &error)) {
    g_warning("Tree validation failed: %s\n", error->message);
}

/* Get node count */
g_print("Tree has %u nodes\n", lrg_dialog_tree_get_node_count(tree));

/* Get node IDs */
GList *ids = lrg_dialog_tree_get_node_ids(tree);
for (GList *l = ids; l != NULL; l = l->next) {
    g_print("Node: %s\n", (const gchar *)l->data);
}
g_list_free(ids);

/* Get start node */
LrgDialogNode *start = lrg_dialog_tree_get_start_node(tree);
if (start) {
    g_print("Start node: %s\n", lrg_dialog_node_get_text(start));
}

/* Retrieve node by ID */
LrgDialogNode *shopping_node = lrg_dialog_tree_get_node(tree, "shopping");
if (shopping_node) {
    g_print("Found shopping node\n");
}
#+end_src

** Loading and saving YAML
:PROPERTIES:
:CUSTOM_ID: loading-and-saving-yaml
:END:
*** Format
:PROPERTIES:
:CUSTOM_ID: format
:END:
=lrg_dialog_tree_new_from_file()= and =lrg_dialog_tree_new_from_data()= read this format; =lrg_dialog_tree_save_to_data()= and =lrg_dialog_tree_save_to_file()= write it:

#+begin_src yaml
id: briefing-01                 # required: the tree id
title: Mission 1 Briefing       # optional
description: The first briefing # optional (read since 0.9.0)
start: middle                   # optional: the start node; the first node when absent
nodes:                          # required, non-empty, in order
- id: intro                     # required, unique
  speaker: hashbro              # optional
  text: Crispy on the outside...  # required
  next: choice                  # optional: the node that follows
  metadata:                     # optional string -> string map
    portrait: hashbro-determined
  conditions:                   # optional: all must pass to show the node
  - flag:met-maple
  effects:                      # optional: applied when the node is shown
  - set-flag:briefed
- id: middle
  text: An auto-chained line.   # no next, no responses: continues with the following node
- id: choice
  text: Ready to go?
  responses:                    # optional: the player's choices
  - text: Let's go              # required
    next: outro                 # required
    conditions: [flag:ready]    # optional
    effects: [set-flag:go]      # optional
  - text: Not yet
    next: dead-end
- id: dead-end
  text: Then wait.
  next: null                    # explicit null: a terminal node that is not last
- id: outro
  text: Good luck out there.    # the last node is terminal
#+end_src

The loader validates the result with =lrg_dialog_tree_validate()= (every =next= and =start= names an existing node). Response ids are generated as =<node id>-r<index>=.

*** Auto-chaining and explicit terminals
:PROPERTIES:
:CUSTOM_ID: auto-chaining
:END:
A node with neither =next= nor =responses= continues with the node after it (a linear scene needs no =next= keys); the last node is terminal. Since 0.9.0 a node with an explicit =next: null= is terminal wherever it is; before, =null= was read like an absent key and chained.

*** Saving
:PROPERTIES:
:CUSTOM_ID: saving
:END:
#+begin_src C
gchar         *lrg_dialog_tree_save_to_data (LrgDialogTree  *self,
                                             gsize          *length,
                                             GError        **error);
gboolean       lrg_dialog_tree_save_to_file (LrgDialogTree  *self,
                                             const gchar    *path,
                                             GError        **error);
#+end_src

=lrg_dialog_tree_save_to_data()= returns the YAML (transfer full; =length= optional) and =lrg_dialog_tree_save_to_file()= writes it atomically. The writer:

- writes =title= and =description= when set, and =start= only when it is not the first node (the loader's default);
- writes the nodes in =lrg_dialog_tree_get_node_ids()= order, with =speaker=, =next=, =metadata= (keys sorted: the node keeps them unordered), =conditions=, =effects= and =responses= when present;
- leaves out a =next= that auto-chaining restores (no responses, =next= is the following node) and writes =next: null= for a terminal node that is not last, so the loaded tree links exactly as the saved one;
- fails with =G_IO_ERROR_INVALID_DATA= for a tree without nodes or a response without a next node, which the format cannot express.

Saving a tree loaded from saved text gives the same bytes; =tests/test-format-writers.c= checks this on a real-format fixture and on trees built in code.

#+begin_src C
g_autoptr(LrgDialogTree) tree = lrg_dialog_tree_new_from_file ("data/dialog/merchant.yaml", &error);

lrg_dialog_node_set_text (lrg_dialog_tree_get_node (tree, "greeting"), "Back again?");
if (!lrg_dialog_tree_save_to_file (tree, "data/dialog/merchant.yaml", &error))
    g_warning ("%s", error->message);
#+end_src

*** Using it from the editor
:PROPERTIES:
:CUSTOM_ID: using-it-from-the-editor
:END:
The editor's dialog data editor ([[file:../../editor/data-editors.org][Data editors]]) edits dialog files as documents (comments and unknown keys such as =mood:= kept), draws them as a node graph and validates them with =lrg_dialog_tree_new_from_data()= on the document text; its play pane walks a fresh tree from the same call. The engine writer is for games and tools that generate or rewrite dialog files.
