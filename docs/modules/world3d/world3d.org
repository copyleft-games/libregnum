#+title: LrgWorld3D
#+description: The runtime 3D world: entity tree, GUID map, frame phases, fixed-step accumulator, render lists, light/camera registries, spatial queries.

* LrgWorld3D
:PROPERTIES:
:CUSTOM_ID: lrgworld3d
:END:
=LrgWorld3D= (=src/world3d/lrg-world3d.h=, final =GObject=) runs a 3D scene made of [[file:entity3d.org][LrgEntity3D]] nodes and their =LrgComponent= behaviours. The same header defines the *render-list contract* between components and renderers (=LrgRenderList=, =LrgRenderItem=) and the light description renderers consume (=LrgLight3DDesc=).

** Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:
A world owns one *root entity* (named ="root"=, =lrg_world3d_get_root()=). Everything in the root's subtree is "in the world". Design decision: a single root rather than a list of roots, so every hierarchy operation (reparent with keep-world, path lookup, walks) is uniform and "top-level entity" simply means "child of the root". The root itself is never counted, never in the GUID map unless you give it a GUID, never indexed spatially, and must not be removed.

The world maintains, automatically as entities join and leave:

- a GUID to entity map (O(1) =lrg_world3d_find_by_guid()=),
- an =LrgOctree= of entity world bounds (re-indexed lazily),
- a coalesced queue of moved entities (=transform-changed=),
- light and camera registries and the audio listener.

** Concepts
:PROPERTIES:
:CUSTOM_ID: concepts
:END:
*** Frame phase order
:PROPERTIES:
:CUSTOM_ID: phase-order
:END:
#+begin_example
 lrg_world3d_step (world, dt)           (skipped while :paused)
 │
 ├─ 1. fixed_update   accumulator += dt
 │      while accumulator >= fixed-step and n < max-substeps:
 │          every enabled component of every active entity: fixed_update(step)
 │          flush transform-changed
 │          accumulator -= step ; fixed_time += step
 │      leftover >= step (hitch)  ->  dropped (accumulator %= step)
 │
 ├─ 2. update         update(dt) on every enabled component   -> flush
 │
 ├─ 3. late_update    late_update(dt) on every enabled component -> flush
 │
 └─ (per camera / per frame, by the game or LrgWorld3DRenderer)
    4. collect_render(camera, list)  -> flush, clear list, set view,
       walk active+visible entities in the cull mask, components'
       collect_render(list), add lights, sort
    5. renderer replays the list per pass (depth, shadow maps, colour)
#+end_example

Walk order in every phase: depth first, pre-order (a parent before its children), components in attach order. Inactive entities skip their whole subtree; disabled components are skipped. Children and components are snapshotted (with references) per entity, so a component may spawn or destroy entities during a phase: new entities run next frame; an entity reparented away mid-phase is skipped for the rest of the phase.

The three phases are also public individually (=lrg_world3d_fixed_update()=, =lrg_world3d_update()=, =lrg_world3d_late_update()=) for games that need custom ordering (for example physics between fixed update and update). They run even while =paused=; only =lrg_world3d_step()= honours it.

*** Fixed-step accumulator
:PROPERTIES:
:CUSTOM_ID: fixed-step
:END:
- =fixed-step= (default 1/60 s) and =max-substeps= (default 8) are properties.
- The number of fixed updates depends only on accumulated time, not on frame pacing: 60 frames of 1/60 s and 25 frames alternating 30/50 ms both give ~50 substeps at 0.02 s (± one for float rounding). =lrg_world3d_fixed_update()= returns the substep count.
- =lrg_world3d_get_fixed_alpha()= (= accumulator / step, in [0, 1)) is the blend factor for interpolating rendered transforms between the last two fixed states.
- =lrg_world3d_get_time()= sums =update= deltas; =lrg_world3d_get_fixed_time()= sums executed substeps.

*** Membership and component world hooks
:PROPERTIES:
:CUSTOM_ID: membership
:END:
#+begin_example
 add_child / add_entity (subtree joins, parents first)
   for each entity:  GUID map += ; spatial record ; components.world_entered(world)
                     emit LrgWorld3D::entity-added
 remove_child / remove_entity / clear (subtree leaves, children first)
   for each entity:  emit LrgWorld3D::entity-removed
                     components.world_exited(world)  (reverse attach order)
                     octree -= ; GUID map -= ; audio listener cleared if it was this
#+end_example

Light, camera and listener components use =world_entered= / =world_exited= to register and unregister themselves. Adding a component to an entity that is already in a world calls =world_entered= immediately.

*** Render lists: the contract for renderer and component authors
:PROPERTIES:
:CUSTOM_ID: render-list-contract
:END:
An =LrgRenderList= is a flat, by-value array of =LrgRenderItem= records plus four index lists and a light array:

#+begin_example
 LrgRenderList
 ├── items[]          LrgRenderItem by value (pointers stable until add/clear)
 ├── OPAQUE[]         indices, sorted (sort_key, near -> far)
 ├── CUTOUT[]         indices, sorted (sort_key, near -> far)
 ├── TRANSPARENT[]    indices, sorted far -> near
 ├── SHADOW_CASTER[]  indices, sorted sort_key; NOT frustum culled
 ├── lights[]         LrgLight3DDesc by value (enabled, layer_mask & cull_mask)
 └── view             eye[3], cull_mask, view_projection[16] (optional)
#+end_example

*Component side* (inside =collect_render (self, list)=):

1. Start from =lrg_render_item_init_for_entity (&item, entity, self)= (world matrix, layer, entity/component back-pointers, defaults: opaque, casts and receives shadows, white, unknown bounds).
2. Set =kind= and the handle(s): =PRIMITIVE= (=primitive= + =params=), =MESH= (=mesh=, a =GrlMesh=), =MODEL= (=model=, a =GrlModel=, =mesh_index= -1 for all), =BILLBOARD= (=texture=, =params[0..1]= size), or =CUSTOM= (=draw_func= + =user_data=).
3. Set =material= (an =LrgMaterial3D= now; =LrgMaterial= from M2), =color=, =flags=, =sort_key=.
4. Set bounds with =lrg_render_item_set_local_bounds()= (or leave them unknown: never culled).
5. =if (lrg_render_list_accepts (list, &item)) lrg_render_list_add (list, &item);=

Handles are *borrowed*: the component keeps them alive at least until the list is cleared (normally the next frame's collect). =user_data= is *owned* by the list once added: =user_data_destroy= runs on clear/free.

Categorisation: =TRANSPARENT= flag wins, then =CUTOUT=, else =OPAQUE=. Items with =CAST_SHADOW= are also in =SHADOW_CASTER=. A caster outside the camera frustum is accepted but only lands in =SHADOW_CASTER= (it can still shadow visible geometry). =NO_CULL= skips the frustum test; unknown bounds (=min > max=) are never frustum culled. The layer test always applies.

*Renderer side*: call =lrg_world3d_collect_render (world, camera, list)= once per camera per frame, then replay each category per pass with =lrg_render_list_foreach()= (or index it with =lrg_render_list_get_n_items()= / =lrg_render_list_get_item()=). Read lights with =lrg_render_list_get_n_lights()= / =lrg_render_list_get_light()=, and the view with =lrg_render_list_get_eye()=, =lrg_render_list_get_cull_mask()=, =lrg_render_list_get_view_projection()=. Reuse one list per camera so its arrays stay allocated.

Camera handling in collection: the cull mask comes from =lrg_camera_get_cull_mask()= (any =LrgCamera=); for an =LrgCamera3D= the eye is its position and, when =frustum-culling= is on, the view-projection is built from position/target/up/fovy/aspect with near 0.05 and far 10000 (=LrgCamera3D= has no clip-plane properties); orthographic cameras use =fovy= as the view height. =NULL= camera: eye at the origin, all layers, no frustum.

*** Lights
:PROPERTIES:
:CUSTOM_ID: lights
:END:
=LrgLight3DDesc= is a plain boxed struct a light component fills from its properties and its entity's world transform (=lrg_entity3d_get_world_position()=, =lrg_entity3d_get_forward()=) and pushes with =lrg_world3d_register_light (world, G_OBJECT (component), &desc)=. Calling it again for the same source updates in place (order is stable). The registry stores a copy and no reference on the source: unregister in =world_exited=. Collection copies enabled lights whose =layer_mask= intersects the camera mask into the list.

| field          | meaning                                                           |
|----------------+-------------------------------------------------------------------|
| =kind=         | =LRG_LIGHT3D_DIRECTIONAL=, =LRG_LIGHT3D_POINT=, =LRG_LIGHT3D_SPOT= |
| =color[3]=     | linear RGB 0..1                                                   |
| =intensity=    | multiplier                                                        |
| =range=        | attenuation range (point/spot)                                    |
| =inner_angle=  | spot full-intensity half-angle, radians                           |
| =outer_angle=  | spot cutoff half-angle, radians                                   |
| =cast_shadows= | renderer should render a shadow map                               |
| =enabled=      | contributes at all                                                |
| =position[3]=  | world position                                                    |
| =direction[3]= | unit world direction the light travels (entity forward, -Z)       |
| =layer_mask=   | layers it lights                                                  |
| =source=       | registering object (set by the registry)                          |

Defaults from =lrg_light3d_desc_init()= / =lrg_light3d_desc_new()=: enabled white point light, intensity 1, range 10, cone 30°/45°, no shadows, origin, direction (0, 0, -1), all layers. =lrg_light3d_desc_copy()= / =lrg_light3d_desc_free()= manage heap copies (=g_autoptr= supported).

*** Cameras and the audio listener
:PROPERTIES:
:CUSTOM_ID: cameras
:END:
Camera components register their =LrgCamera= with a priority (=lrg_world3d_register_camera()=, the world holds a reference). =lrg_world3d_get_active_camera()= returns the camera forced with =lrg_world3d_set_active_camera()=, else the highest priority (earliest registered on ties), else =NULL=. The audio listener (=lrg_world3d_set_audio_listener()=) is a weak entity pointer cleared automatically when the entity leaves.

*** Spatial index
:PROPERTIES:
:CUSTOM_ID: spatial-index
:END:
Each entity (not the root) has a spatial record with its world AABB (=lrg_entity3d_get_world_bounds()=). Records are refreshed lazily before =lrg_world3d_query_box()=, =lrg_world3d_query_sphere()= and =lrg_world3d_get_octree()= for every subtree marked dirty by a transform write, a join, a component add/remove, or =lrg_world3d_invalidate_bounds()= (call it when a component's =get_bounds()= result changes for another reason, for example a new mesh). The octree covers ±4096; =LrgOctree= keeps out-of-bounds objects in its root node and anything it rejects is kept in an overflow list scanned linearly. Queries return only entities active in the hierarchy.

*** A game loop
:PROPERTIES:
:CUSTOM_ID: example-game-loop
:END:
#+begin_src c
g_autoptr(LrgWorld3D) world = lrg_world3d_new ();
g_autoptr(LrgRenderList) list = lrg_render_list_new ();

/* ... fill the world (lrg_level_instantiate_3d() or by hand) ... */

while (!grl_window_should_close (window))
{
	gfloat dt = grl_window_get_frame_time (window);
	LrgCamera *camera;

	lrg_world3d_step (world, dt);

	camera = lrg_world3d_get_active_camera (world);
	lrg_world3d_collect_render (world, camera, list);
	/* hand the list to LrgWorld3DRenderer (or replay it yourself) */
}
#+end_src

*** A component that draws a cube
:PROPERTIES:
:CUSTOM_ID: example-collect-render
:END:
#+begin_src c
static void
my_cube_collect_render (LrgComponent  *component,
                        LrgRenderList *list)
{
	MyCube *self = MY_CUBE (component);
	LrgRenderItem item;
	LrgBoundingBox3D local = { { -0.5f, -0.5f, -0.5f }, { 0.5f, 0.5f, 0.5f } };

	lrg_render_item_init_for_entity (&item, lrg_component_get_entity (component),
	                                 component);
	item.kind = LRG_RENDER_ITEM_PRIMITIVE;
	item.primitive = LRG_PRIMITIVE_CUBE;
	item.material = self->material;                  /* borrowed */
	item.sort_key = GPOINTER_TO_SIZE (self->material);
	lrg_render_item_set_local_bounds (&item, &local);

	if (lrg_render_list_accepts (list, &item))
		lrg_render_list_add (list, &item);
}

static gboolean
my_cube_get_bounds (LrgComponent     *component,
                    LrgBoundingBox3D *out)
{
	out->min.x = out->min.y = out->min.z = -0.5f;
	out->max.x = out->max.y = out->max.z = 0.5f;
	return TRUE;
}
#+end_src

*** A light component registering itself
:PROPERTIES:
:CUSTOM_ID: example-light
:END:
#+begin_src c
static void
my_light_push (MyLight *self, LrgWorld3D *world)
{
	LrgEntity3D *e = lrg_component_get_entity (LRG_COMPONENT (self));
	LrgLight3DDesc d;

	lrg_light3d_desc_init (&d);
	d.kind = LRG_LIGHT3D_SPOT;
	d.intensity = self->intensity;
	lrg_entity3d_get_world_position (e, d.position);
	lrg_entity3d_get_forward (e, d.direction);
	lrg_world3d_register_light (world, G_OBJECT (self), &d);
}

static void
my_light_world_entered (LrgComponent *c, LrgWorld3D *world)
{
	my_light_push (MY_LIGHT (c), world);
}

static void
my_light_late_update (LrgComponent *c, gfloat dt)
{
	my_light_push (MY_LIGHT (c), lrg_component_get_world3d (c));
}

static void
my_light_world_exited (LrgComponent *c, LrgWorld3D *world)
{
	lrg_world3d_unregister_light (world, G_OBJECT (c));
}
#+end_src

** Performance notes
:PROPERTIES:
:CUSTOM_ID: performance
:END:
- Phases allocate two small snapshot arrays per visited entity; for very large worlds prefer fewer, fatter components over many tiny entities.
- =collect_render= is O(visible entities); frustum culling is per item against six planes. Reusing a list keeps its arrays allocated; items are stored by value (no per-item allocation).
- Spatial refresh cost is proportional to the size of dirty subtrees, not the world; static entities never re-index after their first query.
- GUID lookups are hash lookups; name and tag lookups walk the tree.

** Pitfalls
:PROPERTIES:
:CUSTOM_ID: pitfalls
:END:
- Do not remove or reparent the root; add top-level content under it.
- Handles in render items are borrowed: freeing a mesh between collect and draw is a use-after-free.
- Register lights from =world_entered= and refresh them in =late_update=; a light registered in =update= may lag one frame behind a parent moved later in the same =update=.
- =lrg_world3d_get_lights()= returns pointers into the registry: do not keep them across register/unregister calls.
- Signal handlers on =transform-changed= that move other entities are handled in the same flush (bounded to 16 rounds).
- =LrgCamera3D= exposes no clip planes, so frustum culling uses near 0.05 / far 10000; disable =frustum-culling= for unusual cameras.

** Using it from the editor
:PROPERTIES:
:CUSTOM_ID: editor
:END:
When you press Play on a 3D level, the editor's play session instantiates the level into an =LrgWorld3D=, steps it every frame, and the viewport draws the runtime world through =LrgWorld3DRenderer= consuming the same render lists described above, so editor and game render identically. The hierarchy panel shows the live entity tree; on Stop, changed TRS values sync back to the authored nodes. See [[file:../../editor/editor-runtime.org][Editor runtime (play mode)]].
