* LrgScriptingGjs
:PROPERTIES:
:CUSTOM_ID: lrgscriptinggjs
:END:
** Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:
=LrgScriptingGjs= is the Gjs (GNOME JavaScript) scripting backend. It uses native GObject Introspection bindings via SpiderMonkey (Mozilla's JavaScript engine), allowing scripts to access the full Libregnum GObject Introspection API directly.

*Requirements:*

- Gjs 1.50+ (=gjs-1.0= pkg-config)
- GObject Introspection runtime (=gobject-introspection-1.0= pkg-config)

*Installation (Fedora):*

#+begin_src sh
sudo dnf install gjs-devel
#+end_src

** When to Use
:PROPERTIES:
:CUSTOM_ID: when-to-use
:END:
Choose =LrgScriptingGjs= when:

- Scripts need access to the full Libregnum type system
- You want native GI bindings (=imports.gi.Libregnum=)
- Interoperating with other GI-based libraries (GLib, Gio, Gtk, etc.)
- Building modding systems that leverage the type system
- You prefer JavaScript syntax over Python

Choose =LrgScriptingPyGObject= when:

- You prefer Python syntax
- You need Python's extensive package ecosystem
- Your modding community is more familiar with Python

Choose =LrgScriptingLua= when:

- You need lightweight, fast scripting without GI overhead
- Scripts don't need direct access to Libregnum types
- Performance is critical (LuaJIT)

*Example:*

#+begin_src C

                           "print('Hello from Gjs!');",
                           &error);

** Typical Setup
:PROPERTIES:
:CUSTOM_ID: typical-setup
:END:
The recommended setup pattern for =LrgScriptingGjs=:

#+begin_src C
g_autoptr(LrgScriptingGjs) scripting = lrg_scripting_gjs_new ();
LrgScriptingGI *gi_self = LRG_SCRIPTING_GI (scripting);
g_autoptr(GError) error = NULL;

/* 1. Load the Libregnum typelib */
if (!lrg_scripting_gi_require_libregnum (gi_self, &error))
{
    g_printerr ("Failed to load Libregnum typelib: %s\n", error->message);
    return 1;
}

/* 2. Set engine and registry */
LrgEngine *engine = lrg_engine_get_default ();
lrg_scripting_gi_set_engine (gi_self, engine);
lrg_scripting_gi_set_registry (gi_self, lrg_engine_get_registry (engine));

/* 3. Expose engine to scripts */
lrg_scripting_gi_expose_object (gi_self, "engine", G_OBJECT (engine), &error);

/* 4. Add script search paths (before loading scripts) */
lrg_scripting_gi_add_search_path (gi_self, "scripts");
lrg_scripting_gi_add_search_path (gi_self, "mods/mymod/scripts");

/* 5. Load and run scripts */
lrg_scripting_load_file (LRG_SCRIPTING (scripting), "scripts/main.js", &error);

/* 6. Register update hooks */
lrg_scripting_gi_register_update_hook (gi_self, "game_update");
#+end_src

#+begin_src C
gboolean

                          const gchar   *name,
                          GValue        *value,
                          GError       **error);

lrg_scripting_set_global (LrgScripting  *scripting,
                          const gchar   *name,
                          const GValue  *value,
                          GError       **error);
#+end_src

Access and set JavaScript global variables.

*Example:*

#+begin_src C
/* Set a global from C */
GValue value = G_VALUE_INIT;
g_value_init (&value, G_TYPE_INT);
g_value_set_int (&value, 42);
lrg_scripting_set_global (LRG_SCRIPTING (scripting), "score", &value, NULL);
g_value_unset (&value);

/* Script can access it */
lrg_scripting_load_string (LRG_SCRIPTING (scripting),
                           "use_score",
                           "print('Score: ' + score);",
                           NULL);
#+end_src

Values round-trip through the host bridge (see [[#host-bridge][Host Bridge]]): booleans,
integers (as =G_TYPE_INT64=), doubles and strings.  JavaScript =null= or
=undefined=, and non-scalar values such as functions, arrive as a =NULL=
=G_TYPE_POINTER= value.

*** lrg_scripting_call_function
:PROPERTIES:
:CUSTOM_ID: lrg_scripting_call_function
:END:
#+begin_src C
gboolean
lrg_scripting_call_function (LrgScripting  *scripting,
                             const gchar   *func_name,
                             GValue        *return_value,
                             guint          n_args,
                             const GValue  *args,
                             GError       **error);
#+end_src

Calls a JavaScript function defined in the global namespace.

*Example:*

#+begin_src C
/* Define a function in JavaScript */
lrg_scripting_load_string (LRG_SCRIPTING (scripting),
                           "funcs",
                           "function calculate_damage(base, multiplier) {\n"
                           "    return Math.floor(base * multiplier);\n"
                           "}",
                           NULL);

/* Call from C */
GValue args[2] = { G_VALUE_INIT, G_VALUE_INIT };
GValue result = G_VALUE_INIT;

g_value_init (&args[0], G_TYPE_DOUBLE);
g_value_set_double (&args[0], 100.0);
g_value_init (&args[1], G_TYPE_DOUBLE);
g_value_set_double (&args[1], 1.5);

lrg_scripting_call_function (LRG_SCRIPTING (scripting),
                             "calculate_damage",
                             &result, 2, args, &error);

/* result holds G_TYPE_INT64 150: integral numbers come back as INT64 */

g_value_unset (&args[0]);
g_value_unset (&args[1]);
g_value_unset (&result);
#+end_src

** Complete Example
:PROPERTIES:
:CUSTOM_ID: complete-example
:END:
#+begin_src C
#include <libregnum.h>

int
main (int argc, char *argv[])
{
    g_autoptr(LrgEngine) engine = lrg_engine_get_default ();
    g_autoptr(LrgScriptingGjs) scripting = lrg_scripting_gjs_new ();
    LrgScriptingGI *gi_self = LRG_SCRIPTING_GI (scripting);
    g_autoptr(GError) error = NULL;

    /* Load required typelibs */
    if (!lrg_scripting_gi_require_typelib (gi_self, "GLib", "2.0", &error) ||
        !lrg_scripting_gi_require_libregnum (gi_self, &error))
    {
        g_printerr ("Failed to load typelibs: %s\n", error->message);
        return 1;
    }

    /* Connect scripting to engine */
    lrg_scripting_gi_set_engine (gi_self, engine);
    lrg_scripting_gi_set_registry (gi_self, lrg_engine_get_registry (engine));
    lrg_engine_set_scripting (engine, LRG_SCRIPTING (scripting));

    /* Expose engine to scripts */
    lrg_scripting_gi_expose_object (gi_self, "engine", G_OBJECT (engine), &error);

    /* Add script search path */
    lrg_scripting_gi_add_search_path (gi_self, "scripts");

    /* Load main game script */
    if (!lrg_scripting_load_file (LRG_SCRIPTING (scripting),
                                  "scripts/main.js",
                                  &error))
    {
        g_printerr ("Script error: %s\n", error->message);
        return 1;
    }

    /* Register update hook */
    lrg_scripting_gi_register_update_hook (gi_self, "game_update");

    /* Game loop */
    lrg_engine_startup (engine, NULL);
    while (lrg_engine_is_running (engine))
    {
        gfloat delta = 0.016f;  /* ~60 FPS */
        lrg_scripting_gi_update (gi_self, delta);
        lrg_engine_update (engine, delta);
    }
    lrg_engine_shutdown (engine);

    return 0;
}
#+end_src

const Libregnum = imports.gi.Libregnum;

}

print("Using GLib version: " + GLib.MAJOR_VERSION + "." + GLib.MINOR_VERSION);

** Gjs-Specific Considerations
:PROPERTIES:
:CUSTOM_ID: gjs-specific-considerations
:END:
*** Host Bridge
:PROPERTIES:
:CUSTOM_ID: host-bridge
:END:
Gjs allows only one =GjsContext= per thread, so every =LrgScriptingGjs= shares a
single runtime.  Each context still behaves as if it had its own:

- Loaded code runs inside a function whose =globalThis= is a private scope
  object, wrapped in =with (globalThis)=.  Top-level =function=, =let= and
  =const= declarations stay local to the context, =globalThis.x = 1= writes
  the context's scope, and names the host publishes (registered functions,
  =set_global= values, exposed objects) resolve as plain identifiers.  Names
  it does not define, such as =imports=, =print= and =Math=, fall through to
  the real global object.
- A sloppy assignment to an undeclared name (=counter = 0=) briefly lands on
  the real global.  After each load or call of the context it is moved into
  that context's scope, so other contexts never see it.  Reading an
  undeclared name still raises =ReferenceError=, and =typeof= still works for
  feature checks.
- =__lrg= (the prelude) cannot be replaced or deleted by scripts.
- While Gjs runs, its own reports of script exceptions (warnings in the
  =Gjs= domain) never abort the process.  Host functions called from
  JavaScript run under the caller's fatal mask, so engine CRITICALs stay
  fatal where the caller wanted them.
- Arguments, results and names cross as =GVariant= values through the
  introspectable =LrgScriptHost= (=imports.gi.Libregnum.script_host_*=).
  Nothing from C is ever spliced into source text, so quotes and newlines in
  strings are harmless.
- =lrg_scripting_register_function()= really calls the C function.  Its
  result comes back as the JavaScript return value, and a =GError= becomes a
  thrown exception that the script may catch.
- =lrg_scripting_reset()= and finalization drop only that context's scope.

The bridge needs =Libregnum-1.typelib= and =Graylib-1.typelib=.  They are
looked up in =LRG_TYPELIB_PATH=, next to the loaded libregnum object
(=../gir= in the build tree, where the build copies both, or
=girepository-1.0= when installed), and in =GI_TYPELIB_PATH=.  Without them,
plain evaluation still works, but calls, globals and registered functions
fail with =LRG_SCRIPTING_ERROR_TYPELIB_NOT_FOUND=.

#+begin_src C
static gboolean
host_scale (LrgScripting *s, guint n, const GValue *args, GValue *ret,
            gpointer user_data, GError **error)
{
    g_value_init (ret, G_TYPE_DOUBLE);
    g_value_set_double (ret, g_value_get_double (&args[0]) * g_value_get_double (&args[1]));
    return TRUE;
}

lrg_scripting_register_function (ctx, "scale", host_scale, NULL, &error);
lrg_scripting_load_string (ctx, "area",
                           "function area(w, h) { return scale(w, h); }", &error);
/* lrg_scripting_call_function (ctx, "area", &result, 2, args, &error) → scale() runs in C */
#+end_src

*** Error Handling
:PROPERTIES:
:CUSTOM_ID: error-handling
:END:
Exceptions thrown while loading or calling are reported only through the
=GError= (=LRG_SCRIPTING_ERROR_SYNTAX= or =LRG_SCRIPTING_ERROR_RUNTIME=, with the
exception text and stack); Gjs's own uncaught-error logging is silenced during
evaluation:

#+begin_src C
g_autoptr(GError) error = NULL;

if (!lrg_scripting_load_string (LRG_SCRIPTING (scripting),
                                "bad_code",
                                "undefined_variable + 1;",
                                &error))
{
    g_printerr ("JavaScript error: %s\n", error->message);
    /* Output: JavaScript error: ReferenceError: undefined_variable is not defined */
}
#+end_src

*** Search Paths
:PROPERTIES:

#+begin_src C
/* Add paths before loading */
lrg_scripting_gi_add_search_path (gi_self, "scripts");
lrg_scripting_gi_add_search_path (gi_self, "mods/mymod");

lrg_scripting_load_file (LRG_SCRIPTING (scripting), "scripts/main.js", &error);

** Comparison with PyGObject
:PROPERTIES:
:CUSTOM_ID: comparison-with-pygobject
:END:
| Aspect            | Gjs                             | PyGObject                             |
|-------------------+---------------------------------+---------------------------------------|
| Language          | JavaScript (ES6+)               | Python 3.12+                          |
| Engine            | SpiderMonkey                    | CPython                               |
| GI Access         | =imports.gi.Namespace=          | =from gi.repository import Namespace= |
| Syntax            | C-like braces                   | Indentation-based                     |
| Package ecosystem | npm (limited GI compat)         | pip (extensive)                       |
| GNOME integration | Native (default for GNOME apps) | Well supported                        |
