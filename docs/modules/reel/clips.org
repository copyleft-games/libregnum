* LrgReelClip — Timed layers
:PROPERTIES:
:CUSTOM_ID: lrgreelclip-timed-layers
:END:
=LrgReelClip= is the drawable unit of a composition.  Each clip owns a timing
window (from-frame, duration), an opacity, and a visibility flag.  The renderer
calls each clip's render vfunc once per frame while the clip is active, passing
the current =LrgReelContext= and the =LrgImageCanvas= to draw onto.

=LrgReelClip= is a *derivable* GObject type: subclass it for reusable clip
objects, or construct a base instance with a render callback for quick one-off
layers.

** Authoring style 1: render callback
:PROPERTIES:
:CUSTOM_ID: authoring-callback
:END:
The simplest approach.  Create a base =LrgReelClip= and supply a
=LrgReelRenderFunc= callback.

#+begin_src c
typedef void (*LrgReelRenderFunc) (LrgReelClip    *clip,
                                   LrgReelContext *ctx,
                                   LrgImageCanvas *canvas,
                                   gpointer        user_data);
#+end_src

#+begin_src c
static void
draw_banner (LrgReelClip    *clip,
             LrgReelContext *ctx,
             LrgImageCanvas *canvas,
             gpointer        user_data)
{
    const gchar *text = (const gchar *) user_data;
    gint         frame = lrg_reel_context_get_frame (ctx);
    GrlColor     fg = { 255, 255, 255, 255 };
    gdouble      opacity;

    opacity = lrg_reel_interpolate_clamped (frame, 0.0, 10.0, 0.0, 1.0,
                                            LRG_EASING_EASE_OUT_QUAD);
    fg.a = (guint8) (opacity * 255.0);
    grl_image_draw_text_bitmap (lrg_image_canvas_get_image (canvas),
                                text, 20, 20, 24, &fg);
}

/* The clip owns the string via the destroy notifier. */
g_autoptr(LrgReelClip) banner =
    lrg_reel_clip_new_with_func (draw_banner,
                                 g_strdup ("Level 1"),
                                 g_free);
lrg_reel_add_clip (reel, banner);
#+end_src

The =destroy= parameter is a =GDestroyNotify= invoked when the clip is finalized,
allowing safe ownership of =user_data=.  Pass =NULL= for both if =user_data= is
not heap-allocated or is managed elsewhere.

** Authoring style 2: subclass
:PROPERTIES:
:CUSTOM_ID: authoring-subclass
:END:
Subclassing is preferable for clips that carry their own state or are reused
across multiple compositions.

#+begin_src c
/* Declaration */
G_DECLARE_FINAL_TYPE (MyBannerClip, my_banner_clip, MY, BANNER_CLIP, LrgReelClip)

/* In the .c file */
struct _MyBannerClip
{
    LrgReelClip parent_instance;
    gchar      *text;
    GrlColor    color;
};

static void
my_banner_clip_render (LrgReelClip    *clip,
                       LrgReelContext *ctx,
                       LrgImageCanvas *canvas)
{
    MyBannerClip *self = MY_BANNER_CLIP (clip);
    grl_image_draw_text_bitmap (lrg_image_canvas_get_image (canvas),
                                self->text, 20, 20, 24, &self->color);
}

static void
my_banner_clip_class_init (MyBannerClipClass *klass)
{
    LrgReelClipClass *clip_class = LRG_REEL_CLIP_CLASS (klass);
    clip_class->render = my_banner_clip_render;
}
#+end_src

Subclasses should call =lrg_reel_clip_render()= to dispatch the vfunc from
outside the class; do not call the vfunc pointer directly.

** Timing properties
:PROPERTIES:
:CUSTOM_ID: timing-properties
:END:
#+begin_src c
/* When the clip becomes active (parent-relative frame). */
lrg_reel_clip_set_from_frame (clip, 15);

/* How long it is active.  LRG_REEL_DURATION_INFINITE = until end. */
lrg_reel_clip_set_duration_in_frames (clip, 45);

/* Test whether a given frame is within the clip's window. */
gboolean active = lrg_reel_clip_is_active_at (clip, 20);  /* TRUE */
#+end_src

=lrg_reel_clip_is_active_at()= uses the half-open interval =[from, from +
duration)=.  A duration of =LRG_REEL_DURATION_INFINITE= (or negative) means the
clip is active from =from= to the end of its parent context.

** Opacity and visibility
:PROPERTIES:
:CUSTOM_ID: opacity-visibility
:END:
#+begin_src c
/* Opacity is applied by the renderer at composite time: [0.0, 1.0]. */
lrg_reel_clip_set_opacity (clip, 0.75);

/* Visibility is a hard on/off toggle; invisible clips are not rendered. */
lrg_reel_clip_set_visible (clip, FALSE);
#+end_src

Opacity compositing is performed by the renderer on the clip's rendered output
image before blending it into the canvas.  Clips that draw their own per-pixel
alpha (e.g. using =fg.a=) can set their clip-level opacity to 1.0 and manage
transparency themselves.

** Name
:PROPERTIES:
:CUSTOM_ID: name
:END:
#+begin_src c
lrg_reel_clip_set_name (clip, "title-card");
const gchar *name = lrg_reel_clip_get_name (clip);
#+end_src

The name is a convenience label for debugging; it has no effect on rendering.

** LrgReelRenderFunc signature
:PROPERTIES:
:CUSTOM_ID: render-func-signature
:END:
| Parameter  | Type              | Meaning                                          |
|------------+-------------------+--------------------------------------------------|
| =clip=     | =LrgReelClip *=   | The clip being rendered (access name etc.)       |
| =ctx=      | =LrgReelContext *= | Frame, fps, dimensions; call =get_frame()= here  |
| =canvas=   | =LrgImageCanvas *= | Draw target; obtain the backing image via =lrg_image_canvas_get_image()= |
| =user_data=| =gpointer=        | Data passed to =lrg_reel_clip_new_with_func()=   |

The callback must draw synchronously and return.  It must not seek the context
or push/pop offsets.

** Pitfalls
:PROPERTIES:
:CUSTOM_ID: pitfalls
:END:
- Clip-level opacity (=lrg_reel_clip_set_opacity=) is applied by the renderer
  on the composed clip output.  In v1 this only affects top-level reel clips;
  nested children inside a sequence draw at full opacity and are composited as
  a unit.  As of v2, nested-clip opacity composites correctly through the
  layer pool.
- For headless text rendering use =grl_image_draw_text_bitmap()= rather than
  =grl_image_draw_text()=.  The default-font variant of =grl_image_draw_text()=
  may crash when called without a GL context; =grl_image_draw_text_bitmap()=
  always uses the embedded bitmap font and is safe headless.
- =lrg_reel_clip_new_with_func= takes =(scope notified)= on the callback; do not
  free or invalidate =user_data= before the clip is finalized unless you
  provided a =destroy= notifier.
- =lrg_reel_clip_is_active_at()= accepts parent-relative frames, not absolute
  frames.  When querying from outside a render context, pass an absolute frame
  only if the clip is a direct child of the reel (no intermediate sequence).
- A clip's =render= must not write to state kept on the clip object, its effects or its transitions. =lrg_reel_renderer_render_parallel()= renders different frames of the same clip objects on several threads at once, so a canvas, cache or counter stored on the object is drawn into by every worker. Keep per-frame buffers in locals (allocate and free them inside =render=), or derive them from the =LrgReelContext= you are given; that context belongs to one renderer, and therefore to one thread. The built-in transition series takes its two overlap buffers from the context for this reason ([[file:rendering.org::#parallel-rendering][Parallel rendering]]).

** Per-clip transform
:PROPERTIES:
:CUSTOM_ID: per-clip-transform
:END:
Every =LrgReelClip= carries an optional affine transform applied to its layer
before it is composited onto the frame.  Scale and rotation pivot about an
anchor point expressed as a fraction of the frame dimensions.

#+begin_src c
/* Translate the clip 100 px right and scale it to 80 %. */
lrg_reel_clip_set_transform (clip,
                              100.0,  /* x */
                              0.0,    /* y */
                              0.8,    /* scale_x */
                              0.8,    /* scale_y */
                              0.0);   /* rotation (radians) */

/* Move the pivot to the bottom-centre of the frame. */
lrg_reel_clip_set_anchor (clip, 0.5, 1.0);

/* Individual setters are also available. */
lrg_reel_clip_set_x        (clip, 320.0);
lrg_reel_clip_set_y        (clip, 180.0);
lrg_reel_clip_set_scale_x  (clip, 1.5);
lrg_reel_clip_set_scale_y  (clip, 1.5);
lrg_reel_clip_set_rotation (clip, G_PI / 6.0);  /* 30° */
#+end_src

A non-identity transform forces the clip onto an off-screen compositing path;
no extra cost is incurred for clips that remain at the identity (the default).

*** Pitfall: anchor vs. position

The anchor affects only scale and rotation; it is *not* subtracted from the
position.  Translating a clip with =set_x= / =set_y= always moves it relative
to the frame's (0, 0) origin regardless of the anchor setting.

** Per-clip blend mode
:PROPERTIES:
:CUSTOM_ID: per-clip-blend-mode
:END:
By default clips are composited using standard source-over (=LRG_REEL_BLEND_NORMAL=).
Alternative blend modes let you create glow, colour-burn, and other photographic
layer effects on individual clips without touching the full composition.

*** Translucent pixels inside a clip
:PROPERTIES:
:CUSTOM_ID: translucent-pixels
:END:
Source-over holds for the pixels a clip draws, not only for the clip as a whole: every clip's =render= runs on a canvas in =GRL_IMAGE_BLEND_OVER=. A shape clip with fill ={0,0,0,115}= over white gives grey (=140,140,140,255=), and so do a translucent =LrgReelSolidClip=, a caption box and anything a render callback draws with the =grl_image_draw_*= and =lrg_image_canvas_*= calls. The same holds whether the clip draws straight onto the frame or, with an opacity, transform, blend mode or effect, into a scratch layer first.

| Drawn by the clip                                   | Result over the frame below    |
|-----------------------------------------------------+--------------------------------|
| opaque colour (alpha 255)                           | replaces the pixel (as always) |
| translucent colour (alpha 1–254)                    | blends over it                 |
| fully transparent colour (alpha 0)                  | leaves it as is                |
| an =LrgReelSolidClip= with alpha 255                | clears the frame to that colour |
| an =LrgReelSolidClip= with alpha < 255              | tints the whole frame          |

A callback that needs to store pixels as they are (to punch a transparent hole, or to copy pixels across) sets the mode itself; the change lasts for that clip's own drawing only, and the next clip starts in OVER again:

#+begin_src c
static void
punch (LrgReelClip *clip, LrgReelContext *ctx, LrgImageCanvas *canvas, gpointer data)
{
    GrlColor clear = { 0, 0, 0, 0 };
    g_autoptr(GrlRectangle) r = grl_rectangle_new (0.0f, 0.0f, 32.0f, 64.0f);

    lrg_image_canvas_set_blend_mode (canvas, GRL_IMAGE_BLEND_REPLACE);
    grl_image_draw_rectangle (lrg_image_canvas_get_image (canvas), r, &clear);
}
#+end_src

Transitions and effects are not clips: they rebuild or rewrite pixels and still run on a canvas in =GRL_IMAGE_BLEND_REPLACE=, so their output is unchanged.

**** Migration from 0.13.7 and earlier
:PROPERTIES:
:CUSTOM_ID: translucent-pixels-migration
:END:
Before 0.13.8 a clip drawing straight onto the frame (no opacity, transform, blend mode or effect) drew in =REPLACE=: its translucent pixels replaced the frame's, leaving holes that a video encoder turns black. A translucent =LrgReelSolidClip= replaced the whole frame the same way. The old workaround, an opaque fill plus =lrg_reel_clip_set_opacity()=, still gives the same result. Code that relied on a clip punching holes now has to ask for it, as in the example above. A fully transparent =LrgReelSolidClip= used to clear the frame to transparent and is now a no-op; to clear, give the renderer no background and start a clip's callback with =lrg_image_canvas_clear()=, which always stores.

| Enum value                    | Effect                                    |
|-------------------------------+-------------------------------------------|
| =LRG_REEL_BLEND_NORMAL=       | Standard source-over (default)            |
| =LRG_REEL_BLEND_MULTIPLY=     | Darken (multiply channel values)          |
| =LRG_REEL_BLEND_SCREEN=       | Lighten (invert-multiply)                 |
| =LRG_REEL_BLEND_OVERLAY=      | Multiply + screen depending on luminance  |
| =LRG_REEL_BLEND_SOFT_LIGHT=   | Subtle contrast boost                     |
| =LRG_REEL_BLEND_ADD=          | Additive / linear dodge (glow)            |
| =LRG_REEL_BLEND_COLOR_DODGE=  | Strong lightening                         |
| =LRG_REEL_BLEND_COLOR_BURN=   | Strong darkening                          |

#+begin_src c
/* Overlay a lens-flare image additively. */
g_autoptr(LrgReelImageClip) flare =
    lrg_reel_image_clip_new_from_file ("flare.png", &error);
lrg_reel_clip_set_blend_mode (LRG_REEL_CLIP (flare), LRG_REEL_BLEND_ADD);
lrg_reel_add_clip (reel, LRG_REEL_CLIP (flare));
#+end_src

Using any mode other than =LRG_REEL_BLEND_NORMAL= forces the clip onto the
compositing path (same cost as a non-identity transform).

** Per-clip effects
:PROPERTIES:
:CUSTOM_ID: per-clip-effects
:END:
Effects are =LrgReelEffect= objects appended to a clip's effect chain with
=lrg_reel_clip_add_effect()=.  They execute in order on the clip's composited
off-screen layer before it is blended onto the frame.  See [[file:compositing.org][compositing.org]] for
details on each concrete effect type.

#+begin_src c
g_autoptr(LrgReelBlurEffect) blur = lrg_reel_blur_effect_new (8);
lrg_reel_clip_add_effect (clip, LRG_REEL_EFFECT (blur));

/* Count and remove all effects. */
guint n = lrg_reel_clip_get_n_effects (clip);
lrg_reel_clip_clear_effects (clip);
#+end_src

The effect clip sees the clip's own pixels, not the full frame, so an effect
on a small text clip does not degrade large regions of the frame.

** LrgReelSolidClip — full-frame fill
:PROPERTIES:
:CUSTOM_ID: solid-clip
:END:
The simplest background layer: fills the entire canvas with a single opaque or
semi-transparent color.  No subclassing, no render callback — just a color.

#+begin_src c
GrlColor bg = { 20, 24, 36, 255 };
g_autoptr(LrgReelSolidClip) solid = lrg_reel_solid_clip_new (&bg);

/* Update the fill color at any time. */
GrlColor red = { 220, 40, 40, 255 };
lrg_reel_solid_clip_set_color (solid, &red);

lrg_reel_clip_set_duration_in_frames (LRG_REEL_CLIP (solid), 90);
lrg_reel_add_clip (reel, LRG_REEL_CLIP (solid));
#+end_src

*** Pitfall

A =LrgReelSolidClip= clears the entire canvas on each frame it is active.  If
you want a solid clip to cover only part of the frame, use =LrgReelShapeClip=
with =LRG_REEL_SHAPE_RECT= instead.

** LrgReelGradientClip — gradient fill
:PROPERTIES:
:CUSTOM_ID: gradient-clip
:END:
Fills the frame with a linear (horizontal or vertical) or radial gradient.

#+begin_src c
GrlColor top    = {  20,  20,  40, 255 };
GrlColor bottom = { 100,  60, 140, 255 };

/* Linear gradient from top to bottom. */
g_autoptr(LrgReelGradientClip) grad =
    lrg_reel_gradient_clip_new_linear (&top, &bottom,
                                        GRL_GRADIENT_AXIS_VERTICAL);

/* Radial gradient — inner bright, outer dark. */
GrlColor inner = { 255, 200, 100, 255 };
GrlColor outer = {  20,  10,   5, 255 };
g_autoptr(LrgReelGradientClip) radial =
    lrg_reel_gradient_clip_new_radial (&inner, &outer);

lrg_reel_add_clip (reel, LRG_REEL_CLIP (grad));
#+end_src

Colors can be updated after construction using
=lrg_reel_gradient_clip_set_start_color()= and
=lrg_reel_gradient_clip_set_end_color()=.  For a radial gradient "start" is
the inner (centre) color and "end" is the outer (edge) color.

** LrgReelImageClip — static image
:PROPERTIES:
:CUSTOM_ID: image-clip
:END:
Renders a static =GrlImage= onto the frame, optionally scaled to a destination
box and tinted.

#+begin_src c
g_autoptr(GError)          err  = NULL;
g_autoptr(LrgReelImageClip) img =
    lrg_reel_image_clip_new_from_file ("logo.png", &err);

/* Scale to fill a 640×360 sub-rectangle, preserving aspect ratio. */
lrg_reel_image_clip_set_box (img, 0, 0, 640, 360);
lrg_reel_image_clip_set_fit (img, LRG_REEL_FIT_CONTAIN);

/* Optional tint (NULL = no tint). */
GrlColor warm = { 255, 220, 160, 255 };
lrg_reel_image_clip_set_tint (img, &warm);

lrg_reel_add_clip (reel, LRG_REEL_CLIP (img));
#+end_src

The fit modes mirror CSS =object-fit=:

| =LrgReelFit=          | Behaviour                                          |
|-----------------------+----------------------------------------------------|
| =LRG_REEL_FIT_FILL=   | Stretch to fill box (ignore aspect ratio)          |
| =LRG_REEL_FIT_CONTAIN=| Scale to fit inside box, letterbox if needed       |
| =LRG_REEL_FIT_COVER=  | Scale to fill box, crop excess                     |
| =LRG_REEL_FIT_NONE=   | Native size, top-left aligned                      |

*** Pitfall

=lrg_reel_image_clip_get_tint()= returns a =gboolean= (whether a tint is
set), not a color pointer.  To read the current tint color, inspect the
=LrgReelImageClip:tint= GObject property directly if needed.

** LrgReelTextClip — text block
:PROPERTIES:
:CUSTOM_ID: text-clip
:END:
Renders a UTF-8 text block at a fixed position.  The default font is the
embedded 8×8 bitmap font; a =GrlImageFont= can be supplied for display-quality
output.

#+begin_src c
g_autoptr(LrgReelTextClip) label = lrg_reel_text_clip_new ("Score: 9999");

GrlColor white = { 255, 255, 255, 255 };
lrg_reel_text_clip_set_color  (label, &white);
lrg_reel_text_clip_set_font_size (label, 48.0);
lrg_reel_text_clip_set_text_x (label, 40);
lrg_reel_text_clip_set_text_y (label, 30);
lrg_reel_text_clip_set_align  (label, LRG_REEL_TEXT_ALIGN_LEFT);

/* Optional word-wrap. */
lrg_reel_text_clip_set_max_width (label, 560);
lrg_reel_text_clip_set_line_height (label, 1.4);

/* Drop shadow. */
lrg_reel_text_clip_set_shadow (label, TRUE);
GrlColor shadow = { 0, 0, 0, 200 };
lrg_reel_text_clip_set_shadow_color  (label, &shadow);
lrg_reel_text_clip_set_shadow_offset (label, 3, 3);

lrg_reel_add_clip (reel, LRG_REEL_CLIP (label));
#+end_src

To load a TTF/OTF font use =lrg_reel_text_clip_set_font_from_file()=.

*** Alignment and text-x
:PROPERTIES:
:CUSTOM_ID: text-clip-alignment
:END:
=text-x= is the text's horizontal anchor. What it anchors depends on =align= and on whether =max-width= is set:

| =max-width= | =align=  | =text-x= is                     | Each line is drawn                          |
|-------------+----------+---------------------------------+---------------------------------------------|
| 0 (default) | =left=   | the left edge of the text       | starting at =text-x=                        |
| 0 (default) | =center= | the centre of the text          | centred on =text-x=                         |
| 0 (default) | =right=  | the right edge of the text      | ending at =text-x=                          |
| =W= > 0     | =left=   | the left edge of a =W=-wide box | at the box's left edge (=text-x=)           |
| =W= > 0     | =center= | the left edge of a =W=-wide box | centred in the box, on =text-x + W / 2=     |
| =W= > 0     | =right=  | the left edge of a =W=-wide box | ending at the box's right edge (=text-x + W=) |

Multi-line text (explicit =\n= or word-wrap) is aligned line by line against the widest line, so a centred paragraph keeps its lines centred on each other. =text-y= is always the top edge of the first line.

To centre a title on a 1280-wide frame, either set =text-x= to the centre and leave =max-width= at 0, or give the clip the whole width as its box:

#+begin_src c
/* Centred on x = 640. */
lrg_reel_text_clip_set_align  (title, LRG_REEL_TEXT_ALIGN_CENTER);
lrg_reel_text_clip_set_text_x (title, 640);

/* The same, wrapping at the frame's width minus 80 px margins. */
lrg_reel_text_clip_set_align     (title, LRG_REEL_TEXT_ALIGN_CENTER);
lrg_reel_text_clip_set_text_x    (title, 40);
lrg_reel_text_clip_set_max_width (title, 1200);
#+end_src

**** Migration from 0.13.5 and earlier
:PROPERTIES:
:CUSTOM_ID: text-clip-alignment-migration
:END:
Before 0.13.6, without a =max-width= the block always started at =text-x=, so =center= and =right= did nothing: a centred line with =text-x = 640= started at x = 640 and ran off to the right. Clips that set a =max-width= render exactly as before. Clips with =align: center= or =align: right= and no =max-width= now move left by half (centre) or all (right) of the text's width. If you had worked around the old behaviour with =text-x = x - W= and =max-width = 2 * W=, that still centres on =x= and needs no change; if you had moved =text-x= left by hand to fake centring, set it back to the centre point.

Layout helpers are also provided as free functions:

#+begin_src c
/* How big will the text be at 48 px? */
gint tw, th;
lrg_reel_measure_text (NULL, "Hello World", 48.0, &tw, &th);

/* What font size fills an 800×100 box? */
gdouble size = lrg_reel_fit_text (NULL, "Level Complete",
                                   800, 100, 96.0);
#+end_src

Pass =NULL= as the font argument to both utilities to measure with the bitmap
font.

** LrgReelShapeClip — vector shapes
:PROPERTIES:
:CUSTOM_ID: shape-clip
:END:
Renders a filled and/or stroked shape every frame.  Supports nine shape kinds
from =LrgReelShapeKind=: rect, rounded rect, circle, ellipse, triangle, star,
line, polygon, and path.

#+begin_src c
/* A rounded rectangle. */
g_autoptr(LrgReelShapeClip) box =
    lrg_reel_shape_clip_new (LRG_REEL_SHAPE_ROUNDED_RECT);
lrg_reel_shape_clip_set_shape_x      (box, 100);
lrg_reel_shape_clip_set_shape_y      (box, 50);
lrg_reel_shape_clip_set_shape_width  (box, 400);
lrg_reel_shape_clip_set_shape_height (box, 200);
lrg_reel_shape_clip_set_corner_radius (box, 16);

GrlColor fill   = {  40,  60, 120, 200 };
GrlColor stroke = { 100, 160, 255, 255 };
lrg_reel_shape_clip_set_fill_color   (box, &fill);
lrg_reel_shape_clip_set_stroke_color (box, &stroke);
lrg_reel_shape_clip_set_stroke_width (box, 3);

lrg_reel_add_clip (reel, LRG_REEL_CLIP (box));

/* Convenience constructors for common shapes. */
g_autoptr(LrgReelShapeClip) rect =
    lrg_reel_shape_clip_new_rect (10, 10, 200, 100);

g_autoptr(LrgReelShapeClip) circle =
    lrg_reel_shape_clip_new_circle (320, 180, 80);
#+end_src

For a polygon, supply a vertex array:

#+begin_src c
GrlVector2 pts[] = { {100,200}, {200,50}, {300,200} };
g_autoptr(LrgReelShapeClip) tri =
    lrg_reel_shape_clip_new (LRG_REEL_SHAPE_POLYGON);
lrg_reel_shape_clip_set_points (tri, pts, G_N_ELEMENTS (pts));
#+end_src

For an arbitrary bezier/path use =LRG_REEL_SHAPE_PATH= and call
=lrg_reel_shape_clip_set_path()=.  See [[file:motion.org][motion.org]] for path utilities.

*** Pitfall

Setting a fill color with =alpha = 0= draws nothing for the fill, but the
stroke is drawn independently.  You can have a stroke-only shape by setting
the fill alpha to 0 and the stroke width to a positive value.

** LrgReelSkeleton2DClip — an animated 2D character
:PROPERTIES:
:CUSTOM_ID: skeleton2d-clip
:END:
Draws an [[file:../animation/skeleton2d.org][LrgSkeleton2D]] character, posed for each frame, on the CPU: no window is needed, so a character renders to frames headless (CI, a render server) and exports through any reel exporter.  Since 0.14.

Each frame the clip:
1. resets the skeleton to its setup pose (=lrg_skeleton2d_reset_pose()=), so a frame never depends on the frame rendered before it;
2. applies its animation (an =LrgSkeleton2DClip=) at the clip-relative time =lrg_reel_context_get_seconds()= (sub-frame included, so motion blur works) times the speed, wrapped into the animation's duration when looping (the default) or clamped to it otherwise (=lrg_reel_skeleton2d_clip_get_animation_time()= returns that time);
3. calls the pose callback, if any (=LrgReelSkeleton2DPoseFunc=, set with =lrg_reel_skeleton2d_clip_set_pose_func()=): procedural layers such as blinks, breathing or a look-at go here, as pure functions of the time;
4. places the skeleton through its root transform (=lrg_reel_skeleton2d_clip_set_placement (clip, x, y, scale)=, =lrg_reel_skeleton2d_clip_set_flip_x()=), the way =LrgSkeleton2DComponent= places it from a game object, computes the world transforms and draws it with =lrg_skeleton2d_draw_to_canvas()=.

The inherited clip transform, opacity, blend mode and effects work too: the canvas transform composes with the placement.  Attachment images load on the first frame relative to the skeleton's =base-dir= (or set CPU source images with =lrg_skinned_sprite_set_source_image()=); see [[file:../animation/skeleton2d.org::#cpu-drawing][Drawing on the CPU]].

*** Example: a character to a PNG sequence
A complete program: it builds a two-bone arm with a generated texture, plays a bend clip with a procedural sway on top, and renders 48 frames to =frames/wave_00000.png= .. on four threads.

#+begin_src c
/* wave.c: a waving arm rendered to frames/wave_00000.png .. headless */
#include <libregnum.h>
#include <math.h>

/* procedural layer: the upper arm sways on top of the "bend" clip */
static void
sway (LrgReelSkeleton2DClip *clip,
      LrgSkeleton2D         *skel,
      gdouble                seconds,
      gpointer               user_data)
{
    gint upper = lrg_skeleton2d_find_bone (skel, "upper");

    lrg_skeleton2d_set_bone_local (skel, upper, 0.0f, 0.0f,
                                   (gfloat)(-25.0 * sin (seconds * G_PI)), 1.0f, 1.0f);
}

int
main (void)
{
    g_autoptr(GError)                error = NULL;
    g_autoptr(LrgSkeleton2D)         skel = lrg_skeleton2d_new ();
    g_autoptr(LrgSkinnedSprite)      strip = lrg_skinned_sprite_new_grid (0, -8, 120, 16, 12, 1);
    g_autoptr(LrgSkeleton2DClip)     bend = lrg_skeleton2d_clip_new ("bend");
    g_autoptr(GrlImage)              skin = NULL;
    g_autoptr(LrgReel)               reel = lrg_reel_new ("wave", 320, 240, 24.0, 48);
    g_autoptr(LrgReelSolidClip)      bg = NULL;
    g_autoptr(LrgReelSkeleton2DClip) arm = NULL;
    g_autoptr(LrgReelRenderer)       renderer = NULL;
    g_autoptr(LrgReelSeqExporter)    seq = NULL;
    GrlColor                         sky = { 40, 50, 70, 255 };
    GrlColor                         c1 = { 240, 160, 90, 255 };
    GrlColor                         c2 = { 170, 80, 50, 255 };
    gint                             upper;
    gint                             fore;
    gint                             slot;

    /* the character: two bones, one 12-cell strip mesh weighted to both,
     * textured with a generated gradient (no image files needed) */
    upper = lrg_skeleton2d_add_bone (skel, "upper", -1, 0, 0, 0, 1, 1, 60);
    fore = lrg_skeleton2d_add_bone (skel, "fore", upper, 60, 0, 0, 1, 1, 60);
    slot = lrg_skeleton2d_add_slot (skel, "arm", upper, "arm");
    lrg_skeleton2d_update_world (skel);
    {
        gint bones[2];

        bones[0] = upper;
        bones[1] = fore;
        lrg_skeleton2d_compute_auto_weights (skel, strip, bones, 2, 4.0f, 2, 1);
    }
    skin = grl_image_new_gradient_linear (64, 16, 90, &c1, &c2);
    lrg_skinned_sprite_set_source_image (strip, skin);
    lrg_skeleton2d_set_attachment (skel, NULL, slot, "arm", strip);

    /* the animation: the forearm bends 90 degrees and back over 2 s */
    lrg_skeleton2d_clip_add_rotate_key (bend, "fore", 0.0f, 0.0f, LRG_SKELETON2D_CURVE_LINEAR);
    lrg_skeleton2d_clip_add_rotate_key (bend, "fore", 1.0f, 90.0f, LRG_SKELETON2D_CURVE_LINEAR);
    lrg_skeleton2d_clip_add_rotate_key (bend, "fore", 2.0f, 0.0f, LRG_SKELETON2D_CURVE_LINEAR);

    /* the reel: a background and the character clip, placed with its
     * shoulder at (80, 120), 1.2x, swaying procedurally */
    bg = lrg_reel_solid_clip_new (&sky);
    lrg_reel_add_clip (reel, LRG_REEL_CLIP (bg));
    arm = lrg_reel_skeleton2d_clip_new (skel, bend);
    lrg_reel_skeleton2d_clip_set_placement (arm, 80.0, 120.0, 1.2);
    lrg_reel_skeleton2d_clip_set_pose_func (arm, sway, NULL, NULL);
    lrg_reel_add_clip (reel, LRG_REEL_CLIP (arm));

    /* 48 PNG frames, rendered on 4 threads */
    renderer = lrg_reel_renderer_new (reel);
    seq = lrg_reel_seq_exporter_new ("frames", "wave_%05d", LRG_REEL_IMAGE_FORMAT_PNG);
    if (!lrg_reel_renderer_render_parallel (renderer, 4, LRG_REEL_EXPORTER (seq), &error))
    {
        g_printerr ("render failed: %s\n", error->message);
        return 1;
    }
    g_print ("wrote %u frames\n", lrg_reel_seq_exporter_get_frame_count (seq));
    return 0;
}
#+end_src

Loading a rig from disk is one call: =lrg_reel_skeleton2d_clip_new_from_file ("hero.rskel2d", "walk", &error)= loads the file and picks the clip by name (a missing name is an error).

*** API
| Function | Description |
|----------+-------------|
| =lrg_reel_skeleton2d_clip_new (skeleton, animation)= | new clip; both nullable; loops at speed 1, origin at the canvas origin |
| =lrg_reel_skeleton2d_clip_new_from_file (path, animation, error)= | load a =.rskel2d= and pick a clip by name |
| =lrg_reel_skeleton2d_clip_get_skeleton= / =lrg_reel_skeleton2d_clip_set_skeleton= | the skeleton (a reference is kept) |

| =lrg_reel_skeleton2d_clip_get_speed= / =lrg_reel_skeleton2d_clip_set_speed= | animation seconds per clip second; negative plays backwards |

| =lrg_reel_skeleton2d_clip_set_placement (self, x, y, scale)= / =lrg_reel_skeleton2d_clip_get_placement= | skeleton origin in canvas pixels and uniform scale |
| =lrg_reel_skeleton2d_clip_get_flip_x= / =lrg_reel_skeleton2d_clip_set_flip_x= | mirror about the origin |
| =lrg_reel_skeleton2d_clip_set_pose_func (self, func, user_data, destroy)= | procedural posing layer, run after the animation |
| =lrg_reel_skeleton2d_clip_get_animation_time (self, seconds)= | the animation time used for a clip time |

Properties: =skeleton=, =animation=, =animation-name=, =file= (a =.rskel2d= path; setting it loads the skeleton), =speed=, =loop=, =origin-x=, =origin-y=, =skeleton-scale=, =flip-x=.  The names avoid the inherited =x=, =y= and =scale-x= transform properties.

*** YAML
The loader registers the clip as =skeleton2d-clip= ([[file:data-yaml.org][Data-driven YAML]]); =file= names the rig (relative paths are relative to the current directory) and =animation-name= the clip:

#+begin_src yaml
clips:
  - type: skeleton2d-clip
    file: "rigs/hero.rskel2d"
    animation-name: walk
    origin-x: 320
    origin-y: 400
    skeleton-scale: 1.5
    loop: true
#+end_src

A pose callback can only be set from code.

*** Parallel rendering
=lrg_reel_renderer_render_parallel()= renders different frames of the same clip objects on several threads, and the reel's rule is that a clip keeps no mutable render state on itself ([[file:rendering.org::#parallel-rendering][Parallel rendering]]).  A skeleton is mutable render state through and through: its local pose, world matrices, slot colours, attachments and draw order, and the deformed vertex buffer of every attachment are written while a frame is posed and drawn.  There are two ways to stay correct: copy the skeleton per frame, or lock.  =LrgReelSkeleton2DClip= locks:
- =LrgSkeleton2D= has no deep copy, and a copy per frame would allocate every mesh again (and would have to learn every new channel, such as blend-shape weights).
- The lock is one process-wide recursive mutex around steps 1 to 4 above, not one per clip or per skeleton, because attachments are shared by reference: two skeletons, and so two clips, can deform the same =LrgSkinnedSprite=.  It is recursive so a pose callback may render a nested reel holding another skeleton clip.
- The cost: the skeleton clips of different frames pose and draw one at a time.  Everything else in those frames (other clips, effects, compositing, encoding) still runs in parallel, and posing and drawing a character is a small part of a frame.  The output is byte-identical to a sequential render; =tests/test-reel.c= (=/reel/skeleton2d/parallel=) renders two clips sharing one skeleton, with a pose callback, three times on 8 threads and compares every frame byte for byte (without the lock the same test fails).
- The pose callback runs under the lock, on whichever renderer thread renders the frame; it must not wait for another thread that renders a skeleton clip.

*** Pitfalls
- The clip owns the skeleton's pose and root transform while a reel renders: do not pose or draw the same skeleton elsewhere at the same time.  After a render the skeleton is left in the last rendered pose.
- A pose callback must be a pure function of =seconds=: frames render out of order and on several threads, so state carried from one call to the next breaks determinism.
- A =file= that does not load leaves the clip empty and logs a warning (a property setter cannot return an error); use =lrg_reel_skeleton2d_clip_new_from_file()= in code to get the =GError=.
