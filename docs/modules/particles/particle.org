* LrgParticle
:PROPERTIES:
:CUSTOM_ID: lrgparticle
:END:
=LrgParticle= (=particles/lrg-particle.h=) is a plain boxed struct holding one particle's state: position, velocity, colour, size, rotation, lifetime and, since 0.9.0, the start values and identity the module stack uses. Systems keep particles in a fixed pool (=LrgParticlePool=) and hand them to emitters, forces, modules, renderers and =lrg_particle_system_foreach_active()= callbacks by pointer; read and write the fields directly.

** Structure
:PROPERTIES:
:CUSTOM_ID: structure
:END:
#+begin_src C
struct _LrgParticle
{
    gfloat   position_x, position_y, position_z;   /* world space */
    gfloat   velocity_x, velocity_y, velocity_z;   /* units per second */
    gfloat   color_r, color_g, color_b, color_a;   /* 0 .. 1 */
    gfloat   size;                                 /* world units (billboard side, mesh scale) */
    gfloat   rotation;                             /* radians */
    gfloat   rotation_velocity;                    /* radians per second */
    gfloat   life;                                 /* seconds left */
    gfloat   max_life;                             /* seconds at birth */
    gfloat   age;                                  /* seconds since birth */
    gboolean alive;

    /* module stack data (0.9.0) */
    gfloat   start_size;                           /* size after the init stage */
    gfloat   start_color_r, start_color_g, start_color_b, start_color_a;
    gfloat   start_rotation_velocity;
    gfloat   random;                               /* per-particle number in [0, 1) from the system's generator */
    guint32  id;                                   /* spawn serial in its system, from 1 */
    guint32  collisions;                           /* hits so far */
};
#+end_src

The over-life modules compute values from the start fields and the normalized age (=age / max_life=), so they never compound; ribbons key trails on =id= and connect particles in its order; the mesh renderer derives a stable tumble axis from =random=.

** Usage
:PROPERTIES:
:CUSTOM_ID: usage
:END:
#+begin_src C
static void
count_hot (const LrgParticle *p,
           gpointer           user_data)
{
	if (p->color_r > 0.9f && lrg_particle_get_normalized_age (p) < 0.5f)
		(*(guint *) user_data)++;
}

guint hot = 0;
lrg_particle_system_foreach_active (system, count_hot, &hot);
#+end_src

** Memory Management
:PROPERTIES:
:CUSTOM_ID: memory-management
:END:
Particles inside a system belong to its pool; never free them. Stand-alone particles (tests, tools) use =g_autoptr=:

#+begin_src C
g_autoptr(LrgParticle) particle = lrg_particle_new_at (0.0f, 1.0f, 0.0f, 2.0f);
#+end_src
