* Particle System Module
:PROPERTIES:
:CUSTOM_ID: particle-system-module
:END:
The Particle System module provides a flexible and performant particle effects system for visual effects like fire, smoke, explosions, magic, and ambient particles.

** Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:
The particle system follows a producer-consumer pattern with object pooling for performance:

- *LrgParticle* - Individual particle data (position, velocity, life, color, size)
- *LrgParticlePool* - Pre-allocated pool of particles for efficient memory management
- *LrgParticleEmitter* - Spawns particles with configurable shapes and properties
- *LrgParticleForce* - Modifies particle behavior (gravity, wind, attractors, turbulence)
- *LrgParticleSystem* - Coordinates emitters, forces, the 0.9.0 module stack and its seeded generator
- *LrgParticleAsset* / *LrgParticleEffect* (0.9.0) - The =.rparticles= format (emitters, module stacks, renderers) and its playing instance
- *Renderers* - billboards, ribbons and trails, instanced meshes; GPU particles for very large counts

For authored effects start with [[file:particle-asset.org][Particle assets]] and the [[file:../../guides/vfx.org][Visual effects guide]].

** Quick Start
:PROPERTIES:
:CUSTOM_ID: quick-start
:END:
#+begin_src C
/* An authored effect (0.9.0) */
g_autoptr(LrgParticleAsset)  asset = lrg_particle_asset_new_from_file ("fx/fire.rparticles", NULL);
g_autoptr(LrgParticleEffect) fire = lrg_particle_effect_new (asset);

lrg_particle_effect_play (fire);
/* each frame: */
lrg_particle_effect_update (fire, delta_time);
lrg_particle_effect_draw_camera (fire, camera);   /* inside BeginMode3D () */

/* A system built in code (legacy emitters and forces) */
LrgParticleSystem  *system = lrg_particle_system_new (1000);
LrgParticleEmitter *emitter = lrg_particle_emitter_new ();
lrg_particle_emitter_set_emission_rate (emitter, 50.0f);
lrg_particle_system_add_emitter (system, emitter);
lrg_particle_system_add_force (system, lrg_particle_force_gravity_new (0.0f, -9.81f, 0.0f));
lrg_particle_system_play (system);
#+end_src

** Key Concepts
:PROPERTIES:
:CUSTOM_ID: key-concepts
:END:
*** Particle Lifecycle
:PROPERTIES:
:CUSTOM_ID: particle-lifecycle
:END:
1. *Birth* - Emitter spawns particle with initial properties
2. *Life* - Forces modify velocity; particle ages toward death
3. *Death* - Particle reaches end of lifetime; returned to pool

*** Emission Shapes
:PROPERTIES:
:CUSTOM_ID: emission-shapes
:END:
- *Point* - All particles spawn at a single point
- *Circle* - Spawn randomly within a circle
- *Rectangle* - Spawn randomly within a rectangle
- *Sphere* - Spawn randomly within a sphere (3D)
- *Cone* - Spawn with directional spread

*** Force Types
:PROPERTIES:
:CUSTOM_ID: force-types
:END:
| Force      | Description                            |
|------------+----------------------------------------|
| Gravity    | Constant directional acceleration      |
| Wind       | Directional force with noise variation |
| Attractor  | Point-based attraction or repulsion    |
| Turbulence | Perlin noise-based chaotic movement    |

** Performance Tips
:PROPERTIES:
:CUSTOM_ID: performance-tips
:END:
- Use object pooling (LrgParticlePool) for many particles
- Limit active particle count based on hardware
- Use texture atlases for varied particle appearances
- Consider level-of-detail for distant effects
