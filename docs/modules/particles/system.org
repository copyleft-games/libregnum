* LrgParticleSystem
:PROPERTIES:
:CUSTOM_ID: lrgparticlesystem
:END:
=LrgParticleSystem= is the main coordinator for particle effects. It manages emitters, forces, particle pools, and rendering.

** Type
:PROPERTIES:
:CUSTOM_ID: type
:END:
#+begin_src C
#define LRG_TYPE_PARTICLE_SYSTEM (lrg_particle_system_get_type ())
G_DECLARE_DERIVABLE_TYPE (LrgParticleSystem, lrg_particle_system, LRG, PARTICLE_SYSTEM, GObject)
#+end_src

This is a derivable type, allowing subclasses to override behavior.

** Functions
:PROPERTIES:
:CUSTOM_ID: functions
:END:
*** Creation
:PROPERTIES:
:CUSTOM_ID: creation
:END:
#+begin_src C
LrgParticleSystem *lrg_particle_system_new (guint max_particles);
#+end_src

Creates a particle system with the specified maximum capacity. The internal pool is sized to this limit and never grows: once =max_particles= particles are alive, rate and burst emission stop until some die (=lrg_particle_system_emit()= returns how many it could emit). Live particles are kept in a flat array, newest first when iterated (=foreach_active=, =draw=), as before.

Pool ownership is tracked separately from the public particle =alive= flag. Lifetime expiry or an explicit kill clears that flag before the system returns the slot; release now returns the outstanding lease exactly once. Bulk dead-slot reclamation is linear in capacity and does not scan the free list for every particle. The expired-leases and expired-cohorts regressions cover direct release, double release, bulk reclamation, externally killed particles, pool-driven updates and repeated fixed-capacity system bursts.

The capacity is the construct-only property =max-particles= (default 1000); the pool is created in =constructed()=, so a subclass built with =g_object_new (MY_TYPE_SYSTEM, "max-particles", 256, NULL)= gets its pool as well.  =lrg_particle_system_emit()= and =emit_at()= call the class's =on_particle_spawn= for every particle they emit, like rate emission during =update()=.

*** Reading active particles
:PROPERTIES:
:CUSTOM_ID: foreach-active
:END:

Calls =func= for every alive particle, newest first.  The callback must not add or remove particles.  Renderers ([[file:billboard-renderer.org][LrgParticleBillboardRenderer]]) read particles through it; the default =draw= virtual still draws nothing.

/* Create system */

lrg_particle_system_set_position (fire, 400.0f, 500.0f, 0.0f);

lrg_particle_emitter_set_rate (emitter, 100.0f);
lrg_particle_emitter_set_lifetime (emitter, 1.5f);
lrg_particle_emitter_set_initial_velocity (emitter, 0.0f, -80.0f, 0.0f);
lrg_particle_emitter_set_start_color (emitter, 255, 200, 50, 255);
lrg_particle_emitter_set_end_color (emitter, 255, 50, 0, 0);
lrg_particle_system_add_emitter (fire, emitter);

/* Add forces */
lrg_particle_system_add_force (fire, lrg_particle_force_wind_new (15.0f, 0.0f, 0.0f));
lrg_particle_system_add_force (fire, lrg_particle_force_turbulence_new (20.0f));

/* Start */
lrg_particle_system_play (fire);

#+begin_src C
/* In game update */
void
game_update (gfloat delta_time)
{
    /* Update all particle systems */
    lrg_particle_system_update (fire_system, delta_time);
    lrg_particle_system_update (smoke_system, delta_time);
    lrg_particle_system_update (sparkles_system, delta_time);

    /* Remove finished one-shot effects */
    if (!lrg_particle_system_is_alive (explosion))
    {
        g_clear_object (&explosion);
    }
}

/* In game render */
void
game_render (void)
{
    /* Draw particles (usually after scene, before UI) */
    lrg_particle_system_draw (fire_system);
    lrg_particle_system_draw (smoke_system);
    lrg_particle_system_draw (sparkles_system);
}
#+end_src

** Render layers
:PROPERTIES:
:CUSTOM_ID: render-layers
:END:
The =layer= property (=lrg_particle_system_set_layer()= / =lrg_particle_system_get_layer()=, 0 by default) puts a system on a render layer. =lrg_particle_system_draw()= and =lrg_particle_billboard_renderer_draw()= draw nothing while =lrg_particle_system_is_layer_visible()= is =FALSE= (the layer is outside the active cull mask); custom renderers should test it too. See [[file:../graphics/render-layers.org][Render layers]].

** Module stack (0.9.0)
:PROPERTIES:
:CUSTOM_ID: module-stack
:END:
Besides the legacy emitter and force lists, a system runs a /module stack/: =LrgParticleModule= objects, each in one stage (=LrgParticleModuleStage=: =SPAWN=, =SHAPE=, =INIT=, =FORCE=, =COLLISION=, =OVER_LIFE=, =EVENT=). Every update the spawn modules return particle counts; new particles go through the shape and init modules (their results become the start values); every live particle goes through the force modules, the integration step, the collision modules and the over-life modules; birth, death and collision events go to the event modules. Stages run in that order, modules of a stage in stack order. The step order and data flow are described in detail in [[file:particle-asset.org::#concepts-modules][Particle assets: the module stack]]; the built-in modules (created by kind name with =lrg_particle_module_new()=) and the =.rparticles= format that stores them live there too. Legacy emitters and forces keep working and run before the modules.

*** The generator
:PROPERTIES:
:CUSTOM_ID: rng
:END:
=LrgParticleRng= is a PCG32 generator (XSH-RR output, 64-bit state), a plain boxed struct (=state=, =inc=). Each system owns one, seeded from =seed= and reseeded on =lrg_particle_system_restart()= and on play after a stop.

| Function | Description |
|----------+-------------|
| =lrg_particle_rng_get_type ()= | boxed =GType= (=LRG_TYPE_PARTICLE_RNG=) |
| =lrg_particle_rng_new (seed)=, =lrg_particle_rng_copy (self)=, =lrg_particle_rng_free (self)= | heap generators (=g_autoptr= works) |
| =lrg_particle_rng_seed (self, seed)= | restart a sequence |
| =lrg_particle_rng_next_u32 (self)= | 32 random bits |
| =lrg_particle_rng_next_float (self)= | [0, 1), 24 bits |
| =lrg_particle_rng_range (self, min, max)= | [min, max); returns =min= without drawing when equal |
| =lrg_particle_rng_unit_vector (self, out)= | uniform direction |

*** Modules
:PROPERTIES:
:CUSTOM_ID: module-class
:END:
=LrgParticleModule= is a derivable, abstract GObject with one property, =enabled=. A subclass sets =LrgParticleModuleClass.stage= in =class_init= and implements the vfunc of its stage; all vfuncs are optional:

| Vfunc | Stage | Called |
|-------+-------+--------|
| =reset (self)= | any | at a fresh start (play after stop, restart): clear accumulators |
| =spawn_count (self, ctx)= | =SPAWN= | once per step: particles to emit |
| =init_particle (self, ctx, particle)= | =SHAPE=, =INIT= | per new particle |
| =update_particle (self, ctx, particle)= | =FORCE=, =COLLISION=, =OVER_LIFE= | per live particle per step |
| =particle_event (self, ctx, particle, event)= | =EVENT= | per birth, death, collision (=LrgParticleEvent=) |

=LrgParticleModuleContext= is what a vfunc sees: =system=, =rng=, =dt= (time-scaled), =time= (since play), =cycle_time=, =cycle_fraction= (0 .. 1 of the duration), =cycle= (completed loops), =origin= (system position or the sub-emitter point), =rotation= (quaternion x y z w), =direction= (spawn direction: the rotated +Y before the shape stage; shape modules write it, velocity modules read it), =inherit_velocity= (the system's own movement per second), =moved= (distance moved this step), =event_point= and =event_normal= (for events).

| Function | Description |
|----------+-------------|
| =lrg_particle_module_get_stage (self)= | the class's stage |
| =lrg_particle_module_get_enabled (self)=, =set_enabled (self, enabled)= | on/off |
| =lrg_particle_module_reset (self)= | calls =reset= |
| =lrg_particle_module_spawn_count (self, ctx)= | calls =spawn_count= (0 when disabled or absent) |
| =lrg_particle_module_init_particle (self, ctx, p)=, =update_particle (self, ctx, p)=, =particle_event (self, ctx, p, event)= | call the vfuncs when enabled |
| =lrg_particle_module_copy (self)= | same type, same property values (curves deep-copied), fresh run state |
| =lrg_particle_module_stage_get_type ()=, =lrg_particle_event_get_type ()= | enum types |
