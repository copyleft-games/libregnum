* Weather System Module
:PROPERTIES:
:CUSTOM_ID: weather-system-module
:END:
The Weather System provides dynamic weather effects including rain, snow, fog, lightning, day/night cycles, and smooth weather transitions.

** Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:
The weather system coordinates multiple effects for atmospheric immersion:

- *LrgWeatherEffect* - Abstract base for weather effects (derivable): intensity with smooth transitions, wind, render layer, the particle space, the camera volume and three render passes
- *LrgRain* - Rain drops: screen-space lines or world-space streaks around the camera, with splashes
- *LrgSnow* - Snow flakes: screen-space dots or world-space sprites that sway and ride the wind
- *LrgFog* - Distance fog parameters for shaders ([[file:../graphics/light-set.org][LrgLightSet]]) plus a screen-veil fallback (uniform, linear, exponential, height-based)
- *LrgLightning* - Strikes of flickering flashes with a brightness curve, optional bolts and a thunder signal
- *LrgWeather* - Weather state definition combining effects
- *LrgDayNightCycle* - Time-of-day system with color transitions
- *LrgWeatherManager* - Coordinates weather states, crossfades, wind, the render passes and the scene fog
- *LrgCelestial* - Pure sky maths: moon phases from a calendar day, the lit part of a moon disc, orbit directions, a deterministic star field, thunder delay over distance
- *LrgCloudLayer* - A drifting cloud deck drawn as stacked slices of noise, with CPU-sampled cloud shadows and a baked shadow light map
- *LrgSnowCover* - Lying snow that builds with snowfall, melts with warmth and takes footprint tracks
- *LrgWeatherField* - A simulated weather map: moisture and storms carried by the wind, relaxing to each cell's climate, with seeded fronts
- *LrgGroundOverlay* - A blended second terrain pass: lying snow and its tracks, and the cloud shadows
- [[file:../graphics/sky-bodies.org][LrgSkyBodies]] (graphics) - Sun disc, phased moons and stars drawn over the sky dome

** Spaces and render passes
:PROPERTIES:
:CUSTOM_ID: spaces-and-render-passes
:END:
Every effect has a *space* (=LrgWeatherSpace=, property =space=):

| Space                      | Units                | Particles live in                       | Drawn by           |
|----------------------------+----------------------+-----------------------------------------+--------------------|
| =LRG_WEATHER_SPACE_SCREEN= | pixels (default)     | an area (=set_area()=)                  | =render()=         |
| =LRG_WEATHER_SPACE_WORLD=  | world units (metres) | a box centred on the camera (=set_volume()=) | =render_world()= |

Switching the space resets the unit-dependent settings (speeds, lengths, sizes, sway, splash height) to that space's defaults, so set them *after* =set_space()=.

There are three passes, each a virtual method of =LrgWeatherEffect= with a wrapper on =LrgWeather= and =LrgWeatherManager= (effects in ascending render layer, insertion order within a layer):

| Pass              | When                                                     | Draws                                                                 |
|-------------------+----------------------------------------------------------+-----------------------------------------------------------------------|
| =render()=        | 2D games, anywhere                                       | screen rain and snow, fog veil, lightning flash and a 2D bolt          |
| =render_world()=  | inside =BeginMode3D()=, after opaque geometry            | world rain streaks, snow flakes, splashes, lightning bolts             |
| =render_overlay()= | after =EndMode3D()=, before the UI (3D games)           | fog veil, lightning flash                                             |

- The built-in effects draw nothing without a window, so every pass is safe headless; custom effects' vfuncs are always called.
- =render_world (camera)= also remembers the camera (=lrg_weather_effect_get_camera_position()=); the next update wraps and spawns particles around it. =set_camera_position()= does the same without drawing.
- World particles test depth but do not write it, with face culling off; the pass flushes rlgl's batch before and after and restores raylib's 3D defaults (culling and depth writes on).

** Quick Start
:PROPERTIES:
:CUSTOM_ID: quick-start
:END:
A 3D storm (world-space rain, lightning with bolts, shader fog):

#+begin_src C
g_autoptr(LrgWeatherManager) weather = lrg_weather_manager_new ();
g_autoptr(LrgWeather) storm = lrg_weather_new ("storm", "Thunderstorm");
g_autoptr(LrgRain) rain = lrg_rain_new ();
g_autoptr(LrgLightning) lightning = lrg_lightning_new ();
g_autoptr(LrgFog) fog = lrg_fog_new ();

lrg_weather_effect_set_space (LRG_WEATHER_EFFECT (rain), LRG_WEATHER_SPACE_WORLD);
lrg_rain_set_drop_count (rain, 3000);              /* x intensity are drawn */
lrg_rain_set_color (rain, 160, 170, 190, 170);
lrg_weather_add_effect (storm, LRG_WEATHER_EFFECT (rain));

lrg_lightning_set_bolts_enabled (lightning, TRUE);
lrg_weather_add_effect (storm, LRG_WEATHER_EFFECT (lightning));

lrg_fog_set_fog_type (fog, LRG_FOG_TYPE_EXPONENTIAL);
lrg_fog_set_density (fog, 0.02f);                  /* per metre */
lrg_fog_set_color (fog, 90, 95, 105, 255);
lrg_fog_set_veil_opacity (fog, 0.0f);              /* the shader fogs instead */
lrg_weather_add_effect (storm, LRG_WEATHER_EFFECT (fog));

lrg_weather_manager_register_weather (weather, storm);
lrg_weather_manager_set_weather (weather, "storm", 5.0f);   /* 5 s crossfade */

/* each frame */
lrg_weather_manager_update (weather, delta_time);
lrg_weather_manager_apply_fog (weather, lights);            /* before apply */
lrg_light_set_apply (lights, eye.x, eye.y, eye.z);

BeginMode3D (camera);
/* ... opaque world, billboards ... */
lrg_weather_manager_render_world (weather, &eye);
EndMode3D ();
lrg_weather_manager_render_overlay (weather, GetScreenWidth (), GetScreenHeight ());
/* ... UI ... */
#+end_src

A 2D game keeps the defaults (screen space) and calls =lrg_weather_manager_render()= after drawing the scene.

** Weather Effects
:PROPERTIES:
:CUSTOM_ID: weather-effects
:END:
*** Rain
:PROPERTIES:
:CUSTOM_ID: rain
:END:
#+begin_src C
LrgRain *rain = lrg_rain_new ();
lrg_rain_set_drop_count (rain, 1000);
lrg_rain_set_drop_speed (rain, 400.0f);
lrg_rain_set_drop_length (rain, 20.0f);
lrg_rain_set_drop_thickness (rain, 1.0f);
lrg_rain_set_color (rain, 180, 200, 255, 150);
lrg_rain_set_splash_enabled (rain, TRUE);
lrg_rain_set_splash_height (rain, 600.0f);         /* screen Y or world ground height */
#+end_src

| Setting              | Screen default | World default | Meaning                                   |
|----------------------+----------------+---------------+-------------------------------------------|
| =drop-speed=         | 500 px/s       | 9 units/s     | base fall speed                           |
| =drop-speed-variation= | 100          | 1.5           | ± per drop                                |
| =drop-length=        | 15 px          | 0.5           | streak length (× 0.8 .. 1.2 per drop)     |
| =drop-thickness=     | 1 px           | 0.012         | line / ribbon width                       |
| =splash-enabled=     | TRUE           | FALSE         | splash at the splash height               |
| =splash-height=      | 600 px         | 0             | screen Y / world ground plane             |

- *Screen*: drops fall through the area; a dead drop respawns at the top with the intensity as its per-update chance (the original 2D behaviour); =render()= draws each as a line slanted by the wind ending at the drop, splashes as two spreading ticks.
- *World*: every drop keeps a world position and is folded back into the half-open camera box whenever it leaves, so moving or teleporting the camera never empties the volume and nearby drops show parallax. Velocity = (wind_x, -speed, wind_y). The first =drop_count × intensity= drops are drawn as camera-facing ribbons from tail to head along the velocity, head at the rain colour and tail transparent. With splashes on and the box reaching above the ground plane, a drop crossing it leaves a fading ring (6 segments, 0.3 s, at most 128 live) and restarts just under the top of the box; drops below the plane are never drawn. A drop leaving through the bottom restarts at a fresh X/Z so columns do not repeat.
- Inspection (headless): =get_visible_count()=, =get_drop (i, &pos)= (exactly where it is drawn), =get_splash_count()=.

*** Snow
:PROPERTIES:
:CUSTOM_ID: snow
:END:
#+begin_src C
LrgSnow *snow = lrg_snow_new ();
lrg_weather_effect_set_space (LRG_WEATHER_EFFECT (snow), LRG_WEATHER_SPACE_WORLD);
lrg_snow_set_flake_count (snow, 2000);
lrg_snow_set_flake_speed (snow, 1.0f);
lrg_snow_set_sway_amount (snow, 0.4f);
lrg_snow_set_color (snow, 240, 240, 250, 220);
#+end_src

| Setting                | Screen default | World default |
|------------------------+----------------+---------------|
| =flake-speed=          | 100 px/s       | 1.2 units/s (× 0.5 .. 1.5 per flake) |
| =flake-size=           | 4 px           | 0.05          |
| =flake-size-variation= | 2 px           | 0.02          |
| =sway-amount=          | 30 px/s        | 0.35 units/s  |
| =sway-speed=           | 2              | 1.5           |

- *Screen*: flakes sway on X, drift with 30% of the wind, are drawn as dots (=flake-size= is the diameter); accumulation draws a band of the accumulated height along the bottom of the area.
- *World*: flakes fall, sway on X (=sin=) and Z (=cos= at 0.7× the rate, own phase: a lazy spiral), ride the full wind and wrap around the camera box like rain; the first =flake_count × intensity= are drawn as camera-facing squares (camera basis from the modelview matrix). Accumulation counts drawn flakes leaving through the bottom.
- Inspection: =get_visible_count()=, =get_flake (i, &pos)=.

*** Fog
:PROPERTIES:
:CUSTOM_ID: fog
:END:
#+begin_src C
LrgFog *fog = lrg_fog_new ();
lrg_fog_set_fog_type (fog, LRG_FOG_TYPE_LINEAR);
lrg_fog_set_color (fog, 200, 200, 210, 255);      /* alpha caps the fog */
lrg_fog_set_start_distance (fog, 100.0f);
lrg_fog_set_end_distance (fog, 500.0f);
lrg_fog_set_veil_opacity (fog, 0.0f);             /* 3D: shader fog only */
#+end_src

Fog is distance fog for shaders with a screen veil as fallback:

- =lrg_fog_apply (fog, lights)= hands the parameters to an [[file:../graphics/light-set.org][LrgLightSet]] (=set_fog()= + =set_fog_height()=), whose shader and lit billboards blend toward the colour per fragment. The colour's alpha is scaled by the intensity, so manager transitions fade the fog; inactive or zero intensity clears the light set's fog (returns =FALSE=).
- =lrg_fog_get_amount (fog, distance, height)= is the same model on the CPU: the share of fog colour, already × alpha × intensity.
- The *veil*: =render()= (whole screen) and =render_overlay (w, h)= draw a rectangle of the fog colour with alpha = colour alpha × intensity × =veil-opacity= (default 0.5). A 3D scene with shader fog sets the opacity to 0 (or keeps a little).
- =get_scroll_offset()= exposes the animated offset (scroll speeds + wind/10, integrated by update) for shaders that texture their fog.

*** Fog Types
:PROPERTIES:
:CUSTOM_ID: fog-types
:END:
=d= is the distance from the camera, =h= the world height; the result is then × colour alpha (× intensity for =LrgFog=).

| Type          | Amount                                                          |
|---------------+-----------------------------------------------------------------|
| =UNIFORM=     | =density=, at every distance                                    |
| =LINEAR=      | =clamp ((d - start) / (end - start))=; a hard edge at =end= when =end <= start= |
| =EXPONENTIAL= | =1 - exp (-density × d)=                                        |
| =HEIGHT=      | exponential × =exp (-falloff × max (h - base, 0))=              |

*** Lightning
:PROPERTIES:
:CUSTOM_ID: lightning
:END:
#+begin_src C
LrgLightning *lightning = lrg_lightning_new ();
lrg_lightning_set_min_interval (lightning, 5.0f);
lrg_lightning_set_max_interval (lightning, 15.0f);
lrg_lightning_set_flash_duration (lightning, 0.1f);
lrg_lightning_set_flash_count (lightning, 2);
lrg_lightning_set_flash_intensity (lightning, 0.8f);
lrg_lightning_set_bolts_enabled (lightning, TRUE);
lrg_lightning_set_bolt_shape (lightning, 150.0f, 90.0f, 1.0f);   /* distance, height, width */
lrg_lightning_set_color (lightning, 255, 255, 230);
g_signal_connect (lightning, "thunder", G_CALLBACK (play_thunder), NULL);
#+end_src

- A strike is =flash-count= sub-flashes (+ up to 2 more at full intensity) of =flash-duration= each, every =min-interval= .. =max-interval= seconds; =trigger_flash()= starts one now. =thunder= fires =thunder-delay= (+ 0..2 s) later.
- *Flash level* (=get_flash_level()=, 0..1): within a sub-flash a 10% attack from 60% to full, then a quadratic decay to dark; flicker sub-flashes after the first are at 60%; × =flash-intensity= × the effect intensity. The overlay pass draws the lightning colour with the level as alpha; =lrg_weather_manager_get_flash_level()= gives the brightest one, e.g. to add to the scene's ambient light while it lasts.
- *Bolts* (=bolts-enabled=): each strike generates a 33-point jagged polyline by midpoint displacement. In the world pass it stands =distance= away from the camera of the moment on a random bearing, its top =height= above the camera, spanning 1.25 × =height= (a quarter below the camera, so terrain hides its foot), drawn as =width=-wide camera-facing ribbons at 1.5 × the flash level. The 2D pass draws it from the top of the screen at a random column. =get_bolt_point_count()= / =get_bolt_point()= read it headless.

** Weather Transitions
:PROPERTIES:
:CUSTOM_ID: weather-transitions
:END:
#+begin_src C
/* Crossfade over 10 seconds: the old weather's effects fade 1 -> 0,
 * the new one's 0 -> 1 (world rain thins, fog alpha fades) */
lrg_weather_manager_set_weather (weather, "stormy", 10.0f);

/* Instant change (doors, loading screens) */
lrg_weather_manager_set_weather (weather, "clear", 0.0f);
lrg_weather_manager_clear_weather (weather, 2.0f);

if (lrg_weather_manager_is_transitioning (weather))
    ;   /* both weathers update and draw */
#+end_src

During a crossfade =apply_fog()= blends the two weathers' fogs: densities, distances, heights and colours averaged weighted by each fog's alpha × intensity, the stronger fog's type, alpha = the sum (at most 255). Without fog it clears the light set's fog and returns =FALSE=, so a scene with its own base fog (interiors, dungeons) sets that afterwards.

** Wind System
:PROPERTIES:
:CUSTOM_ID: wind-system
:END:
#+begin_src C
/* Propagated to the active (and fading) weather's effects */
lrg_weather_manager_set_wind (weather, 3.0f, -1.0f);
#+end_src

Screen space: pixels per second, y down the screen (rain adds half of it to the fall speed, snow drifts with 30% / 20%). World space: horizontal wind along X and Z in world units per second; rain slants its streaks along the resulting velocity, snow is carried by it in full.

** Sky maths (LrgCelestial)
:PROPERTIES:
:CUSTOM_ID: celestial
:END:
=src/weather/lrg-celestial.h= holds pure functions, the same everywhere (an integer hash, no global random):

| Function | Result |
|----------+--------|
| =lrg_celestial_moon_phase (day, period, offset)= | =frac ((day + offset) / period)= in [0, 1): 0 new, 0.25 first quarter, 0.5 full, 0.75 last quarter; negative days wrap upwards; 0 for invalid periods |
| =lrg_celestial_moon_illumination (phase)= | lit fraction =(1 - cos 2 pi p) / 2= |
| =lrg_celestial_moon_is_waxing (phase)= | phase in (0, 0.5) |
| =lrg_celestial_moon_disc_span (phase, v, &l, &r)= | the lit span of row =v= of a unit disc lit from the right while waxing: between the limb =sqrt (1 - v^2)= and the terminator ellipse =sqrt (1 - v^2) cos 2 pi p= (mirrored while waning) |
| =lrg_celestial_orbit_direction (angle, tilt, out)= | =(cos a, sin a cos t, sin a sin t)=: rising east at 0, top of the arc at pi/2; the sun of hour h is at =(h - 6) / 24 x 2 pi= |
| =lrg_celestial_moon_orbit_angle (sun_angle, phase)= | a moon trails the sun by =2 pi phase= (full moons rise at sunset) |
| =lrg_celestial_night_factor (sun_height)= | star visibility: 0 above 3 degrees of sun height, 1 below -9, smoothstep between |
| =lrg_celestial_generate_stars (seed, count, dirs, bright)= | unit directions uniform on the sphere and brightness 0.15 .. 1 (cubed: few bright stars) |
| =lrg_celestial_rotate_sky (dir, angle, tilt, out)= | turns a star about the orbit normal =(0, -sin t, cos t)=, the way the sun goes |
| =lrg_celestial_thunder_delay (distance)= | =distance / LRG_SPEED_OF_SOUND= (343 m/s); 0 for negative or non-finite distances |

** Distance-delayed thunder
:PROPERTIES:
:CUSTOM_ID: thunder-from-distance
:END:
=lrg_lightning_set_thunder_from_distance (TRUE)= (property =thunder-from-distance=, default off, so existing games keep the fixed =thunder-delay=) makes every strike queue its thunder for =lrg_celestial_thunder_delay (distance)= seconds.  Random strikes then land between half and one and a half times the bolt distance away, so delays vary from strike to strike.  Up to 8 thunders are in the air at once and a new strike never cancels an earlier one (with a full queue the soonest is dropped).  =lrg_lightning_strike_at (distance, bearing)= forces a strike now at a chosen place (a storm on the horizon), even while flashing.  In a =thunder= handler =lrg_lightning_get_thunder_distance()= gives the distance of the strike being heard (scale the volume by it); =get_strike_distance()= is the latest strike's, =get_pending_thunder_count()= the thunders not heard yet.

** Cloud layer
:PROPERTIES:
:CUSTOM_ID: cloud-layer
:END:
=LrgCloudLayer= (=src/weather/lrg-cloud-layer.h=) is a cloud deck at an altitude (default 1200 m, 300 m thick) whose density is four-octave value noise on a 256-periodic integer lattice (one cell =scale= metres, default 1800), thresholded by the coverage over a softness of 0.35.  The CPU (=sample_density()=, =sample_shadow()=, =bake_shadow_image()=) and the GLSL (=LRG_CLOUD_NOISE_GLSL= in =lrg-cloud-layer-private.h=) compute the same noise: the hash is integer, and the shaders get the noise coordinate of the eye or of draw-space 0 folded into [0, 256) by the CPU in double precision, so floating origins far from 0 keep float precision.

- *Wind*: =set_wind (vx, vz)= in metres per second, =advance (seconds)= moves the pattern (the offset is folded by one noise period, so it never loses precision); a time-lapse simply passes more seconds.  =get_offset()= / =set_offset()= save and restore it.
- *Drawing*: =draw (eye, sky_radius, towards_sun)= after the sky dome and before the world, depth off.  The deck is =slices= (default 3) horizontal grids of 24 x 24 quads over a 12 km radius around the eye, scaled about the eye into 0.8 x the sky radius (directions are kept, the far plane never clips it).  The fragment shader thins the coverage towards the top of the deck (rounded tops), shades by the density a little towards the sun (thick clouds are dark underneath, thin edges bright), dims at night and fades with distance.  Decks below the eye (mountain tops) are not drawn.  A shader that fails is warned about once.
- *Shadows*: =sample_shadow (x, y, z, towards_sun)= follows the ray to the sun up to the cloud base and returns density x shadow strength (default 0.5), faded out as the sun drops below 15 degrees and nothing below 3.  =bake_shadow_image()= writes the same as a light map (white is sun) over a square of ground: a renderer with its own shadow pass can project it (multiply its sun term) instead of using the ground overlay.

** Snow cover
:PROPERTIES:
:CUSTOM_ID: snow-cover
:END:
=LrgSnowCover= (=src/weather/lrg-snow-cover.h=) is a linear accumulation model: =update (seconds, snowfall, warmth)= adds =(snowfall x build - warmth x melt) x hours= to a level clamped to 0 .. 1 (defaults: full snowfall fills it in 6 hours, full warmth melts it in 12; =set_rates()=).  Long times integrate in one step, so resting is the same as many small updates.  Tracks: =stamp (x, z, radius, depth)= walks a footprint into lying snow (nothing on bare ground); a stamp within half a radius of the newest track deepens it instead of adding one; the newest =LRG_SNOW_COVER_MAX_TRACKS= (64) are kept.  Tracks fill at 4 x the build rate while it snows and fade with the melt; bare ground drops them all.  =get_depth_at (x, z)= is the level less the deepest track there (full inside half the radius, smooth to nothing at the rim).

** Weather field
:PROPERTIES:
:CUSTOM_ID: weather-field
:END:
=LrgWeatherField= (=src/weather/lrg-weather-field.h=) is a grid of cells holding moisture (0 .. 1) and storminess (0 .. 1) over a game world.  Every fixed step (=set_step()=, default one game hour):

1. both grids are advected by the wind (=set_wind()=, cells per hour) semi-Lagrangian: each cell takes the bilinear value from where its air was a step ago, clamped at the edges;
2. moisture relaxes towards the cell's base (=set_base()=, the climate: dry deserts, wet swamps) by =1 - (1 - relax)^hours= (=set_relaxation()=, default 4% an hour); storms decay twice as fast;
3. a front forms with probability =fronts_per_day x step / 86400= (=set_fronts()=, default one a day, radius 6 cells, strength 0.6): a Gaussian blob of moisture at a hashed place, a third of them stormy.  The decision, the place and the storminess hash =(seed, step number)=, not a random stream.

=advance (seconds)= runs every whole step that fits into the carried time and keeps the rest, so the same seed and the same total time give the same field bit for bit however the time was split.  =get_moisture (x, y)= / =get_storm (x, y)= sample bilinearly between cell centres; =set_cell()= forces a cell.  =save_state()= is an =a{sv}= (size, seed, step count, carry, wind, both grids as =ad=); =restore_state()= validates everything (size, ranges) before applying anything and fails with =G_IO_ERROR_INVALID_DATA=.  Bases are not saved: a game sets them from its climate.

** Ground overlay
:PROPERTIES:
:CUSTOM_ID: ground-overlay
:END:
=LrgGroundOverlay= (=src/weather/lrg-ground-overlay.h=) draws lying snow and cloud shadows as a second, alpha-blended pass over terrain that is already drawn, so it works over any terrain shader (lit or not):

#+begin_src C
lrg_terrain_draw_chunk (terrain, cx, cz);           /* the lit terrain */
if (lrg_ground_overlay_begin (overlay, terrain))   /* shader, blend, no depth writes */
{
    lrg_terrain_draw_chunk (terrain, cx, cz);       /* the same chunks again */
    lrg_ground_overlay_end (overlay, terrain);
}
#+end_src

The shader whitens flat ground (normal y from 0.55 to 0.85) by the snow level (patchy below full cover), less the newest 64 tracks, which also darken slightly as dents; and darkens ground under the clouds along the sun.  The two compose as one blend: =a = 1 - (1 - snow)(1 - shadow)=, =rgb = snow_colour x snow (1 - shadow) / a=.  =begin()= returns =FALSE= (draw nothing, do not call =end()=) with no snow and no visible shadow, without a window, or when the shader failed (warned once).  =end()= leaves the terrain without a shader.

*** Over objects

Buildings, models and props take the same snow and cloud shadows: draw them a second time with the overlay's shader.

#+begin_src C
gdouble origin[3];                                  /* the draw space's origin in the world */
GrlShader *shader;

lrg_terrain_get_origin (terrain, &origin[0], &origin[1], &origin[2]);
shader = lrg_ground_overlay_begin_objects (overlay, origin);
if (shader != NULL)
{
    lrg_static_batch_set_shader (batch, shader);
    lrg_ground_overlay_set_model_matrix (overlay, matrix);   /* what the rlgl stack holds, or NULL */
    lrg_static_batch_draw (batch, LRG_STATIC_BATCH_ALL_LAYERS);
    lrg_static_batch_set_shader (batch, NULL);
    lrg_ground_overlay_end_objects (overlay);
}
#+end_src

=rlgl='s matrix stack (=rlPushMatrix()=, a scene translated to its anchor, an object's rotation) moves the vertices but is not in the shader's =matModel=, so the caller hands the same matrix to =set_model_matrix()= (16 floats, OpenGL column-major, =NULL= for the identity; each draw group under its own matrix sets it again).  The shader multiplies it in before sampling the clouds and the snow patches, and rotates the normal with it: a roof (normal up) whitens, a wall does not, a sideways surface turned by the matrix does not.  Texels of the bound texture with alpha under 0.35 (fences, grates) get nothing, so cut-out models are not boxed in snow or shadow.  Same blend, same =FALSE= / =NULL= cases as for terrain.  =tests/test-weather-render.c= =/weather-render/draw/ground-overlay-objects= (a floor drawn identity, with no matrix and turned on its side).
