#+title: Non-networking engine capability audit
#+date: 2026-09-18

* Scope and method

This is a source-level capability audit against common game-engine needs, not
an assertion that every engine needs every feature. Checked public APIs and
implementations in core, templates, input, audio, pathfinding, editor, assets,
and atlas packing. Networking and multiplayer are excluded. Existing roadmap
entries were checked against code rather than treated as proof of absence.
The first pass implemented reusable gameplay timers. The follow-up pass implements
the three engine capabilities identified for further work: audio mixer buses,
triangle navigation meshes, and the advertised atlas packing algorithms.

* Implemented: gameplay timer manager

Added =LrgTimerManager= to the public library, installation/GIR inputs, and
forward declarations. It offers one-shot/repeating timers, scaled/unscaled
clock selection, per-timer pause/resume, cancellation, remaining-time queries,
and clear. Synchronous timeout delivery tolerates handler-driven changes and
protects the manager's lifetime. Repeats coalesce missed intervals while
preserving phase. Invalid deltas and recursive updates leave state unchanged.

Every game template owns a manager and advances it once per host frame; pause,
time scaling, hit stop, raw unscaled time, and shutdown are connected. Standalone
loops can drive isolated managers explicitly. Existing specialized counters are
retained because their persistence and update semantics differ.

See [[file:modules/core/timer-manager.org][timer API, examples, delivery rules, and tests]].

* Implemented follow-ups

- [[file:modules/audio/mixer.org][Audio mixer]]: named parent buses, cycle-checked post-fader sends, gain/mute,
  low-pass and feedback-delay processing, independently owned looping/pausable
  voices, format conversion, offline rendering, and a graylib stream pump.
- [[file:modules/pathfinding/nav-mesh.org][Navigation meshes]]: atomic walkable-triangle baking with slope filtering and
  shared-edge adjacency, nearest-surface projection, polygon blocking, and
  ordered-frontier A* returning a surface-contained waypoint corridor.
- [[file:modules/atlas/packing.org][Atlas algorithms]]: MaxRects and Guillotine implementations, candidate-bin
  search, rotation for all methods, padding/overflow safety, correct power-of-two
  limits, stale-result invalidation, and reproducible packing comparisons.

Application-specific asset migration and timer action persistence were design
ideas in the first audit, not part of these three capability implementations.
They require application contracts for replacing live objects and naming actions.
The limitations of each implemented capability are stated in its API guide.

* Validation: initial timer pass

- Full headless =make test=: 88 test binaries, 2,582 passed cases and 125
  hardware/environment skips. Dependency directory overrides reused this
  checkout's graylib, yaml-glib, and crispy builds from the parent checkout.
- Static/shared library, loader, GIR, and typelib builds completed. Existing
  duplicate-comment and annotation warnings remain in unrelated GIR inputs;
  the new timer API passed a separate =--warn-all --warn-error= scanner run.
- All nine scheduler regressions passed ASan/UBSan with leak detection and
  Valgrind with no memory errors or definite leaks. The headless template
  integration scenario also passed Valgrind with no errors or definite leaks.
- Python GI constructed the manager, called its methods, and received timeout.
- New documentation links/source blocks and =git diff --check= passed.

The full engine sanitizer suite and hardware-dependent paths were not run.
No new external dependency or host package was installed.

* Validation: audio/navigation/atlas follow-up pass

- Full headless =make test=: 91 C test binaries, 2,609 passed cases and 125
  skips. The three new binaries contribute 27 focused regressions.
- Static/shared libraries, loader, GIR, and typelib built successfully.
  A strict =--warn-all --warn-error= scan passed for the new mixer/navmesh API.
  Existing warnings in unrelated GIR inputs remain.
- All 27 focused tests passed with the changed C implementations instrumented
  under ASan/UBSan with leak detection. The same tests passed Valgrind with
  zero errors and zero definite leaks.
- =make test-followups-gi= passed both Python binding regressions, including
  caller-allocated projection output and owned PCM arrays. This target requires
  =python3-gobject=; set =GI_PYTHON= to select another compatible interpreter.
- New org document links/source blocks and =git diff --check= passed.

The full engine sanitizer suite and physical audio-device playback were not run.
Builds used the existing parent-checkout dependency directories; no packages
were installed. The mixer itself adds no dependency beyond existing engine
libraries, and the navmesh/packer use GLib/GIO and libm.
