=examples/game-showcase-3d.c= is the 0.9.0 game-shaped example. =--self-test= needs no window. It tags a node, asks =LrgLevelStream= which cell contains a point, samples a =LrgUiAnimation= and an =LrgAnimationClip=, drops a sphere in an =LrgDynamicsWorld=, walks an =LrgNavAgent= across a baked floor, and loads =examples/data/pbr-showcase/pbr-showcase.rlevel= into an =LrgWorld3D=. The default path is that file from the repository root and =data/pbr-showcase/pbr-showcase.rlevel= from =examples/=. A missing level fails the self-test. The success line names the level path and the entity count. With a display, and without =--self-test=, the same level is drawn with =LrgWorld3DRenderer= until Esc. Orbit controls and the rendering toggles stay in [[file:pbr-showcase.org][pbr-showcase]]; physics toys stay in [[file:physics-sandbox.org][physics-sandbox]].

** Build and run
:PROPERTIES:
:CUSTOM_ID: game-showcase-3d-build
:END:
From the repository root, =make examples=. The binaries land in =examples/build/release/examples/=. From =examples/=:

#+begin_src sh
cd examples
./build/release/examples/game-showcase-3d --self-test
./build/release/examples/game-showcase-3d --help
./build/release/examples/game-showcase-3d --license
./build/release/examples/game-showcase-3d --level data/levels/level-3d-runtime.rlevel --frames 120
#+end_src

From the repository root the same binary is =./examples/build/release/examples/game-showcase-3d=; the default level is found either way.

=--frames N= closes the window after N frames. No display runs the self-test and exits 0.

** What is not in this binary
:PROPERTIES:
:CUSTOM_ID: game-showcase-3d-limits
:END:
The unified transform gizmo, a second inspector, WYSIWYG canvas drag, the export dialog and a live multi-user session live in the editor, documented in [[file:../editor/workflows.org][editor workflows]]. Packing a project is =lrgpack= and =export.run=, documented in [[file:../modules/core/pack-writer.org][LrgPackWriter]].
