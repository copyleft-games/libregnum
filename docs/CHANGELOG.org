** 0.9.1
:PROPERTIES:
:CUSTOM_ID: changelog-0-9-1
:END:
Fixes to the visual-script (blueprint) editor and the 3D examples. No 0.9.0 symbol is renamed or removed.

- The visual-script canvas draws every link the program holds. It asks the program's type rule (=any= meets anything, =int= widens to =float=) instead of the canvas's equal-type default, so a =string= output into an =any= input (Concat into Log) is no longer stored but invisible. A link the canvas still refuses is logged.
- Comment frames are drawn on the canvas. =LrgNodeGraph= gains notes: =lrg_node_graph_add_note()=, =lrg_node_graph_clear_notes()=, =lrg_node_graph_get_n_notes()=. They paint under the wires, take no input, count towards =lrg_node_graph_frame_all()= and go with =lrg_node_graph_clear()=.
- Cards show their parameters and unlinked literals on a value line (Get Variable ="health"=, a Float =5=, a Log's text).
- The canvas fits the graph when a file is opened or a subgraph is shown. =lrg_node_graph_frame_all()= before the first layout now runs on the first sized step instead of doing nothing. New IPC method =vscript.frame= (=lrgeditorctl vscript frame=, MCP =vscript_frame=) fits all nodes or the selection.
- New node =string.from= (To String): any value in, its text out, so a number can feed a string input.
- =pbr-showcase= and =level-3d-runtime= find their default level from the repository root, from =examples/= or beside the binary. =pbr-showcase= exits before writing its generated assets when no level is found, instead of creating a stray =data/pbr-showcase/= in the working directory. Its key legend widens to fit the longest view-mode name.
- The 3D example docs give the right binary path (=examples/build/release/examples/=).

** 0.9.0
:PROPERTIES:
:CUSTOM_ID: changelog-0-9-0
:END:
Not tagged until the landing commit. graylib's =MAJOR.MINOR= moves to 0.9 in that same commit.

- Runtime levels live in =src/level/= and build with =BUILD_EDITOR=0=. =lrg_level_load_world3d()= is the game entry point. Shared math is =lrg_math3d_*()=.
- 3D runtime: =LrgEntity3D=, =LrgWorld3D=, =LrgWorld3DRenderer=, materials (=.rmat=), user shaders, PBR, environment and probes, lightmaps and probe grids, decals, post stacks (=.rpost=).
- Animation: glTF skins and clips, =.ranim= graphs, retargeting, IK, root motion, =.rseq= sequences, 2D skeletons.
- Physics: =LrgDynamicsWorld= (shapes, joints, CCD, islands), ragdolls, cloth, fracture. Navigation: =.rnav= bakes, =LrgNavAgent=, ORCA crowds. AI: =.rbt=, =.rfsm=.
- Terrain, foliage, water, particles (CPU and GPU), weather, mixer and spatial audio, rule tiles and =.rsprite=.
- Scripting: =.rvscript=, hot reload, Lua/Python debugger, DAP, LSP client, editor tool scripts. Profiling: hierarchical profiler, GPU timer, frame debugger, memory and network panels.
- Assets and export: =LrgPackWriter= and =lrgpack= (rres, content-addressed VFS, ustar, store-only zip, Flatpak manifest, AppDir, Windows zip). Cooking applies import settings and DXT1 when the sidecar asks. =LrgAssetRefs= refuses a rename or delete while quotes remain. Reimport uses =dest.stamp=. The =fbx= importer writes an OBJ through vendored ufbx (MIT, =deps/ufbx=). =.ply= is not a model. =LrgGameHost= loads top-level =autoloads:=. Per-platform =platforms:= overrides layer over =settings:=. =empty= and =mod= templates. File > Export runs a profile and shows =export-log=. Project Settings has a Steam tab. A plugin's panel, menu, action and inspector are installed into the dock. Flatpak does not run flatpak-builder. AppImage runs =appimagetool= only when it is on =PATH=.
- Editor workflows, each one an =lrgeditorctl= verb and an MCP tool: scene bar (=scenes.open=, =scenes.active=), =tag:= outliner filter, one gizmo (=gizmo.pivot=, =gizmo.apply= for snap, drop, align, distribute, surface), game-view letterbox, nested inspector and =inspector-2=, UI drag-to-place and =lrg_ui_animation_sample()=, =po.import= / =po.export= / =po.extract= / =po.pseudo=, VCS panel (diff, history, commit, git-lfs locks, Magit handoff that does not start Emacs), =lrgeditorctl merge= and =lrg_level_merge_install_driver()=, =collab.*= (GUID op log, last-writer-wins, locks, presence).
- Follow-ups in the same release: an instant weather change restores both levels of a crossfade; the 2D weather overlay uses the render-target size; lightning bolts draw a core and a halo; tilemap cell quads follow iso, hex and flip bits; the audio emitter suggestion is radius 50; a nav agent takes =destination-x= / =destination-y= / =destination-z= and =target-node= from YAML; terrain picks hit the heightfield; shader-graph nodes sit on a grid; problems carry a line and column; the physics sandbox ragdoll is an =LrgRagdoll=; a level's =audio: mixer:= loads on instantiate; a nav bake can run in tiles (=lrg_nav_bake_set_tile_extent()=). A second shortcut that flips a tile vertically without sharing the snap chord is left for later.
