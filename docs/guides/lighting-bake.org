* Lighting bake
:PROPERTIES:
:CUSTOM_ID: lighting-bake
:END:
#+begin_quote
*[[file:../index.org][Home]]* > Guides > Lighting bake
#+end_quote

Realtime lights give direct light and shadows; everything else (light bouncing off walls, a room lit by a window, the sky's light reaching under a roof) is expensive to compute per frame. The lighting bake computes it once, offline, for the parts of a level that never move, and stores it in two forms the lit shader reads at almost no cost:

- *lightmaps* ([[file:../modules/lighting/lightmap3d.org][LrgLightmap3D]]): textures over the surfaces of static meshes, through each mesh's second UV set;
- *probe grids* ([[file:../modules/lighting/probe-grid.org][LrgProbeGrid]]): boxes of L2 spherical-harmonic probes that light everything without a lightmap (characters, moving props).

This guide covers the runtime side (0.9.0 M3, data and shader) and the authoring flow; the sections on the baker itself (=LrgLightmapBaker=: settings, progress, the path tracer, unwrapping and denoising) are added with it.

** The pieces
:PROPERTIES:
:CUSTOM_ID: lighting-bake-pieces
:END:
| Piece | Where | Role |
|-+-+-|
| =LrgMeshRendererComponent:static-lighting= (=static_lighting=) | node param on primitive / mesh visuals | the mesh takes part in the bake: it blocks and bounces light and gets a lightmap entry |
| =LrgMeshRendererComponent:lightmap-scale= (=lightmap_scale=) | node param | its lightmap resolution relative to the bake's texels per unit; 0 = probe lit only |
| =LrgLightComponent:bake-mode= (=bake_mode=) | node param on lights | =realtime=, =mixed= or =baked= |
| =lighting:= block | the =.rlevel= | the lightmap and grid files, and the bake settings |
| =LrgLightmap3D= / =.rlightmap= + =.hdr= | baker output | per-object baked irradiance |
| =LrgProbeGrid= / =.rprobes= | baker output | SH irradiance for everything else |
| =LRG_BAKED_GLSL= | the lit shader | reads one of them per draw |
| =LrgWorld3DRenderer= | runtime | picks the lightmap entry or grid per item |

** Light modes
:PROPERTIES:
:CUSTOM_ID: lighting-bake-modes
:END:
| Mode | Baked into lightmaps | Baked into probes | At runtime |
|-+-+-+-|
| =realtime= | nothing | nothing | lights everything |
| =mixed= | its bounce | its bounce | lights everything (direct + shadows) |
| =baked= | its direct light (soft shadows) and bounce | its bounce | lights everything *except* lightmapped draws |

Pick =mixed= for the sun or any light whose shadows must follow moving objects, =baked= for static fill and practical lights (lamps, windows, emissive panels) to save their per-frame cost, =realtime= for lights that move or switch (a torch carried by the player, a flickering alarm). A baked light still lights dynamic objects at runtime so they match the scene; that is why probes never contain the direct part of baked lights.

** The authoring flow
:PROPERTIES:
:CUSTOM_ID: lighting-bake-flow
:END:
1. Mark static geometry: =static_lighting: true= on its nodes (and mark the entities static for batching where they are not lightmapped). Give important surfaces a higher =lightmap_scale=, small clutter 0.
2. Set the lights' =bake_mode=.
3. Cover the playable space with probe volumes (one probe every 1 .. 4 units).
4. Set the bake settings in =lighting: settings:= (=texels_per_unit=, =samples=, =bounces=, =max_lightmap_size=, =denoise=, =probe_spacing=).
5. Bake: the baker writes =<level>.rlightmap= with its pages and one =.rprobes= per volume and fills =lighting: lightmap:= / =probes:=.
6. Load the level: =lrg_level_load_world3d()= (or play-in-editor) puts them on the world and the renderer uses them.

#+begin_src yaml
lighting:
  lightmap: town.rlightmap
  probes: [town-0.rprobes]
  settings: { texels_per_unit: 8, samples: 256, bounces: 2, max_lightmap_size: 1024, denoise: true, probe_spacing: 2 }
nodes:
  - name: Street
    guid: 6f1c0e2a-0000-0000-0000-000000000001
    visual:
      kind: mesh-asset
      asset: meshes/street.glb          # TEXCOORD_1 is the lightmap UV when present
      params: { static_lighting: true, lightmap_scale: 2.0 }
  - name: Lamp
    guid: 6f1c0e2a-0000-0000-0000-000000000002
    transform: { location: [4.0, 3.0, 0.0] }
    visual:
      kind: light
      params: { light_type: point, range: 8.0, bake_mode: baked }
#+end_src

** The runtime path
:PROPERTIES:
:CUSTOM_ID: lighting-bake-runtime
:END:
1. =lrg_level_instantiate_3d()= loads =lighting: lightmap:= into =lrg_world3d_set_lightmap()= and each =probes:= file into =lrg_world3d_add_probe_grid()=; entities keep their node GUIDs.
2. Each frame =LrgWorld3DRenderer= syncs the lights (with their modes) into its =LrgLightSet= and replays the items. For each lit item it binds:
   - mode 1 (*lightmap*) when the item's entity GUID has an entry: the page texture and the entry's uv2 scale / offset;
   - mode 2 (*probes*) otherwise, when a grid contains the item's centre (=lrg_world3d_find_probe_grid()=, the smallest box wins);
   - nothing otherwise (the environment's IBL or the flat ambient, as before 0.9.0 M3).
3. In the shader the baked value replaces only the *indirect diffuse* term: =kd x albedo x lrg_baked_diffuse(p, n)=. Specular reflections still come from the environment and reflection probes, SSAO and material occlusion still multiply it, and on lightmapped draws lights in =baked= mode (and a baked sun) are skipped.

#+begin_src C
/* a game: load and draw, nothing bake-specific */
g_autoptr(LrgWorld3D)         world = lrg_world3d_new ();
g_autoptr(LrgWorld3DRenderer) renderer = lrg_world3d_renderer_new ();
g_autoptr(LrgLevel)           level = lrg_level_load_world3d ("levels/town.rlevel", world, &error);

while (!WindowShouldClose ())
{
	lrg_world3d_step (world, GetFrameTime ());
	BeginDrawing ();
	lrg_world3d_renderer_render (renderer, world, NULL, NULL, 0, 0);
	EndDrawing ();
}
#+end_src

** Units and conventions
:PROPERTIES:
:CUSTOM_ID: lighting-bake-units
:END:
- Lightmap texels and probe SH are *irradiance / pi in linear radiance*, the same scale as =LrgEnvironment='s diffuse light: under a constant sky of colour C an unoccluded white floor bakes to C.
- Probe SH coefficients use =LrgEnvironment='s order and normalisation (=lrg_environment_sh_irradiance()= evaluates them).
- uv2 is raylib's =texcoords2= (=vertexTexCoord2= in shaders), glTF =TEXCOORD_1=. A mesh without it reads (0, 0).
- Lightmap entries are keyed by node / entity GUID strings.

** Checking the result without a GPU
:PROPERTIES:
:CUSTOM_ID: lighting-bake-cpu-checks
:END:
Both outputs can be inspected on the CPU, which is what tests and tools do:

#+begin_src C
gfloat uv2[2] = { 0.5f, 0.5f }, up[3] = { 0, 1, 0 }, p[3] = { 2, 1, 0 }, rgb[3];

lrg_lightmap3d_sample (lrg_world3d_get_lightmap (world), guid, uv2, rgb);   /* the texel under uv2 */
lrg_probe_grid_sample (lrg_world3d_find_probe_grid (world, p), p, up, rgb);   /* what a dynamic object gets */
#+end_src

** Pitfalls
:PROPERTIES:
:CUSTOM_ID: lighting-bake-pitfalls
:END:
- Moving, rescaling or re-meshing a static object invalidates its bake: bake again.
- Duplicated or re-created nodes get new GUIDs and lose their entries until the next bake (they fall back to probes).
- Do not mark lights that the game switches off as =baked=: their light stays in the lightmap.
- An object outside every probe grid and without a lightmap entry is lit by the environment or the ambient only: leave no gaps.
- Custom lit shaders must call =lrg_baked_set_uv2(fragTexCoord2)= to read lightmaps (see [[file:../modules/graphics/light-set.org::#glsl-library][the GLSL library]]).

** Using it from the editor
:PROPERTIES:
:CUSTOM_ID: lighting-bake-editor
:END:
The editor tools come in the next 0.9.0 wave: a bake panel (settings, bake / cancel, progress), the lightmap scale and static lighting toggles in the inspector, a bake mode field on lights, probe volume nodes with a probe visualisation, and a lightmap texel-density view. Until then the node params and the =lighting:= block can be edited in the inspector's raw params and the =.rlevel= text, and play-in-editor shows the baked result.
