A libregnum widget is a GObject subclass of =LrgWidget= (or =LrgContainer= when it has children) that implements a handful of virtual methods. The framework does the rest: input routing, focus, hover and press state, springs, theme lookups, style rules, appear animations, focus rings, layout scheduling and batched SDF rendering. This guide explains the anatomy of a modern widget and then builds a complete one, a rotary *knob*, in the house style (gnu89, GObject, GIR comments).

If you are porting a widget written before the paint rework, read [[file:ui-migration.org][the migration guide]] first.

** Anatomy of a widget
:PROPERTIES:
:CUSTOM_ID: extending-anatomy
:END:
| Piece | What you write | What the framework does with it |
|-------+----------------+---------------------------------|
| =paint (self, list)= | Record your shapes into the paint list at world coordinates | Wraps it in opacity, appear transforms and the focus ring; batches it with the rest of the UI |
| =style_defaults (self, part, state, look)= | Fill the built-in look of each part in each state from the theme | Merges theme style rules on top, blends resting / hovered / pressed by springs (=lrg_widget_resolve_look()=) |
| =measure (self, &w, &h)= | Preferred size without margin | Layouts use it with your margin, alignment and min/max hints |
| =handle_event (self, event)= | React to pointer, keys, text, ACTIVATE, CANCEL; return =TRUE= to consume | Routing, bubbling, capture, focus, hover flags |
| =arrange (self)= | Optional: cache geometry after a resize | Called after allocation |
| =init= | =lrg_widget_set_focusable (self, TRUE)= for interactive widgets | Enables click / Tab / gamepad focus |
| setters | =lrg_widget_queue_layout (self)= when the preferred size changes | Re-layout before the next paint |

Rules of thumb:

1. *Never hard-code colours or sizes.* Read roles (=lrg_theme_get_color()=) and metrics (=lrg_theme_get_metric()=) from =lrg_widget_get_theme (self)= in =style_defaults()= and =measure()=. Your widget then fits every preset and every user theme.
2. *Describe states, do not animate them.* =style_defaults()= says what the hovered or pressed look is; the springs animate between them.
3. *Name your parts* (=LrgUIPart=) so theme authors can target them: =widget: GameKnob, part: fill=.
4. *Be usable without a mouse*: focusable, =ACTIVATE=, arrow keys (return =TRUE= for the ones you use).
5. *Paint, don't draw*: no raylib calls in =paint()= (use =lrg_paint_list_callback()= only for things the paint list cannot express).

** Walkthrough: a rotary knob
:PROPERTIES:
:CUSTOM_ID: extending-knob
:END:
=GameKnob= is a volume-style knob: a round body with a soft shadow, a 270 degree track arc, an accent arc showing the value, an indicator dot, and the value as text in the middle. Dragging vertically turns it, the wheel and the arrow keys step it, Home/End jump to the ends, and Enter / gamepad A resets it to its default value. The displayed value glides with a spring when it changes.

Parts it draws:

| Part | Used for | Look fields read |
|------+----------+------------------|
| =LRG_UI_PART_KNOB= | Round body | full box look (=lrg_widget_paint_box()=) |
| =LRG_UI_PART_TRACK= | Background arc | =foreground= (colour), =size= (thickness) |
| =LRG_UI_PART_FILL= | Value arc | =foreground=, =size= |
| =LRG_UI_PART_THUMB= | Indicator dot | =background=, =size= (diameter) |
| =LRG_UI_PART_LABEL= | Value text | =foreground= |
| =LRG_UI_PART_FOCUS= | Focus ring | from =LrgWidget=, made circular |

#+begin_src c
/* game-knob.c
 *
 * Copyright 2026 Your Name
 *
 * SPDX-License-Identifier: AGPL-3.0-or-later
 *
 * A rotary knob: round body, 270 degree track and value arcs, an
 * indicator dot and the value as text. Drag vertically, scroll, use
 * the arrow keys or Home/End; ACTIVATE resets to the default value.
 */

#include <math.h>
#include "game-knob.h"

/* The arc starts bottom-left (135 degrees, y down) and sweeps 270
 * degrees clockwise through the top to bottom-right */
#define KNOB_START_DEG (135.0)
#define KNOB_SWEEP_DEG (270.0)

/* Line segments used to approximate a full sweep of the arcs */
#define KNOB_ARC_SEGMENTS (40)

/* Pixels of vertical drag for the whole 0..1 range */
#define KNOB_DRAG_RANGE (200.0)

struct _GameKnob
{
	LrgWidget  parent_instance;

	gdouble    value;
	gdouble    step;
	gdouble    default_value;

	/* Dragging: where it started */
	gboolean   dragging;
	gfloat     drag_start_y;
	gdouble    drag_start_value;

	/* Displayed value: a spring chasing value */
	LrgSpring  display;
	gint64     last_paint_us;
};

G_DEFINE_FINAL_TYPE (GameKnob, game_knob, LRG_TYPE_WIDGET)

enum
{
	PROP_0,
	PROP_VALUE,
	PROP_STEP,
	N_PROPS
};

enum
{
	SIGNAL_VALUE_CHANGED,
	N_SIGNALS
};

static GParamSpec *properties[N_PROPS];
static guint       signals[N_SIGNALS];

/* ==========================================================================
 * Looks
 * ========================================================================== */

/*
 * game_knob_style_defaults:
 *
 * Built-in looks from the theme. Every state gets a complete look so
 * the hover / press springs blend between full descriptions. PRESSED
 * is tested before HOVERED because the pressed variant carries both.
 */
static void
game_knob_style_defaults (LrgWidget      *widget,
                          LrgUIPart       part,
                          LrgWidgetState  state,
                          LrgPartLook    *look)
{
	LrgTheme *theme = lrg_widget_get_theme (widget);
	gboolean  pressed = (state & LRG_WIDGET_STATE_PRESSED) != 0;
	gboolean  hovered = (state & LRG_WIDGET_STATE_HOVERED) != 0;
	gboolean  disabled = (state & LRG_WIDGET_STATE_DISABLED) != 0;
	gfloat    blur = lrg_theme_get_metric (theme, LRG_THEME_METRIC_SHADOW_BLUR);

	switch (part)
	{
	case LRG_UI_PART_KNOB:
		/* body: a control-coloured disc that lifts on hover */
		lrg_part_look_set_background (look, lrg_theme_get_color (theme,
			pressed ? LRG_THEME_COLOR_CONTROL_PRESSED
			        : hovered ? LRG_THEME_COLOR_CONTROL_HOVER
			                  : LRG_THEME_COLOR_CONTROL));
		lrg_part_look_set_border (look, lrg_theme_get_color (theme, LRG_THEME_COLOR_BORDER),
		                          lrg_theme_get_metric (theme, LRG_THEME_METRIC_BORDER_WIDTH));
		lrg_part_look_set_radius (look, G_MAXFLOAT);
		lrg_part_look_set_shadow (look, lrg_theme_get_color (theme, LRG_THEME_COLOR_SHADOW),
		                          hovered && !pressed ? blur * 0.6f : blur * 0.35f,
		                          hovered && !pressed ? 4.0f : 2.0f);
		lrg_part_look_set_opacity (look, disabled ? 0.45f : 1.0f);
		break;

	case LRG_UI_PART_TRACK:
		lrg_part_look_set_foreground (look, lrg_theme_get_color (theme, LRG_THEME_COLOR_TRACK));
		lrg_part_look_set_size (look, 4.0f);
		break;

	case LRG_UI_PART_FILL:
		lrg_part_look_set_foreground (look, lrg_theme_get_color (theme,
			disabled ? LRG_THEME_COLOR_DISABLED
			         : hovered ? LRG_THEME_COLOR_ACCENT_HOVER : LRG_THEME_COLOR_ACCENT));
		lrg_part_look_set_size (look, hovered ? 5.0f : 4.0f);
		break;

	case LRG_UI_PART_THUMB:
		lrg_part_look_set_background (look, lrg_theme_get_color (theme, LRG_THEME_COLOR_HANDLE));
		lrg_part_look_set_size (look, pressed ? 9.0f : hovered ? 8.0f : 6.0f);
		break;

	case LRG_UI_PART_LABEL:
		lrg_part_look_set_foreground (look, lrg_theme_get_color (theme,
			disabled ? LRG_THEME_COLOR_DISABLED : LRG_THEME_COLOR_TEXT));
		break;

	case LRG_UI_PART_FOCUS:
		/* the parent's ring, made round like the knob */
		LRG_WIDGET_CLASS (game_knob_parent_class)->style_defaults (widget, part, state, look);
		lrg_part_look_set_radius (look, G_MAXFLOAT);
		break;

	default:
		LRG_WIDGET_CLASS (game_knob_parent_class)->style_defaults (widget, part, state, look);
		break;
	}
}

/* ==========================================================================
 * Painting
 * ========================================================================== */

/*
 * paint_arc:
 *
 * Approximates an arc with round-capped line segments (the caps make
 * the joins seamless). @from and @to are 0..1 along the sweep.
 */
static void
paint_arc (LrgPaintList   *list,
           gfloat          cx,
           gfloat          cy,
           gfloat          radius,
           gdouble         from,
           gdouble         to,
           gfloat          thickness,
           const GrlColor *color)
{
	gint    n;
	gint    i;
	gdouble a0;
	gdouble a1;

	if (to <= from || thickness <= 0.0f)
		return;

	n = MAX (1, (gint) ceil ((to - from) * KNOB_ARC_SEGMENTS));
	for (i = 0; i < n; i++)
	{
		a0 = (KNOB_START_DEG + KNOB_SWEEP_DEG * (from + (to - from) * i / n)) * G_PI / 180.0;
		a1 = (KNOB_START_DEG + KNOB_SWEEP_DEG * (from + (to - from) * (i + 1) / n)) * G_PI / 180.0;
		lrg_paint_list_line (list,
		                     cx + radius * (gfloat) cos (a0), cy + radius * (gfloat) sin (a0),
		                     cx + radius * (gfloat) cos (a1), cy + radius * (gfloat) sin (a1),
		                     thickness, color);
	}
}

/*
 * step_display:
 *
 * The display spring is our own, so the canvas does not step it:
 * advance it from wall-clock time between paints.
 */
static void
step_display (GameKnob *self)
{
	gint64 now = g_get_monotonic_time ();
	gfloat dt;

	dt = self->last_paint_us == 0 ? 0.0f : (gfloat) (now - self->last_paint_us) / 1.0e6f;
	self->last_paint_us = now;

	lrg_spring_set_motion (&self->display, lrg_widget_get_motion (LRG_WIDGET (self)));
	lrg_spring_step (&self->display, MIN (dt, 0.1f));
}

static void
game_knob_paint (LrgWidget    *widget,
                 LrgPaintList *list)
{
	GameKnob        *self = GAME_KNOB (widget);
	LrgTheme        *theme = lrg_widget_get_theme (widget);
	GrlFont         *font = lrg_theme_get_ui_font (theme);
	gfloat           font_size = lrg_theme_get_metric (theme, LRG_THEME_METRIC_FONT_SIZE_SMALL);
	gfloat           x = lrg_widget_get_world_x (widget);
	gfloat           y = lrg_widget_get_world_y (widget);
	gfloat           w = lrg_widget_get_width (widget);
	gfloat           h = lrg_widget_get_height (widget);
	gfloat           d = MIN (w, h);
	gfloat           cx = x + w * 0.5f;
	gfloat           cy = y + h * 0.5f;
	gfloat           ring;
	gfloat           body;
	gdouble          v;
	gdouble          angle;
	gfloat           tw;
	gfloat           th;
	g_autofree gchar *text = NULL;
	LrgPartLook      knob;
	LrgPartLook      track;
	LrgPartLook      fill;
	LrgPartLook      thumb;
	LrgPartLook      label;

	step_display (self);
	v = CLAMP (self->display.value, 0.0, 1.0);

	/* Resolved looks: defaults + theme rules, blended by hover/press */
	lrg_widget_resolve_look (widget, LRG_UI_PART_KNOB, &knob);
	lrg_widget_resolve_look (widget, LRG_UI_PART_TRACK, &track);
	lrg_widget_resolve_look (widget, LRG_UI_PART_FILL, &fill);
	lrg_widget_resolve_look (widget, LRG_UI_PART_THUMB, &thumb);
	lrg_widget_resolve_look (widget, LRG_UI_PART_LABEL, &label);

	/* Arcs on the outer ring, the body inside them */
	ring = d * 0.5f - MAX (track.size, fill.size) * 0.5f - 1.0f;
	body = ring - MAX (track.size, fill.size) - 4.0f;

	paint_arc (list, cx, cy, ring, 0.0, 1.0, track.size, &track.foreground);
	paint_arc (list, cx, cy, ring, 0.0, v, fill.size, &fill.foreground);

	lrg_widget_paint_box (widget, list, &knob, cx - body, cy - body, body * 2.0f, body * 2.0f);

	/* Indicator dot near the body's edge at the value's angle */
	angle = (KNOB_START_DEG + KNOB_SWEEP_DEG * v) * G_PI / 180.0;
	lrg_paint_list_circle (list,
	                       cx + (body - thumb.size) * (gfloat) cos (angle),
	                       cy + (body - thumb.size) * (gfloat) sin (angle),
	                       thumb.size * 0.5f, &thumb.background);

	/* Value text, centred */
	text = g_strdup_printf ("%d", (gint) floor (self->value * 100.0 + 0.5));
	lrg_paint_measure_text (font, text, font_size, 0.0f, &tw, &th);
	lrg_paint_list_text (list, font, text, cx - tw * 0.5f, cy - th * 0.5f,
	                     font_size, 0.0f, &label.foreground);
}

static void
game_knob_measure (LrgWidget *widget,
                   gfloat    *preferred_width,
                   gfloat    *preferred_height)
{
	LrgTheme *theme = lrg_widget_get_theme (widget);
	gfloat    d = roundf (lrg_theme_get_metric (theme, LRG_THEME_METRIC_CONTROL_HEIGHT) * 1.75f);

	*preferred_width = d;
	*preferred_height = d;
}

 * Input

static gboolean
game_knob_handle_event (LrgWidget        *widget,
                        const LrgUIEvent *event)
{
	GameKnob *self = GAME_KNOB (widget);

	switch (lrg_ui_event_get_event_type (event))
	{
	case LRG_UI_EVENT_MOUSE_BUTTON_DOWN:
		if (lrg_ui_event_get_button (event) != GRL_MOUSE_BUTTON_LEFT)
			return FALSE;
		/* the canvas already focused us and captured the pointer */
		self->dragging = TRUE;
		self->drag_start_y = lrg_ui_event_get_y (event);
		self->drag_start_value = self->value;
		return TRUE;

	case LRG_UI_EVENT_MOUSE_MOVE:
		if (!self->dragging)
			return FALSE;
		/* up increases; moves keep arriving outside our bounds while
		 * the button is held (pointer capture) */
		game_knob_set_value (self, self->drag_start_value +
		                     (self->drag_start_y - lrg_ui_event_get_y (event)) / KNOB_DRAG_RANGE);
		return TRUE;

	case LRG_UI_EVENT_MOUSE_BUTTON_UP:
		if (lrg_ui_event_get_button (event) != GRL_MOUSE_BUTTON_LEFT)
			return FALSE;
		self->dragging = FALSE;
		return TRUE;

	case LRG_UI_EVENT_SCROLL:
		game_knob_set_value (self, self->value + lrg_ui_event_get_scroll_y (event) * self->step);
		return TRUE;

	case LRG_UI_EVENT_KEY_DOWN:
		/* Return TRUE for every key we use: unhandled arrows would
		 * also move focus away */
		switch (lrg_ui_event_get_key (event))
		{
		case GRL_KEY_UP:
		case GRL_KEY_RIGHT:
			game_knob_set_value (self, self->value + self->step);
			return TRUE;
		case GRL_KEY_DOWN:
		case GRL_KEY_LEFT:
			game_knob_set_value (self, self->value - self->step);
			return TRUE;
		case GRL_KEY_PAGE_UP:
			game_knob_set_value (self, self->value + self->step * 10.0);
			return TRUE;
		case GRL_KEY_PAGE_DOWN:
			game_knob_set_value (self, self->value - self->step * 10.0);
			return TRUE;
		case GRL_KEY_HOME:
			game_knob_set_value (self, 0.0);
			return TRUE;
		case GRL_KEY_END:
			game_knob_set_value (self, 1.0);
			return TRUE;
		default:
			return FALSE;
		}

	case LRG_UI_EVENT_ACTIVATE:
		/* Enter / Space / gamepad A */
		game_knob_set_value (self, self->default_value);
		return TRUE;

	case LRG_UI_EVENT_FOCUS_OUT:
		self->dragging = FALSE;
		return FALSE;

	default:
		return FALSE;
	}
}

static void
game_knob_get_property (GObject    *object,
                        guint       prop_id,
                        GValue     *value,
                        GParamSpec *pspec)
{
	GameKnob *self = GAME_KNOB (object);

	switch (prop_id)
	{
	case PROP_VALUE:
		g_value_set_double (value, self->value);
		break;
	case PROP_STEP:
		g_value_set_double (value, self->step);
		break;
	default:
		G_OBJECT_WARN_INVALID_PROPERTY_ID (object, prop_id, pspec);
	}
}

static void
game_knob_set_property (GObject      *object,
                        guint         prop_id,
                        const GValue *value,
                        GParamSpec   *pspec)
{
	GameKnob *self = GAME_KNOB (object);

	switch (prop_id)
	{
	case PROP_VALUE:
		game_knob_set_value (self, g_value_get_double (value));
		break;
	case PROP_STEP:
		game_knob_set_step (self, g_value_get_double (value));
		break;
	default:
		G_OBJECT_WARN_INVALID_PROPERTY_ID (object, prop_id, pspec);
	}
}

static void
game_knob_class_init (GameKnobClass *klass)
{
	GObjectClass   *object_class = G_OBJECT_CLASS (klass);
	LrgWidgetClass *widget_class = LRG_WIDGET_CLASS (klass);

	object_class->get_property = game_knob_get_property;
	object_class->set_property = game_knob_set_property;

	widget_class->paint = game_knob_paint;
	widget_class->style_defaults = game_knob_style_defaults;
	widget_class->measure = game_knob_measure;
	widget_class->handle_event = game_knob_handle_event;

	/**
	 * GameKnob:value:
	 *
	 * The knob's value, between 0 and 1.
	 */
	properties[PROP_VALUE] =
		g_param_spec_double ("value", NULL, NULL, 0.0, 1.0, 0.5,
		                     G_PARAM_READWRITE | G_PARAM_STATIC_STRINGS |
		                     G_PARAM_EXPLICIT_NOTIFY);

	/**
	 * GameKnob:step:
	 *
	 * How much one arrow key or wheel notch changes the value.
	 */
	properties[PROP_STEP] =
		g_param_spec_double ("step", NULL, NULL, 0.001, 1.0, 0.05,
		                     G_PARAM_READWRITE | G_PARAM_STATIC_STRINGS |
		                     G_PARAM_EXPLICIT_NOTIFY);

	g_object_class_install_properties (object_class, N_PROPS, properties);

	/**
	 * GameKnob::value-changed:
	 * @knob: the knob
	 *
	 * Emitted whenever the value changes, by the user or in code.
	 */
	signals[SIGNAL_VALUE_CHANGED] =
		g_signal_new ("value-changed", G_TYPE_FROM_CLASS (klass), G_SIGNAL_RUN_LAST,
		              0, NULL, NULL, NULL, G_TYPE_NONE, 0);
}

static void
game_knob_init (GameKnob *self)
{
	self->value = 0.5;
	self->default_value = 0.5;
	self->step = 0.05;
	self->last_paint_us = 0;
	lrg_spring_init (&self->display, 0.5f, LRG_MOTION_SMOOTH);

	/* Interactive: clicks, Tab and the gamepad can focus it */
	lrg_widget_set_focusable (LRG_WIDGET (self), TRUE);
}

/* ==========================================================================
 * Public API
 * ========================================================================== */

GameKnob *
game_knob_new (void)
{
	return g_object_new (GAME_TYPE_KNOB, NULL);
}

gdouble
game_knob_get_value (GameKnob *self)
{
	g_return_val_if_fail (GAME_IS_KNOB (self), 0.0);

	return self->value;
}

void
game_knob_set_value (GameKnob *self,
                     gdouble   value)
{
	g_return_if_fail (GAME_IS_KNOB (self));

	value = CLAMP (value, 0.0, 1.0);
	if (value == self->value)
		return;

	self->value = value;
	/* the display glides there; retargeting keeps its velocity */
	lrg_spring_set_target (&self->display, (gfloat) value);

	g_object_notify_by_pspec (G_OBJECT (self), properties[PROP_VALUE]);
	g_signal_emit (self, signals[SIGNAL_VALUE_CHANGED], 0);
}

gdouble
game_knob_get_step (GameKnob *self)
{
	g_return_val_if_fail (GAME_IS_KNOB (self), 0.0);

	return self->step;
}

void
game_knob_set_step (GameKnob *self,
                    gdouble   step)
{
	g_return_if_fail (GAME_IS_KNOB (self));
	g_return_if_fail (step > 0.0);

	if (step == self->step)
		return;
	self->step = step;
	g_object_notify_by_pspec (G_OBJECT (self), properties[PROP_STEP]);
}

void
game_knob_set_default_value (GameKnob *self,
                             gdouble   value)
{
	g_return_if_fail (GAME_IS_KNOB (self));

	self->default_value = CLAMP (value, 0.0, 1.0);
}

Nothing in the code above deals with any of these, yet the knob has them:

- *Hover and press animation*: the body lightens and lifts, the value arc thickens and the dot grows, all blended by springs with the theme's motion (bouncy in the Catppuccin presets, instant in high-contrast).
- *Focus*: clicking focuses it; Tab and the gamepad D-pad reach it; a round focus ring appears only for keyboard / gamepad focus.
- *Pointer capture*: the drag keeps working when the pointer leaves the knob.
- *Theming*: every colour and size comes from the theme, so all five presets and any user theme work, and theme files can restyle each part.
- *Disabled state*: =lrg_widget_set_enabled (knob, FALSE)= fades it to 45 %, greys the arc, and blocks input and focus.
- *Appear animations, opacity, clipping and batching*: =lrg_widget_set_appear (knob, LRG_APPEAR_POP, 0.1f)= just works; the whole knob is a few dozen instances in the same draw call as the rest of the UI.

*** Styling it from YAML
:PROPERTIES:
:CUSTOM_ID: extending-knob-yaml
:END:
Because the knob names its parts, a theme file can restyle it without touching code. Type names match by name, so these rules can live in the theme before =GAME_TYPE_KNOB= is registered:

#+begin_src yaml
styles:
  # every knob: thicker arcs
  - widget: GameKnob
    part: track
    size: 6
  - widget: GameKnob
    part: fill
    size: 6

  # the volume knob: gradient body and a glowing green value arc
  - widget: GameKnob
    class: volume
    part: knob
    gradient:
      kind: radial
      center-x: 0.35
      center-y: 0.3
      start: '#3a3a44'
      end: '#18181d'
  - widget: GameKnob
    class: volume
    part: fill
    foreground: '#34d399'

  # while dragging (pressed), glow the body
  - widget: GameKnob
    class: volume
    part: knob
    state: pressed
    glow: '#34d39966'
    glow-size: 14
#+end_src

Specificity resolves the overlaps: the class rules (3, or 5 with the state) beat the type-only rules (1).

** Custom containers
:PROPERTIES:
:CUSTOM_ID: extending-containers
:END:
Derive from =LrgContainer=, implement =measure= and =layout_children= (placing children with =lrg_widget_place_in_slot()=), and optionally =paint= a background before chaining up to paint the children. A complete wrapping flow box is in [[file:../modules/ui/layout.org::#layout-custom-container][layout: writing a custom container]]. If you override =handle_event=, ignore bubbling events for children (see [[file:ui-migration.org::#migration-no-rebroadcast][the migration guide]]).

#+begin_src c
static void
game_card_paint (LrgWidget    *widget,
                 LrgPaintList *list)
{
	LrgPartLook box;

	/* our own surface first ... */
	lrg_widget_resolve_look (widget, LRG_UI_PART_BOX, &box);
	lrg_widget_paint_box (widget, list, &box,
	                      lrg_widget_get_world_x (widget), lrg_widget_get_world_y (widget),
	                      lrg_widget_get_width (widget), lrg_widget_get_height (widget));

	/* ... then the children, clipped to the card */
	lrg_paint_list_push_clip (list, lrg_widget_get_world_x (widget), lrg_widget_get_world_y (widget),
	                          lrg_widget_get_width (widget), lrg_widget_get_height (widget));
	LRG_WIDGET_CLASS (game_card_parent_class)->paint (widget, list);
	lrg_paint_list_pop_clip (list);
}
#+end_src

*A widget outside the clip is not painted.*  =lrg_widget_paint()= skips any widget lying wholly outside the current clip by more than 64 px, so a scroll box records only what can reach its viewport.  Keep ink within that distance of your bounds: a widget that draws far outside its own allocation (a callout, a connector line to a distant point) should be sized to cover what it draws, or it disappears when its bounds scroll out of view.  Widgets still gliding or appearing are never culled.

** Best practices
:PROPERTIES:
:CUSTOM_ID: extending-best-practices
:END:
- Fill *complete* looks for every state in =style_defaults()=; test =PRESSED= before =HOVERED=; chain up for =FOCUS= and unknown parts.
- Keep =style_defaults()= and =measure()= pure and cheap: they run several times per frame.
- Measure and paint text with the same font, size and spacing.
- Use =size= in a part look for part-specific dimensions so themes can change them.
- Use =CHECKED=, =SELECTED= and =OPEN= state flags for toggled visuals (=lrg_widget_set_state_flags()=), so rules can target them.
- Step springs you own exactly once per frame (from =paint()= with monotonic time, as above).
- Check your widget in all presets (=lrg_theme_list_presets()=) and with =lrg_motion_set_reduced (TRUE)=.
- Prefer =paint= over =lrg_paint_list_callback()=; callbacks break batches and are not animated.
