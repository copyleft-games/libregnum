* Shapes System
:PROPERTIES:
:CUSTOM_ID: shapes-system
:END:
The shapes system provides a set of drawable primitive shapes that wrap graylib's drawing functions. All shapes implement the =LrgDrawable= interface and can be rendered directly.

** Architecture
:PROPERTIES:
:CUSTOM_ID: architecture
:END:

    +-- LrgShape3D (abstract, world-space)

The built-in 3D shapes draw with =lrg_shape3d_get_render_transform()= (caller-allocated outputs, any may be =NULL=): position and scale blend linearly, each Euler angle along its shorter arc. The setters now write the shape's vectors in place, so the pointer returned by =lrg_shape3d_get_position()= (and the rotation/scale getters) stays valid across sets.

*** Shape batches
:PROPERTIES:
:CUSTOM_ID: shape-batches
:END:
Drawn one by one, every solid sphere, cylinder and cone is one =DrawMesh()= (a shared cached mesh, see [[file:../performance.org::#render3d-pass][the 3D render pass]]) and every cube goes through rlgl's immediate batch, which transforms its 36 corners on the CPU. A *shape batch* draws them in a few instanced calls instead:

#+begin_src C
void     lrg_shape3d_begin_batch (void);  /* nests */
void     lrg_shape3d_end_batch   (void);  /* the outermost end draws the queue */
void     lrg_shape3d_flush_batch (void);  /* draw the queue now, stay open */
gboolean lrg_shape3d_is_batching (void);  /* inside a batch that queues */
#+end_src

#+begin_src C
BeginMode3D (camera);
lrg_shape3d_begin_batch ();
for (i = 0; i < crates->len; i++)
    lrg_drawable_draw (g_ptr_array_index (crates, i), delta);
lrg_shape3d_end_batch ();       /* one instanced draw per shared mesh */
EndMode3D ();
#+end_src

Between the two calls an opaque (alpha 255) solid =LrgCube3D=, =LrgSphere3D=, =LrgCylinder3D= or =LrgCone3D= is not drawn on the spot: its model-view-projection (the very product =DrawMesh()= would send, taken from the rlgl matrices of that draw, so the camera may change inside a batch) and its colour join its mesh's instance list. The end draws each list with one =glDrawElementsInstanced()= through a small program that computes what raylib's default shader computes for these untextured meshes (position times the matrix; the colour as is, not interpolated). All unit cubes share one mesh (a cube's size is part of its matrix); spheres share one per rings and slices, cylinders and cones one per radii, height and sides.

Rules:
- *Order.* The queue is drawn after everything else drawn inside the batch and grouped by mesh. That is invisible while the depth test decides what is in front, so batch opaque shapes in a 3D mode with the depth test on, and keep the render target, viewport and depth/blend state the batch began with (call =lrg_shape3d_flush_batch()= before changing them). Coplanar overlapping shapes (exactly equal depth) may resolve the other way round.
- *Translucency.* Translucent shapes (any =LrgShape= whose colour has alpha below 255) are not queued and first flush the queue, so they blend over everything drawn before them, as without a batch. Something translucent that is not a shape (a billboard, a particle system) needs a =lrg_shape3d_flush_batch()= before it.
- *Wireframes* and the other shapes draw immediately, as without a batch.
- *Fallback.* Without a graphics context with GLSL 330, or in stereo rendering, nothing queues and the shapes draw one by one. The batch's program is built by the first =lrg_shape3d_begin_batch()= in a context.
- *Lifetime.* A shape freed while the batch holds its draw is fine: the queue keeps its mesh until it has drawn it.

=tests/test-shape-batch.c= renders a grid of rotated, scaled shapes of every kind one by one and batched into render textures and compares them: the spheres, cylinders and cones must match pixel for pixel (the instanced draw uses =DrawMesh()='s own matrix product), the cubes within a few edge pixels (one by one their corners are transformed on the CPU, batched on the GPU; under llvmpipe they match exactly too), and the scene with a translucent sphere over the batch exactly; and it frees a shape while its draw is queued. =lrg-bench= =shapes3d-batched= and =shapes-round-batched= measure it.

** Usage with LrgDrawable
:PROPERTIES:
:CUSTOM_ID: usage-with-lrgdrawable
:END:
All shapes implement =LrgDrawable=, so they can be drawn using the standard interface:

#+begin_src C
void
draw_scene (gfloat delta)
{
    g_autoptr(LrgSphere3D) player = lrg_sphere3d_new_full (
        player_x, player_y, player_z, 0.4f, player_color
    );

    g_autoptr(LrgLine3D) direction = lrg_line3d_new_full (
        player_x, player_y, player_z,
        player_x + dir_x * 0.6f, player_y, player_z + dir_z * 0.6f,
        grl_color_green ()
    );

    g_autoptr(LrgText2D) score = lrg_text2d_new_full (
        10.0f, 10.0f, "Score: 0", 20.0f, grl_color_white ()
    );

    /* Draw all shapes */
    lrg_drawable_draw (LRG_DRAWABLE (player), delta);
    lrg_drawable_draw (LRG_DRAWABLE (direction), delta);
    lrg_drawable_draw (LRG_DRAWABLE (score), delta);
}
#+end_src

** Creating Custom Shapes
:PROPERTIES:
:CUSTOM_ID: creating-custom-shapes
:END:
To create a custom shape, subclass =LrgShape2D= or =LrgShape3D= and implement the =draw= virtual method:

#+begin_src C
struct _MyCustomShape
{
    LrgShape3D parent_instance;
    /* custom properties */
};

G_DEFINE_FINAL_TYPE (MyCustomShape, my_custom_shape, LRG_TYPE_SHAPE3D)

static void
my_custom_shape_draw (LrgShape *shape, gfloat delta)
{
    MyCustomShape *self = MY_CUSTOM_SHAPE (shape);
    GrlVector3 *pos = lrg_shape3d_get_position (LRG_SHAPE3D (self));
    GrlColor *color = lrg_shape_get_color (shape);

    /* Custom drawing code using graylib functions */
    grl_draw_my_primitive (pos, color);
}

static void
my_custom_shape_class_init (MyCustomShapeClass *klass)
{
    LrgShapeClass *shape_class = LRG_SHAPE_CLASS (klass);
    shape_class->draw = my_custom_shape_draw;
}
#+end_src

** Best Practices
:PROPERTIES:
:CUSTOM_ID: best-practices
:END:
1. *Use autoptr for automatic cleanup:*

   #+begin_src C
   g_autoptr(LrgSphere3D) sphere = lrg_sphere3d_new ();
   #+end_src

2. *Reuse shapes when possible* - Creating shapes has overhead. For static geometry, create once and reuse.

3. *Use wireframe mode for debugging:*

   #+begin_src C
   lrg_shape3d_set_wireframe (LRG_SHAPE3D (shape), TRUE);
   #+end_src

4. *z-index for 2D layering* - Higher z-index renders on top:

   #+begin_src C
   lrg_shape_set_z_index (LRG_SHAPE (background), 0);
   lrg_shape_set_z_index (LRG_SHAPE (foreground), 10);
   #+end_src

5. *visibility toggle* - Hide shapes without destroying them:

   #+begin_src C
   lrg_shape_set_visible (LRG_SHAPE (shape), FALSE);
   #+end_src
