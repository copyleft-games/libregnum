* .rlevel YAML Format Reference
:PROPERTIES:
:CUSTOM_ID: rlevel-yaml-format-reference
:END:
This document describes the YAML format used by =LrgLevelSerializer= for =.rlevel=
authoring documents. The =.rprefab= format is identical except that the top-level
=type= is =prefab= and only one root node is serialized.

** Format Overview
:PROPERTIES:
:CUSTOM_ID: format-overview
:END:
#+begin_src yaml
type: level
name: "my_level"
default_view: 3d   # or "2d"
nodes:
  - name: "floor"
    guid: "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
    is_2d: false
    visible: true
    locked: false
    transform:
      location: [0.0, 0.0, 0.0]
      rotation: [0.0, 0.0, 0.0]
      scale:    [1.0, 1.0, 1.0]
    visual:
      kind: primitive
      primitive: primitive_cube
      material:
        color: [0.8, 0.8, 0.8, 1.0]
        roughness: 0.5
        metallic: 0.0
    components:
      - type: "health"
        props:
          max_hp: 100
    scripts:
      - language: lua
        script: "scripts/floor.lua"
        enabled: true
    children: []
#+end_src

** Top-Level Fields
:PROPERTIES:
:CUSTOM_ID: top-level-fields
:END:
| Field | Type | Required | Description |
|-------+------+----------+-------------|
| =type= | string | Yes | Always ="level"= |
| =name= | string | No | Level display name |
| =default_view= | string | Yes | ="3d"= or ="2d"= (controls IDE viewport hint) |
| =nodes= | sequence | Yes | Root-level node sequence (children of the implicit root) |
| =timelines= | sequence | No | Keyframed animation clips (see [[#timelines][Timelines]]); omitted when the level has none |

** Node Fields
:PROPERTIES:
:CUSTOM_ID: node-fields
:END:
Each element in a =nodes:= or =children:= sequence has the following structure.

*** Identity and Flags
:PROPERTIES:
:CUSTOM_ID: identity-and-flags
:END:
| Field | Type | Default | Description |
|-------+------+---------+-------------|
| =name= | string | — | Human-readable node name |
| =guid= | string | — | Stable UUID (auto-generated on creation) |
| =is_2d= | bool | =false= | 2D viewport/gizmo hint |
| =visible= | bool | =true= | Visibility in editor viewport |
| =locked= | bool | =false= | Locked against editing |

*** Transform
:PROPERTIES:
:CUSTOM_ID: transform
:END:
#+begin_src yaml
transform:
  location: [x, y, z]  # float, default [0,0,0]
  rotation: [rx, ry, rz]  # Euler radians, default [0,0,0]
  scale:    [sx, sy, sz]  # default [1,1,1]
#+end_src

All three sub-keys are optional and default to identity values if omitted.

*** Visual Payload
:PROPERTIES:
:CUSTOM_ID: visual-payload
:END:
The =visual:= mapping is optional. If absent the node is a group node with no
visual representation.

#+begin_src yaml
visual:
  kind: primitive          # see LrgNodeVisualKind nick values below
  primitive: primitive_cube  # for kind=primitive; LrgPrimitiveType nick
  asset: "models/door.glb"   # for asset-backed kinds (path or guid)
  material:
    color: [r, g, b, a]    # floats 0.0–1.0, default [0.8,0.8,0.8,1.0]
    roughness: 0.5         # float 0.0–1.0
    metallic: 0.0          # float 0.0–1.0
  params:                  # typed parameter bag; keys are kind-specific
    intensity: 2.5
    fov: 60.0
    segments: 32
  tilemap:                 # kind=tilemap only, optional: the painted grid
    width: 16              # cells (1..4096)
    height: 8
    tile_width: 16         # tileset slicing in pixels
    tile_height: 16
    layers:                # bottom first
      - name: base
        visible: true
        rows:              # one string per row, space-separated tile ids
          - "1 1 2 0 ..."  # 0 = empty, N = tileset tile N-1
#+end_src

For =tilemap= nodes, =asset= is the tileset image and =params.tile_size= the world size of one cell. Rows are padded/truncated to =width= on load. See [[file:editor-tools.org::#tilemap-painting][Tilemap painting]].

*** Components
:PROPERTIES:
:CUSTOM_ID: components
:END:
#+begin_src yaml
components:
  - type: "health"          # registry type name (string)
    props:
      max_hp: 100           # typed values; ints round-trip as int64
      regen_rate: 0.5
      invincible: false
      tag: "player"
  - type: "collider"
    props:
      shape: "box"
      width: 2.0
      height: 1.0
#+end_src

=props= is a mapping of property names to values. Integer values are preserved as
=int64= typed YAML scalars; floating-point values are stored as floats. The
serializer uses a heuristic: a YAML scalar without a decimal point is read back
as =int64=.

*** Scripts
:PROPERTIES:
:CUSTOM_ID: scripts
:END:
#+begin_src yaml
scripts:
  - language: lua       # see LrgScriptLanguage nick values below
    script: "scripts/patrol.lua"
    enabled: true
  - language: python
    script: "scripts/hud.py"
    enabled: false
#+end_src

**** =language= values (=LrgScriptLanguage= enum nicks)
:PROPERTIES:
:CUSTOM_ID: language-values
:END:
| YAML string | Enum |
|-------------+------|
| =none= | =LRG_SCRIPT_LANGUAGE_NONE= |
| =lua= | =LRG_SCRIPT_LANGUAGE_LUA= |
| =python= | =LRG_SCRIPT_LANGUAGE_PYTHON= |
| =gjs= | =LRG_SCRIPT_LANGUAGE_GJS= |
| =crispy= | =LRG_SCRIPT_LANGUAGE_CRISPY= |

*** Children
:PROPERTIES:
:CUSTOM_ID: children
:END:
#+begin_src yaml
children:
  - name: "leg_left"
    guid: "..."
    # ... same structure as a root node ...
    children: []
#+end_src

=children:= is a recursive sequence of node mappings using the same schema. If a
node has no children the key may be omitted entirely or set to an empty sequence.

*** Prefab Link Block
:PROPERTIES:
:CUSTOM_ID: prefab-link-block
:END:
Since 0.8.1 the root of a linked prefab instance (see [[file:prefabs.org::#linked-instances][Linked Instances]]) carries an optional =prefab:= mapping. The node and its whole subtree are still written out in full, exactly as before; the block only adds editor metadata that ties the expanded copy back to its source. The runtime (=lrg_level_instantiate()=, =lrg_level_to_scene()=) never reads it, and readers older than 0.8.1 ignore it.

#+begin_src yaml
- name: "Crate2"
  guid: "4a1e0c55-2d0b-4f3b-9f71-0c7f61c9a0d2"
  # ... transform, visual, components, scripts as usual ...
  prefab:
    source: "assets/prefabs/crate.rprefab"
    guid: "b0c4f3c2-8a52-4d1e-a3a1-6b2f4f7d9e10"   # asset guid, omitted when unknown
    map:
      4a1e0c55-2d0b-4f3b-9f71-0c7f61c9a0d2: 0f6f3a52-71a4-4c4e-8d2a-9a1c55c1e7b3
      8e2a3c4d-1f0b-5a6c-9d7e-112233445566: 5c0ffee0-1234-4abc-8def-001122334455
    overrides:
      - "transform/scale"
      - "components/health/max"
      - "8e2a3c4d-1f0b-5a6c-9d7e-112233445566:visible"
      - "children/+77d0a3b1-9c2e-4b51-a0f4-3e5d6c7b8a90"
  children:
    - name: "Lid"
      guid: "8e2a3c4d-1f0b-5a6c-9d7e-112233445566"
      # ...
#+end_src

| Field | Type | Required | Description |
|-------+------+----------+-------------|
| =source= | string | Yes | Path of the source =.rprefab=, as given to the editor; a block without it is ignored |
| =guid= | string | No | Asset guid of the source (from its =.meta= sidecar); resolution falls back to =source= when absent |
| =map= | mapping | Yes | Instance node guid to source node guid, for every node of the instance that mirrors a source node (the root included); nodes added in the instance are not listed |
| =overrides= | sequence | No | Override keys, sorted; omitted when empty |

An override key is a property path relative to one node of the instance. A bare path (=visible=, =transform/scale=) addresses the instance root; any other node is addressed as =<instance-node-guid>:<path>=. The path grammar is described in [[file:prefabs.org::#override-paths][Override Paths]].

Nested instances (a prefab instance stored inside a prefab) carry the same block on their own root, in both =.rprefab= and =.rlevel= files. Inside a =.rprefab= the outermost node never carries a block: prefab variants are not supported, so =lrg_prefab_save()= drops it and =lrg_prefab_load()= ignores it.

A 0.8.0 file has no block; its instances load unlinked and keep their 0.8.0 marker (a =prefab:source= visual param, or a =prefab-instance= visual whose =asset= is the source), which the editor's Relink action uses.

      location: [2.0, 1.5, 0.0]
      rotation: [0.0, 0.0, 0.0]

      - name: "flame_light"
        guid: "33333333-0000-0000-0000-000000000001"

** Timelines
:PROPERTIES:
:CUSTOM_ID: timelines
:END:
Optional, additive (older readers ignore it). Each entry is an =LrgTimeline=; tracks address nodes by GUID and a channel name (=location.x|y|z=, =rotation.x|y|z= in radians, =scale.x|y|z=, =color.r|g|b|a=, =roughness=, =metallic=, =param.NAME=). =easing= is an =LrgEasingType= nick applied from that key to the next; it is omitted for =linear=. See [[file:editor-tools.org::#animation-timeline][Animation timeline]].

#+begin_src yaml
timelines:
  - name: Door
    length: 1.5           # seconds
    loop: false
    autoplay: true        # plays during play-in-editor
    tracks:
      - node: 9b6e2d0c-0f3c-4a7e-8e0a-5f1d2c3b4a59
        channel: rotation.y
        keys:
          - time: 0.0
            value: 0.0
            easing: ease-in-out-sine
          - time: 1.5
            value: 1.5708
#+end_src

** Notes
:PROPERTIES:
:CUSTOM_ID: notes
:END:
- The =guid= field should be a UUID string; the serializer does not validate
  format, but the editor generates RFC 4122 UUIDs.
- Float values use standard YAML floating-point scalars.
- Integer prop values in the =props= or =params= bags round-trip as =int64= (YAML
  plain integers without decimal point).
- The =.rprefab= format reuses this schema with =type: prefab= and a single root
  node mapping. Since 0.8.1 =lrg_prefab_save()= writes node guids unchanged (they
  used to be regenerated on every save), because linked instances map onto them.
- Comments in YAML are supported when reading but are not preserved on write.
