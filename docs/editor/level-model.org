* Level Model
:PROPERTIES:
:CUSTOM_ID: level-model
:END:
This document covers the three authoring types that form the editor document:
=LrgLevel=, =LrgNode=, and =LrgNodeVisual=, plus the supporting record types
=LrgComponentDesc= and =LrgScriptBinding=.

#+begin_quote
*[[file:../index.org][Home]]* > *[[file:overview.org][Editor Module]]* > Level Model

#+end_quote

** LrgLevel
:PROPERTIES:
:CUSTOM_ID: lrglevel
:END:
=LrgLevel= is a final GObject. It owns the entire authoring document: a name, a
default view preference (2D or 3D), and a root =LrgNode= whose descendants form the
editable scene tree. The root node itself is not serialized; only its children are
written to and read from the =.rlevel= file.

*** Construction and Properties
:PROPERTIES:
:CUSTOM_ID: construction-and-properties
:END:
#+begin_src C
/* Create a new, empty level */
g_autoptr(LrgLevel) level = lrg_level_new ("overworld");

lrg_level_set_name (level, "Overworld");
lrg_level_set_default_2d (level, FALSE);   /* default: 3D view */

/* The root node is always present */
LrgNode *root = lrg_level_get_root (level);  /* (transfer none) */
#+end_src

*** Node Management
:PROPERTIES:
:CUSTOM_ID: node-management
:END:
All structural mutations are performed through =LrgLevel=, not through the nodes
directly, so the level can emit the appropriate signal.

#+begin_src C
g_autoptr(LrgNode) node = lrg_node_new ("floor");

/* Add under root (parent = NULL) */
lrg_level_add_node (level, node, NULL);

/* Add under an existing node */
lrg_level_add_node (level, child_node, node);

/* Remove */
lrg_level_remove_node (level, node);

/* Find by guid anywhere in the tree */
LrgNode *found = lrg_level_find_node (level, guid);  /* (transfer none) */

/* Notify the host IDE that a node's properties changed */
lrg_level_notify_node_changed (level, node);
#+end_src

*** Signals
:PROPERTIES:
:CUSTOM_ID: signals
:END:
| Signal | When emitted | Detail argument |
|--------+-------------+-----------------|
| =node-added= | after a node is inserted | the added =LrgNode= |
| =node-removed= | after a node is detached | the removed =LrgNode= |
| =node-changed= | when a node's data changes | the changed =LrgNode= |

** LrgNode
:PROPERTIES:
:CUSTOM_ID: lrgnode
:END:
=LrgNode= is a derivable GObject. It is the single unifier of 2D and 3D authoring:
the transform is always 3D; 2D nodes live at Z=0 with =is-2d= set as a viewport
hint. Custom node kinds can subclass =LrgNode= and override the =instantiate= vfunc
to build a custom runtime representation.

*** Identity
:PROPERTIES:
:CUSTOM_ID: identity
:END:
Every node has a human-readable name and a stable, globally unique =guid= that
persists across save/load cycles. The guid is auto-generated on =lrg_node_new()=
and should not be changed except when loading from serialized data.

#+begin_src C
LrgNode *node = lrg_node_new ("torch");

const gchar *name = lrg_node_get_name (node);
const gchar *guid = lrg_node_get_guid (node);   /* e.g. "a1b2c3d4-..." */

lrg_node_set_name (node, "wall_torch");
/* lrg_node_set_guid() is only needed when loading from a .rlevel file */
#+end_src

*** Flags
:PROPERTIES:
:CUSTOM_ID: flags
:END:
| Property | Default | Description |
|----------+---------+-------------|
| =visible= | =TRUE= | node is rendered in the editor viewport |
| =locked= | =FALSE= | node cannot be selected or mutated in the editor |
| =is-2d= | =FALSE= | viewport gizmo and camera hint: treat as 2D |

#+begin_src C
lrg_node_set_visible (node, TRUE);
lrg_node_set_locked (node, FALSE);
lrg_node_set_is_2d (node, FALSE);
#+end_src

*** Transform
:PROPERTIES:
:CUSTOM_ID: transform
:END:
The local TRS transform uses =GrlVector3= boxed types (from graylib). Getters
return borrowed references (=transfer none=); do not free them.

#+begin_src C
/* Set location / rotation / scale */
lrg_node_set_location_xyz (node, 0.0f, 1.0f, 0.0f);
lrg_node_set_rotation_xyz (node, 0.0f, 0.0f, 1.5708f);  /* 90 degrees */
lrg_node_set_scale_xyz    (node, 1.0f, 1.0f, 1.0f);

/* Read back (transfer none — do NOT free) */
GrlVector3 *loc = lrg_node_get_location (node);
GrlVector3 *rot = lrg_node_get_rotation (node);
GrlVector3 *scl = lrg_node_get_scale    (node);
#+end_src

*** Parent / Children
:PROPERTIES:
:CUSTOM_ID: parent-children
:END:
The child list is ordered; =lrg_node_add_child()= appends.

#+begin_src C
lrg_node_add_child (parent, child);    /* takes a ref on child */
lrg_node_remove_child (parent, child); /* returns TRUE if found */

GPtrArray  *children = lrg_node_get_children (parent);  /* (transfer none) */
guint       n        = lrg_node_get_n_children (parent);
LrgNode    *par      = lrg_node_get_parent (child);      /* (transfer none) */

/* Recursive search by guid */
LrgNode *found = lrg_node_find_by_guid (root, guid);
#+end_src

*** Visual Payload
:PROPERTIES:
:CUSTOM_ID: visual-payload
:END:
A node optionally carries a single =LrgNodeVisual= describing how it looks.
Setting it to =NULL= makes the node a pure group node.

#+begin_src C
g_autoptr(LrgNodeVisual) vis = lrg_node_visual_new (LRG_NODE_VISUAL_PRIMITIVE);
/* configure the visual (see LrgNodeVisual section below) */
lrg_node_set_visual (node, vis);

LrgNodeVisual *v = lrg_node_get_visual (node);  /* (transfer none) */
#+end_src

*** Components and Scripts
:PROPERTIES:
:CUSTOM_ID: components-and-scripts
:END:
Components and scripts are stored as ordered lists of description records. They
are materialized into live =LrgComponent= and =LrgScriptComponent= objects during
=lrg_level_instantiate()=.

#+begin_src C
/* Attach a component description */
g_autoptr(LrgComponentDesc) desc = lrg_component_desc_new ("health");
lrg_component_desc_set_int (desc, "max_hp", 100);
lrg_node_add_component (node, desc);

/* Attach a script binding */
g_autoptr(LrgScriptBinding) bind = lrg_script_binding_new (
    LRG_SCRIPT_LANGUAGE_LUA, "scripts/enemy.lua");
lrg_node_add_script (node, bind);

/* Access the ordered arrays */
GPtrArray *comps   = lrg_node_get_components (node);  /* (transfer none) */
GPtrArray *scripts = lrg_node_get_scripts (node);     /* (transfer none) */
#+end_src

*** Prefab Link
:PROPERTIES:
:CUSTOM_ID: prefab-link
:END:
Since 0.8.1 the root of a linked prefab instance holds an =LrgPrefabLink= in its =prefab-link= property (=lrg_node_get_prefab_link()= / =lrg_node_set_prefab_link()=). The link stores the source =.rprefab= path and asset guid, a map from every mirrored instance node guid to its source node guid, and the instance's override keys. Nested instances inside an instance carry their own link on their own root. The link is identity metadata, like the guid: =lrg_node_copy_state()= and =lrg_node_state_equal()= ignore it, so snapshot undo of ordinary edits never touches it.

Any node of an instance can answer which source node it mirrors with =lrg_node_get_prefab_source_guid()=. The value is looked up in the map of the owning instance root (=lrg_prefab_find_owner()=), so it never goes stale; it is =NULL= for nodes outside instances and for nodes added in the instance.

#+begin_src C
LrgNode       *owner = lrg_prefab_find_owner (node);         /* instance root, or NULL */
LrgPrefabLink *link  = owner ? lrg_node_get_prefab_link (owner) : NULL;
const gchar   *src   = lrg_node_get_prefab_source_guid (node);

if (lrg_prefab_is_overridden (node, "transform/location"))
    g_print ("%s keeps its own location\n", lrg_node_get_name (node));
#+end_src

See [[file:prefabs.org][Prefabs]] for the full model and [[file:yaml-format.org::#prefab-link-block][Prefab Link Block]] for the file format.

*** Instantiate Vfunc
:PROPERTIES:
:CUSTOM_ID: instantiate-vfunc
:END:
=lrg_node_instantiate()= is called by =lrg_level_instantiate()= for each node. The
default implementation applies component descriptions to the game object. To add
custom runtime behaviour, subclass =LrgNode= and override =LrgNodeClass::instantiate=:

#+begin_src C
static void
my_node_instantiate (LrgNode       *self,
                     LrgGameObject *object)
{
    /* Chain up: applies component descriptions */
    LRG_NODE_CLASS (my_node_parent_class)->instantiate (self, object);

    /* Add custom components or configure the game object */
}
#+end_src

** LrgNodeVisual
:PROPERTIES:
:CUSTOM_ID: lrgnodevisual
:END:
=LrgNodeVisual= is a final GObject carrying the visual/content payload for a node.
Its kind (=LrgNodeVisualKind=) determines which fields are meaningful.

*** Kinds
:PROPERTIES:
:CUSTOM_ID: kinds
:END:
| Kind | Description | Key fields |
|------+-------------+------------|
| =LRG_NODE_VISUAL_NONE= | Group / empty node | — |
| =LRG_NODE_VISUAL_PRIMITIVE= | Built-in geometry | =primitive=, =material=, =params= |
| =LRG_NODE_VISUAL_MESH_ASSET= | External mesh (gltf/obj) | =asset=, =material= |
| =LRG_NODE_VISUAL_SPRITE= | 2D texture sprite | =asset=, params |
| =LRG_NODE_VISUAL_TILEMAP= | 2D tilemap | =asset= (tileset image), =tile_size= param, =LrgNodeTilemap= grid (=lrg_node_visual_get_tilemap()=; see [[file:editor-tools.org::#tilemap-model][Tilemap painting]]) |
| =LRG_NODE_VISUAL_LIGHT= | Light source | params (intensity, color, range) |
| =LRG_NODE_VISUAL_CAMERA= | Camera | params (fov, near, far) |
| =LRG_NODE_VISUAL_AUDIO_EMITTER= | Positional audio | =asset=, params (volume, radius) |
| =LRG_NODE_VISUAL_PREFAB_INSTANCE= | Saved prefab | =asset= (path to =.rprefab=) |

*** Construction and Common Operations
:PROPERTIES:
:CUSTOM_ID: construction-and-common-operations
:END:
#+begin_src C
g_autoptr(LrgNodeVisual) vis = lrg_node_visual_new (LRG_NODE_VISUAL_PRIMITIVE);

lrg_node_visual_set_kind (vis, LRG_NODE_VISUAL_PRIMITIVE);
lrg_node_visual_set_primitive (vis, LRG_PRIMITIVE_CUBE);

/* Material (used by PRIMITIVE and MESH_ASSET) */
g_autoptr(LrgMaterial3D) mat = lrg_material3d_new ();
lrg_material3d_set_color (mat, 0.8f, 0.2f, 0.1f, 1.0f);
lrg_material3d_set_roughness (mat, 0.5f);
lrg_material3d_set_metallic (mat, 0.0f);
lrg_node_visual_set_material (vis, mat);

/* Asset reference for asset-backed kinds */
lrg_node_visual_set_asset (vis, "models/door.glb");

/* Kind-specific parameters */
lrg_node_visual_set_param_double (vis, "intensity", 2.5);
gdouble intensity = lrg_node_visual_get_param_double (vis, "intensity", 1.0);

/* Generic typed parameter (GValue) */
GValue v = G_VALUE_INIT;
g_value_init (&v, G_TYPE_INT);
g_value_set_int (&v, 32);
lrg_node_visual_set_param (vis, "segments", &v);
g_value_unset (&v);

const GValue *stored = lrg_node_visual_get_param (vis, "segments");  /* (transfer none) */

/* Enumerate set parameters */
g_autoptr(GList) names = lrg_node_visual_get_param_names (vis);  /* (transfer container) */
#+end_src

Note: =lrg_node_visual_get_param_double()= coerces any numeric =GValue= type to
=gdouble=; use it when you do not know the exact type stored by the serializer.

** LrgComponentDesc
:PROPERTIES:
:CUSTOM_ID: lrgcomponentdesc
:END:
=LrgComponentDesc= is a serializable record of a component to instantiate: a
registry type name plus a bag of typed property values. It is data-only; no live
=LrgComponent= is held.

#+begin_src C
g_autoptr(LrgComponentDesc) desc = lrg_component_desc_new ("health");

/* Set properties by type */
lrg_component_desc_set_int     (desc, "max_hp",    100);
lrg_component_desc_set_double  (desc, "regen_rate", 0.5);
lrg_component_desc_set_string  (desc, "tag",       "player");
lrg_component_desc_set_boolean (desc, "invincible", FALSE);

/* Generic typed access */
GValue v = G_VALUE_INIT;
g_value_init (&v, G_TYPE_INT);
g_value_set_int (&v, 200);
lrg_component_desc_set_value (desc, "max_hp", &v);
g_value_unset (&v);

const GValue *cur = lrg_component_desc_get_value (desc, "max_hp");

/* Inspect */
gboolean has = lrg_component_desc_has (desc, "max_hp");
g_autoptr(GList) keys = lrg_component_desc_get_keys (desc);  /* (transfer container) */
const gchar *type_name = lrg_component_desc_get_type_name (desc);
#+end_src

** Node property source
:PROPERTIES:
:CUSTOM_ID: node-property-source
:END:
=LrgEditorNodeSource= (=src/editor/lrg-editor-node-source.h=, since 0.8.1) exposes one /section/ of one =LrgNode= as an =LrgPropertySource= (see [[file:../modules/ui/property-grid.org][Property grid]]), so the inspector can give an =LrgPropertyGrid= one source per selected node and get multi-edit, mixed values, hints and state markers for free. Every write goes through the =LrgEditor= undo stack, so it is undoable and marks prefab overrides automatically; a gesture (a drag in the grid) over N nodes is exactly one undo step, and a cancelled gesture (Escape) restores every node exactly.

What the inspector does, in one block:
#+begin_src C
/* Once, when the panel is built: route the grid's edits through the editor */
lrg_editor_node_source_connect_grid (transform_grid, editor);

/* On every selection change: one source per selected node */
GPtrArray           *nodes = lrg_editor_selection_get_nodes (lrg_editor_get_selection (editor));
g_autoptr(GPtrArray) sources = lrg_editor_node_source_new_for_nodes (editor, nodes,
                                                                     LRG_EDITOR_NODE_SECTION_TRANSFORM, NULL);
lrg_property_grid_set_sources (transform_grid, sources);
#+end_src

*** Sections
:PROPERTIES:
:CUSTOM_ID: node-property-source-sections
:END:
=LrgEditorNodeSection= picks what a source lists. Property names are valid =GParamSpec= names (the grid matches sources by name and type), labels are what the grid shows.

| Section     | Properties (name: type, hint)                                                                                         | Notes                                                                                   |
|-------------+-----------------------------------------------------------------------------------------------------------------------+-----------------------------------------------------------------------------------------|
| =HEADER=    | =name= string, =visible= bool, =locked= bool, =is-2d= bool, =path= and =guid= read-only strings                        | Flag edits on N nodes are one step                                                      |
| =TRANSFORM= | =location=, =rotation=, =scale= =GrlVector3= (=vector3=, scale =vector3:uniform=), =world= read-only =GrlVector3=     | Rotation is shown and written in degrees, stored in radians                             |
| =VISUAL=    | =kind= enum, =primitive= enum, =asset= string (=asset:model=, =asset:texture=, ...), material, parameters            | The list follows the kind; see below                                                    |
| =COMPONENT= | =component-type= read-only string, then the registered type's properties, then raw stored keys                        | One source per component; the constructor names it                                      |
| =SCRIPTS=   | per binding /i/: =script-i-enabled= bool, =script-i-language= enum, =script-i-path= string (=asset:script=)           | Grouped per script                                                                      |

The visual section lists =primitive= only for primitives and =asset= only for asset-backed kinds (mesh, sprite, tilemap, prefab instance, CAD part, audio emitter). Drawable kinds and lights get a /Material/ group: =color= (=GrlColor=, hint =color=; "Light color" for lights) and, except for lights, =roughness=, =metallic= and =emission= (doubles with range hints). The /Parameters/ group lists every key of the visual's param bag plus the usual keys of the kind even when unset (light =intensity=, =range=, =spot_angle=; camera =fov=, =near=, =far=; audio =volume=, =radius=; sprite =frame=, =pixels_per_unit=; tilemap =tile_size=), each with a range or angle hint and its usual default. A key becomes the property =param-<key>= with every character outside =[A-Za-z0-9]= turned into =-= (=cad:thickness= is =param-cad-thickness=); the label keeps the original key. Keys starting with =prefab:= are internal markers and stay hidden.

The component section is named by type: =lrg_editor_node_source_new (editor, node, LRG_EDITOR_NODE_SECTION_COMPONENT, "Health")=, and ="Health#2"= for the second component of that type (the same convention as prefab override paths). The type is looked up in the default engine's =LrgRegistry=, then by =GType= name. Its properties are those the 0.8.0 inspector showed: writable, not construct-only, not object-typed, not declared by =GObject= itself, with the class's own =GParamSpec= (so ranges, enum and flags types, defaults, and =[hint:...]= blurbs or hint qdata all apply). Stored values are converted to the property's type on read: numbers by =GValue= transforms, strings (as a YAML load keeps them) by enum and flags nicks, integers onto enums and flags. Writes store the property's own type. Stored keys the type does not declare, and every key of an unregistered type, are listed as raw values of their stored type.

*** Values and undo
:PROPERTIES:
:CUSTOM_ID: node-property-source-undo
:END:
=lrg_property_source_get_value()= reads the node every time. =lrg_property_source_set_value()= converts the value to the property's type (validating it against the =GParamSpec=, so ranges clamp), writes it into the node in place and records the difference with =lrg_editor_commit_node_state()= as one =NODE_STATE= command labelled "Set <label>". Because every command passes through the editor's execute path, the paths it changes are marked as prefab overrides when the node belongs to a linked instance, and undo clears exactly those marks.

=lrg_property_source_reset()= stores the default: the pspec default for header flags and parameters, (0, 0, 0) for location and rotation, (1, 1, 1) for scale, white, 0.5, 0 and 0 for the material, the usual value of suggested parameters. For component properties reset removes the stored key, so the type's default applies again. Name, path, asset, primitive and raw keys have no default.

*** Gestures
:PROPERTIES:
:CUSTOM_ID: node-property-source-gestures
:END:
=lrg_editor_node_source_begin_gesture()= snapshots the node; until =lrg_editor_node_source_end_gesture()= every write is a /preview/: it changes the node in place, tells the level (=lrg_level_notify_node_changed()=) and emits =LrgEditor::changed= so views redraw, but records nothing. =end_gesture (self, TRUE, label)= then records the whole difference as one command; =end_gesture (self, FALSE, NULL)= copies the snapshot back (=lrg_node_copy_state()=) and records nothing. Gestures nest, only the outermost pair counts, and =lrg_editor_node_source_in_gesture()= tells whether one is open. Ending N gestures between =lrg_editor_begin_group()= and =lrg_editor_end_group()= makes an edit of N nodes one undo step:
#+begin_src C
lrg_editor_node_source_begin_gesture (a);
lrg_editor_node_source_begin_gesture (b);
lrg_property_source_set_value (LRG_PROPERTY_SOURCE (a), "locked", &value);   /* preview */
lrg_property_source_set_value (LRG_PROPERTY_SOURCE (b), "locked", &value);
lrg_editor_begin_group (editor, "Lock");
lrg_editor_node_source_end_gesture (a, TRUE, "Lock");
lrg_editor_node_source_end_gesture (b, TRUE, "Lock");
lrg_editor_end_group (editor);                                               /* one undo step */
#+end_src

*** Connecting a grid
:PROPERTIES:
:CUSTOM_ID: node-property-source-grid
:END:
=lrg_editor_node_source_connect_grid (grid, editor)= does the above for whatever sources the grid holds at the time of each edit. It switches the grid to =LRG_PROPERTY_APPLY_DELEGATE= and handles its signals:

| Grid signal       | What the link does                                                                                                                                       |
|-------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------|
| =edit-begin=      | Captures the grid's sources and begins a gesture on every =LrgEditorNodeSource=; remembers the current value of other sources                             |
| =edit-value=      | Writes =lrg_property_grid_get_value_for_source()= into every source (vectors keep each node's other axes), then notifies views once                       |
| =edit-end=        | Commit: ends every gesture inside one =lrg_editor_begin_group()=, so the drag is ONE undo step. Cancel (Escape): restores every node, records nothing    |
| =reset-requested= | One undo group: overridden prefab properties are reverted to the prefab's value, the rest reset to their default                                         |

Sources that are not node sources (an =LrgObjectPropertySource= over a live play-mode object) are written directly, not undoably, and restored on cancel. Previews of a batch are announced once per frame (one =LrgEditor::changed=), not once per node, so a drag over many nodes stays cheap. Connecting twice does nothing; =lrg_editor_node_source_disconnect_grid()= commits an open gesture and removes the handlers. =pick-requested= is left to the inspector (it opens the asset or node picker and writes the result with =lrg_property_grid_set_reference_value()=).

*** States
:PROPERTIES:
:CUSTOM_ID: node-property-source-states
:END:
=lrg_property_source_get_state()= combines:
- =DEFAULT= when the value equals the default described above.
- =OVERRIDDEN= when the node belongs to a linked prefab instance and the property's override path is covered by the instance's override set (=lrg_prefab_is_overridden()=). =lrg_editor_node_source_get_override_path()= gives the path (=transform/location=, =visual/params/intensity=, =components/Health/max-hp=, =components/+Health= for the type row, =scripts/<path>/enabled=, =scripts/+<path>= for the path row; see [[file:prefabs.org::#override-paths][Override Paths]]).
- =ANIMATED= when a timeline of the level has a track for one of the property's channels on this node: =location.x|y|z= for location (and likewise rotation and scale), =color.r|g|b|a= for the colour, =roughness=, =metallic=, =param.<key>= for parameters.
- =INVALID= for an asset or script path that names a file which does not exist, and for the type row of a component type the editor does not know. Paths are tried absolute, against =lrg_editor_node_source_set_asset_root()= (the project root) when set, otherwise against the level file's directory and the current directory. Values without a =/= or =.= (asset guids) are never invalid.

Per-row prefab actions: =lrg_editor_node_source_revert_override()= puts the prefab's value back (=lrg_editor_prefab_revert()=, one undo step) and =lrg_editor_node_source_apply_override()= writes the instance's value into the prefab and syncs the other instances (=lrg_editor_prefab_apply()=). Both act on the override key that covers the property, which may be a parent path (=visual= covers =visual/asset=), and fail with =G_IO_ERROR_NOT_FOUND= when nothing is overridden.

*** Change notification
:PROPERTIES:
:CUSTOM_ID: node-property-source-changes
:END:
A source follows =LrgEditor::changed=, =LrgEditor::level-replaced= and =LrgLevel::node-changed= (for its node) and emits =property-changed= coalesced: it re-reads the node and emits once per property whose value or state really changed since the last emission, and nothing for notifications without a change. When the property list itself changed (a visual kind change, a component key added, a script attached) it emits once with a =NULL= name, which makes the grid re-read the schema. =lrg_editor_node_source_refresh()= forces the check after mutating a node behind the editor's back.
