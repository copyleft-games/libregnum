* How the work was run (method)
:PROPERTIES:
:CUSTOM_ID: method
:END:
- Worktree =trees/v0.9.0= on =feat/v0.9.0=. The lead pre-creates stubs (=scratch/mkstub.sh=, =scratch/mktest.sh=) and registers them in =Makefile=, =src/libregnum.h=, =tests/Makefile= (see =scratch/reg-m8.py= for the pattern), commits them, then runs up to 8 parallel agents with disjoint file ownership. Shared rules for agents: [[file:scratch/brief.md][scratch/brief.md]]; UI tool patterns: [[file:scratch/brief-w4.md][scratch/brief-w4.md]].
- Builds are shared: every agent takes =flock= on a lock file before =make=.
- Agents never touch git; the lead commits each feature by staging only its files, adds registry rows (=src/core/lrg-registry.c= + =docs/modules/core/registry.org=; helper =scratch/reg-add.py ANCHOR name:get_type:Type[:include]=), applies shell patches (=lrg-editor-app.c=, =-window.c=) and index links.
- Cross-owner hooks: agents drop patches in =m8-patches/=, IPC lists in =m8-ipc/<AGENT>.md= (=FINAL= when done); PLUMB generates CLI/MCP/docs from the lists.
- Paths in the scratch files point at the old machine's =/tmp/claude-1000/.../scratchpad/v090/= (now =handoff/v0.9.0/scratch/=) and =/var/home/zach/source/projects/libregnum/trees/v0.9.0=: adjust when reusing them.
- Gate (every milestone): =make all= (GIR, 0 warnings), =make docs-check=, =make examples=, =tests/check-level-noeditor.sh=, =build-aux/xrun.sh make test=, =make test-editorctl=, =make test-emacs=, =make test-editor-x11= (all GPU/display work under =build-aux/xrun.sh=; never on the developer's session). Script: =scratch/gate.sh=. Tests need =G_TEST_SRCDIR=$PWD/tests= and =LD_LIBRARY_PATH=$PWD/build/release/lib:$PWD/deps/graylib/build/lib:$PWD/deps/yaml-glib/build=.
- Every milestone also: gap-analysis rows + ROADMAP line, skill updates (=skills/skill-libregnum/=) and =make install-skills=, screenshots at 1920x1080 dark + light looked at; send Zach screenshots after M10.
- Zach's constraints: no =dnf install= / =bootc usr-overlay= on the host (list Fedora packages instead); podman not docker; =gio trash= not =rm=; never force-push master/main; ask before =psql=; gnu89, tabs, =/* */= comments, GIR-clean, zero warnings; docs in org without hard wraps.
